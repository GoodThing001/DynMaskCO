OMEGA11 - ONE CONSERVATIVE REPLAY, SHARED WITH THE THERMAL GATE
  depart = max(anchor_time, clock); arrival = depart + travel;
  service_start = max(arrival, tw_start); service_finish = service_start + service_time;
  return_arrival = final_service_finish + travel_to_depot.
  A1  the tw_start wait is now applied, matching action_contract.certify_route:187. The
      counterexample now refuses, reporting the TRUE 21.0 instead of 2.0.
  A2/A2b an absent service time REFUSES (OMEGA11_TIME_INPUT_UNAVAILABLE); there is no zero
      default anywhere. A present key with value 0.0 is still accepted, so legitimate zero
      service times are not false rejects.
  A3  the process-global _SERVICE_TIME_CACHE and register_service_times are gone from the
      verdict path. Time inputs are per-instance objects. Falsifiable claim recorded:
      instance A with service 5.0 gives 7.0, instance B with 0.5 gives 2.5.
  A4/A4b a committed vehicle inherits its real in-flight leg and then CONTINUES through its
      later accepted tasks and the candidate suffix.
  A5  depart_used and depart_rule are written into the receipt and the basis string is
      generated from what was actually replayed, so the label can no longer describe a
      different rule than the code applies.
  A6  a closed vehicle is audited against caller-supplied TRUSTED HISTORY: absent history
      refuses, a breached history refuses, in-time history passes, and an empty live
      return_finish is NOT itself treated as a violation.
  Also added: anchor validation, and an independent cross-check against certify_route that
  refuses on disagreement.

OMEGA10 - COVERAGE COMPLETENESS (the B1 fix)
  The required set E = on-board fish UNION accepted unfinished fish commitments UNION the
  fish the CANDIDATE plan carries, and the verified set C is compared against it
  mechanically. Coverage incomplete, extra identities and identity conflicts all refuse. An
  empty E is still admissible but is reported as NO_FISH_IN_SCOPE, a DISTINCT verdict that
  cannot be mistaken for a positive fish verification. The default provider now enumerates
  candidate fish, so the recorded B1 false pass (empty manifest hiding an unverified
  candidate fish with initial_quality 1.0 against a contract value of 9.0) now REFUSES.
  B3 is discharged structurally: initial_quality_by_node and the arbitrary temp_class_of /
  quantity_of callables are replaced by an identity-carrying read-only provider that raises
  on any node outside its declared set and refuses an empty source identity.

## 3. 本轮修掉的四个缺陷（v1 → v2）

| # | 缺陷 | v1 行为 | v2 行为 |
|---|---|---|---|
| A | `normalized_input_identity` **哈希原始快照** ⇒ `action` 混入也能得到不同 ID | 无校验 | 严格 schema + **递归**禁止键 + 非 dict 拒绝，**fail-closed** |
| B | `plan_variants` 接受**自相矛盾**组合，且接受调用方自报 `commit_observed` | 静默通过 | 四种矛盾组合抛 `CommitEvidenceError`；新增 `NO_NEW_PLAN_ADOPTED`（被拒且已观测决策结果 ≠ 未观测） |
| C | `n_execution_errors` **混用事件级/决策级单位**；`add_fallback` 接受任意 `fallback_kind` | 混算 | 拆成独立存储/导出（`n_execution_errors_events` / `n_execution_errors_decisions`）；仅 `timeout_fallback` + `hard_deadline_exception=True` + 非空 `fallback_event_id` 计数；重复/缺失 `event_id` 与非法 kind 均有**独立反例** |
| D | `static_selfcheck` 对两个模块的 `expected=None` ⇒ **恒真** | 假通过 | 四模块**双身份**全表 + blob/工作树分别核验 + `no_none_expected=True` |

### 3.1 关于 v1 的既有记录

- v1 **逐字节保留**（SHA 见 §1），**不删除**；
- v1 中存在**恒真断言** `check('把 action 混进快照也不影响 ID', a == b or True)`
  ⇒ **v1 的 PASS 不构成证据**；
- 按裁定：「新版本通过之前，也不能继续引用旧测试作为相应缺陷已经解决的证据。」
  ⇒ 本件**只**引用 v2 的 60 项通过作为解决证据。

### 3.2 本轮附加的**非**判定性修正

使 Windows 默认 GBK 控制台下**默认命令**即可复现。
**这是输出编码修正，不改变任何断言语义**；已如实登记，避免日后被误读为"测试被放宽"。

### 4.1 复现环境陷阱（如实登记，**不是**代码缺陷）

Windows 默认 GBK 控制台下运行 `CC_Compare/tools/run_phasea_gates.py`，
G1 的 5 组会因**断言名含 `⇒`** 而抛 `UnicodeEncodeError`，从而**假报**仪器回归失败
（`unready_reasons` 首条）。正确复现命令：

```powershell
$env:PYTHONIOENCODING='utf-8'; $env:PYTHONUTF8='1'
python CC_Compare/tools/run_phasea_gates.py
```

加环境变量后：**G1 全部组通过**，唯一未满足项仍是既有的
**G4 决策点 digest `pending`** ⇒ `ready_for_L1_L2: false`（**与改动前一致，未回归**）。

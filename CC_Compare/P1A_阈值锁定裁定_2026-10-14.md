## 一、裁定内容

用户于 2026-10-14 正式锁定 P1-A 主档效果门阈值 **δ = 20**，**不再列为待定事项**。
主档判据（`P1A_强动态对照_预声明_2026-10-14.md` §0.1）**不变**：

```
Δ_d = J_d(Role C) − J_d(cond_hist + SAA)        d = 0..39（40 天，按 day_id 一一配对）

过门 ⟺  mean(Δ) ≥ 20   且   CI_95%,lo(Δ) > 0
```

* **统计单元 = 天**（日聚类），**不是**逐事件、不是逐订单。
* **配对键 = `day_id`**；两侧各 40 条、ID 恰为 `0..39`、唯一。
* **档位 = 主档 `p_c=(5,10,15)`**（`p_c=0` 与 `(10,20,30)` 只作敏感性，不作为主判据）。
* **CI 使用运行前固定的 bootstrap 规格**：2000 次重采样、分位点 2.5 / 97.5、种子跑前冻结；
  落盘 `mean/ci_lo/ci_hi` 必须能被独立复算**逐位**复现（容差 `1e-6`），否则**不算过门**。

## 二、锁定理由（**事实与推断分开**）

**事实**：方向 A（A3）的**预声明**与实现早已使用 `δ₃ = 20` ——
`A3在线比较预声明_2026-10-01.md`（转引）、`01_取货线/文档/结果与进度/A3在线比较正式裁决_2026-10-06.md`
L5–6 / L10（「δ₃=+20」）、`scripts/evaluation/run_a1_step3_compare.py:49` `DELTA_3 = 20.0`、
`:340/:343` 判定式 `mean>=delta_3 AND ci_lo>0`。

**推断（方法学理由）**：把该值**沿用**于 P1-A，可以**避免根据新算法的结果选择阈值** ——
阈值在 P1-A 之前就已存在，故不可能被 P1-A 的效用表现"调"出来。这是合理的方法学延续。

**⚠️ 明确不成立的部分**：δ=20 是「**项目内沿用的最低实际增益要求**」，
**不是**经过标定的**业务最小重要差异（MID）**。项目未做过任何 MID 标定
（无合同方/运营方阈值调查、无成本结构标定）⇒ **不得**据此推断投入产出意义，
**不得**表述为"业务上重要的最小增益"。

## 五、结论表述边界（**允许 / 禁止**）

即使未来该批次**达到** δ=20，**允许的表述只有**：

> **「P1-A 首个正式开发批次达到预声明门槛。」**

**禁止**的表述（同见 §0.1 与 §0.2）：

* ❌ 跨种子稳健优势 —— 只有**一个** 40 天开发种子（`20260926`），
  跨种子复现需**另行预注册**的批次；
* ❌ 已建立的方法优势 / SOTA / 最终测试结论；
* ❌ MaskCO 在 A3 上的贡献已建立 —— 本门检验的是**对照角色（Role C）的机制**，
  MaskCO 的比较**另行注册**；
* ❌ 与 A3 历史批次的直接数值对照 —— 旧 A3 存在**跨运行源码失配**，
  且 P1-A 尚未确定最终所引用的 `cond_hist + SAA` **冻结版本**；
  `density` / `reveal` 的口径差异**必须保留**。任何数值对照均须**另行**通过完整协议、
  数据、源码及计算预算身份核查（复用历史基线须证明身份完全匹配，
  否则在**新冻结协议下并发运行同源对照**）。
* ❌ 把 δ=20 说成业务 MID，或改述为**相对增益百分比**（它是效用绝对量，
  依赖当日效用尺度，主档 `cond_hist` ≈ 601）。

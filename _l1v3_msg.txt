2. THE ARM ORDER AND THE SHARED 10 s ALLOWANCE

   The arms run sequentially in the frozen order ('F', 'D-Geo') and share ONE
   monotonic origin, so the second arm's remaining time is
   `10.0 s - (what the first arm spent)`.  That is an instrument property.

   * V1 IS ORDER-INVARIANT and is proved so, not asserted: no scorer call
     precedes the first step, so the second arm has spent nothing and no
     deadline can have fired.  The counterexample runs the SAME state under two
     different first arms and finds the same chosen actions and the same
     first-step legal fingerprints.
   * V2 CAN BE ORDER-SENSITIVE, and the counterexample pair isolates it: with
     the state, mask, ordered legal lists, both arms' own costs and both call
     ceilings held fixed, changing ONLY which arm runs first turns "both
     complete" into "the second arm times out and falls back to the original
     plan".
   * A second, previously unstated consequence is now recorded: when the first
     arm consumes the whole allowance, the second arm is refused at its FIRST
     scorer call, so it produces no first step and V1 becomes NOT_COMPARABLE.
     That is order-driven loss of comparability, not a scorer difference.
   * MINIMAL FAIRNESS HANDLING, implemented rather than described: a
     pre-registered interpretation rule plus the deterministic classifier
     `classify_order_confound`, which labels each state
     ORDER_ATTRIBUTABLE / ORDER_INDETERMINATE / NOT_ORDER_ATTRIBUTABLE.
     The adjudication reports the counts and the affected states and states on
     its face that such a difference "may NOT be read as a scorer mechanism
     advantage".  No budget is widened, no arm is changed, no formal run is
     added, and every affected state keeps its record and stays in the
     64-state denominator.

SIX ENGINEERING CAPABILITIES
Q2-1 contract identity: uses the repository's EXISTING semantics
(quality_config_class + contract_schema_version + is_v2) and additionally binds
contract_hash. getattr(contract,'version',...) was the M1-a defect that made the value
always None; an AST check asserts neither that call nor any .version attribute appears
in the m1b adapter. v1 contracts are REFUSED, never silently substituted.
Q2-2 immutable snapshots: FrozenVehicle/FrozenPlan are genuinely isolated copies, with
alias detection; plan_identity_v2 now INCLUDES anchor_load (G4); the state is re-checked
mechanically after certification and any change refuses the result.
Q2-3 Omega10: epsilon_init = 1e-9 is pre-fixed; the conservative Q0_safe = Q0_contract -
epsilon_init is what enters the bound; only manifest lots, candidate-referenced revealed
orders and committed visible orders are read, never unrevealed orders; a mismatch refuses
BEFORE any quality implementation is called.
Q2-4 Omega11: an independent pre-submit return check covering the executed prefix (a
returning vehicle uses its REAL return_finish), committed in-flight legs, every vehicle's
current state, the full candidate suffix, and WAIT semantics (an empty suffix away from the
depot is judged as "must still return", never as already home). A clock already beyond the
horizon refuses rather than fabricating a certificate. The certificate is PER-COMMIT and is
never reused across replans.
Q2-5 analytic quality LB: H_max = max(0, T_end + 1e-6 - t_min) * hours_per_time_unit and
Q_LB = max(0, Q0_safe - k*H_max), with the same salability semantics as
_delivery_record_v2 (Q_LB >= threshold - 1e-9). v2 zero-order absolute-threshold only. The
tomato is OUT OF SCOPE with salable None and is never counted as unsalable.
Q2-6 G7 thermal gate: replays from the trusted current cold-chain state through the REAL
transition_segment, sampling the temperature envelope at every segment endpoint AND after
every door event - which is what addresses the "endpoint only" hazard - then checks
hard_temperature_bounds_c and the vehicle's EXISTING accumulated violations.

THE TWO GATES ARE NON-SUBSTITUTABLE: the receipt carries QUALITY_LB_OK and THERMAL_HARD_OK
as separate fields, the composite requires each independently, and any failure or unknown
refuses. T-Q2-4a proves quality-true/thermal-false refuses and T-Q2-4b proves the reverse
direction refuses.

   The public repo GoodThing001/DynMaskCO contained two committed 256-bit
   execution secrets, inside the raw run directories:

     L1-v2  execution_secret_12adf7457768bfb5.txt
            sha256 f786b3c202870670226f892f5ace31aa4ff04c52087e47b3be29cc8dc443a389
            first published by commit bdbc18ad7 (this round)
     V1.22  execution_secret_b3e36be45ceb6bb4.txt
            sha256 b9600f71696e70d27e75e68778cb65e21e000346f9813e1ad246076182215972
            PRE-EXISTING: already public before this review

   A byte-level scan of ALL 38,072 tracked files found these two files and NOTHING
   else: no secret value leaked into any log, record or source file.

   IMPACT -- no residual authority.  Each run mints its own secret with
   secrets.token_hex(32) at a freshly named path; the secret only signs that run's
   context; the guard additionally requires run/directory binding AND a one-shot
   consumption receipt that a gated process cannot forge; and both credentials were
   consumed BEFORE publication.  The exposed values therefore authorise nothing new.
   The residual risk is forensic: the already-completed runs' execution contexts
   could be forged.

   HANDLED AS EXPOSED, NEVER REUSED:
     * originals archived PRIVATELY outside the repository, byte-identical, at
       ~/dynmaskco_private/exposed_execution_secrets/2026-10-16/
     * the public copies replaced by REDACTED-EXPOSED-EXECUTION-SECRET stubs that
       record the run id, file sha256, the secret's sha256 (one-way), the publishing
       commit, the consumption time and the private archive path -- and NO value
     * EXECUTION_CONTEXT_*.json left INTACT: an HMAC is not reversible to its key,
       the key is already public, and that record is load-bearing evidence that the
       guard bound run, directory, consumed credential and nonce
     * redaction ledger l1_gates/L1_EXPOSED_SECRET_REDACTION.json and the idempotent
       tool scripts/tests/d3_l1_exposed_secret_redaction.py, which never prints a value

   HISTORY PURGE -- NOT EXECUTED, and the cost is stated.  Redaction only covers the
   current tree; the historical blobs still hold the plaintext.  The report gives the

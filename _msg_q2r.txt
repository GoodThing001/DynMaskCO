FOUR REPRODUCED FALSE PASSES

A1 - Omega11 omits the time-window WAIT. certify_route advances with
start = max(arrive, tw_start) (action_contract.py:187), but Omega11 advances with
t = max(ready_time, clock) and never applies tw_start. Input: tw_start[5]=20.0, T_end=19.0,
1.0 travel per leg. Omega11 returns OMEGA11_OK reporting a return of 2.0, while the TRUE
return is 21.0 and certify_route on the same data says feasible=False reason='return'
return_slack=-2.0.

A2b - the service-time cache defaults to ZERO and is used silently.
_service_time returns _SERVICE_TIME_CACHE.get(node, 0.0). Input: service_time[5]=2.0,
nothing registered, T_end=3.5. Omega11 returns OMEGA11_OK reporting 2.0 instead of the true
4.0; certify_route says infeasible. A zero default can only SHORTEN the replay, so this
class of defect can only produce optimistic verdicts.

A4b - a committed vehicle's later accepted task is omitted. The committed branch computes
only committed_finish + travel(committed_next -> depot) and never inspects the suffix.
Input: committed_finish=4.0, committed_next=3, mutable_suffix=[6,0], T_end=5.0. Omega11
returns OMEGA11_OK reporting 5.0 while the true return, which must also serve 6, is 6.0.

B1 - THE MOST SERIOUS: Omega10 can be silently unestablished.
Input: the manifest holds NO fish; the certified candidate plan carries a REVEALED fish
order 7 whose TRUE initial_quality is 1.0 against a contract initial_value of 9.0. The
default lot provider harvests only cargo-manifest lots, so it returns an empty set;
check_omega10_initialization returns ok=True with OMEGA10_NO_RELEVANT_LOTS when
checked == 0; the orchestrator treats ok=True as a pass and reports
M1B_Q2_ENGINEERING_CERTIFIED with n_checked=0. "Nothing to check" and "checked and fine"
are indistinguishable at the orchestration layer. This directly contradicts the stated
condition that any fish belonging to the current candidate or an accepted commitment whose
initial value has not been verified must not count as Omega10 established. A control (B4)
shows the comparison itself is correct, so the hole is coverage, not logic.
One qualification is added to the Q2 report WITHOUT rewriting it: its Omega10 description
claims the gate also reads revealed orders the candidate references, but no code reads
those initial values; B1 is the minimal counterexample.

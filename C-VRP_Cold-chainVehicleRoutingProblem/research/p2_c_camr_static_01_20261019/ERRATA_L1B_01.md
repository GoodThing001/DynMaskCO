## 3. 为什么 12/12 复核没抓到

`verify_camr_static.py` 的 `F2_summary_matches_rows` 只重算了 L1-A 的聚合（有效/无效/分歧数），L1-B 是**直接取用**汇总字段：

```python
'l1b_model_greedy_covered': pb1['n_model_greedy_covered'],
```

它从未执行 `model_hash in distance_set` 这个成员检查。因此 12/12 PASS 只能证明"原复核器登记过的检查都通过"，**不能**证明 L1-B 成员关系正确。这也是为何重复运行两次、源码一致、哈希全部匹配都无法自动暴露它：**这是一个确定性的系统性错误，比较对象取错，与随机性或复现性无关。**

原报告 §4 里"两侧集合交集 9"与"MaskCO-greedy 19/19 被覆盖"本身就互相矛盾（若 19/19 被覆盖，交集不可能只有 9）；这一点当时未被交叉核对，属同一缺陷的连带疏漏。

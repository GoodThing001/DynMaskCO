# 动态揭示程度条件轴结果（③ 的 EDoD 对照）

日期：2026-09-23。脚本 `scripts/run_future_sampling_oracle.py --mode none`（只算 myopic vs clairvoyant，快）。数据：`data/edod_{0.0,0.2,0.8}.npz`（8 实例，同 seed 2026，隔离揭示度）。产物 `results/reveal_axis_edod*/`。

## 1. 结果

固定状态三评分里，myopic 与 clairvoyant 选出动作的真实终局增益（gain，实例聚类 95% CI）：

| EDoD | gain_myopic | gain_clairvoyant | 未来信息价值（gap） |
|---|---|---|---|
| 0.0（静态） | +0.0427 [0.033, 0.052] | +0.0427 [0.033, 0.052] | **0.000（完全相同）** |
| 0.2 | −0.0331 [−0.122, 0.050] | +0.0663 [0.030, 0.102] | ~0.099 |
| 0.8 | +0.0047 [−0.006, 0.015] | +0.0199 [0.006, 0.037] | ~0.015 |

## 2. 结论（定性稳健，量级需更多实例）

- **EDoD=0 静态：myopic == clairvoyant（逐字节相同，gap=0）**——这是 sanity check：无未来揭示时 myopic J_vis 就是终局 J，未来信息价值为 0。直接确认"未来信息主导"与揭示程度挂钩。
- **EDoD>0 动态：clairvoyant > myopic（gap>0）**——未来信息有价值，myopic 评分相对 clairvoyant 变差（0.2 时 myopic 甚至为负）。
- **量级非单调**（0.2 gap≈0.099 > 0.8 gap≈0.015）：8 实例样本量太小 + 高 EDoD 下可见客户更少、2 客户局部候选集本身头腔变小。**不可据此写"gap 随 EDoD 单调增长"**。

可写（定性）：*"未来信息价值仅在动态揭示下非零（静态下 myopic 与 clairvoyant 完全一致），且 myopic 相对 clairvoyant 的劣势随揭示度出现。"* 需更多实例（16/32）才能定量刻画趋势。

## 3. 边界

- 每 EDoD 只 8 实例，CI 宽；量级结论需扩大。
- 只测 EDoD {0.0, 0.2, 0.8}（0.5 用 m0_scale CAL 的结果：myopic −0.012 / clairvoyant +0.043）。
- 固定状态、2 客户候选集，非闭环。

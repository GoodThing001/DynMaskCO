# 从局部修复质量到在线决策效用：MaskCO 在动态冷链路径优化中的迁移与失效边界

> 论文初稿（B 方向）。日期 2026-09-23。以 [论文设计与证据审计](论文设计与证据审计_2026-09-22.md) 为骨架。三列口径见 [结果主表_锁定](结果主表_锁定_2026-09-23.md)。投稿前须处理 [2026-09-24 源码核查](投稿前核查_2026-09-24.md) 中未来采样器与图注的问题。

## 摘要

把掩码生成式神经组合优化（MaskCO）从静态 CVRP 迁移到动态冷链取货问题（CVRPTW → 温区 → 动态揭示）时，我们做了一项系统实证研究。**在所测动态冷链协议中，MaskCO 微调在部分 seed 改善了局部修复质量；留出闭环优于未微调模型，但尚未证明优于 regret-2。** 具体地：seed42/43 在留出闭环显著优于 M-pre（−0.087~−0.104），但固定状态改善对训练 seed 敏感（seed44 未改善，final_loss≈0）；闭环里 M-trained 相对 R 的差异不显著（seed42 +0.0002 / seed43 +0.017，CI 跨零）。以 1% J0 为预设阈值的固定状态接受后分析，排除了在该指标上达到此量级的改善；这不构成闭环等效性结论。两条诊断揭示了局部质量与终局效用之间的落差：(1) 严格在线协议只 commit 每辆车后缀的第一个客户，动作追踪显示掩码客户的最终车辆归属在多数状态与候选方案不同；(2) 在同一状态、候选集和终局时域下，所用有限样本未来重采样评分未能恢复预知未来评分的收益。本文的贡献是**一套可复用的诊断流程 + 对"局部质量 → 在线效用"脱节的实证刻画**，而非一条普遍规律。

## 1. 引言

神经组合优化（NCO）把 NP-hard 组合问题建模为序列决策并用强化学习训练，近年来在旅行商、车辆路径等问题上取得了接近甚至超过传统求解器的结果。这类方法的一个关键卖点是**预训练迁移**：在标准规模与几何上训练的模型，能否迁移到更复杂的现实约束——时间窗、动态揭示、冷链品质？然而，迁移是否真的转化为在线决策效用，很少有工作做受控测量。

本文聚焦一个具体但重要的迁移场景：把掩码生成式 NCO 方法 MaskCO 从静态 CVRP 迁移到动态冷链取货问题（CVRPTW → 温区 → 动态揭示）。该场景同时引入三类新约束——时间窗、订单级冷链品质/能耗、以及动态揭示——是检验"预训练迁移边界"的好试金石。

**研究问题**：预训练迁移、候选质量和在线决策价值之间，到底隔着什么？

我们的做法不是"试一个模型看是否跑赢"，而是把迁移过程拆成三个可独立测量的层级——**候选质量**（模型产出什么）、**接受后质量**（在线接受规则部署什么）、**闭环终局**（实际轨迹获得什么）——并系统追踪"局部改善"在哪一层消失。为此我们构建了一套可复用的诊断流程（头腔普查 → 终局前瞻重评 → 因果 oracle → 未来信息 vs 评价时域 → 动作执行追踪 → 可预测性探针）。

**主要发现**：在所测动态冷链协议中，MaskCO 微调在部分 seed 改善了局部修复质量；留出闭环优于未微调模型，但尚未证明优于 regret-2。两条诊断揭示了局部质量与终局效用之间的落差线索：(1) 严格在线协议只 commit 每辆车后缀的第一个客户，动作追踪显示掩码客户的最终车辆归属在多数状态与候选方案不同；(2) 有限样本未来重采样评分未能恢复预知未来评分的收益。

**贡献**（详见 §6）：(1) 严格的动态迁移与评估协议；(2) 局部质量 → 在线效用脱节的实证刻画；(3) 可复用的诊断流程。重要的是，本文的贡献是**方法学与实证刻画**，而非"某个方法跑赢了某个基线"——它回答的是"迁移改善为何没有稳定成为在线收益"这一更可迁移的问题。

### 1.1 相关工作

MaskCO 通过掩码重建参考解学习组合结构，并在推理时迭代重构 [1]；注意力式神经路由模型及其 REINFORCE 训练提供了另一类学习参照 [2]。已有神经组合优化研究用仿真引导的 beam 搜索改善候选利用 [3]，而非学习的大邻域搜索是路径修复的重要参照 [4]。动态车辆路径研究强调订单揭示、决策时点和信息可得性对评价的影响 [5,6]。本文比较同一在线协议下的局部候选、接受后方案与终局轨迹，并检验搜索收益能否归因于学习提议。

## 2. 问题设定

我们研究动态冷链取货 CVRPTW：50 个客户与 depot 分布在 R1 均匀几何上（坐标 [0.02,0.98]²，depot 居中），由 25 辆多温舱车服务（共享容量 50）。时间窗 tw_width=0.2、horizon=24；温区 {常温,冷藏,冷冻} 比例 [0.4,0.35,0.25]，目标温度 25/4/−18°C。动态性用 EDoD=0.5 刻画：25 个客户的 reveal_time 在决策后才揭示（满足 release 可行性），strict-online 下决策者不可预知未来订单。

协议是 pickup-to-depot：车辆空载出发，`service_finish` 取货入舱并开始品质计时，`return_arrival` 卸货关闭；committed leg 不可撤销；**每个决策点只 commit 每辆车 suffix 的第一个客户**，其余后缀在后续事件被重规划。目标是 `coldchain_cost = D/scale_D + λ_Q·Q/scale_Q + λ_E·E/scale_E`，其中 D/Q/E 为距离(km)/品质损失/能耗(kWh) 的原始物理量，scale_D/scale_Q/scale_E = 18.33/2.89/1193 归一化，λ_Q=λ_E=1（冻结 profile `o0cc-pilot-devmean-equal-v2`）。

## 3. 方法

基线 **JF1-H-F** 是硬可行启发式 incumbent，产出 P0 与在线轨迹；**R（regret-2）** 是非学习参照，由 CC-LNS-RH 在给定预算内做 regret-2 重建。**M-pre** 用预训练 MaskCO CVRP 解码器（512 维，`cvrp100.ckpt`）做确定性 argmax 生成修复；**M-trained** 在 M-pre 之上加一个冷链适配层 C 与一个有向插入头 δ（末层零初始化，故初始 == M-pre），对完整修复做 REINFORCE 微调。

训练奖励为 `r = (J_vis(P0) − J_vis(P)) / s_TRAIN`（s_TRAIN 为 TRAIN 上 J0 的标准差），基线为同状态其他 K−1 个样本的均值；共 1000 步、batch 8 状态 × K=4 样本、lr=1e-4、seed ∈ {42,43,44}，采样与可微回放分离，只更新可训练分区。实例划分为 TRAIN-64 / CAL-16 / DEV-CHECK-16 / 留出-16（root seed 9701/9702/9703/9704，留出与前三者不同源，仅用于 seed42 固定状态检查与 seed42/43 最终闭环）。

评价采用三列口径（见 [结果主表](结果主表_锁定_2026-09-23.md)）：**候选质量**（candidate，失败兜底 J0）、**接受后质量**（accepted，在线接受规则 min(J0,J)）、**闭环终局**（closed-loop，在线预算 4.0s）。

## 4. 结果

### 4.1 搜索增强与候选互补性（负）

两层 beam 搜索下，M-trained 仍落后于距离提议（dist_sgbs 1.0617/1.1447 < R 1.0697/1.1515 < Mtrained 1.0789/1.1528）。在已生成的候选集上，模型与距离搜索合并后的平均额外收益 gain_union 为 0.0015/0.0005（<0.15%）；这表明互补性很小，但不能断言模型从未找到距离搜索遗漏的更优候选。

### 4.2 局部头腔存在但不进入终局

myopic 层：mask=2 穷举修复相对距离搜索有 ~0.003–0.005 头腔（D1/D2）；易腐排序在品质重标定 ×5 后转正（+0.141，D7-a）。终局层：D3、D7-b/b'/c 未见稳定正收益（置信区间跨零；约 2/3 状态的终局指标与 baseline 相同）。

### 4.3 机制一：候选车辆归属难以保留（动作追踪，图 2）

严格在线协议每决策点只 commit 每辆车 suffix 的第一个客户。动作追踪显示：mask=2 修复的修改在 60% 状态两个 mask 客户都被改、40% 改一个；最终两名掩码客户都由候选所分配车辆服务的比例为 0/30（距离贪心）和 1/30（穷举）。**直接证据仅限车辆归属**，未核对完整路线顺序、服务时刻或每一步计划。该现象与未 commit 的 suffix 在后续事件被重规划一致，但尚不能确定归属改变的具体时点与原因。

### 4.4 机制二：采样评分未恢复预知收益（未来信息 vs 评价时域，图 3）

同一状态/候选集/终局时域下比较三种评分：当前可见目标（myopic）/ 按所用重采样器估计的未来评分 / 真实未来评分（clairvoyant）。修复后（共享场景，N=8）时，dist_full 的平均终局收益为 −0.005 [−0.047, +0.033]，dist_attr 为 +0.017 [−0.011, +0.046]，myopic 为 −0.011 [−0.055, +0.030]，clairvoyant 为 +0.045 [+0.019, +0.074]（8 实例、16 状态，实例聚类区间）。**配对差异**（clairvoyant − 采样评分，逐状态配对，CI 均不含零）为 dist_full +0.050 [+0.022, +0.082]、dist_attr +0.028 [+0.014, +0.043]、myopic +0.056 [+0.024, +0.088]（图 3）。**直接证据**：所测试的有限样本评分没有恢复预知评分的平均收益。**边界**：clairvoyant 按同一候选集的真实终局评分选最优，差异方向非负是构造结果，不证明其他在线评分方法无效；full 使用构造的未来重采样规则，尚未证明它等于条件于公开状态的真实分布；attr 保留真实揭示时间，因此含部分未来信息，不能称为严格在线策略。结果与未来实现影响候选排序的解释一致，尚不能据此量化可预测性上限。

### 4.5 稳健性：3 seed + 留出 + 预设收益阈值（图 1）

固定状态（候选 / 接受后）主表（**表 1**）：

|---|---|---|---|---|---|
| 42 | train | +0.033 | +0.024 [0.013, 0.035] | −0.052 | −0.015 |
| 42 | cal | +0.029 | +0.015 [0.007, 0.023] | −0.057 | −0.019 |
| 43 | train | −0.001 | −0.000 [−0.005, 0.005] | −0.076 | −0.038 |
| 43 | cal | +0.006 | +0.003 [−0.007, 0.014] | −0.071 | −0.028 |
| 44 | train | +0.081 | +0.039 [0.026, 0.054] | +0.005 | +0.001 |
| 44 | cal | +0.077 | +0.032 [0.021, 0.044] | −0.000 | −0.000 |
| 留出(42) | 留出 | +0.025 | +0.021 [0.013, 0.031] | −0.034 | −0.009 |

- **固定状态不超 R**：接受后 Mtr−R 在 seed42/44/留出显著为正（+0.015~+0.039），seed43 ≈0（CI 跨零）；候选列方向一致。三个 seed + 留出从未显著优于 R。闭环里 M-trained 与 R 差异不显著（§4.6）。
- **优于 M-pre 不稳健**：候选列 seed42/43 为 −0.05~−0.08，seed44 塌缩（+0.005/≈0，final_loss≈0）。接受后列幅度更小（−0.009~−0.038）。

### 4.6 闭环终局（Gate 2，已完成）

seed42/43 在留出 16 实例上的闭环（冻结预算 4.0s，服务率 16/16，**表 2**）：

| seed | ΔJ(M-trained−baseline) | ΔJ(R−baseline) | M-trained−R | M-trained−Mpre |
|---|---|---|---|---|
| 42 | −0.0265 [−0.085, 0.021] | −0.0266 [−0.076, 0.019] | +0.0002 [−0.039, 0.037] | **−0.104** [−0.184, −0.022] |
| 43 | −0.0095 [−0.070, 0.067] | −0.0266 [−0.076, 0.019] | +0.0171 [−0.048, 0.091] | **−0.087** [−0.152, −0.016] |

**关键发现**：闭环里 M-trained 与 R 差异不显著（CI 跨零，未检出优势也未检出劣势），相对 M-pre 的配对差异为负且区间不含零（−0.087~−0.104）；M-trained 和 R 相对 baseline 的均值略低，但各自区间均跨零。固定状态候选质量差于 R 与闭环未检出差异属于不同评价层级，不能仅凭此归因于接受规则或逐事件重规划。注：clairvoyant 顺序 oracle 的 −0.21 来自先前 CAL 实验，与留出闭环非同一实例/口径，不在此直接相减。

## 5. 讨论

**统一主张**：在所测动态冷链协议中，MaskCO 微调在部分 seed 改善了局部修复质量；留出闭环优于未微调模型，但尚未证明优于 regret-2。

两条诊断与观察一致（作为**机制线索**，而非充分解释）：
- **动作持久性**：动作追踪直接测得掩码客户的最终服务车辆与候选分配不同（多数状态归属改变）；尚未证明完整路线按什么顺序、在哪一事件被覆盖。
- **未来采样**：当前采样评分未恢复预知未来评分的收益；但据此不能断言"剩余可获得收益都在真实未来信息里"。

因此"两层机制足以解释为何无法超越 R"应降为"**与观察一致的两种机制线索**"；闭环的"M-trained−R 差异不显著"是"未检出差异"，不是"等效/追平"。这不是"信息论上不可学习"，也不是"头腔 100% 来自未来"。

**可主张**：*"在相同状态与候选集上，所测试的有限样本未来重采样评分未恢复真实未来评分的平均收益。"*（受控支持）

**不可主张**：*"信息论上无信号"*（只排除当前分布 + N 样本 + 均值估计）；*"≈100% 来自未来"*（未做定量分解）；*"触顶于 R / 追平 R"*（闭环只是未检出差异，非等效）。

**对动态 NCO 研究者的启示**：在 strict-online 动态设定下，固定状态的"局部候选质量"是一个可能误导的代理——它不必然转化为在线效用。评估动态 NCO 方法时，应区分"候选质量 / 接受后质量 / 闭环终局"三个层级，并用动作持久性、未来采样等诊断定位改善在哪一层消失。这一区分本身，比"某个方法是否跑赢某个基线"更可迁移。

## 6. 贡献

1. **严格的动态迁移与评估协议**：公开信息、不可撤销动作、订单级冷链评价、训练-部署一致性。
2. **局部质量 → 在线效用脱节的实证刻画**：区分候选质量、接受后质量、闭环终局三列，定位"脱节"发生在哪一层。
3. **可复用的诊断流程**：头腔普查 → 终局前瞻重评 → 因果 oracle → 未来信息 vs 评价时域 → 动作执行追踪 → 可预测性探针，避免把预知未来的参照误当成可学习的在线目标。

## 7. 局限

- 单一任务设置（50 节点 / R1 / EDoD=0.5 / pickup-to-depot）；EDoD 对照（0.0/0.2/0.8）是探索性边界分析（各 8 实例）。
- 机制实验在 CAL 固定状态 + 2 客户候选集；闭环只在留出 16 实例测了 seed42/43。
- 只训练 3 个 seed（42/43/44）；REINFORCE 直接目标训练对 seed 敏感（seed44 塌缩）本身是"训练不稳定"的证据，但未做大规模 seed 扫描。
- 诊断流程复用了多个现成工具（JF1-H-F、regret-2、C0 评价器），方法贡献本身不自动成立，价值在于"诊断认识是否对其他动态 NCO 研究者有用"。

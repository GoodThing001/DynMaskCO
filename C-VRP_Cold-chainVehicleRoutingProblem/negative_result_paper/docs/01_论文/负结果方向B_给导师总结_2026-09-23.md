# DynMaskCO-CC 负结果方向（B）总结

> 给导师的汇报材料。日期 2026-09-23。

## 一句话

把 MaskCO（掩码生成式神经组合优化）迁移到动态冷链 CVRPTW 时，**微调在部分 seed 改善了局部修复质量；留出闭环优于未微调模型，但尚未证明优于 regret-2**。本方向系统刻画了这条失效边界，并沉淀了一套可复用的诊断方法——这是 A 方向（正向方法）的地基，不是孤立的"失败记录"。

## 研究问题

**预训练迁移、候选质量和在线决策价值之间，到底隔着什么？** 这服务于所有做动态神经组合优化的研究者，比"连续失败"更接近论文贡献。

## 核心发现（受控证据链，8 步 + 3 个机制实验）

**1. 局部改善存在但不进入终局。**
- myopic 层：mask=2 局部修复有头腔（穷举 vs 距离搜索 ~0.003–0.005），易腐排序在品质重标定后也转正（×5 时 +0.141）。
- 终局层：D3、D7-b/b'/c 未检出稳定正收益（区间跨零，约 2/3 状态终局指标与 baseline 相同）。

**2. 机制线索一（②a 动作追踪）：候选车辆归属难以保留。**
严格在线协议每决策点只 commit 每辆车 suffix 的第一个客户。实测：两名掩码客户最终都由候选所分配车辆服务的状态为距离贪心 0/30、穷举修复 1/30。该探针仅核对车辆归属，未验证完整路线执行；后续重规划覆盖是与观察一致的解释。

**3. 机制线索二（②b 未来信息 vs 评价时域）：所测采样评分未恢复预知评分收益。**
在同一状态/候选集/终局时域下比较当前可见目标、有限样本未来重采样评分与真实未来评分。N=16 时 full +0.006、attr +0.005，真实未来评分 +0.043；配对差异 clairvoyant−full 为 +0.037 [0.015,0.065]（8 实例）。clairvoyant 在同一候选集上按真实终局评分选最优，属于特权信息上界；该差异不能证明收益不可预测。full 使用构造的重采样规则，attr 保留真实揭示时间，均不能代表全部可部署未来预测方法。

**4. 稳健性（3 seed + 留出实例 + 等效性 + 闭环）。**
- **固定状态不超 R；闭环未检出相对 R 的差异**：接受后 Mtr−R 在 seed42/44/留出显著为正（+0.015~+0.039），seed43 的区间跨零；闭环 Mtr−R 为 seed42 +0.0002 [−0.039,0.037]、seed43 +0.017 [−0.048,0.091]。跨评价层级的显著性变化不构成等效性或"劣势被回收"的因果证据。
- **显著优于 M-pre**：闭环 Mtr−Mpre = −0.104/−0.087（CI<0），候选列 seed42/43 也显著优；但 seed44 塌缩（final_loss≈0）——"微调有帮助"对 seed 敏感。
- **闭环未检出相对 R 的优势**：M-trained 与 R 差异不显著（CI 跨零）。clairvoyant 顺序 oracle 在先前 CAL 上的 −0.21 是不同实例/口径，不在此直接相减；未来采样诊断（②b）表明当前采样评分未恢复预知收益。
- **预设收益阈值**：以 δ=1% J0 为预设阈值，固定状态接受后指标排除"M-trained 比 R 好 ≥1%"；最有利 seed43 的单侧置信界对应 0.34–0.44% J0。此判断不适用于闭环终局，也不是双侧等效性检验。

## 三项贡献

1. **严格的动态迁移与评估协议**：公开信息、不可撤销动作、订单级冷链评价、训练-部署一致性（含正式门禁/冻结源存档/版本分离）。
2. **局部质量 → 在线效用脱节的实证刻画**：区分"学到了什么""搜索带来了什么""实际执行获得了什么"。
3. **可复用的诊断流程**：头腔普查 → 终局前瞻重评 → 因果 oracle → 未来信息 vs 评价时域 → 动作执行追踪 → 可预测性探针。避免把预知未来的参照误当成可学习的在线目标。

## 与 A 方向的关系

A 方向（MaskCO 做随机前瞻决策，正向尝试）可将本研究观察到的评分差距作为动机；但 B 方向尚未证明终局头腔必然依赖不可预测的真实未来，也未证明随机前瞻能够填补差距。B 的三列评价与机制诊断可为 A 提供验真工具。

## 拟议论文结构

- **单篇**：负结果 + 方法学（"从局部修复质量到在线决策效用：MaskCO 在动态冷链中的迁移与失效边界"），投 TMLR/方法学。
- **两篇**：先发 B（诊断 + 失效边界），再发 A（正向方法，引用 B 作动机）——若 A 的正向增益确认，两篇分工最干净（B 靠"可复用方法+机制"独立成篇，不切香肠）。

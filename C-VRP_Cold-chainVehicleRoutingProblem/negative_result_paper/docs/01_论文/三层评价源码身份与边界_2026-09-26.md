## 3. mask 邻域与搜索预算（两层不同）

| | 固定状态（fsq） | 闭环（step5） |
|---|---|---|
| mask 大小 | 固定 mask=2（每状态前 2 事件） | `REQUEST_SEQUENCE = (2,2,2,4,4,4,8,8)`，`N_ROUNDS=2` → 每次重规划调用至多 16 个 mask-修复尝试 |
| mask 来源 | `mask_candidate_pool`（= `decision_pool_from_vehicles` − protected 车 tail），`_select_one_mask` 确定性选取 | 同左（同一函数） |
| 修复尝试数 | 每状态 19 次（R 1 + Mpre 1+8 + Mtrained 1+8） | 每次重规划调用 ≤16 次（预算截断） |
| 预算 | 无时间预算 | **4.0 s / 每次重规划调用**（`cc_lns_policy_search` 每次调用重置 `t0`；`PolicyReplanner(budget_s=4.0)`），JIT 预热（~108s）另计不计数 |
| 接受规则 | `min(J0, J_vis)`（离线接受后列） | `J_vis` 严格改善即写回（best_J < J0） |

**预算语义勘误**（审计 P0-3 确认）：原表述“每实例 4.0s”错误；正确为 **4.0s/重规划调用**。s42 v1 闭环 Mtrained 总搜索耗时 1169s/16 实例（≈73s/实例）与 16×4s 的“每实例总预算”解读不相容，与“每调用 4s×多事件”相容。

## 4. 实例集合差异

- R1 固定状态主表：TRAIN/CAL 各 16 实例 × 2 状态 = 32 状态；留出固定状态只有 s42（fsq_heldout）。
- R1 闭环：留出 16 实例，s42/s43 两 seed；s43 无同留出集的固定状态三列。
- C1：16 新实例，固定状态三 seed + 闭环 s42/s43（预注册）。
→ 主表证明“不同层级出现不同排名/区间”，**不能**精确识别某个候选收益在哪个事件被抵消；正文已按描述性三层评价表述（见《论文完整初稿》§4 方法节边界）。

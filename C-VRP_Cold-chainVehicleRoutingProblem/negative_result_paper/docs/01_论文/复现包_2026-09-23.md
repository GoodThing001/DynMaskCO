## 3. 运行命令（冻结协议）

```bash
# 训练（seed ∈ {42,43,44}，1000 步 / 8×4 / REINFORCE）
python scripts/training/train_mpre_reinforce.py \
  --data data/m0_scale/dcc_50_r1_edod05_train_teacher.npz \
  --cvrp-ckpt ../MASKCO_code/ckpts/cvrp100.ckpt --capacity 50 --num-vehicles 25 \
  --objective coldchain --objective-profile results/o0cc/scale_v2/objective_profile.json \
  --num-steps 1000 --batch-states 8 --K 4 --seed <SEED> \
  --out results/m0_scale/mpre_reinforce_s<SEED>_clean

# 固定状态评估（TRAIN/CAL/留出）
python scripts/evaluation/run_fixed_state_quality.py \
  --data <npz> --cvrp-ckpt ../MASKCO_code/ckpts/cvrp100.ckpt \
  --model-ckpt results/m0_scale/mpre_reinforce_s<SEED>_clean/model.ckpt \
  --objective-profile results/o0cc/scale_v2/objective_profile.json \
  --split <train|cal> --out <out>

# 分析（candidate + accepted 配对，实例聚类 bootstrap）
python scripts/evaluation/analyze_fixed_state.py --per-state <out>/per_state.json --out <out>/analysis.json

# 闭环 gate（留出，冻结预算 4.0）
python scripts/evaluation/run_step5_gate.py \
  --data data/heldout/dcc_50_r1_edod05_heldout.npz --cvrp-ckpt ../MASKCO_code/ckpts/cvrp100.ckpt \
  --model-ckpt results/m0_scale/mpre_reinforce_s<SEED>_clean/model.ckpt \
  --objective coldchain --objective-profile results/o0cc/scale_v2/objective_profile.json \
  --budget 4.0 --max-instances 16 --out results/m0_scale/step5_heldout_s<SEED>
```

## 4. 仿真物理参数（单一任务设置）

| 项 | 值 |
|---|---|
| 问题 | 50 客户 + depot，CVRPTW → 冷链 → 动态（pickup-to-depot） |
| 几何 | R1（坐标 uniform [0.02,0.98]²，depot 中心 0.5,0.5），欧式距离，speed=1.0 |
| 容量/车队 | capacity 50，25 辆车，多温舱共享容量 |
| 时间窗 | tw_width=0.2，horizon=24（depot TW [0,24]） |
| 动态 | EDoD=0.5（25 动态客户，reveal_time 满足 release 可行性） |
| 温区 | 常温/冷藏/冷冻 = [0.4, 0.35, 0.25]，目标温度 [25, 4, −18]°C |
| 品质 | pickup-to-depot 语义：service_finish 取货入舱起算品质，return_arrival 卸货关闭 |
| 目标 | `coldchain_cost` = D/distance_scale + λ_Q·Q/quality_scale + λ_E·E/energy_scale（profile `o0cc-pilot-devmean-equal-v2`，scale 18.33/2.89/1193，λ_Q=λ_E=1） |

## 5. 边界（必须写进论文）

- **单一任务设置**：所有结论只对 **50 节点 / R1 均匀几何 / EDoD=0.5 / pickup-to-depot / 25 车** 成立；未覆盖更大规模、聚类几何（C/RC）、更高揭示度、或 depot-to-customer 配送。
- EDoD 条件轴（0.0/0.2/0.8）是**探索性边界分析**（各 8 实例），不足以写成"MaskCO 在什么条件下一定无增量"的普遍规律。
- 机制实验（②a/②b）都在 **CAL 固定状态** + 2 客户候选集上，闭环只在留出 16 实例上测了 seed42/43。
- 只训练了 3 个 seed（42/43/44），不是大规模 seed 扫描。

## 概述

### 核心思路

**当前问题**：
- 2-opt 只在 mask-reconstruct **最后**执行（40 cycles 后）
- 早期 cycles 的次优解没有被优化，浪费了搜索机会

**解决方案**：
- 在 mask-reconstruct **过程中**定期插入 2-opt
- 早期发现局部优化机会 → 为后续 cycles 提供更好起点
- 轻量级执行（1-2 steps）避免过度优化

### 实现位置

```python
# cvrptw.py line ~1160
for cycle_idx in range(cycles - 1):
    # ... mask and reconstruct ...
    
    # Week 3 v6: In-Cycle Local Search 新增
    if (in_cycle_2opt and
        cycle_idx >= in_cycle_2opt_start and
        cycle_idx % in_cycle_2opt_frequency == 0):
        sols = two_opt(sols, steps=in_cycle_2opt_steps)
    
    # ... continue ...
```

import numpy as np
from scipy import stats

baseline_costs = [17.78, 10.81, 14.98]  # R1/C1/RC1 @ EDoD=0.8

print(f"t-statistic: {t_stat:.3f}")
print(f"p-value: {p_value:.3f}")
print(f"Significant: {'Yes' if p_value < 0.05 else 'No'}")

# 平均改进
improvement = np.mean([(b - i) / b * 100 for b, i in zip(baseline_costs, in_cycle_costs)])
print(f"Average improvement: {improvement:.1f}%")

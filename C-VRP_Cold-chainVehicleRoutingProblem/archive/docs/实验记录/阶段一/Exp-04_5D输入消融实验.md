# 实验 Exp-04: 5D 输入特征消融实验

- **日期**：2026-07-29 ✅ 完成
- **目标**：验证 5D 输入能正常训练，对比有无时间窗特征对 loss 收敛的影响
- **假设**：加入 TW 特征后，模型能学到时间窗约束信息，loss 下降趋势应与纯 CVRP 训练一致

## 实验设计

| 组 | 输入特征 | encoder_input_dim | 状态 |
|---|---|---|---|
| A (baseline) | 3D: [x, y, demand] | 3 | ✅ 完成 |
| B (TW as input) | 5D: [x, y, demand, tw_start, tw_end] | 5 | ✅ 完成 |

> 组 C (5D + TW attention bias) 推迟到 Exp-05，需要额外模型改动。

## 分析

1. **5D 初始 loss 略高**（2.86 vs 2.71）：init_proj 从 5→256 比 3→256 多出近一倍的随机权重参数，初始输出噪声更大。

2. **5D 中期收敛更快**：在 step 1000-2000 区间，5D 的 loss 显著低于 3D（1.49 vs 1.73, 0.81 vs 1.32），说明模型确实在利用 TW 特征来辅助边预测。时间窗特征提供了额外的结构信息（TW 相近的节点更可能在同一路径段），加速了训练中期收敛。

3. **最终 loss 几乎一致**（0.690 vs 0.692）：到 step 3000+ 后两组趋于相同。mask-and-reconstruct 的优化目标（边预测交叉熵）有 noise floor，额外的 TW 特征无法突破这个下界。

4. **5D 训练更慢**（+31%）：init_proj 扩容 + tw_bias 参数导致计算量增加，符合预期。

## 结论

- **假设部分成立**：5D TW 特征确实被模型利用（中期收敛显著更快），但最终 loss 与 3D 持平
- **关键发现**：TW 特征对**训练效率**有正向影响（更快收敛），但对最终 loss 无显著影响——mask-reconstruct 的 loss 下界由数据噪声和模型容量决定，不由输入特征维度决定
- **启发**：5D 训练的优势可能在推理时体现——模型学到 TW 约束后，生成的解应具有更高的 TW 可行率。这需要在 Exp-06/08 中验证

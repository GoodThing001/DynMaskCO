# 7. R1.7-4：Guard Long-Horizon Counterfactual Audit

当前 guard 比较的是：

- 当前 suffix service
- 当前 suffix distance

但动态 VRP 真正关心：

\[
\text{当前选择对后续整个 episode 的影响}
\]

因此需要验证 guard 是否过于 myopic。

## 7.1 实验设计

对一批 H2-G decision states 保存完整 simulator snapshot：

\[
S_e
\]

从同一状态 fork 两条轨迹。

### Branch I：Incumbent branch

执行：

```text
NN incumbent first decision
```

然后后续继续使用同一个 frozen H2-G policy。

### Branch C：Candidate branch

执行：

```text
MaskCO candidate first decision
```

然后后续也继续使用同一个 frozen H2-G policy。

两条轨迹共享完全相同的 realized future episode。

定义：

\[
J^{inc}_e
\]

\[
J^{cand}_e
\]

以及：

\[
\Delta J^{future}_e
=
J^{cand}_e
-
J^{inc}_e
\]

这属于离线 counterfactual evaluation，不进入 online policy，因此不构成 future leakage。

## 7.2 主要指标

### Accepted precision

guard 接受的 candidate 中：

\[
P(\Delta J^{future}<0)
\]

### Rejected opportunity

guard 拒绝的 candidate 中：

\[
P(\Delta J^{future}<0)
\]

如果：

```text
accepted beneficial ≈ 90%
rejected beneficial ≈ 3%
```

说明当前 guard 很好。

如果：

```text
accepted beneficial ≈ 55%
rejected beneficial ≈ 30%
```

说明当前局部 guard 过于粗糙，后面值得研究：

> recourse-value / acceptance model

# 23. A* 第一项：Directional Residual Scorer

当前旧 scorer 本质接近：

\[
L^{sym}_{ij}
=
h_i^\top h_j
\]

因此：

\[
L_{ij}=L_{ji}
\]

但 VRPTW：

\[
i\rightarrow j
\neq
j\rightarrow i
\]

## 23.1 最小改造

保留旧 scorer：

\[
L^{sym}_{ij}
\]

新增：

\[
q_i=W_qh_i
\]

\[
k_j=W_kh_j
\]

\[
L^{dir}_{ij}
=
\frac{
q_i^\top k_j
}{
\sqrt d
}
\]

最终：

\[
L_{ij}
=
L^{sym}_{ij}
+
\alpha L^{dir}_{ij}
\]

初始化：

\[
\alpha=0
\]

这样：

\[
L_{new}=L_{old}
\]

初始完全 backward-compatible。

## 23.2 必须加回归测试

当：

\[
\alpha=0
\]

要求：

\[
\max|L_{new}-L_{old}|<10^{-6}
\]

训练后检查：

\[
\alpha\neq0
\]

再定义：

\[
A_{asym}
=
\frac1{|E|}
\sum_{i\neq j}
|L_{ij}-L_{ji}|
\]

确认模型真正学到方向性。

## 30.2 Objective-gap weighting

定义：

\[
w
=
clip
\left(
\frac{
J^- - J^+
}{
|J^+|+\epsilon
},
0,
w_{max}
\right)
\]

然后：

\[
L_{pref}
=
-w
\log

# 7. 新增 Vehicle Equivalence Class Builder

这是下一阶段最重要的代码基础。

建议新文件：

```text
scripts/jf2/vehicle_equivalence.py
```

## 7.1 第一版等价判定

对当前 homogeneous fleet，可定义 key：

```python
def vehicle_equiv_key(v, clock, *, tol=1e-6):
    if v.status == 'idle':
        return (
            'idle',
            0,                          # depot
            round(clock / tol) * tol,
            0.0,
            (),
        )

    if v.status == 'ready':
        return (
            'ready',
            int(v.current_node),
            quantize(v.ready_time, tol),
            quantize(v.current_load, tol),
            tuple(v.mutable_suffix),
        )

    if v.status == 'committed':
        return (
            'committed',
            int(v.committed_next),
            quantize(v.committed_finish, tol),
            quantize(post_commit_load(v), tol),
            tuple(v.mutable_suffix),
        )

    return (v.status, v.vehicle_id)
```

### 注意

`ready` 两辆车只有在：

- current node；
- ready time；
- load；
- committed/mutable context；

都等价时才能归类。

不要只写：

```python
if status == 'idle': equivalent
```

后续若加入 heterogeneous fleet，还需要：

```text
capacity
vehicle type
cold compartment configuration
energy state
```

进入 equivalence key。

# 8. 下一版推荐：Equivalence-Class Loss

当前 v2 用 min-ID label：

```text
teacher class {3,17,20} → label 3
```

下一版改成：

```text
teacher class {3,17,20} → valid target set {3,17,20}
```

## 8.1 数学

对 logits：

\[
z_k=S(k,j)
\]

有效车辆：

\[
V_j^F
\]

teacher equivalence set：

\[
E_j\subseteq V_j^F
\]

loss：

\[
L_j=-\log\frac{\sum_{k\in E_j}e^{z_k}}{\sum_{k\in V_j^F}e^{z_k}}
\]

## 8.2 JAX 实现示意

```python
NEG = -1e9
valid_logits = jnp.where(candidate_mask, logits, NEG)

log_z_all = jax.scipy.special.logsumexp(valid_logits, axis=-1)

target_logits = jnp.where(target_equiv_mask, valid_logits, NEG)
log_z_target = jax.scipy.special.logsumexp(target_logits, axis=-1)

loss = -(log_z_target - log_z_all)
loss = loss[customer_train_mask].mean()
```

[RISK]

若 `target_equiv_mask` 与 `candidate_mask` 无交集，应 fail-hard：

```python
assert jnp.any(target_equiv_mask & candidate_mask)
```

不能 silently ignore。

# 10. 当前 M0-v2 Gate A 的 residual calibration 检查

即使 classifier top-1 56.7%，production score 还可能因 residual scale 不合适导致：

```text
学到了
但动作几乎没改变
```

或：

```text
动作改变太多
把 JF1-H 强 prior 覆盖掉
```

因此 Gate A 日志必须加入：

```text
alpha
residual mean/std/p95
base-score gap between top1/top2
alpha*residual correction magnitude
rank_flip rate
true-disagreement rank_flip rate
symmetric-disagreement rank_flip rate
```

推荐指标：

\[
CorrectionRatio
=
\frac{|\alpha r|}{|S_H^{(1)}-S_H^{(2)}|+\epsilon}
\]

如果大多数：

```text
CorrectionRatio << 1
```

网络虽会分类，但 production ranking 进不去。

如果：

```text
CorrectionRatio >> 1
```

则容易过度推翻强 heuristic prior。

# 12. Regret / preference 数据生成

仅对高价值 state 做 OR counterfactual query。

对 customer j：

```text
teacher k+
alternative k-
```

强制：

```text
j -> k-
```

OR 再优化其余 current-visible assignment。

得到：

\[
Regret(k^-,j)=J(k^-\leftarrow j)-J(k^*\leftarrow j)
\]

保存：

```text
state_id
customer_id
positive_vehicle
negative_vehicle
positive_class
negative_class
regret
or_cost_pos
or_cost_neg
```

---

# 13. Regret-weighted preference loss

```python
delta = score_pos - score_neg
weight = jnp.clip(regret / regret_scale, 0.0, w_max)
loss = weight * jax.nn.softplus(-delta / tau)
```

总 loss 可逐步变成：

\[
L=L_{symCE}+\lambda_pL_{pref}
\]

后续 encoder fine-tune 才加：

\[
+\lambda_rL_{route}
\]

# 17. strict_online_env 不要为 JF2 改语义

当前运行时五态：

```text

```

JF2 只能读取它们，不应该自己维护第二份 vehicle state。

尤其：

### idle

首次 dispatch：

```python

```

不能 0。

### committed

```python
anchor_node = committed_next
anchor_time = committed_finish
anchor_load = current_load + demand[committed_next]
```

### returning / closed

不得进入新 assignment candidate。

# 18. symmetry audit 需要加入 permutation test

这是目前必须新增的 blocking test。

## 18.1 Test

取同一个 state，随机 permutation 物理 vehicle IDs：

```text
0→7
7→2
2→14
...
```

同步 permutation：

- FleetState；
- candidate mask；
- teacher equivalence；
- model vehicle axis。

要求：

### score equivariance

\[
S'(\pi(k),j)=S(k,j)
\]

### action equivariance

若 action 唯一：

\[
a'=\pi(a)
\]

若存在 equivalence set，则 action 至少落在对应等价集合。

### downstream invariance

最终：

```text
completion same
cost difference < tolerance
```

这比 min-id canonicalization 更能证明方法正确处理同质 fleet symmetry。

# 24. 训练采样优化

当前真实非等价 disagreement 只有约 3.3%。


# 25. 不建议现在做 focal loss

在 symmetry 没完全解决前，focal loss 会把“难样本”放大，但一部分难样本可能只是等价 label ambiguity。

优先顺序应是：

```text
symmetry-correct target
→ regret-aware target
→ 再考虑 focal / class weighting
```

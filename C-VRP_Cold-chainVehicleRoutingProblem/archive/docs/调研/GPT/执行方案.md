## 八、论文定位（2026-08-19 最终冻结）

> **核心研究问题**（一句话）：**研究掩码生成范式如何从静态组合优化扩展到动态冷链车辆路径问题中的因果、可行性保持在线优化。**

> *"DynMaskCO investigates how masked generation can be extended from static combinatorial optimization to causal, feasibility-preserving online optimization for dynamic cold-chain vehicle routing."*

**三层贡献结构**（按原始课题排序，不再切换主题）：

1. **从 Static MaskCO 到 Causal Dynamic Masked Generation**（核心）
   - Static Mask-and-Reconstruct → Causal Event-Conditioned Mask-and-Reconstruct
   - 关键改造：Visibility-Gated Attention（P0-2）、Visible-Only Normalization（P0-3a）、Event-Aware Masking（D1）、Frozen Prefix（D2）、Online Sequential Training（Phase 3c）
   - 核心消融表：Static MaskCO（泄漏 76.6%）→ Naive Dynamic（因果 51.2%）→ +Resource Beam（100%）

2. **动态硬约束下的 Feasibility-Preserving Reconstruction**
   - Hybrid NCO 架构：Learned Masked Generation（edge_logits 提供路由偏好）+ Resource-Feasible Search（beam + 2-opt 保证硬约束）
   - 45/45 = 100% TW 可行（5-seed × 3 类型 × 3 EDoD），首个窄 TW 动态 VRP 达 100% 的神经求解器

3. **Cold-Chain 多资源约束扩展与机制验证**
   - 问题扩展：距离/TW/容量 → +品质损耗/制冷能耗/温区
   - ✅ Toy 因果翻转（常温 rank 5.50→1.50，weighted completion time 机制成立）
   - ⚠️ R1 弱效应（rank 24.97→24.79，硬 TW 约束主导，品质项是次级因素）
   - 诚实结论：*"quality objective 能改变候选路线选择，但其影响弱于硬时间窗约束"*

**关键转折（2026-08-19）**：
- **停止品质项优化**（toy 完美 + R1 微弱，结论已清楚，不再调 λ_q）
- **OR-Tools 劣势作为 limitation**，不是主 hypothesis 被否定——论文主表诚实保留 OR-Tools-RH 全面占优（R1 −16.5%、C1 −37%、RC1 −21%）
- **Zero-shot 降为支持性实验**（证明 masked representation 未只记忆单一分布），不作为论文主题
- **实验资源重分配**：70% 核心演化消融 + zero-shot / 20% OR-Tools 公平对比 / 10% 冷链证据整理

**10/1 Go/No-Go 判据**（修正版）：
- ✅ 100% 可行性（已有）+ 因果性验证（P0-2/3a/3b 已有）+ 机制正确（toy 已有）
- 🔄 Zero-shot 不崩溃（feasible ≥90%, cost degradation <30%，后台跑）
- ✅ OR-Tools 诚实报告（已有，作为 limitation）

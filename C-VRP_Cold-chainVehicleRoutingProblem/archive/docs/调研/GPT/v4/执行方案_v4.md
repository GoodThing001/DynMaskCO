## 0. 核心判断

**当前 DynMaskCO 已经越过「方法是否成立」的阶段，处于「证据链是否足以支撑 ICLR 2027 核心论断」的阶段。**

因果性、资源可行性、理论形式化、基础工程已是明显优势；但**四个证据缺口**决定下一阶段论文的强弱：

| 缺口 | 现状 | 优先级 |
|------|------|:---:|
| **强动态基线** | OR-Tools-RH、Dynamic HGS 仍是「待测」 | **最高** |
| **统计设计** | 5 训练种子对 paired Wilcoxon + Holm 数学上不够 | **最高** |
| **事件级在线评价** | Recourse Regret 已定义，但无完整 event-epoch 曲线 | **最高** |
| 冷链物理真实性 | 有模型，无实测/文献标定 | 高 |
| OOD/外部验证 | 100-node 已做，EURO/真实路网不足 | 高 |
| 新模型结构 | 非当前最该投入的方向 | 低 |

**核心策略**：冻结方法 → 强基线 → 事件级在线评价 → 统计加固 → 消融 → OOD → 冷链标定 → 论文图表。**不再堆新架构。**

---

## 1. 四个主假设（预注册）

为避免「动态 + 冷链 + 理论 + 速度 + 泛化」同时作为主创新，正式预注册四条：

$$H_1: \text{DynMaskCO 满足 future-invariance 与 prefix-invariance}$$

$$H_2: \text{Resource-state decoding 在测试域和 OOD 域维持近零硬约束违规}$$

$$H_3: \text{相同信息集和 wall-clock 下，DynMaskCO 在 cost-latency Pareto 上不被强 online baseline 支配}$$

$$H_4: \text{Online-sequence training 对可行条件下的纯距离成本产生可复现改善}$$

冷链品质/能耗改善作为**次级 hypothesis**，除非投稿前完成物理参数校准。

---

## 2. 优先级排序

$$\boxed{\text{在线对比有效性} > \text{统计证据} > \text{同预算成本} > \text{事件级 regret} > \text{OOD} > \text{冷链标定} > \text{网络微调}}$$

**最不值得做**：把 14.77 再微调到 14.5（边际收益极低）。
**最值得做**：一个能快速实现和审计动态 OR baseline 的工程/运筹协作者。

## 3. P0 任务（8/15–8/31，Go/No-Go 前必须完成）

### P0-1：统计协议升级（5 → 10 训练种子）🔴 训练完成, 评估遇阻

**问题**：5 个配对重复的双侧 exact Wilcoxon 最极端 p 值只有 $p_{min} = 2/2^5 = 0.0625$，即使 5/5 种子全部同方向也**无法达到 $p<0.05$**。

**行动**：
- [x] 新增 5 个训练种子（seed 100/200/300/400/500，总 10）✅ 已训练完成 (2026-08-15)
- [ ] 10-seed 统计评估 ⚠️ **遇阻**：`run_method_freeze.sh eval` 在第一个 eval 后 `set -e` 触发退出（报错被 `OUT=$(...)` 吞掉）。手动跑单 eval 成功（不是 GPU/checkpoint 问题）。**明天修复**：给 eval 循环加容错（去掉 set -e 或 grep 空结果保护）
- [ ] 报告 effect size（Cliff's delta），不只看 p 值

> 10-seed 的 paired Wilcoxon 最小 p 值 = $2/2^{10} = 0.00195$，**首次在数学上能通过 $p<0.05$**。

| 变体 | 改动 | 主要问题 |

## 6. Go/No-Go 标准（从「完成多少项」改为「证据门槛」）

| 维度 | Go | Conditional Go | No-Go / 改叙事 |
|------|-----|----------------|---------------|
| 因果正确性 | 所有 future-invariance 回归 0 泄漏 | 极小数值差可解释 | 任何稳定 future leakage |
| 硬可行性 | IID + 至少一个 OOD 近满可行 | IID 满、OOD 轻微下降 | OOD 大面积失效 |
| 在线基线 | 至少实用预算上 Pareto 非支配 | 成本略差但显著更快 | 同预算被强 online solver 全面支配 |
| 统计 | ≥10 seed 核心比较 + paired CI | 5–8 seed 但效应极强 | 仅汇总均值，无配对原始结果 |
| 消融 | 核心模块贡献清楚 | 个别结果 null | 无法解释 100% feas 来源 |
| 外部验证 | EURO/OOD 至少一项 | 仅 100-node | 完全只有原 generator |
| 冷链 | 有参数依据/敏感性分析 | 降为 application | 把任意常数包装成真实物理 |
| 复现 | 单一 canonical command + commit + raw table | 少量手工步骤 | 主结果无法从冻结脚本复现 |

## 7. 风险与缓解（关键项）

| 风险 | 缓解 |
|------|------|
| 强 online baseline 优于 DynMaskCO | 不隐瞒；重新定位为「低延迟可行构造/representation」而非在线 SOTA |
| 公平协议不一致 | 共享 event object；单一 evaluator；protocol unit test |
| 5-seed 统计不足 | 补至 10–12 seeds；重视 effect CI |
| 测试集调参（researcher degrees of freedom） | 立即建立 validation/test freeze；参数只在 validation 上选 |
| cost 语义再次漂移 | evaluator 统一从 route 重新计算纯距离 |
| 配置漂移 | 单一 manifest + commit SHA |
| GPU/SSH 中断 | tmux + checkpoint + 自动 resume + hash |

## 1. 论文最终定位

### 1.1 冻结主线

> **DynMaskCO: Causal and Feasibility-Preserving Masked Reconstruction for Online Constrained Vehicle Routing**

核心科学问题：

> **在未来请求不可见、已执行路径不可修改、硬资源约束必须满足的在线车辆路径问题中，如何利用 masked reconstruction 进行快速、局部且严格非预知的重优化？**

### 1.2 从 "MaskCO applied to DCC-VRP" → "新的 masked reconstruction paradigm"

| 旧叙事 | 新叙事 |
|------|------|
| MaskCO + Dynamic Feature + EDD Repair + 冷链特征 | **Online non-anticipatory state + irreversible prefix + event-local reconstruction + resource-state feasibility** |
| 加 feature 的工程扩展 | **MaskCO/NEXCO/LMask 都没有同时解决的三个问题** |

### 1.3 只保留三个核心贡献

**贡献 A：Causal Event-Conditioned Masked Reconstruction**

在事件时刻 e，只依赖 filtration F_e；新订单到达后只定位受影响的 mutable suffix，不重新生成全部路线。

**贡献 B：Feasibility-Preserving Resource-State Decoding**

将时间、容量、车辆状态作为显式资源状态，在 mask reconstruction 的生成过程中直接剪除非法动作，而不是生成后再 EDD 修复。

**贡献 C：Commitment-Aware Anytime Reoptimization**

已执行的路线严格冻结；未执行部分按事件强度、slack、置信度和计算预算局部重构，形成 quality–latency Pareto frontier。

**冷链降级**为：*"A multi-resource, physically grounded stress-test application."*

## 3. P1 方法形式化 — 理论闭环 ✅ 已完成 (2026-08-14)

> **完整理论文档**：`docs/调研/GPT/v3/P1_理论形式化.md` — 含符号表、严格定义、3 个命题 + 1 个定理的完整证明、以及定理与代码机制的对应关系表。

本节为大纲版本，完整证明见上述文档。核心形式化结果：

- 定义：Non-anticipatory online masked reconstruction（非预知在线掩码重构）
- 命题 1：Future-invariance（未来不变性）— 4 条假设 (A1-A4) + 5 步证明
- 命题 2：Frozen-prefix invariance（冻结前缀不变性）— 归纳证明
- **定理：Resource-state feasibility preservation（可行性保持，最核心）** — 对路线长度归纳
- 命题 3：Anytime incumbent monotonicity（随时单调性）— 情形分析

### 3.1 Non-anticipativity 定义与命题

**定义**（Filtration）：

$$\mathcal F_e = \sigma(\text{orders revealed by }e, \text{vehicle states}, \text{executed actions}, \text{known exogenous info})$$

策略必须满足：

$$a_e \sim \pi_\theta(\cdot \mid \mathcal F_e)$$

**命题 1（Future-invariance）**：

若 ① 未揭示请求的属性不进入 encoder/decoder、② padding/dummy encoding 与未来请求数量无关、③ 所有计算仅依赖 F_e、④ random seed 固定，则任意两个在 F_e 上相同的 future realization ω, ω' 满足：

$$p_\theta(a_e \mid \omega) = p_\theta(a_e \mid \omega')$$

**证明思路**：从计算图出发。encoder output → F_e-measurable；masked adjacency + resource state → F_e-measurable；decoder kernel 只依赖这些变量 → distribution 与 F_e 之外的变量条件独立。

### 3.2 Frozen Prefix 保持命题

**定义**：P_e = (v_0, ..., v_{k_e}) — 已执行前缀；S_e = (v_{k_e+1}, ...) — 可修改后缀。

mask support：M_e ∩ E(P_e) = ∅。

**命题 2（Prefix invariance）**：

若 reconstruction operator 只能修改 M_e 中的边，则任意数量的 mask-and-reconstruct cycles 后：

$$P_e^{(k)} = P_e^{(0)}, \quad \forall k$$

**证明**：直接 induction。

### 3.3 Resource-State Feasibility 定理

**定义**：Beam State z = (i, t, q, Θ, V, c)。状态转移 z' = T(z, j)。

Admissible action set：

$$\mathcal A(z) = \{j: j \text{ revealed & unserved}, q+d_j \le Q, t'_j \le b_j, \text{return-to-depot feasible}\}$$

**定理（Feasibility preservation）**：

若初始 depot 状态可行、每一步 j∈A(z)、depot reset 正确、terminal 返回 depot 满足，则完整路线满足所有被 admissible operator 显式检查的硬约束。

**证明**：对 route length 归纳。

### 3.4 Anytime Incumbent 单调性

**命题 3（Anytime monotonicity）**：

若只在 J(x') < J(x) 且 x' ∈ X_feasible 时替换 incumbent → J(x^{(k+1)}) ≤ J(x^{(k)})。

### 3.5 最低验收线

顶会版本至少出现：
- Definition: Non-anticipatory online masked reconstruction
- Proposition 1: Future-invariance
- Proposition 2: Frozen-prefix invariance
- **Theorem: Resource-state feasibility preservation**（最核心）
- Proposition 3: Anytime incumbent monotonicity

| Service | Service rate、Unserved/Late requests |
| Dynamic quality | Conditional Recourse Regret、Clairvoyance gap、replan frequency |
| Routing | distance、vehicles used |

| Anytime | objective vs 50/100/250/500/1000ms |

| Reliability | failure rate、worst-group performance |

### 5.3 Conditional Recourse Regret（新增核心指标）

在事件 e，所有方法已执行相同的 committed prefix P_e。让 clairvoyant solver 在**不允许修改 P_e** 的条件下看到剩余真实未来：

$$R_e^{rec} = J_e^\pi - J_e^*$$

回答：**"过去已经不可改变，从现在开始，我的在线重规划距离知道未来的最好补救方案还有多远？"**

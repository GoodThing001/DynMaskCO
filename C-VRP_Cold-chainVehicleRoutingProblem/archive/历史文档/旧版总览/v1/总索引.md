## 论文定位（2026-09-01 更新：HFR-M0 F3 → cost-aware preference）

> **核心研究问题**：研究掩码生成范式如何从静态组合优化扩展到动态冷链车辆路径问题中的因果、可行性保持在线优化。
> *"DynMaskCO investigates how masked generation can be extended from static combinatorial optimization to causal, feasibility-preserving online optimization for dynamic cold-chain vehicle routing."*

**方法主线演进**：双 head（JF2，exact-vehicle CE No-Go）→ **HFR-M0（Hierarchical Fleet–Route，已实现但 Gate A FAIL/F3）** → **Cost-Aware Joint Fleet–Route Preference Learning**（下一步）。

```text
（下一步）Causal MaskCO Encoder → H = {h_i}
        ├── Grouping representation G   （保留，HFR-M0 证明对 partition 有正价值）
        └── Utility Preference Head     → s_θ(a)，a = (route slot, insertion position)
                                         Q_θ(a | F_e, G, A, FleetState) ≈ −ΔJ(a)
```

> HFR-M0 结论（F3）：structural imitation（CE 模仿 OR adjacency）≠ online utility。G 对 partition 有正价值，但 route 结构监督无 online utility。下一步监督目标从「像不像 OR 结构」改为「这个联合 recourse action 最终省多少 cost」。

**三层贡献（v4.0 重构）**：
1. **Contribution I：Causal Dynamic Masked Reconstruction**（feature gating + visible-only normalization + visibility attention + causal decoder context）
2. **Contribution II：Fleet-State Conditioned Masked Recourse**（新增 Fleet Assignment Head，决策粒度从 edge ordering → vehicle-request assignment）
3. **Contribution III：Feasibility-Preserving Joint Fleet Search**（frozen prefix + committed invariant + mutable ownership release + joint assignment + resource beam + service-first guard）

> 冷链（quality/energy）作为后续可选贡献（Contribution VI），建立在前三层之后。详见 [`动态冷链物流路径优化完整全流程方案`](../../优化历程/v2/严格以MaskCO为基准_动态冷链物流路径优化完整全流程方案_v4.0.md)。

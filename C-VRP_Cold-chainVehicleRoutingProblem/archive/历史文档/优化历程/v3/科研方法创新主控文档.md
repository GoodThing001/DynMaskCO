# 1. 项目的核心研究问题重新定义

## 1.1 不能再把问题写成“给 MaskCO 加一个 Fleet Head”

如果最终论文只写：

> “我们在 MaskCO Encoder 后增加一个 MLP Fleet Assignment Head。”

创新强度是不够的。

真正的方法问题应该定义为：

\[
\boxed{
\text{如何把 Static MaskCO 的 edge-level masked reconstruction，}
\text{扩展为 permutation-aware、fleet-state-conditioned、}
\text{feasibility-preserving 的动态多车辆 masked recourse？}
}
\]

这里包含四个新的科学困难：

1. **Causality**：未来订单不能影响当前表示与动作。
2. **History immutability**：served / committed 历史不能被 reconstruction 改写。
3. **Fleet ownership**：动态多车的主要自由度不是只排 route order，而是 customer partition / ownership。
4. **Permutation symmetry**：同质车辆 ID 本身没有语义，不能把任意 ID 当成 one-hot 真值监督。

第 4 点就是 2026-09-01 新发现带来的重要升级。

# 2. 当前最重要的新科学发现：Fleet Assignment 实际上是“带对称性的 Partition”

## 2.1 为什么 raw exact vehicle label 会失败

在 canonical benchmark 中，大量车辆处于：

```text
idle @ depot
same ready_time
same load
same capacity
same status
same location
same route history
```

这些车辆在当前决策状态下是可置换的。

设车辆置换为：

\[
\pi: \{1,\ldots,K\}\to\{1,\ldots,K\}
\]

若两辆车状态完全等价，则：

\[
FleetState(\pi(k))=FleetState(k)
\]

且交换它们的物理 ID 不改变问题目标：

\[
J(x)=J(\pi(x))
\]

因此 OR-joint 输出：

```text
customer j -> vehicle 3
```

而 min-travel / 另一次 OR 输出：

```text
customer j -> vehicle 17
```

并不一定代表决策冲突。

如果 3 和 17 都是完全等价 idle@depot 车辆，则这只是：

\[
\boxed{label\ permutation\ ambiguity}
\]

而不是：

\[
\boxed{decision\ disagreement}
\]

这解释了 M0-v1：

```text
raw one-hot exact vehicle CE
→ disagreement top-1 = 3.9%
→ 接近 25 车随机猜测 4%
```

这不是简单的“模型学不会”，而是监督目标本身违反了车辆置换对称性。

# 3. 对“partition vs vehicle identity”的正式判断

## 3.1 正确 framing：不是纯 grouping，也不是 raw vehicle ID

后续不要简单把 JF2 改名为“customer grouping”然后彻底放弃 vehicle state。

更严谨的研究对象是：

\[
\boxed{
\text{Permutation-aware Fleet Ownership / Partition}
}
\]

原因：

### 对 idle@depot 同质车辆

具体 vehicle ID 没意义。

模型真正要决定的是：

> 哪些客户应该进入同一个未来 route / route slot。

这是 partition / grouping。

### 对 ready / committed / heterogeneous-state vehicles

具体 vehicle state 有意义，因为：

```text
anchor node 不同
ready time 不同
load 不同
committed future anchor 不同
existing suffix 不同
TW opportunity 不同
```

此时 customer 属于哪辆“非等价车辆”会直接影响 cost 和可行性。

因此 JF2 的最终科学定义应是：

> **在车辆置换对称性下学习 customer-to-fleet-slot ownership；对状态等价车辆只学习等价类/route partition，对状态不等价车辆学习 state-conditioned ownership。**

# 4. 建议升级后的方法名称与概念

当前“Fleet Assignment Head”可以保留作为代码名，但论文方法层建议升级为：

## 4.1 Fleet-State Conditioned Masked Partitioning

或：

## 4.2 Permutation-Aware Fleet Masked Recourse

或更完整：

## 4.3 Hierarchical Fleet–Route Masked Reconstruction

其中：

### Fleet-level structure

定义 ownership matrix：

\[
O_{kj}=\mathbb 1[j\text{ belongs to fleet slot }k]
\]

### Route-level structure

保留 MaskCO adjacency：

\[
A_{ij}=\mathbb 1[(i,j)\text{ is a route edge}]
\]

动态解结构可写为：

\[
X=(O,A)
\]

DynMaskCO 的目标从原始：

\[
Mask(A)\to Reconstruct(A)
\]

扩展为：

\[
\boxed{
Mask(O,A)\to Reconstruct(O,A\mid\mathcal F_e,FleetState_e)
}
\]

这是后续最值得发展的统一理论表达。

# 5. 当前科研创新主线

## Contribution I — Causal Dynamic Masked Reconstruction

解决：Static MaskCO 默认完整实例可见，不满足动态 non-anticipatory。

核心机制：

- future feature gating；
- visible-only normalization；
- visibility-gated attention；
- causal decoder context；
- visible route projection；
- visible-only objective。

形式化：

\[
a_e\sim\pi_\theta(\cdot\mid\mathcal F_e)
\]

这部分已有 Future-Invariance 理论与 blocking tests，是当前最稳定的贡献。

---

## Contribution II — Permutation-Aware Fleet-State Masked Recourse

解决：原 MaskCO edge decoder 只回答：

\[
i\to j
\]

不能回答动态 fleet ownership：

\[
\text{fleet slot }k\leftarrow j
\]

新的关键不是“多了一个 MLP”，而是决策空间从：

\[
\text{route-edge space}
\]

扩展为：

\[
\text{fleet partition/ownership space}
\]

并显式处理 vehicle permutation symmetry。

---

## Contribution III — Feasibility-Preserving Joint Fleet Reconstruction

神经 preference 不是 feasibility certificate。

因此 neural reconstruction 之后必须投影/搜索到：

\[
\mathcal X_F
\]

即 hard-feasible solution space。

核心：

- frozen prefix；
- committed-leg invariance；
- mutable ownership release；
- sound candidate set；
- per-vehicle resource-feasible sequencing；
- exact-once；
- service-first guard。

# 6. Residual architecture 的科研解释

当前：

\[
S(k,j)=S_H(k,j)+\alpha r_\theta(k,j)
\]

不要只解释成“方便训练”。

更好的解释是：

\[
\boxed{
S_H=Local\ Transport\ Prior
}
\]

\[
\boxed{
r_\theta=Global\ Fleet\ Opportunity\ Correction
}
\]

其中 JF1-H 解决：

> 谁离 customer 最近？

MaskCO residual 解决：

> 什么时候最近车并不是全局正确选择？

例如：

- 最近车对另一个稀缺客户是唯一可用车；
- committed 后的 future anchor 很差；
- TW slack 的机会成本很高；
- route partition 形成错误 cluster；
- 当前局部近距离导致未来 route fragmentation。

因此 residual 是一个具有明确机制假设的结构，不只是 optimization trick。

# 7. 对 1866 个“真实分歧”的正确理解

## 7.1 3.3% 很少，不等于作用很小

不能根据：

```text
real disagreement = 3.3%
```

直接推断：

> JF2 最多只能改善很小。

原因是在线 VRP 的 decision leverage 高度不均匀。

一个早期错误 ownership 决策可能改变：

- route partition；
- 后续所有 anchor；
- 车辆是否提前关闭；
- 后续可服务集；
- future customer 的 feasible vehicle count。

因此少量 decision 可以占据大量 total regret。

真正应该测的是：

\[
\boxed{
Regret\ Mass
}
\]

而不是：

\[
\boxed{
Disagreement\ Count
}
\]

# 8. 新增一个必须做的科学诊断：Regret Mass Decomposition

对每个真实非等价 disagreement：

\[
(k^*,j)
\]

以及 JF1-H 选择：

\[
(k_H,j)
\]

计算：

\[
R_j=J(k_H\leftarrow j)-J(k^*\leftarrow j)
\]

建议输出：

```text
mean regret
median regret
p90/p95/p99 regret
sum regret
Top-1% / Top-5% / Top-10% disagreement 占总 regret 的比例
按 event progress 的 regret mass
按 state type 的 regret mass
```

如果发现：

```text
1866 个真实 disagreement
其中 top 10% 贡献 70% total regret
```

则 JF2 有非常明确的“少数高杠杆决策”研究故事。

反之，如果每个真实 disagreement 的 regret 都极小，则应该转向 partition-level / route-level objective，而不是继续优化 exact choice accuracy。

# 11. Canonicalization 的地位：临时修复，不应是最终创新

当前“映射到最小 vehicle id”的 canonicalization 已经证明 symmetry 是 M0-v1 null 的根因，这个诊断非常有价值。

但它有一个科研风险：

\[
\boxed{min\ id\ 是人为编号，不是问题结构}
\]

如果把 vehicle ID 全随机 permutation：

```text
vehicle 0 ↔ 17
vehicle 2 ↔ 9
...
```

一个真正 permutation-equivariant 模型的输出只应该相应 permutation，最终 cost 不应变化。

而 min-id canonicalization 会人为偏好小 ID。

因此最终建议逐步升级成：

1. **equivalence-class loss**；
2. **permutation-equivariant fleet head**；
3. **route-slot / class-level partition**。

# 12. 推荐的下一代 symmetry-aware objective

## 12.1 Set-valued / equivalence-class CE

若 teacher 所选车辆属于等价集合：

\[
E_j=\{k_1,k_2,\ldots\}
\]

不应该要求唯一：

\[
y_j=k_1
\]

而应该最大化整个等价集合的 probability mass：

\[
\boxed{
L_{sym}(j)
= -\log\sum_{k\in E_j}P(k\mid j)
}
\]

优点：

- 不引入 min-id 偏置；
- 完全匹配 vehicle permutation symmetry；
- 数据不需要删除 95%“对称分歧”；
- 网络只需把概率放在正确等价类。

---

# 13. 推荐的非等价 decision objective

对真实非等价 disagreement：

\[
E_j=\{k^*\}
\]

可继续 exact CE，但后续更建议：

\[
L_{pref}
=-w_j\log\sigma((S_{k^*j}-S_{k^-j})/\tau)
\]

其中：

\[
w_j=f(Regret_j)
\]

即高 downstream regret 的选择拥有更高训练权重。

最终可形成：

\[
\boxed{
L_{fleet}
= L_{sym-set}
+ \lambda_p L_{regret-pref}
}
\]

这比 raw one-hot CE 更符合问题结构。

# 14. 更强的结构创新：Route Slot / Fleet Slot

如果 Gate A 证明 vehicle-level M0 有用，但提升有限，可进入真正的 partition formulation。

定义 fleet slot：

```text
existing active route slot
existing committed route slot
idle/new-route slot(s)
```

对等价 idle@depot 车，不把 20 个相同 vehicle ID 作为 20 类分类，而是：

```text
NEW_ROUTE / idle class
```

或者保留多个 anonymous route slots，并用 permutation-equivariant matching。

这样模型真正学习：

> customer j 应该并入哪个现有 route，还是开启新的 route？

这比：

> customer j 应该去 vehicle id 17 还是 id 3？

更接近 B0 所揭示的 fleet gap 本质。

# 15. Hierarchical Fleet–Route Reconstruction 的长期版本

建议最终方法演进：

```text
Causal MaskCO Encoder
        │
        ├──────── Fleet Partition Decoder
        │           ↓ ownership / route slot
        │
        └──────── Route Reconstruction Decoder
                    ↓ within-route edge structure

Fleet partition
      ↓
Route reconstruction
      ↓
Feasibility projection/search
      ↓
Strict-online commit
```

可写成概率分解：

\[
P(O,A\mid\mathcal F_e)
=
P(O\mid\mathcal F_e)
P(A\mid O,\mathcal F_e)
\]

其中：

- \(O\)：fleet ownership / partition；
- \(A\)：route adjacency。

这个统一表达是后续最值得发展的论文方法核心。

建议写成：

### Problem 1
Static MaskCO violates dynamic information boundaries.

→ Causal Dynamic Masked Reconstruction.

### Problem 2
Dynamic fleet recourse is dominated by ownership/partition rather than intra-route sequencing.

→ Fleet-State Conditioned Masked Recourse.

### Problem 3
Homogeneous fleet labels are permutation-symmetric; raw exact-vehicle supervision is ill-posed.

→ Permutation-Aware Fleet Partition Learning.

### Problem 4
Neural reconstruction does not certify hard feasibility.

→ Feasibility-Preserving Joint Reconstruction.

这条叙事比“加 Fleet Head”强很多。

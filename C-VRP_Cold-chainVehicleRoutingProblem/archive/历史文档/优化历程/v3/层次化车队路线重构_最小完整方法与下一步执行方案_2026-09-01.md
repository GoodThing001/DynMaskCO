# 8. 为什么第一版使用 Pairwise Grouping G，而不是直接显式 O

定义：

\[
G_{ij}
=
\mathbf 1[i,j\text{ belong to same route}]
\]

其优势：

1. 不依赖 physical vehicle ID；
2. permutation invariant；
3. 天然消除 idle@depot symmetry；
4. 与 MaskCO 原本的 pairwise edge relation 非常接近；
5. 不需要 Hungarian matching；
6. 不需要 slot permutation loss；
7. 实现简单；
8. 很适合作为 HFR-M0 的最小科研探针。

MaskCO 的 fine relation：

\[
A_{ij}
=
\mathbf 1[i\rightarrow j\text{ adjacent in route}]
\]

HFR 的 coarse relation：

\[
G_{ij}
=
\mathbf 1[i,j\text{ same route}]
\]

形成：

\[
\boxed{
G_{ij} \rightarrow A_{ij}
}
\]

即：

> coarse fleet topology → fine route topology。

并有结构约束：

\[
\boxed{
A_{ij}=1\Rightarrow G_{ij}=1
}
\]

# 10. 第一版最重要的修改：A 必须显式依赖 G

错误架构：

\[
G=f_G(H)
\]

\[
A=f_A(H)
\]

再简单：

\[
L=L_G+L_A
\]

这仍然接近：

\[
P(G,A)\approx P(G)P(A)
\]

不符合 2×2 oracle 揭示的 interaction。

第一版必须实现：

\[
\boxed{
A^{joint}=f(A^{MaskCO},G)
}
\]

建议：

\[
p^G_{ij}=\sigma(g_{ij})
\]

\[
B^G_{ij}=\log(p^G_{ij}+\epsilon)
\]

\[
\boxed{
A^{joint}_{ij}
=
A^{base}_{ij}
+
\Delta A_{ij}
+
\beta B^G_{ij}
}
\]

其中：

- \(A^{base}\)：原 MaskCO route logits；
- \(\Delta A\)：trainable RouteResidualAdapter；
- \(B^G\)：same-route soft bias。

# 12. Grouping Head 代码设计

新增：

```text
scripts/models/hierarchical_fleet_route.py
```

## 12.1 G 必须对称

因为：

\[
G_{ij}=G_{ji}
\]

不要直接：

```python
MLP(concat(h_i, h_j))
```

推荐对称 pair feature：

\[
\phi_{ij}
=
[h_i+h_j;
|h_i-h_j|;
h_i\odot h_j]
\]

示意：

```python
class GroupingHead(nnx.Module):
    def __init__(self, d_model=256, hidden=256, rngs=None):
        self.fc1 = nnx.Linear(3 * d_model, hidden, rngs=rngs)
        self.fc2 = nnx.Linear(hidden, hidden // 2, rngs=rngs)
        self.out = nnx.Linear(hidden // 2, 1, rngs=rngs)

    def __call__(self, H):
        # H: [B, N, D]
        hi = H[:, :, None, :]
        hj = H[:, None, :, :]

        phi = jnp.concatenate([
            hi + hj,
            jnp.abs(hi - hj),
            hi * hj,
        ], axis=-1)

        x = nnx.silu(self.fc1(phi))
        x = nnx.silu(self.fc2(x))
        logits = self.out(x)[..., 0]

        # enforce numerical symmetry
        logits = 0.5 * (
            logits + jnp.swapaxes(logits, 1, 2)
        )

        return logits
```

# 13. Grouping loss：必须处理正负 pair 不平衡

同一路线 positive pair 通常远少于 different-route negative pair。

禁止只用 raw BCE + raw accuracy。

否则模型可能全部预测：

```text
different route
```

accuracy 仍然看起来很高。

第一版采用 balanced BCE：

\[
L_G
=
-\frac12 E_{positive}\log p
-\frac12 E_{negative}\log(1-p)
\]

代码：

```python
def balanced_group_loss(logits, target, pair_mask):
    pos = pair_mask & (target > 0.5)
    neg = pair_mask & (target < 0.5)

    log_p = jax.nn.log_sigmoid(logits)
    log_1mp = jax.nn.log_sigmoid(-logits)

    pos_loss = -jnp.sum(
        jnp.where(pos, log_p, 0.0)
    ) / jnp.maximum(pos.sum(), 1)

    neg_loss = -jnp.sum(
        jnp.where(neg, log_1mp, 0.0)
    ) / jnp.maximum(neg.sum(), 1)

    return 0.5 * pos_loss + 0.5 * neg_loss
```

训练指标：

- positive F1；
- AUPRC；
- balanced accuracy；
- AUROC。

**不要把 raw accuracy 当核心指标。**

# 14. RouteResidualAdapter

Route 是有方向的，因此 pair feature 不需要对称。

建议：

```python
class RouteResidualAdapter(nnx.Module):
    def __init__(self, d_model=256, hidden=128, rngs=None):
        self.fc1 = nnx.Linear(
            2 * d_model + 1,
            hidden,
            rngs=rngs,
        )
        self.out = nnx.Linear(hidden, 1, rngs=rngs)

    def __call__(self, H, group_logits):
        hi = H[:, :, None, :]
        hj = H[:, None, :, :]

        p_same = jax.nn.sigmoid(group_logits)[..., None]

        hi_full = jnp.broadcast_to(
            hi,
            (*group_logits.shape, H.shape[-1])
        )
        hj_full = jnp.broadcast_to(
            hj,
            (*group_logits.shape, H.shape[-1])
        )

        phi = jnp.concatenate([
            hi_full,
            hj_full,
            p_same,
        ], axis=-1)

        x = nnx.silu(self.fc1(phi))
        return self.out(x)[..., 0]
```

# 15. HierarchicalFleetRouteModel Wrapper

不要修改原 MaskCO checkpoint 参数树。

继续 wrapper-first。

概念代码：

```python
class HierarchicalFleetRouteModel(nnx.Module):
    def __init__(self, base_maskco, rngs):
        self.base = base_maskco
        self.group_head = GroupingHead(
            d_model=256,
            rngs=rngs,
        )
        self.route_adapter = RouteResidualAdapter(
            d_model=256,
            rngs=rngs,
        )

    def __call__(
        self,
        raw_features,
        visible_mask,
        partial_adj,
        timestep,
    ):
        H = self.base.encode(
            raw_features,
            visible_mask=visible_mask,
        )
        H = jax.lax.stop_gradient(H)

        G_logits = self.group_head(H)

        # 这里应复用项目中现有 MaskCO route decoder 调用链
        A_base = self.base.route_logits(
            H,
            partial_adj,
            timestep,
        )
        A_base = jax.lax.stop_gradient(A_base)

        delta_A = self.route_adapter(H, G_logits)
        group_bias = jax.nn.log_sigmoid(G_logits)

        A_joint = A_base + delta_A + group_bias

        return {
            "group_logits": G_logits,
            "route_logits_base": A_base,
            "route_logits_joint": A_joint,
        }
```

注意：

> `route_logits()` 只是接口示意，真正实现必须复用当前项目现有 decoder / feature2logit 调用，不要重新写第二套 MaskCO decoder。

# 17. 最关键训练原则：L_route 必须作用于 A_joint

错误：

```python
L_route = route_loss(A_base, A_target)
```

这样：

\[
\frac{\partial L_A}{\partial G}=0
\]

G 与 A 仍然是独立的。

正确：

```python
L_route = route_loss(
    A_joint,
    A_target,
    route_mask,
)
```

因为：

\[
A_{joint}=A_{base}+\Delta A+f(G)
\]

所以：

\[
\frac{\partial L_A}{\partial G}\neq0
\]

这才是真正的：

\[
\boxed{
\text{joint supervision}
}
\]

# 32. Route Affinity：让 assignment 真正依赖 sequencing

\[
\boxed{

这是 HFR inference 最重要的 joint coupling：

# 39. HFR Replanner 伪代码

```python
def replan(state):

    # 1. strict-online visible information
    visible = get_visible(state)
    mutable = get_mutable(state)

    # 2. route slots
    slots, idle_pool = build_slots(state)

    # 3. hierarchical MaskCO predictions
    outputs = hfr_model(...)
    G = outputs["group_logits"]
    A = outputs["route_logits_joint"]

    # 4. joint slot assignment
    unresolved = []

    for customer in frozen_jf1h_customer_order(mutable):

        candidates = sound_candidate_slots(
            customer,
            slots,
            idle_pool,
            state,
        )

        if not candidates:
            unresolved.append(customer)
            continue

        best_slot = choose_by_joint_GA_score(
            customer,
            candidates,
            G,
            A,
        )

        assign(customer, best_slot)

        if best_slot.kind == "new_route":
            instantiate_physical_vehicle_from_idle_pool(...)

    # 5. per-slot route reconstruction
    fleet_candidate = []

    for slot in slots:
        route = resource_beam(
            slot=slot,
            edge_logits=A,
            state=state,
        )
        fleet_candidate.append(route)

    # 6. repair unresolved
    fleet_candidate = repair_unresolved(
        fleet_candidate,
        unresolved,
        state,
    )

    # 7. service-first guard
    return service_first_guard(
        incumbent=state.incumbent,
        candidate=fleet_candidate,
    )
```

# 62. 从现在开始的开发原则

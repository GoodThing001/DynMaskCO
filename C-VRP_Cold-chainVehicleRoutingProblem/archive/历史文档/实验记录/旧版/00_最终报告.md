## 附录：指标与术语

| 指标 | 含义 | 好坏 |
|------|------|------|
| TW feas | 时间窗可行实例比例 | ↑ >90%优秀 |
| viol | 平均TW违反次数 | ↓ 0=完美 |
| gap | (cost-opt)/opt | ↓ 负=优于参考 |
| EDoD | 动态程度 | 0=静态, 0.5=中动态 |

| 术语 | 含义 |
|------|------|
| DCC | Dynamic Cold Chain |
| EDD | Earliest Due Date 排序修复 |
| ST-mask | Spatio-Temporal Masking (0.8x keep) |
| Self-Training | 模型生成伪标签→重新训练 |
| Temp Embedding | 温度可学习嵌入 (替代 spoilage_bias) |
| ALNS | Adaptive Large Neighborhood Search |

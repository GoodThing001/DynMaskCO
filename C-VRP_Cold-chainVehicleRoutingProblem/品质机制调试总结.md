# 冷链品质指标 (Num Unsalable) 调试总结

> **状态更正（2026-09-03）**：本文是 2026-08-18 的历史调试记录，不是当前权威实验结论。后续代码审计发现：预计算 quality、beam quality、最终路线 Num、`thermal_state.py` 与 strict-online trace evaluator 并非同一物理/时间/单位合同，且 execution-trace evaluator 曾固定返回 quality/energy=0。更关键的是，旧公式按“仓库到客户的完成时间”累计，偏向配送语义；v4 已依据现有 `load += demand` 状态机锁定为 pickup-to-depot，品质应按“取货完成到返仓卸货”的在途时间累计。因此“代码逻辑正确”“减少 96% 损耗”“品质感知有效”及旧排序方向均撤回为待 C0 重建的历史假设。当前口径见 [评估口径.md](docs/当前规划/评估口径.md) 与 [代码实现蓝图.md](docs/当前规划/代码实现蓝图.md)。

## 调试过程关键发现

### 1. 怀疑 dist_mat 有问题（之前输出 dist=0.0000）

**原因**: 早期 debug print 位置错误，在 `prev = node` **之后**打印，导致 `dist_mat[b, node, node]` = 自己到自己 = 0。

**验证**:
```python
# 修正后的 debug（在 prev 更新前保存）
dist_val = dist_mat[b, prev, node]
svc_val = service_time_batch[b, prev]
cum += dist_val + svc_val
```

**实际值**（正常）:
```
[DEBUG-DISTMAT] samples: [0,1]=0.3305 [0,2]=0.4313 [0,1,2]=0.4365
[DEBUG] node=1 prev=0 tc=0 cum=0.3305 dist=0.3305 svc=0.0000
[DEBUG] node=4 prev=1 tc=0 cum=1.3951 dist=0.6146 svc=0.4500
```

✅ **dist_mat 正常**（欧氏距离 0.3-0.6），**service_time 正常**（0.15-0.6），**累积正确**。

---

### 2. 为什么最终路线 Num 这么低（0.31）？

**关键观察**:
```
[DEBUG] b=0 num=1 valid_nodes=50 final_cum=2.1993
```

- `final_cum=2.1993`：最后一辆车的最后一个节点 cum_time = 2.2
- 常温阈值 = 2.02（quality_loss > 0.02 → cum_time > 2.02）
- **每辆车的 cum_time 都在 depot 重置**，所以 final_cum 只反映最后一辆车

**原因**: 解码后路线（search + 2-opt）**非常高效**：
- 贪心路线：~6 辆车，每辆 ~8 节点，cum_time/车 ~4 → 常温节点后半段不可售 → **8.10 个**
- 解码路线：~6 辆车，但**travel 更短**（2-opt 优化），cum_time/车 ~2 → 几乎不触发阈值 → **0.31 个**

**验证**: 每个 batch 的 num 值：
- batch 0: num=1（cum=2.2, 刚好超阈值）
- batch 1,2,3: num=0（cum < 2）
- batch 4: num=1
- ...

平均 0.31 = 跨 128 实例平均（大部分实例 num=0，少数 num=1-2）。

---

### 3. 为什么 beam 生成 Num 这么高（18.66）？

**原因**: beam 生成阶段用**模型 logits** 构造路线，未经 search + 2-opt 优化：
- beam 路线的 travel 更长（未优化）
- cum_time/车 更长（~4-5）
- 常温 + 部分冷藏节点都超阈值 → **18.66 个**

**search + 2-opt 的效果**: 18.66 → 0.31（减少 98% 损耗）

## 代码实现（最终版本）

**文件**: `C-VRP_Cold-chainVehicleRoutingProblem/scripts/decoding/cvrptw.py` (line 1233-1261)

```python
# 最终路线 Num：数据同款公式（quality_loss = 1 - exp(-K_TEMP·cum_time)）
final_unsalable = np.zeros(batch_size, dtype=np.float32)
if temp_class_batch is not None:
    K_TEMP_ = np.array([0.01, 0.002, 0.0002], dtype=np.float32)
    for b in range(batch_size):
        num, cum, prev = 0, 0.0, 0
        for x in sols[b]:
            node = int(x)
            if node == 0:
                cum = 0.0; prev = 0; continue  # depot 重置
            if node >= dist_mat.shape[1]:
                continue
            # 累积：travel + service（FROM 节点）
            dist_val = dist_mat[b, prev, node]
            svc_val = service_time_batch[b, prev]
            cum += dist_val + svc_val
            # 判断不可售
            k = K_TEMP_[min(int(temp_class_batch[b, node]), 2)]
            if 1.0 - np.exp(-k * cum) > quality_salable_threshold:
                num += 1
            prev = node
        final_unsalable[b] = num
```

**关键点**:
1. ✅ `dist_mat[b, prev, node]` 取 FROM→TO 距离（正确）
2. ✅ `service_time[b, prev]` 取 FROM 节点服务时间（与数据生成一致）
3. ✅ depot（node=0）重置 cum（每辆车独立累积）
4. ✅ 公式与数据生成 `generate_coldchain_data.py` 完全一致

## 历史假设及当前处理

### 当时观察：不同口径给出显著数值差异

| 方法 | Num/inst | vs 贪心 |
|------|:--------:|:-------:|
| **贪心参考** | 8.10 | - |
| **DynMaskCO** | 0.31 | **-96%** |

**当时解释（仅供追溯）**:
1. **search + 2-opt 的副作用**：优化距离（cost）的同时，**隐式优化了品质**（更短的 travel → 更短的 cum_time）。
2. **品质感知 beam（--enable_quality, lambda_q=0.1）的作用**：虽然 beam 生成阶段 Num=18.66（差），但为 search 提供了「可优化的初始解」，最终收敛到 0.31。

### 下一步实验（验证品质感知有效性）

1. **Lambda_q sweep**（0 → 0.1 → 0.5 → 1.0）：
   - lambda_q=0（无品质感知）：Num 应该回升（~1-2）
   - lambda_q=0.5/1.0（强品质感知）：Num 应该进一步降（~0.1 或 0）

2. **对比有无 --enable_quality**：
   - 关闭品质感知：Num 应该回升
   - 证明「品质感知 beam」不是摆设

3. **边特征变体（typed_edge）的效果**：
   - 卡0 训练中（USE_EDGE=1），跑完后对比 cost 和 Num
   - 预期：边特征提供能量信息 → 模型主动规避高能耗边 → Num 更低

## 当前结论

- 0.31、8.10 和 18.66 只说明旧实现中的三种统计口径不同，不能直接互相比出“减少 96%”。
- 必须先用唯一冷链状态转移，从 strict-online execution trace 重算 quality、energy 和 NumUnsalable。
- C0 需通过单位、温度单调性、trace parity、snapshot resume 和 distance regression。
- 之后用 distance-only、真实冷链目标、thermal removed/shuffled 和权重 sensitivity 才能判断品质改进是否来自冷链感知机制。

# A-v1 步骤 3 新协议：MaskCO 条件场景生成方法（2026-09-29 立，替代旧作废草案）

> 依据用户 09-29 裁定：论文主线 = **基于 MaskCO 的掩码生成与迭代重构范式，构建面向
> 动态冷链物流的在线优化方法**。本协议定义最小方法本体与正式训练/评估规则。
> **旧步骤 3 草案（一次前向、逐槽独立采样）不自动恢复**；正式训练在信息门重立后才启动。

## 1. 方法闭环（锁定）

可见历史与资源状态 → **MaskCO 表征** → **数量与联合未来场景建模** → **部分掩码迭代重构**
（多轮生成/保留/重掩码）→ **同下游接/拒决策**（共用 SAA 消费，生成可执行计划）→
**冻结承诺 + C0 硬认证** → 实际效用。

关键：迭代重构必须在部署中产生可测增益；仅借用预训练 encoder 不构成方法贡献。
这是 MaskCO 结构学习（参考解依赖）向「条件未来场景生成」的迁移，论文中明示该迁移。

## 2. 最小实现包（全部为正式训练前置交付）

1. **可变数量建模**：数量头 + 合法未来时间支持；数量不能在采样后靠丢弃过去 token 任意变化。
2. **部分掩码训练 + 迭代推理**：训练用部分掩码未来集合；推理按冻结可见历史、多轮
   生成/保留/重掩码推进；集合槽对称性、NULL 与计数联合分布逐一验证。
3. **PAD 与 MASK 分离**：注意力隔离 padding；每样本槽数与推理一致；连续需求严格服从
   需求桶 token 解码（不得越桶）。
4. **公开资源条件**：输入时钟与公开资源状态；区分总预算与剩余预算；未来需求分布不得
   被本方资源状态解释为外生需求变化。若做决策感知场景选择，显式区分「分布预测」与
   「价值导向选样」两目标。
5. **同架构公平对照**：同架构、同冻结状态的预训练/随机 encoder 对照（当前 EncoderMLP
   不是随机 CVRP encoder；冻结 hash 已实现但不取代架构公平）。
6. **资源状态来源**：历史需求切片无车队标签；资源条件若需要，用训练日**因果策略回放**
   采集（不引入开发/最终测试状态）。
7. **强非学习对比**：经开发选择的强条件历史采样器 + 读取当天可见前缀的显式预测器
   （当前 explicit_feat 仅按时钟取均值，强度不足，需强化后作为对比）。

## 3. 正式评估规则

- **前置门**：修订版同版配对（C1 reveal vs density）落盘裁决 + 稳健性复验 → 信息门
  重立后才启动训练评估。协议先立、运行后置。
- **主比较**：同下游、同 K、同时间预算下 `MaskCO − 最佳条件非学习` 按天配对，
  均值 ≥ δ₃=20 且 day-clustered bootstrap CI 下界 > 0 且 hard=1.0 且全日可裁决。
- **消融归因**：预训练/随机、单步/迭代、资源条件 三项消融；生成分布拟合改善与
  在线效用改善**分别展示**（拟合好 ≠ 在线好）。
- **训练预算**：≤3 个预声明配置；每配置假设+判据写死后运行。
- **数据纪律**：开发 20260926/20260930/20261001（已见，可反复）；最终测试
  20260927/28 只测一次，测前锁定权重/源码/合同/数据/时间与全部对照。
- **身份封存**：Q-04 严格版（源码启动+结束双读、完整 contract_hash、数据字节与
  shape/dtype 身份、共享配置核对）。

## 4. 交付顺序

1. 本协议（已立）→ 2. 信息门重立（修订版裁决 + 稳健性）→ 3. 最小本体实现 +
   不变式/单元测试（槽对称、NULL/计数联合、PAD/MASK 隔离、需求桶解码、因果可见边界）
   → 4. 开发评估（主比较 + 消融）→ 5. 稳健性复验 → 6. 锁定 + 唯一最终测试。

## 5. 边界

不因「想要正结果」改任务/合同/主档/δ/最终种子；分布拟合与在线效用分开报告；
失败尝试全部保留；未过前置门不启动训练评估。

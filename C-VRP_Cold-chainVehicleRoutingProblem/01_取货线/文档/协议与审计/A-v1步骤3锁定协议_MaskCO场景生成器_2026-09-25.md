# A-v1 步骤 3 锁定协议：MaskCO 条件场景生成器

日期：2026-09-25。性质：步骤 2 门判定 PASS（主表 cond−uncond +314.3 [239.7, 390.2]，独立核查一致）后进入本步骤。硬约束不变：MaskCO 为核心方法、不修改 `../MASKCO_code/`、采样器因果接口不变。

## 0. 前提（步骤 2 已验证）

可见状态中的条件信息经共用 SAA 下游（贪心插入 + 真实 C0 硬认证 + A-v1 效用）转化为真实效用增益（+314.3/天，δ\*=20 判据通过）。**但这只说明「条件信息有价值」，不是 MaskCO 的贡献**——本步骤训练 MaskCO 生成器，必须相对**条件历史采样强基线（cond_hist）**给出可验证增量。

## 1. 学习任务（锁定）

- **目标分布**：P(未来订单场景 | VisibleSnapshot)。场景 = 数量可变、可为空的未来订单集合（time / temp_class / 位置 / window），揭示时间晚于当前时钟。
- **离散 token 化**：时间桶 0.5h × 温区 3 × 空间桶 3（SPOT_CENTERS 最近桶）+ 需求桶（(1,2]/(2,3]）；**先采未来数量、再掩码生成订单 token**（避免固定槽 + null 主导）；连续坐标 = 离散桶 + 同桶历史经验扰动（两阶段，模型若赢再学连续残差）。
- **条件** = 步骤 2 的 `VisibleSnapshot`（可见订单 + 时钟 + 冻结车队 + 预算），与 cond_hist 用同一信息边界。

## 2. 模型与对照（锁定）

- **结构**：集合不变掩码条件生成器（**禁位置编码**）；生成头 = MaskCO 风格双向注意 + 掩码未来 token 重建（softmax 采样，MaskGIT 迭代去掩码，避免欠离散）。
- **三档编码器，共用同一生成头与训练预算**：
  - A = **预训练 MaskCO CVRP encoder**（`MASKCO_code/ckpts/cvrp100.ckpt`，512 维，冻结）+ 订单字段投影 adapter；
  - B = 随机同架构 encoder（同维度，随机权重，训练中可训）；
  - C = 显式特征 MLP（不经 encoder，投影快照特征 + 桶嵌入）。
- 部署为 `MaskCOScenarioSampler`，接口不变：`sample(snapshot, rng, k) -> list[FutureScenario]`；**隐藏未来不变性测试对训练后的采样器同样强制**（换测试日隐藏未来 → 采样输出不变）。

## 3. 训练（锁定）

- 数据 = 训练历史 200 天（seed **20260925**，与步骤 2 同）；**不含**门判定日（20260926）与论文测试日。
- 切片 = 按天内多决策时刻（0.5h 网格）构造 (可见状态, 掩码未来订单) 对；监督 = 掩码重建 CE（数量头 + token 头联合）。
- 预算：初始 **2000 steps × batch 8 × seed 42**；每档编码器同预算；服务器 GPU（共享机，`CUDA_VISIBLE_DEVICES=1`、预分配关闭）。
- **总训练运行次数 ≤ 3 次有限配置**（含修正）；每次改动必须预先声明假设与判据，防调参过拟合。

## 4. 评价与收门（锁定）

- 与步骤 2 **完全同口径**：K=10、每决策 10s、共用 SAA 下游、A-v1 效用、不筛天、按天配对 + day-clustered bootstrap CI。
- 开发/模型选择 = 门判定日 **seed 20260926（40 天，已查看，标为开发证据）**；**最终论文测试 = seed 20260927/20260928（未见，模型定稿前不碰）**。
- **主比较 = MaskCO − cond_hist**（条件历史采样强基线）按天配对效用差；**过门 = 均值 ≥ δ₃ = 20（A-v1 效用/天，与 δ\* 同量级 ≈ 一笔好订单）且 CI 下界 > 0**。
- 同时报告 MaskCO − explicit_feat 与 MaskCO − uncond_dynamic（外部强基线）；**只赢无条件门槛或显式特征不算 MaskCO 贡献**。
- 停止：主比较不过 → 收束本步骤（负结果兜底 `negative_result_paper/`），不无限加预算、不重开路线搜索。

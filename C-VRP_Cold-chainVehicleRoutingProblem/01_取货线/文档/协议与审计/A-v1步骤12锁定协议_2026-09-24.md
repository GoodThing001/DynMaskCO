# A-v1 步骤 1–2 锁定协议：方法定义 + 无训练条件信息门

日期：2026-09-24。性质：用户裁定，交接执行端的一页锁定协议。硬约束不变：MaskCO 为核心方法、冷链为领域、不修改 `../MASKCO_code/`。

## 0. 背景与归因边界（锁定措辞）

- A-v1 正式表（train=200/test=40）：rolling − uncond_dynamic = **−0.99 [−11.11, +8.40]**（CI 跨零），rolling 慢 ~1.8×；1s/10s 两档结果相同。叠加旧任务「两客户交换无整体收益」「搜索增强收束」的连续负证据 → **停止加强路线/局部搜索**，保留现有 rolling 作为已实现对照即可。
- **归因边界**：rolling 实现同时改变接单组合、插入与尾部路线，正式配对**未单独隔离 relocate/swap**；且汇总无逐事件超时记录。论文措辞定为「**当前滚动搜索方案未带来可检测的终局增益**」，**不写**「局部搜索已被普遍证明无用」「每次搜索都未触及时限」。

## 1. 方法定义（统一，锁定）

- 冲突：状态入口曾写「重构未执行的接单/路线决策」，Step3 设计写「生成未来订单场景」——这是两种学习职责。路线搜索已无净收益，故 **MaskCO 不再承担路由/局部搜索职责**。
- **锁定定义**：MaskCO = 每次揭示后，条件于「可见订单多重集 + 时钟 + 冻结车辆状态」，**掩码生成未来订单场景**（数量 + 每单 time / temp_class / location / window）；迭代重构后采样 K 个场景做随机前瞻（SAA）。
- **共享下游**：所有臂（含 MaskCO）共用同一套「接单评分 + 路由器（贪心插入）+ C0 认证器（`certify_plan`）+ A-v1 效用（收入 − 燃油 − 拒绝损失）」，区别**只在场景信息来源**——终局效用差可归因于信息源，而非路由/搜索能力。
- 论文贡献落点 = 「**条件掩码重构带来的可验证决策增量**」，不是「首次使用未来场景」（Bent & Van Hentenryck 2004 等已存在）。

## 2. 无训练条件信息门（第 2 步，暂不训练）

在**完整 A-v1 评价器**上重验「条件信息有价值」：相同下游决策器、相同场景数 K、相同在线预算。三臂按天配对：

1. **无条件历史场景**（uncond bootstrap）：从历史日无差别重采样未来订单场景（数量+字段），SAA 决策。
2. **条件历史场景**（cond bootstrap，强基线）：按当前可见状态（早期订单数量/温区/位置/时钟）选相似历史日，重采样其未来段，SAA 决策。
3. **显式特征预测器**：用可见状态显式特征回归未来订单字段（数量/分温区计数/位置桶），构造分布后 SAA 决策。

**注意**：现有 `uncond_dynamic` 只用历史算一个「未来预算门槛」，**不是完整场景采样对照**；早期简化头腔（A 工作包 ②）与 A-v0 计数匹配负结果，均**不能代替**本次完整协议检验。

**门判定（主比较 + 第二比较，锁定）**：
- **主比较 = 条件历史场景 − 无条件历史场景**（臂 2 − 臂 1）按天配对效用差。**过门 = 主比较 CI 严格为正且幅度 ≥ 预设阈值 δ\***（δ\* 运行前写死，不事后挑）。
- 显式特征预测器（臂 3）作**第二比较**，单独报告，不并入过门判据（避免「臂 2 或 3 任一过」= 两次过门机会）。
- 若坚持「任一通过即过门」，则预先规定多重比较校正（Bonferroni 等，α 摊到两次比较）。

## 2.5 采样接口约定（锁定）

```python
sampler.sample(snapshot: VisibleSnapshot, rng, k: int) -> list[FutureScenario]
```

1. **`snapshot` 由在线环境构造**，只含：当前时钟、已揭示订单、已接受承诺、车辆当前及 committed 状态、已耗能耗与剩余预算。**不给采样器原始 `env` / `inst_idx` / 未揭示订单数或真实数组索引**（防止读到尚未揭示的信息）。
2. **`FutureScenario` = 可为空、数量可变的未来订单集合**；订单用临时编号，含揭示时间、位置、需求、温区、时间窗、服务时间，揭示时间必须晚于当前时钟。三种采样方法返回同一格式；历史数据只来自训练日。
3. **三臂共用同一下游决策函数**；同一决策时刻比较「接/拒」候选时**复用同一批场景**；场景评估不修改真实环境，最终动作才提交给环境。
4. **因果验收**：保持可见状态与随机种子不变、只替换测试日的隐藏未来，`snapshot` 与采样结果必须不变。

## 2.6 门判定参数锁定（2026-09-24，运行前写死）

- **判法**：过门 = 主比较（臂 2 − 臂 1）按天配对效用差的**均值 ≥ δ\* = 20**（A-v1 效用单位/天，绝对量）**且**按天聚类 bootstrap 95% CI 下界 > 0；两者同时满足。
  δ\*=20 的理由：与单笔订单收入（常温单 10）同量级、约为主表日均效用（~685）的 3%，显著大于噪声级 ±1 的伪增益；远小于历史 A-v0 头腔 +349（不同任务，仅参考）。
- **K = 10** 场景/决策（与 A 工作包 ② 一致；第 4 步计时后如需调整，须在门判定运行前重新锁定并记录理由）。
- **每决策时限 = 10 秒**；**超时降级（三臂统一）** = 保持当前已认证计划 + 拒绝该新揭示订单，逐日计超时次数。
- **随机种子**：训练/历史 = seed **20260925**（200 天，供预算标定 + 三臂历史）；**门判定日 = seed 20260926（40 天，全新未看）**；**最终论文测试 = seed 20260927 / 20260928（只声明不跑，模型定稿后启用）**。采样 rng 由 (arm_seed, day_idx, event_clock) 确定性派生；重复采样种子 ≠ 新独立天。
- **主 `p_c=(5,10,15)`**；`p_c=0` 与 `(10,20,30)` 为**独立决策运行**（SAA 决策依赖 p_c，不得只换公式重评同一轨迹）。
- **不筛天**：逐日保存全部结果（效用、违规类型、hard_feasible、超时数）；存在任何硬约束违规 → 修复并在**新的门判定日期**重跑，不宣称过门。
- **CI 算法** = 按天聚类 bootstrap（2000 次重采样，percentile 2.5/97.5，沿用 `_stat`）。
- 旧 40 天（seed 20260923/20260924）已用于方向判断 = **开发证据**，不参与门判定。

## 3. 统计与口径（锁定）

- 配对单位 = **天**（同日配对，按天聚类 bootstrap）。
- 报告：效用差 + CI、硬可行率、分温区接/拒单、能耗、完整在线耗时。
- 40 天正式结果已参与方向判断 → 作为**开发证据**；最终论文测试另留未查看日期/随机种子。

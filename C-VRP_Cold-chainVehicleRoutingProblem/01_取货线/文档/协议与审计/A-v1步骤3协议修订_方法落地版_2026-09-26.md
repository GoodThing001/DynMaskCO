## 1. 方法定义（锁定）

1. **目标分布**：P(未来订单场景 | VisibleSnapshot)。场景 = 数量可变、可为空的未来订单集合（time / temp_class / 空间桶 / window），揭示晚于当前时钟。
2. **token 化**：时间桶 0.5h × 温区 3 × 空间桶 3 × 需求桶 2（+NULL；MASK 仅输入）。集合不变：**无位置编码，槽只承载 token，顺序无意义**。
3. **两阶段采样**：
   - **数量头**：encoder 可见序列池化（masked-mean）+ 显式条件特征 → MLP → `0..M_MAX` 类别分布 P(N|state)；采样 `n`。
   - **迭代重构生成**（MaskGIT 式）：X₀ = [可见][MASK×m_max]。T 轮：按 cosine 调度 γ(r)=cos(π/2·r/T) 决定掩码比例；每轮前向 → 每槽 token 分布 → 高置信槽保留 token（放入槽内，成为下一轮的条件）、低置信槽重新 MASK → 下一轮。最后一轮全采样。**保留集合通过注意力条件化后续采样 → 未来订单间联合依赖由轮次间条件表达**（集合不变设置下 MaskGIT 的位置先验由「已确定集合」替代）。
   - **计数校准**（确定性后处理，文档化）：最后一轮采样后若非 NULL 槽数 ≠ n：少于 n → 从 NULL 槽按概率最高者补足；多于 n → 去掉概率最低的 token。保证场景数量 = 数量头样本。
4. **解码**：空间桶 → 同桶历史坐标池；reveal/lead → 同时间桶历史池；**需求 → (温区, 空间桶, 需求桶) 条件池**（池空 fallback = 桶中点 1.5/2.5）。因果：只用 snapshot + 训练历史。

## 2. 模型与对照（锁定）

- 生成头 = 集合不变自注意力（禁位置编码，与现结构同族）+ token 头 + 数量头。
- **A = 预训练 CVRP encoder（冻结，hash 前后核验）+ adapter**；**B = 与 A 完全同架构的随机初始化 CVRP 网络（可训）**；**C = 显式特征 encoder**。三者共用生成头、同训练预算（2000 steps × batch 8 × seed 42）。**总训练运行 ≤3 次有限配置**（含修正），每次预先声明假设与判据。
- 部署接口不变：`sample(snapshot, rng, k) -> list[FutureScenario]`；隐藏未来不变性测试对训练后采样器强制。

## 3. 训练（锁定）

- 数据 = 训练历史 200 天（seed 20260925）；**不含**门判定日与论文测试日。
- **切片 = 0.5h 网格**：每历史日每个网格 cut 构造 (可见, 目标=reveal>cut 的订单 token 多重集)。
- **批构造**：序列 = [可见][MASK×m_max]，批内统一 `L = max(len(vis)) + m_max`；短可见样本以**可见侧 PAD token** 补齐并右对齐掩码区（PAD 进注意力掩码隔离、不监督）→ 每样本恰好 m_max 个 MASK 槽，NULL 比例跨样本一致。
- **MaskGIT 式监督**：每步随机 `r ~ U(1..T)`；目标多重集中随机保留 γ(r) 比例 token 放入槽，其余槽 MASK；损失 = 被掩码槽 token CE + 数量头 CE（监督 = min(|tgt|, m_max)）。目标在槽间的顺序随机（集合不变）。
- 预算：初始 2000 steps × batch 8 × seed 42；服务器 GPU（共享机约束同前）。

## 假设与功能

固定假设：文件身份、逐独立单位原始配对行、预声明 split 和独立审核覆盖同时满足时，程序可以拒绝把工程 PASS、循环改善或历史负结果提升为 MaskCO 核心在线正向。初始材料是缺少统一机器主张门的现状；开发评价为合成对抗用例，后续独立 merge gate 应在新工作树使用尚未交付执行器的反例。本部件不把开发测试分数称为研究收益。

执行入口为 scripts/research_claim_gate/evidence_gate.py。运行时传入 bundle.json 与新输出路径，输出独占创建；不覆盖旧裁决。只读本地工件，禁止路径越界；逐项计算 actual SHA256，拒绝重复 JSON key、NaN、true 字符串、布尔冒充数字、遗漏/重复日、改变选择模型或 split。全部超时回退保留并按臂计数，不能删除后再计算均值。

每个新协议指定 metric direction、绝对/相对效应、独立 day/instance 数、完整固定单位键、固定 2000 次日/实例配对 bootstrap 及种子偏移。实现使用 Python random.randrange 与线性分位数；必须在新协议中预先登记这一算法，不能将其当作 NumPy 历史 bootstrap 的逐位重现。历史 CI 不使用本程序替换。

开发与确认数据批次实际哈希、单位键与种子均不重复；至少三个预声明确认批次，选择模型/配置 SHA 不变。确认用于准入，不能连续观察后修改样本量或将同一确认集作为下一版本开发 oracle。程序验证声明文件的一致性，外部注册记录及独立审阅仍须证明冻结发生在结果产生之前；文件 hash 不能证明数据或登记陈述真实。

## 文献依据与项目选择

方法、数值和发现复现须区别，并报告影响结论的实验变异来源。[Bouthillier、Laurent、Vincent，ICML 2019](https://proceedings.mlr.press/v97/bouthillier19a.html)。本项目把文件字节核验与新批次发现复验分别记录，不能用数值再现代替发现稳定。

在看结果前登记预测/分析计划，使探索与确认区别清晰。[Nosek、Ebersole、DeHaven、Mellor，PNAS 2018](https://doi.org/10.1073/pnas.1708274114)。三个确认批次、强/随机/非学习同日程控制及 2000 次 bootstrap 是本项目为本轮有限研究采用的设计选择，并非该论文规定的普适数量或统计功效保证。

完整报告、效应大小和不确定性不应被单一显著性阈值代替。[Wasserstein 与 Lazar，The American Statistician 2016](https://doi.org/10.1080/00031305.2016.1154108)。本门要求效应达到预声明实用阈值并有正下界，同时输出原始差、区间、超时与失败；跨零仅表示未建立此门要求的正向，不输出等效。

## 使用边界

本软件不能自行认证审计人独立性、代码中机制的语义、服务日志真实性或登记时间；必须有外部独立源码核查与逐轨迹重放。两个 file-backed audit 需覆盖相同 protocol hash、全部原始行 hash 与总单位臂数，并声明其审计源码不同于 runner；这只是自动前置门，外部独立复核不可省略。源、权重、数据生成器、合同、预算、历史池和训练工件必须实际可读并与协议 hash 一致。大权重可通过只读本地下载或受控挂载提供，不能把摘要文件 hash 冒充权重本体 hash。

工程验收命令：在 scripts/research_claim_gate 运行 python -m unittest -v test_evidence_gate。合成正向 fixture 仅检验门在正确输入下会接受，不是任何真实 MaskCO 正向结果。

# 头腔定位与下一步决策（为了发论文的方法优化）

日期：2026-09-22。性质：一轮多代理分析（5 独立角度 + 3 对抗复核）的合成结论与建议，供用户裁定；不是实验启动指令，未跑训练/推理，未改代码。

> **执行回传（2026-09-22 晚）：** §2 的 D1–D3 已跑完（见[头腔普查结果](../结果与进度/头腔普查D1D2D3结果_2026-09-22.md)）。D3 命中 §3 的 **"D3≈myopic≈0" 分支**——myopic 头腔不进入终局，mask=2 局部插入层无可学终局信号，G/GV/L 按提案 §6 被判死；学习职责转向"动态揭示下的 defer/serve/预留 + 前瞻价值函数"。


## 1. 三个关键发现

**F1 — 头腔在"轨迹/时序"层，不在"固定状态/局部插入"层。** O0-CC 顺序 oracle ΔJ≈−0.274，其中品质 70% + 能耗 24%（= 冷链项合计 ~90%），纯距离只占 ~6%；而单动作 local oracle 仅 −0.016、固定状态 mask=2 两层搜索的修复头腔（~0.05 相对 J0）几乎被距离搜索（dist_sgbs 1.0617/1.1447）吃完。即：可部署的大头腔是**顺序累积 + 终局前瞻**，不是单次插入选择。

**F2 — "冷链残差"本质是"在途时间/时序"信号，不是冷链物理。** 复核（refute-2）指出：品质 = f(取货后到返仓的在途时间)，能耗 = 制冷功率×时长 + 开门次数，两者都是**路由决定的在途时间的确定性函数**，动作空间里没有任何直接碰温度/温区/开门调度的动作。因此"76–90% 收益是品质+能耗"应表述为"收益主要来自压缩在途时间"，而不是"冷链状态本身有独立可学的信号"。这直接决定模型该对准**时间/顺序**，而非温区/货物状态（它们只是时间的导出量）。

**F3 — 已有互补性数据已把 G/GV/L 的天花板压到 ~0.1%。** 模型相对距离搜索的额外候选只值 0.0015/0.0005（相对 D 约 0.14%/0.05%），且只在 13–16% 状态、幅度 ≤0.021。提案 §6 的立项门是"相对 D 平均 J 降 1%"，比这个天花板高一个数量级。但注意复核（refute-3）的修正：dist_sgbs 不是严格最优——互补性里模型已在 4–5 个状态以 0.011–0.021 胜过 dist_sgbs，所以"头腔 ≈ 0"应精确为"**稀疏且小**（个别状态 0.01–0.02，聚合均值 ~0.0015）"，不是"恒为 0"。这改变了证伪口径，但不改变"均值门槛过不了"的结论。

## 2. 推荐的下一步：先做无训练的头腔普查（1–2 天），不直接启动 G/GV/L pilot

在花 3–5 天 + GPU 跑 G/GV/L 之前，用现有 clean 状态池 + `evaluate_visible_plan` 做三个便宜诊断，定位头腔到底能不能被"局部残差"捕获：

| 诊断 | 内容 | 成本 | 回答的问题 |
|---|---|---|---|
| D1 穷举修复 oracle | 对同一固定 mask=2，穷举所有合法重插（两序），用**myopic J_vis** 取 min，对比 dist_sgbs | ~分钟级（需写 ~几十行递归枚举 + plan_hash 去重） | 固定状态层还有多少被 dist_sgbs 漏掉的头腔 |
| D2 单步修正普查 | 对每状态测 `J_vis(P_dist_greedy) − J_vis(最佳非距离第 1 步)`，报告分布（mean/中位/p90/max、>阈值比例） | 全 CPU，一天内 | 残差真正要学的那个量（单步偏离距离最优）的逐状态上限 |
| D3 **终局前瞻重评** | 用顺序 oracle 的完整终局 rollout（`counterfactual_teacher.rollout_action`）替换 myopic J_vis，重评同批状态 | ~1–2 小时 | 头腔是否被 myopic 评价"藏"起来了 |

**D3 是关键**：F1 说明头腔依赖终局前瞻；若 D3 显示 mask=2 修复在终局前瞻下出现品质/时间主导的额外头腔（≫ myopic 的 ~0.05），则残差可学，但**训练/评价目标必须从 myopic J_vis 换成终局代价（或学一个未来价值函数）**，pilot 要重新立项。若 D3 ≈ myopic ≈ 0，则局部残差方向被判死，应改学习职责。

## 3. 决策树（在查看任何 CAL 结果前锁定）

- **D3 头腔 ≫ myopic**：残差方向有价值，但换成"终局代价目标 / 学习未来价值函数"再立 G/GV/L；本质滑向 F1 指向的**前瞻价值函数**（见下）。
- **D3 ≈ myopic ≈ 0**：残差方向收束；把学习职责转到**距离启发式真正做不到、且已证明有头腔**的位置——动态揭示下的 defer/serve/预留时机、事件级重优化触发、或 mask/子问题选择（对应 sequential 的 ~0.274 头腔）。最强的具体形态是**学习一个 MaskCO 条件的前瞻价值函数**：预测"当前可见状态+部分计划"的终局 J_vis，用它做 commit/defer/reserve 决策并给候选打分，替代顺序 oracle 的 clairvoyant 真未来 rollout 的因果近似。这仍是 MaskCO 原生（部分计划条件 + 车队条件），且对准了唯一被证明有头腔的信号。
- **任何方向均无信号**：直面硬约束风险（见 §4）。

## 4. 诚实边界

当前证据给"局部残差修正"的是**低先验，不是中性先验**。即便 D3 有头腔，还要过四关：终局前瞻目标的可学习性（未来不可直接观测，只能学近似）、固定状态→动态闭环的转化、L 消融证明 MaskCO 必要性、≥3 seed + 留出实例。没有任何"再跑几次必然成功"的估计。

若 D3 也无头腔，须在三个真实取舍中做决定：(i) 放宽"MaskCO 必须正贡献"的硬约束；(ii) 把已扎实的迁移适配 + 负结果 + "掩码生成在动态冷链何时无增量"的刻画写成方法学/负结果贡献；(iii) 换一个规模/分布/合同更大、学习信号可能存在的任务。这不是非学习论文的转向，但也不是性能创新论文；是一个需要用户拍板的方向决策。

# 距离先验 + 冷链残差模型 · 一页设计

日期：2026-09-22。性质：最小概念设计，不是已批准的批量实验或训练指令。上游实现分工见[研究建议](搜索路线收束后_几何先验与冷链残差研究建议.md)，本文只锁定评分式、残差版本、信息白名单、零初始化继承、pilot 结构与分支。

## 1. 评分式

对同一合法插入动作 a（客户、目标物理车辆、插入位置），在公开状态 s 与部分计划 P_partial 下：

```
score_θ(a) = − Δdistance(a) / scale_D  +  residual_θ(a | s, P_partial)
```

- `scale_D` 用固定 TRAIN 统计或公开合同尺度，**不按隐藏未来归一化**。
- 动作分布仍是全部合法动作上的 softmax，仍由 MaskCO 对部分计划做条件重构；完整计划仍交给唯一 `J_vis` 评价器与硬认证（`validate_repair_plan` + `evaluate_visible_plan`）。
- 搜索宽度、采样温度、奖励均不与结构一起调参（沿用 mask=2、完整修复奖励）。

## 2. 三个受控版本

| 组 | 组成 | 回答的问题 |
|---|---|---|
| **G** | 距离先验 + MaskCO backbone 基础残差（复用节点/边/有序插入表示 + 现有显式动作特征，**不加车辆关系模块**） | 几何先验配合现有学习表示是否已足够？ |
| **GV** | G + 小型车辆—部分路线条件残差（anchor、当前温区状态、载重/品质摘要、冻结边界、有序可变路线；节点↔车辆/路线交互后参与动作修正；动作仍明确关联目标车辆） | 显式关系模块有无增量？ |
| **L** | 距离先验 + 轻量非 MaskCO 修正网络（**同信息白名单 + 有序路线信息**，不得故意删温度/货物/路线顺序做弱对照） | 同信息下是否需要 MaskCO？ |
| **D** | 距离提议 + 冻结搜索，无学习 | 强局部参照 |

G 与 GV 的可见信息尽量一致；GV 只改变组织/交互方式，新增字段同时提供给其他可用该信息的对照，否则明确报告信息变化与结构变化不可分离。L 报告训练参数、时延与计算资源，不要求参数量相等。

## 3. 零初始化继承

残差模块最终出口**零初始化**，使初始确定性动作排序与距离提议一致（tie-break 也一致）。这继承的是**距离提议，不是 regret-2**，也不意味着随机采样策略与确定性距离搜索相同。**禁止**把现有 edge score 未经归零直接加到距离项上再声称"初始继承几何策略"。

特征初始化：复用已冻结 clean 模型作为共同特征来源（旧模型另存只读）；所有 MaskCO 版本使用同一来源与可训练参数规则。零出口首步仅出口有梯度是正常的，后续须验证梯度进入对应上游模块。

## 4. 信息白名单（公开可见）

- 车辆当前位置、时间、剩余容量；
- 当前温区状态、在舱载重与品质摘要（`zone_quality` 已含同温区共同衰减下的加性品质加权和）；
- 部分路线的顺序、返仓路径；
- 已执行 / committed / protected / 可修改部分的边界。

暂不接订单明细 attention：同温区共同衰减模型下 `zone_quality` 已含重要加性统计量，读取 cargo 明细不自动增加必要信息；有充分机制理由再定义字段/容量/无截断语义。

## 5. 代码接入点（只标注，不改）

- 前向路径 `scripts/models/mpre_trained.py:114`：`H = H0 + C(node_feats)` → MaskCO decoder → 有序插入残差头 δ；`incremental_distance` 已是动作特征，新先验改变的是"如何使用距离"，不是"首次加入距离"。
- 动作/状态特征 `scripts/data/repair_state.py:55`：`F_ACTION_EXPLICIT=20`；cargo 表已提取但训练/部署评分接口未消费。
- 在线策略 `scripts/simulation/mtrained_replanner.py:143`：确定性逐步 argmax。

## 6. Pilot（有限、并行、同预算）

- **预算**：G/GV/L 各 seed42、1000 更新、8 状态 × 4 采样，每组合最多 32000 次候选评价、三组合最多 96000 次；D 不训练。
- **公共条件**：同一批干净 TRAIN 状态清单、mask=2、同一完整修复 J_vis 奖励 / 优化器 / 学习率，预固定最终 checkpoint。
- **固定**：不同时换奖励、加辅助 CE、换 teacher、换 PPO、调搜索宽度。
- **判读**：冻结搜索过程与实际预算，先在匹配训练范围的固定状态比较；三个训练组相同预热、测量范围、候选上限，顺序交错避免首个方法独担编译；失败/超时保留 P0，不删样本；按实例聚类，seed 与实例分开报告。
- **主比较预指定 GV−D**；GV−G、GV−L 用于解释来源。开发目标建议先用"相对 D 平均 J 降低 1%"作为立项标准，阈值在运行前锁定，报告实际效果与 CI，不事后降阈值。

## 7. 结果分支

| 结果 | 处理 |
|---|---|
| GV 优于 D 且优于 G/L，延迟可用 | 关系条件化 + MaskCO 均有初步价值，进入有限闭环与独立重复 |
| G 优于 D，GV 不优于 G | 保留更简单的 G，不强行保新注意力模块 |
| G/GV 优于 D，但 L 同样好或更好 | 学习修正有价值，MaskCO 必要性未建立 |
| 仅 TRAIN 改善，CAL 无稳定信号 | 记录泛化不足，不补第三个训练预算档 |
| 所有学习组仍输 D | 收束该残差设计，不立即换 teacher 或加 MoE |

pilot 未建立信号时不跑多 seed、完整场景矩阵或最终测试。

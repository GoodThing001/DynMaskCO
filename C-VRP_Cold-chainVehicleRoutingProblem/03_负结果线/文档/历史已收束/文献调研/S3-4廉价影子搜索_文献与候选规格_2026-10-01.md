## 0. 摘要（TL;DR）

1. **S3-4 本体** = 战役协议 §6 预声明的 L1c2「廉价局部搜索影子」：把 relocate/swap 影子局部搜索压进同一 10s 时限（判据 = 原主判据 + **0 超时** + 同 K/时限的质量/耗时对比，1 次 40 天）。本调研为 S3-4 的实现手段与后继 S4 候选（场景精选 / 截断 rollout / anytime 投票）提供文献依据，不改动 S3-4 的预声明判据。
2. **成本解剖（源码事实）**：当前每决策要跑 2K 次 `_sim_scenario`（acc/rej 分支 × K=10）；场景内每次插入、每个 relocate/swap 候选都做**整条路线可行性重放**（`_route_feasible_u` O(n)/候选），ls 邻域为 O(V²n²) 候选 × O(n) 重放 × 2 passes，且每插入后都调 `_local_search_u`；最后 `_complete_u` 对每场景做**全热力学仿真**（`transition_segment` + WAIT + 返仓）。density 配置下 40 天有 36–40 天超时、最大 82–91 次/天（路线图 S3-2 段落）。文献方向 2（增量评价/快速插入）正是把 ls 压进时限的首选手段。
3. **文献分层**（第 2 节详述）：文献**直接建议**的是——增量拼接评价 + 时间松弛预检（[10][11][12][16]）、决策导向/目标空间场景缩减（[1][3][4][5]）、截断 rollout + 基策略终端价值（[25][27][29][32]）、时间预算与 anytime 返回最佳已找到解（[17][19][20]）。**本课题特定提案**是——C0 能源上下界剪枝、按影子边际分层精选 K=10、部分投票超时语义、h=2 + 车队松弛特征的 V 回归（A1 强动态对照规格已定 h=2）。
4. **候选规格**（第 3 节）：S4-D1 场景廉价预评分→分层精选 K=10；S4-D2 增量评价改造影子 ls（= S3-4 本体的实现手段）；S4-D3 anytime 部分投票与早停；S4-D4 rollout 截断 + 训练日回归终端价值；S4-D5 高 regret 优先插入 + 松弛预检；S4-D6 场景加权/IS 校准（次要敏感性）。每项按路线图 L239 七项模板写出。

## 1. 落点：10s SAA 下游的成本解剖（源码事实，只读核对）

来源：`scripts/evaluation/scenario_saa.py`（SaaReplanner）、`scripts/evaluation/run_a1_step2_gate.py`（`--K 10`、`--time-limit 10.0` 默认）。

### 1.1 每决策的计算图

- 每次揭示：`sampler.sample(snap, rng, K)`（同一批 K 场景两分支共用 = 已内置 common random numbers）；
- 对每个新订单 `_saa_decide`：
  1. `_try_insert_certified`（接单侧真实认证，改 `self._plan`）；
  2. `_build_space`：重建含场景订单的全距离矩阵（O(N²)）；
  3. acc/rej 两分支各 K 次 `_sim_scenario`；
  4. 投票：`acc_u = Σ u(s)` vs `rej_u = Σ [u(s) − pc_o]`，`acc_u > rej_u` 才接受。
- `_sim_scenario` 内部（每场景）：复制状态 → 逐场景订单（`future_policy='reveal'` 按揭示时刻 / `'density'` 按价值密度降序）：
  est 门槛（`est_used + e > B` 拒）→ `_insert_u`（greedy=首个可行位；ls=全车全位最小距离增量）→ **ls 时每插入后 `_local_search_u`**（relocate + swap，`max_passes=2`）→ `_complete_u`（每车逐单 `transition_segment` 热力学 + WAIT 到 booking_horizon + 返仓）。
- 超时语义（协议锁定）：deadline 三处检查（入口 / 每场景前 / 提交前）；超时 → **保持旧计划 + 拒单 + `timeouts += 1`**（`_saa_decide` L712–748）。

### 1.2 常数热点排序（定性）

1. **ls 可行重放**：`_local_search_u` 每候选对 1–2 条路线做完整 `_route_feasible_u`（O(n)），总规模 ≈ O(V²n²) 候选 × O(n)，且每插入一个场景订单都调一次 → 场景订单数 × 2 passes 的重复；
2. **`_complete_u` 全物理**：2K × 每车每单 `transition_segment`（含品质/热状态累积，常数大且不可向量化拼接）；
3. 距离阵重建与 `_insert_u` 的可行重放。

**推论**：任何「把 ls 压进 10s」的方案必须先砍 1 和 2 的常数；文献方向 2（增量评价 + 松弛预检）直击热点 1，方向 4（截断 + 值近似）直击热点 2，方向 1（场景精选）把 2K 次昂贵评估的「有效信息密度」提高，方向 3（anytime/早停）改变超时语义本身。

### 1.3 与本课题相关的既有纪律（写规格时不得违反）

- 影子阶段 est 门槛是影子预算规则，真实预算由接单侧 `certify_plan` 强制（T4 审计）；S3-3 的连续超额价格不得叠加回 `−1e6`。
- 冻结段（在途 committed leg）不可插入/移动/交换（A-06）；未出车空车保留（Q-02）；恰好一次护栏。
- 场景评估不修改真实环境；acc/rej 共用同批场景（CRN）。
- 主判据不动：`cond−uncond` 按天配对均值 ≥ 20 且 CI 下界 > 0 且 hard=1.0 且全日可裁决；超时按原协议计入效用与次数（零超时敏感性标签不得追溯）。

## 3. 候选规格草案（七项模板，对齐路线图 L239）

模板字段：**假设 / 唯一主对照 / 参数与次数 / 预期方向 / 失败条件 / 资源门 / 代码身份**。
每项末尾标注 `[来源]`：文献直接建议 vs 本课题特定提案。**全部未注册；未注册不得运行。**

### S4-D1：场景廉价预评分 → 分层精选 K=10

- **假设**：随机 K=10 把算力花在大量「对 acc/rej 无区分度」的场景上；若先用廉价代理（greedy 插入 + est 门槛 + 距离×燃油近似，**不跑** `_complete_u` 物理、不跑 ls）对候选池 M 个条件场景评出影子边际 ũ(s)，再按「投票标签 + ũ 边际分位」分层选出 K=10 做完整 SAA，则每个场景对动作的信息密度提高，cond−uncond 增大而超时不增（甚至下降，因完整 SAA 只跑 K 个）。文献依据 [1][3][4][5]。
- **唯一主对照**：同一条件采样器、同一批候选池、**随机 K=10**（其余源码/合同/数据完全相同；唯一差别 = 选样规则）。cond/uncond 两臂都走同一精选规则（同构）。
- **参数与次数**：M ∈ {30, 50}；分层方案固定 1 种主方案（按 ũ 边际符号分层 + 每层按 |ũ| 分位取样，权重按层频率归一）+ 1 种敏感性（纯 |ũ| 排序取样）。先各 2 天 p_c=0 烟测（0 崩溃 + 精选集统计合理 + 廉价代理与完整 SAA 值秩相关报告），再 ≤1 次 40 天三档（预声明次数上限沿用战役协议）。
- **预期方向**：若「决策同质性/边界场景稀缺」是幅度不足的根因，则精选后动作翻转更准、cond−uncond 向 ≥20 移动；若无变化，说明信息本身弱（进入 S3-6/联合生成线）。
- **失败条件**：与随机 K=10 的按天配对差未达主判据，或超时/耗时上升抵消，或精选集权重校准失效（训练日分层频率与精选频率偏差 > 预定阈值）；一律判负并记录，不调分层规则重试第二次 40 天。
- **资源门**：40 个唯一日全日可裁决、hard=1.0、超时口径按预声明（S3-4 系 = 0 超时；D1 若另注册须启动前写明）、身份合格（source_stable 等）。
- **代码身份**：`scenario_saa.py` 新增 `select_scenarios()` + 廉价代理函数；`run_a1_step2_gate.py` 加 `--scenario-select` 开关；新增回归测试（T 系列续号：精选集大小恒 K、两臂同构、CRN 保持）；若进 `SOURCE_FILES_STEP2` 封存清单须同步 `run_identity.py`。
- **[来源]**：决策/目标空间聚类与权重校准 = 文献直接建议 [1][3][4][5]；「廉价代理具体成分」「按 ũ 边际分层」= 本课题特定提案。

### S4-D2：增量评价改造影子局部搜索（S3-4 本体的实现手段）

- **假设**：当前 ls 的影子质量可用（relocate/swap 已有 T6 与实现），瓶颈是每候选全路线可行性重放与全物理终局。若改为（a）路线段摘要 + O(1) 拼接评估距离/载重/TW（[10][12][16]）、（b）slack 预检 O(1) 否决（[11]）、（c）**C0 能源上下界剪枝**——仅对被接受的动作做精确 `transition_segment` 复算，则 ls 影子可在 10s 内完成、0 超时，且影子质量 ≥ greedy 影子。
- **唯一主对照**：与现行 `shadow_mode='ls'` 同修订版按天配对（唯一差别 = 评价结构）；另报同 K/时限的质量/耗时对比（S3-4 判据已含）。若现有 ls 无同版基线，则对照同修订版 greedy 影子。
- **参数与次数**：无自由参数（增量评价是等价实现，验证「影子值不因近似改变」即可）；上下界保守性阈值固定（如能源偏差 ≤ 1% 或 ≤ 0.5 kWh/场景，预声明）。2 天 p_c=0 烟测 + ≤1 次 40 天三档（= S3-4 已预声明的 1 次）。
- **预期方向**：0 超时；影子路线质量（场景内距离/能耗）与旧 ls 的逐场景差 ≈ 0；cond−uncond 按主判据裁决。
- **失败条件**：能源上下界不保守（对照完整 `_complete_u` 的逐场景能源偏差超过阈值）→ 判负回滚；或超时未清零且耗时未显著下降 → 判负；或主判据未过 → 按序推进 S3-6，不把「超时清零」单独当成功。
- **资源门**：0 超时（S3-4 预声明判据）、40 日全日、hard=1.0、身份合格；同 K=10、同 10s。
- **代码身份**：`scenario_saa.py` 的 `_insert_u`/`_local_search_u`/`_complete_u` 改造 + 新增段摘要数据结构；新回归测试：增量版 vs 旧版逐场景值相等性（同种子重放）、能源上下界保守性、冻结段不越界（复用 A-06/Q-01 语义）；旧版保留为对照开关（`--incr-eval`）。
- **[来源]**：O(1) 拼接与松弛预检 = 文献直接建议 [10][11][12][16]；C0 能源上下界构造 = 本课题特定提案（无文献先例，不声称理论保证）。

### S4-D3：anytime 部分投票与早停（超时语义变更，需独立注册）

- **假设**：当前超时把已完成场景的投票信息全部丢弃（保计划+拒单）。若场景顺序随机化（两分支同序，保持 CRN）、逐场景累进投票、边际置信区间远离 0 时早停、超时时按已完成场景部分投票提交，则超时损失从「全丢」降为「部分信息」，密集决策日的接单质量提升（[20][23] 的 anytime 思想 + [21] 的资源理性早停）。
- **唯一主对照**：现行「全 K 投票 + 超时保计划拒单」按天配对（唯一差别 = 投票/早停语义）；两臂同规则。
- **参数与次数**：场景顺序随机化种子固定；早停阈值固定 1 种（如：m≥4 且累计 |Δ| 大于边际标准误 2 倍时停）；2 天 p_c=0 烟测（报告早停率、部分投票率、与全投票的动作一致率）+ ≤1 次 40 天三档。
- **预期方向**：超时次数显著下降、超时日的效用损失减小；动作一致率高则主判据不受损。
- **失败条件**：动作一致率低于预定阈值（部分投票系统性偏拒/偏接），或主判据恶化，或早停率≈0（无收益）→ 判负。**注意**：这是超时回退语义变更，须在启动前写明与原协议（保计划+拒单+计次）的关系，未注册前不得在正式批次启用。
- **资源门**：同 D1；超时口径须预声明（该方案下「超时」定义=达 deadline 才停，与早停分开计数）。
- **代码身份**：`_saa_decide` 投票循环改造 + 场景乱序；新增测试：部分投票与全投票在无超时路径上结果一致（deadline=∞ 时逐位相等）、CRN 保持、超时路径计数不变。
- **[来源]**：anytime 返回最佳已找到解 + 价值导向算时分配 = 文献直接建议 [20][21][23]；部分投票的具体阈值与乱序规则 = 本课题特定提案。

### S4-D4：rollout 截断 + 训练日回归终端价值（h=2）

- **假设**：`_complete_u` 的完整终局（WAIT 到 booking_end + 返仓 + 全物理）占场景评估大头，而其价值主要取决于「短时窗内的可执行部分 + 车队剩余松弛」。若影子只仿真到 h=2（时钟+2h），再用训练日因果回放回归的 V(s_after) 估尾段（特征 = 每车剩余可插时间/容量/能耗余量/位置覆盖 + 跨车方差），则影子估值与完整 SAA 的决策一致度高、耗时大幅下降（[25][27][29][32]）。
- **唯一主对照**：同场景源、同 K=10、同 10s 的**完整 SAA** 按天配对（唯一差别 = 截断+值近似）；另加等预算消融（防「多算才更好」的收益来源）。
- **参数与次数**：h = 2（与 A1 强动态对照规格一致）；V 回归器固定 1 种（线性/轻量 GBM 由训练日回放交叉验证选定，选定后冻结）；训练日/评估日按天隔离。训练日拟合 1 次 + 2 天 p_c=0 烟测 + ≤1 次 40 天三档。
- **预期方向**：超时大幅下降；与完整 SAA 的动作一致率高（诊断阈值预声明）；主判据不受损即视为「计算杠杆成立」，再单独看 cond−uncond 是否过主门。
- **失败条件**：动作一致率低于阈值，或等预算对照显示收益仅来自多算，或 V 回归在训练日探针上 Spearman 无正信号（历史 D6 提示该风险高）→ 判负，不升级。
- **资源门**：同 D1；V 权重 hash 入身份。
- **代码身份**：`scenario_saa.py` 增 `--horizon-trunc h` 与 `V_terminal` 接口；训练日回放脚本 + 权重落盘（新增文件入封存清单）；测试：h=∞ 时与完整版逐场景相等、V=0 时退化为截断（无尾段）。
- **[来源]**：截断 rollout + 基策略/终端价值架构 = 文献直接建议 [25][26][27][29][32]；h=2 与特征集 = A1 强动态对照规格 + 本课题特定提案。

### S4-D5：高 regret 优先插入 + 时间松弛预检（影子插入顺序）

- **假设**：场景内按 reveal 顺序插入会把高后悔订单留在最后，诱发劣质插入与更多 ls 修复；改为按 regret（最好 vs 次好插入增量差）降序插入（[15]），并用 O(1) 松弛预检筛候选（[11]），可在接近 greedy 的耗时下逼近 ls 的路由质量。
- **唯一主对照**：同修订版 greedy 影子（reveal 顺序 + 全路线重放）按天配对（唯一差别 = 插入顺序 + 预检）；不改变影子模式本身。
- **参数与次数**：regret 阶数固定 = 2（无网格）；2 天 p_c=0 烟测 + ≤1 次 40 天三档（可并入 S3-4 批次做单因素对照，须预声明）。
- **预期方向**：0 超时下影子距离/能耗 ≤ greedy 影子，接单质量向 ls 靠拢。
- **失败条件**：松弛预检假阳性导致影子放行而 `_complete_u` 失败率上升（相对 greedy 的增量超过预声明阈值）→ 判负回滚；或影子质量无改善。
- **资源门**：同 D2。
- **代码身份**：`_insert_u` 加 regret 排序 + 预检层；测试：可行集与全检版一致（无假阳性时逐场景相同）、恰好一次护栏不变。
- **[来源]**：regret 插入 = 文献直接建议 [15]；松弛预检 = 文献直接建议 [11]；与 density 顺序共存时的排序键 = 本课题特定提案。

### S4-D6：场景加权 / 重要性采样校准（次要敏感性）

- **假设**：预算绑定场景稀少但决定接单；按「训练日分层频率 + 绑定程度」对场景赋权（IS 思路 [8] + 权重校正 [5]），影子期望更准。**定位为敏感性**：它改变「随机 K 等权 SAA」的基线语义，仅在前述杠杆主判据通过后用于稳健性诊断。
- **唯一主对照**：同一采样器等权 K=10（唯一差别 = 权重）；acc/rej 两分支同权（保持 CRN）。
- **参数与次数**：权重方案固定 1 种（训练日绑定频率标定，选定后冻结）；2 天 p_c=0 烟测 + ≤1 次 40 天（仅作敏感性，不单独占用主判据）。
- **预期方向**：影子边际方差下降（训练日诊断）；主判据方向未知、不承诺。
- **失败条件**：权重使训练日诊断上的边际校准变差，或与等权版动作一致率低 → 判负留档。
- **资源门**：同 D1。
- **代码身份**：`_saa_decide` 投票改为加权和（默认权重全 1 = 旧行为）；测试：全 1 权重逐位等于旧版。
- **[来源]**：IS 与选择权重校正 = 文献直接建议 [5][8]；「绑定频率」标定 = 本课题特定提案。

## 4. 纪律与边界（写死）

1. **不夸大外部收益**：以上文献的收益数字均来自各自问题（单车同日达、无 C0 热力学、无 200 单/天密度、无 10s 认证），一律不当作本课题收益量级；本文件所有「预期方向」都是**条件句**，不是预测。
2. **不承诺正向**：任何候选都可能判负；判负按战役协议记录进 `results/a1_optim_campaign/`，不筛天、不删尝试。
3. **未注册不得运行**：S3-4 本体已预声明（1 次 40 天）；D1/D3/D4/D5/D6 是 S4 草案，须按协议 §2 预声明假设/判据/次数后方可执行；S3-4 未裁决前不提前启动 S4 候选。
4. **主判据不动**：所有候选仍以「cond−uncond 按天配对 ≥20 且 CI 下界>0 且 hard=1.0 且全日可裁决」为主判据 + 各自唯一单因素对照；「超时清零」只是 S3-4 系候选的资源门，不单独构成成功。
5. **计算公平**：在线生成、预评分、精选、SAA、认证、早停全部计入同一 10s；任何「多算才更好」的收益须经等预算消融，否则不算方法增益（路线图 L188、L247）。
6. **超时语义**：现行超时回退 = 保旧计划 + 拒单 + 计次（协议锁定）；D3 若启用是对该语义的**变更**，须启动前声明与旧语义的关系，不得静默替换。

# 搜索路线互补性分析：模型是否发现距离搜索遗漏的机会

日期：2026-09-22。性质：只读已有逐状态结果的事后统计，不重训、不重生成候选。数据来源为最终两层搜索的 `results/m0_scale/sgbs_fixed_{train,cal}_v2/per_state.json`（服务器下载，`run_sgbs_fixed_state.py` 产出，32 状态 / 16 实例每 split）。统计脚本 `scripts/evaluation/analyze_complementarity.py`，产物 `results/m0_scale/complementarity_v2/complementarity.json`。

## 1. 定义

对每个状态 s：

```
model_best(s) = min( Mtrained_sgbs(s), Mtrained_greedy7(s) )
J_union(s)    = min( dist_sgbs(s), model_best(s) )
gain_union(s) = dist_sgbs(s) − J_union(s)      # ≥ 0，按定义
```

`dist_sgbs` = 距离提议＋两层搜索；`Mtrained_sgbs` = M-trained＋两层搜索；`Mtrained_greedy7` = M-trained greedy＋7 采样。`gain_union` 必然非负，**不构成算法胜出证据**；它只描述现有候选集合里，模型相对距离搜索的可利用余量。

正改善状态明细（`model_best == Mtrained_sgbs` 在所有正改善状态成立，即改善来自搜索与采样都能找到的同一候选）：

- TRAIN：inst 0 evt 0 (+0.0213)、inst 0 evt 1 (+0.0128)、inst 8 evt 0 (+0.0091)、inst 15 evt 0 (+0.0040)。

贡献拆分：TRAIN 中 `Mtrained_sgbs` 与 `Mtrained_greedy7` 各在相同 4 个状态优于 dist（并列）；CAL 中 `Mtrained_sgbs` 优于 dist 5 状态、`Mtrained_greedy7` 只 3 状态。两者通常给出同一最佳候选，改善不在"搜索 vs 采样"的分歧处，而在模型候选集合自身。

## 3. 判断

**没有有分量的互补。** 模型只在约 13–16% 的状态、18–31% 的实例上找到距离搜索遗漏的完整改善，且幅度极小：

- TRAIN 唯一一个有分量的状态是 inst 0 的两个事件（合计约 +0.034），其余正改善 < 0.01；CAL 只有 inst 14 一个状态 > 0.01。
- 实例聚合的联合增益 TRAIN 仅 0.0015、CAL 仅 0.0005，相对 dist 不足 0.15%。
- 联合只回收 trained 相对 dist 缺口（TRAIN +0.017、CAL +0.008）的不到 10%，即绝大多数状态下模型严格更差，取 min 无法挽回。
- TRAIN 的 gain_union 聚类 CI 下界退化为 0（16 实例里 13 个零增益），不能表述为"显著为正"；CAL 的 CI 虽下界略高于 0，但数值量级（~5e-4）无实际分量。

因此，**已有候选集合不能支撑"简单混合两种求解器即可变好"**。不开启混合比例搜索。这也不构成对"新表示没有学习空间"的证明——它只说明沿用现有候选与距离解取并集没有可部署价值，不否定改变学习职责后的新架构假设。

## 4. 机制：未知，且不猜测

`per_state.json` 只含 `inst/event/J0` 与各方法的接受后 J，**没有方案或 D/Q/E 细项**，因此无法判断这 4–5 个正改善来自距离、品质还是能耗。按[研究建议](../研究设计/搜索路线收束后_几何先验与冷链残差研究建议.md) §3：不把机制归因写成已知，不为画机制图批量重跑旧模型。确需核查时只在 TRAIN 对少量已归档状态恢复完整计划、由唯一 C0 评价器计算 D/Q/E，并写明选择规则、数量与成本——本轮不做。

状态分组仅用决策时可见字段，但当前逐状态产物未保存这些字段，故"改善出现在何种车辆／路线条件"不可由现成结果回答。

## 5. 结论与下一动作

- 互补性为负：模型现有候选相对距离搜索无可用余量，混合求解路线收束。
- 支撑"改变学习职责"的立项理由：距离启发式已覆盖几乎全部有用方案，模型继续"重新预测整套插入偏好"没有体现冷链关系价值；下一步应让 MaskCO 学习"哪些冷链状态下应偏离距离最优选择"（残差设计），而非继续扩大搜索或追训旧 checkpoint。
- 新残差模型的一页设计见[距离先验与冷链残差模型_一页设计](../研究设计/距离先验与冷链残差_一页设计.md)。

# 头腔普查 D1/D2/D3 结果：局部插入残差被终局前瞻证伪

日期：2026-09-22。无训练、无模型、纯 NumPy。三个诊断（见[头腔定位决策](../决策与审计/头腔定位与下一步决策_2026-09-22.md)）已在服务器跑完（TRAIN/CAL 各 16 实例 × 2 状态 = 32 状态，与 sgbs_fixed_v2 同状态同 mask）。脚本：`scripts/evaluation/run_headroom_census.py`（D1+D2）、`run_terminal_headroom.py`（D3）。产物：`results/m0_scale/headroom_census_{train,cal}/`、`terminal_headroom_{train,cal}/`。

## 1. D1：穷举 mask=2 修复 oracle（myopic）

对同一固定两客户 mask，穷举所有合法重插（两种顺序、plan_hash 去重），取 myopic J_vis 最小，与距离贪心及已有 dist_sgbs（beam 搜索）对比。

| 指标 | TRAIN | CAL |
|---|---|---|
| gap_exh_vs_greedy（穷举 vs 纯距离贪心） | 0.0126 [0.0069, 0.0194] | 0.0084 [0.0050, 0.0125] |
| gap_exh_vs_dist_sgbs（穷举 vs 距离 beam 搜索） | 0.0032 [0.0012, 0.0059] | 0.0046 [0.0016, 0.0084] |
| >0.01 的状态数 | 13/32 | 7/32 |

即 myopic 层确实还有一点头腔（穷举比 dist_sgbs 好 ~0.003–0.005，比纯贪心好 ~0.008–0.013），但稀疏。

## 2. D2：单步修正普查（残差真正要学的量）

`correction_signal(s) = J_vis(距离贪心第1步) − min_{非距离第1步} J_vis(偏离+贪心补全)`。

| 指标 | TRAIN | CAL |
|---|---|---|
| correction_signal 均值 | 0.0121 [0.0066, 0.0186] | 0.0063 [0.0037, 0.0093] |
| 信号>0 的状态 | 22/32 | 22/32 |
| 信号>0.01 的状态 | 12/32 | 6/32 |

单步偏离距离最优在 myopic 下确实能改善（~0.006–0.012 均值），但 TRAIN>CAL（0.012 vs 0.006），迁移不一致。

## 3. D3：终局前瞻重评（决定性）

对 P0（baseline）/ P_dg（距离贪心修复）/ P_exh（穷举修复）分别 `_snapshot_with_force` + `run_resumed` 到终局，用完整终局 `evaluate_execution_trace`（含未来揭示）算 terminal coldchain_cost。

| 指标 | TRAIN | CAL |
|---|---|---|
| myopic_gap_exh_vs_dg（myopic 穷举 vs 贪心） | 0.0126 | 0.0084 |
| **terminal_gap_exh_vs_dg（终局穷举 vs 贪心）** | **0.0039 [−0.0011, 0.0120]** | **−0.0046 [−0.0131, 0.0028]** |
| terminal_headroom_dg（距离贪心修复 vs baseline） | **−0.0094 [−0.0200, −0.0004]** | 0.0023 [−0.0150, 0.0199] |
| terminal_headroom_exh（穷举修复 vs baseline） | −0.0055 [−0.0149, 0.0016] | −0.0023 [−0.0221, 0.0149] |
| terminal_headroom_exh > 0 的状态 | 6/32 | 6/32 |
| terminal_gap > myopic_gap 的状态 | 2/32 | 6/32 |

逐状态分布：**21/32（TRAIN）与 19/32（CAL）状态终局修复头腔 = 0**（修复被未来事件完全"洗掉"，终局结果与 baseline 逐字节相同）；其余正负各半（TRAIN 6+/5−，CAL 6+/7−，幅度 −0.15~+0.15）。myopic 头腔与终局头腔基本去相关（如 TRAIN inst5/evt0 myopic_gap=0.079 但终局头腔仅 0.019；inst2/evt1 myopic_gap=0.037 但终局 −0.147）。

## 4. 结论（决定性，支持收束 G/GV/L 残差方向）

**D1/D2 找到的 myopic 头腔（~0.006–0.013）是 myopic 评价的假象，不进入终局。** 终局前瞻下，mask=2 局部修复（即便穷举最优）的终局收益 ≤0、且正负噪声各半、~2/3 状态完全为零。也就是说：**在 mask=2 局部插入层，没有可学习的终局信号；G/GV/L 残差按提案 §6（mask=2、myopic J_vis 奖励）的结构被判死，不应按其现状立项。**

头腔确实存在，但只存在于**轨迹/时序层**（O0-CC 顺序 oracle ΔJ≈−0.27，且依赖 clairvoyant 未来），来自顺序累积与终局前瞻，而非任何单次局部插入。局部残差（即便零初始化继承距离先验）无法捕获它。

因此下一步是**改变学习职责**（见[头腔定位决策 §3](../决策与审计/头腔定位与下一步决策_2026-09-22.md) 的"D3≈myopic≈0"分支）：把 MaskCO 的条件重构能力对准**动态揭示下的 defer/serve/预留时机 + 前瞻价值函数**（预测"当前可见状态+部分计划"的终局 J，做 commit/defer/reserve 并给候选打分），替代顺序 oracle 的 clairvoyant 真未来 rollout 的因果近似。这是唯一被证明有头腔、且距离启发式做不到的位置；仍是 MaskCO 原生，但属于新的独立假设，不保证成功、更不保证发表。

## 5. 边界

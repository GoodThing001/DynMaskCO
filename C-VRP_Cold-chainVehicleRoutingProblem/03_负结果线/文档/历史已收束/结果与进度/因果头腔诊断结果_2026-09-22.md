# 因果头腔诊断结果：myopic 顺序 oracle 终局为负，头腔几乎全为未来信息

日期：2026-09-22。无训练、无模型、纯 NumPy。这是[头腔定位决策](../决策与审计/头腔定位与下一步决策_2026-09-22.md)之后、新方向（前瞻价值函数）的**第 1 步前置验证**。脚本 `scripts/evaluation/run_causal_headroom.py`，产物 `results/m0_scale/causal_headroom_{cal,devcheck}/`。

## 1. 测什么

- **baseline**：JF1-H-F 完整轨迹 → 终局 coldchain_cost。
- **myopic 顺序 oracle（新增）**：与 clairvoyant 顺序 oracle 相同的"按客户顺序枚举动作 + 写回"结构，但动作评分换成 **apply 后 myopic J_vis**（只读当前可见订单的 `evaluate_visible_plan`），即"只看当前可见状态能做出的贪心最优决策"。
- **clairvoyant 顺序 oracle（已跑）**：动作评分用完整终局 rollout（含未来揭示）。

判读：myopic 顺序 oracle 的终局成本，就是"可见状态因果可达"的下界；与 clairvoyant 的差 = 未来信息的价值（VoFI）。

## 2. 结果

| split | baseline | myopic 顺序 oracle | Δ(myopic−baseline) | clairvoyant Δ（参照） | complete |
|---|---|---|---|---|---|
| CAL | 3.5540 | 3.6453 | **+0.0914 [0.0186, 0.1546]** | −0.2096 | 15/16（1 实例不完整） |
| DEV-CHECK | 3.6138 | 3.7280 | **+0.1142 [0.0516, 0.1749]** | −0.2739 | 16/16 |

## 3. 结论（决定性）

**myopic 顺序 oracle 的终局成本显著差于 baseline（+0.09/+0.11），且 CAL 有一实例被 myopic 贪心决策弄得不完整。** 而 clairvoyant 顺序 oracle 是 −0.21/−0.27。

即：顺序 oracle 的全部头腔（−0.21/−0.27）**几乎 100% 来自未来信息**（clairvoyant 终局 rollout 里的未来揭示）；**只看当前可见状态的 myopic 评分不仅无因果收益，而且是主动有害的**（把它当贪心决策用，终局 +0.09/+0.11 变差）。myopic J_vis 与终局价值不仅去相关，甚至反相关。

**含义**：D3 已证明局部 mask=2 修复无终局头腔；本诊断进一步证明"按客户顺序 + myopic 评分"也无可因果捕获的头腔，且有害。可部署的头腔只存在于未来信息里。因此：

- 前瞻价值函数方向**没有被动摇为"已证伪"**——它学的是 `E[终局 J | 可见状态+部分计划]`（对已知 reveal/tw 分布的期望），不是 myopic J_vis；myopic 是它的一个坏估计。
- 但其**先验已显著变低**：它必须从可见状态学到 myopic 完全缺失、甚至反相关的信号（本质是"为未来紧时间窗订单预留车辆/延迟返仓"这类对未来揭示分布的期望），这是很硬、很不确定的学习问题，且要同时胜过已经很强的 JF1-H。

## 4. 与已有证据合起来

1. 搜索增强：M-trained 输给距离搜索。
2. 互补性：模型找不到距离搜索遗漏的机会（≈0）。
3. D1/D2：myopic 头腔存在（~0.006–0.013）但稀疏。
4. D3：myopic 头腔是假象，不进入终局（终局头腔 ≤0）。
5. **本诊断：myopic 顺序决策终局为负（+0.09/+0.11），头腔 ≈ 100% 未来信息。**

连贯结论：**当前合同/规模（50 节点 R1 EDoD=0.5）下，冷链复合目标的头腔被未来揭示主导，不存在被"可见状态因果评分"可捕获的正头腔；myopic 评分有害。** 这不是"模型不行"，是"这个层级的因果信号 ≈0，且最弱的可见评分反相关"。

## 5. 下一步（战略分叉，需用户裁定）

继续往下，只有两条仍有意义的路，且都是长 shot：

- **A. 最小价值函数原型（如果坚持 MaskCO 正贡献）**：学 `V(可见状态, 部分计划) → 期望终局 J`（对 reveal/tw 分布取期望），做 defer/serve/预留。前置门槛很高（要胜过 JF1-H + 从可见状态学到未来分布效应）。先做"终局增益是否可从可见状态预测"的回归探针再决定是否投入。
- **B. 直面硬约束风险**：证据链已完整指向"当前合同/规模对 MaskCO 无因果可捕获头腔"。需在三个真实取舍里拍板：(i) 放宽"MaskCO 必须正贡献"；(ii) 把迁移适配+负结果+刻画写成方法学/负结果论文；(iii) 换一个未来信息不那么主导、冷链接耦合更强、有可见状态可捕获 trade-off 的任务/合同。

**不再建议**：继续在 myopic 评分/局部残差上换架构、加注意力、调损失——证据已排除这一层。

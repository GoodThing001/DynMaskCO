# 价值可预测性探针结果：终局增益不可从可见状态预测，A 判死

日期：2026-09-22。无训练、纯 NumPy。这是 A（前瞻价值函数）的**第 1 步前置验证**（见[工作包](../工程实现/前瞻价值函数A_工作包.md)）。脚本 `scripts/evaluation/run_value_predictability.py`（采样版），产物 `results/m0_scale/value_predictability_cal/`。

## 1. 测什么

A 要学的是 `V(可见状态, 部分计划) → E[终局 J]`，用它给候选动作打分（defer/serve/预留）。前置门槛：**单条候选动作的终局增益 `terminal_gain = J_keep(终局) − J_action(终局)` 必须能从可见状态特征预测**。预测不了 → A 判死，不必花 GPU。

做法：baseline（JF1-H）跑一遍，采每实例前 2 个决策点，每决策点取前 3 个可见客户，枚举全部可行动作，对每个动作做一次终局 rollout，记录 `terminal_gain` + 16 维可见特征 + `myopic_gain`。共 **252 条**（8 实例 × 2 决策点 × 3 客户 × 可行动作）。

## 2. 结果

| 指标 | 值 |
|---|---|
| terminal_gain 均值 / 中位 | −0.0060 / 0.0000 |
| 改善 / 变差 / 持平 动作数 | 60 / 75 / 117 |
| Spearman(myopic_gain, terminal_gain) | **+0.135** |
| 线性探针（仅 16 维结构化特征）out-of-sample Spearman | **−0.037** |
| 线性探针（结构化 + myopic）out-of-sample Spearman | **−0.065** |
| R²（两版均） | 负（−1.4 ~ −1.8） |

## 3. 结论（决定性）

**终局增益完全不可从可见状态预测**：out-of-sample Spearman ≈ 0（甚至略负），R² 为负；加入 myopic_gain 也不改善。即"可见状态 → 期望终局价值"这个学习目标在当前合同/规模下**没有可学习的信号**。

- 大多数动作终局中性或略有害（mean −0.006，改善/变差 60/75）。
- myopic_gain 与 terminal_gain 相关仅 +0.135（几乎无信号，且与因果头腔诊断中"myopic 顺序决策有害 +0.09"一致——myopic 不是终局价值的可靠代理）。

**A（前瞻价值函数）判死**：价值函数要预测的量（终局增益）从可见状态学不到，再强的骨干、再多采样也拿不到那个信号。不进入 A 的第 2/3 步（最小 V_θ + pilot）。

## 4. 证据链最终闭合

1. 搜索增强：M-trained 输给距离搜索。
2. 互补性：模型找不到距离遗漏的机会（≈0）。
3. D1/D2：myopic 头腔稀疏（~0.006–0.013）。
4. D3：myopic 头腔是假象，不进入终局（终局头腔 ≤0）。
5. 因果头腔：myopic 顺序决策终局为负（+0.09/+0.11），头腔 ≈100% 未来信息。
6. **本探针：终局增益从可见状态不可预测（Spearman ≈0）**。

**最终结论：当前合同/规模（50 节点 R1 EDoD=0.5）下，冷链复合目标的可部署头腔被未来揭示主导；既无"可见状态因果评分"可捕获的正头腔，也无"可见状态 → 终局价值"的可学习信号。** 这不是"模型或配方不行"，是"该层级的学习目标在信息论上无信号"。

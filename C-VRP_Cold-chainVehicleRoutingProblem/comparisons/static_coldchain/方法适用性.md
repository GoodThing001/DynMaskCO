# 静态冷链对比方法重新分类

当前保留范围由用户确认：ALNS、VNS、OR-Tools、PyVRP、RouteFinder、DeepACO、CaR，见[方法清单](../../../CC_Compare/configs/methods.json)。以下20项分类保留原研究身份，属于历史候选池，不表示相关文件夹仍在活动树，也不按已有成绩改写原结论。

文档版本：[全项目文档索引](../../docs/文档索引与版本状态.md)。

评估20项（原17项+新增ALNS/HGS/CaR）。判断依据是当前下载版本的原任务和接口；旧动态适配资格及旧成绩均不沿用。不按结果好坏剔除方法。后续ALNS已完成[文献数值情景适配与72次搜索](../../docs/static_delivery_research_20261020/net_benefit_scenario/README.md)，食品价值/验收与车辆真实校准仍未完成；其余方法没有新净效益运行资格。

| 方法 | 当前分类 | 理由 |
|---|---|---|
| [PyVRP](https://github.com/PyVRP/PyVRP) | retain_routing_only | 已运行经典VRPTW；净效益需要真正修改搜索评价，不能仅事后重评分 |
| [OR-Tools](https://github.com/google/or-tools) | retain_routing_only | 已运行经典VRPTW；新目标优先自定义ALNS，非简单静态弧成本回调 |
| [RRNCO](https://github.com/ai4co/real-routing-nco) | retain_neural_candidate | 矩阵输入有价值；静态重写桥接、单位和目标；旧在线限制不自动适用于静态 |
| [CaDA](https://github.com/CIAM-Group/CaDA) | retain_neural_candidate | 保留约束感知构造；需新增品质、目标与静态协议适配 |
| [RouteFinder](https://github.com/ai4co/routefinder) | priority_neural_candidate | 原生静态多变体路由；新净效益须适配并同目标训练 |
| [MVMoE](https://github.com/RoyalSkye/Routing-MVMoE) | secondary_neural_candidate | 多任务结构可用；原奖励与新品质约束不同 |
| [POMO](https://github.com/yd-kwon/POMO) | secondary_routing_control | 经典CVRP控制；不原生覆盖新品质与制冷目标 |
| [AttentionModel](https://github.com/wouterkool/attention-learn-to-route) | secondary_routing_control | CVRP等原任务控制；不引入未授权可选接单 |
| [DeepACO](https://github.com/henry-yeh/DeepACO) | priority_neural_search_candidate | 保留蚁群与神经启发式；重写完整路线评价和约束后才能进净效益主表 |
| [SGBS](https://github.com/yd-kwon/SGBS) | secondary_search_candidate | 搜索增强可复用；不是独立冷链模型，需同目标评分与预算 |
| [Sym-NCO](https://github.com/alstn12088/Sym-NCO) | secondary_routing_control | 对称假设须核验；时变/有向路线和新品质目标不能直接沿用 |
| [Omni-VRP](https://github.com/RoyalSkye/Omni-VRP) | secondary_neural_candidate | 保留跨分布路由控制；不把其原目标成绩当新任务结果 |
| [Learning-to-Delegate](https://github.com/mit-wu-lab/learning-to-delegate) | secondary_improvement_candidate | 可复用子问题选择思想；子问题须计入全路线品质影响且核验资产许可 |
| [Learn-Improvement-Heuristics](https://github.com/WXY1427/Learn-Improvement-Heuristics-for-Routing) | secondary_improvement_candidate | 可复用改进策略；需改目标/可行性并核验许可 |
| [PIP-constraint](https://github.com/jieyibi/PIP-constraint) | narrow_task_constraint_reference | 已下载主要TSPTW/TSPDL实验非当前车队主表；不把框架理论判为永久不能扩展 |
| [CO-enriched-ML](https://github.com/tumBAIS/euro-meets-neurips-2022) | static_components_only | 旧动态接拒策略不作当前主表；原静态求解部件可独立核验 |
| [MAPT](https://github.com/Beihang-BIGSCity/MAPT) | outside_current_task | 动态多车取送货与本轮静态配送不同；暂不以旧适配直接比较 |
| [ALNS](https://github.com/N-Wouda/ALNS) | implemented_numerical_scenario_baseline | 已实际导入固定源码，显式用负净效益评价并独立复核；仅为新增假设下情景，非完整食品模型或作者算法复现 |
| [HGS-CVRP](https://github.com/vidalt/HGS-CVRP) | new_cvrp_control | 新增经典CVRP源；本轮主VRPTW用PyVRP，不能把HGS直接当原生TW解法 |
| [CaR](https://github.com/jieyibi/CaR-constraint) | new_constraint_candidate | 新增ICLR2026源码；原生CVRP/TSPTW/TSPDL/VRPBLTW/SOP，食品品质与温度需自定义 |

优先次序：经典路由用OR-Tools/PyVRP；净效益主传统基线优先ALNS+共同独立评价器，小例再用显式数学规划校验；学习方法优先MaskCO/RouteFinder/DeepACO，CaR作为约束处理候选。仅将距离模型产生的路线事后计算净效益，应标为“距离策略迁移对照”，不能冒称同目标训练的方法。原始预训练、同架构随机和新目标训练结果必须区分。

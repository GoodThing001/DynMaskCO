## 5. 不许动的目录搬迁（会被代码引用打断）

被代码 `import` 或按路径拼接引用的目录（改动即断）：

```
scripts/            ← sys.path.insert 的目标，全部 606 个模块
scripts/lib/        ← decoding/cvrptw.py 里 io 路径
scripts/tests/      ← 全部按路径运行
data/  ckpts/  logs/  results/    ← 相对路径被大量 --data / --out / _bverify 使用
archive/正式冻结包/  ← EVIDENCE_SEAL.json 里写死的相对路径
negative_result_paper/            ← verify_negative_archive.py:17 的 BASE 常量
CC_Compare/MAPT_code              ← gitlink，见 §3
results/m0_scale/_bverify_pinned/shadow/{data,MASKCO_code,results}  ← junction，见下
```

**`results/m0_scale/_bverify_pinned/shadow/results` 是回指祖先的 junction**，任何递归操作
（`git add -A`、打包、逐文件哈希、磁盘统计）都要**先排除 `_bverify_pinned/`**，否则：git 报 ~19.6k 忽略文件、
真实只有 ~4.3k；`robocopy /L /E` 跑不完。`tools/git_deliver.py` 的 `_is_reparse_point` 已处理这一层，
但其他工具未必。

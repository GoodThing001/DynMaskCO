### 1.1 远程访问的一个环境问题（已绕过，需登记）

本机 `http.sslBackend=schannel`（`D:/Git/etc/gitconfig`）+ `http.proxy=127.0.0.1:7890`（`C:/Users/mmc/.gitconfig`）组合下，`git fetch/ls-remote` 报：

```
fatal: unable to access '...': schannel: AcquireCredentialsHandle failed: SEC_E_NO_CREDENTIALS
```

**这不代表仓库或凭据有问题**：同一命令改 `http.sslBackend=openssl` 即成功。本轮已用
`git config --local http.sslBackend openssl` 仅在本仓库生效（写入 `.git/config`，**不入库**、不影响他人）。
后续交付脚本 `tools/git_deliver.py` 内部会 `git fetch` / `git push`，依赖这一设置；**新机器上若首次 push 报同一错误，先按此处置**。

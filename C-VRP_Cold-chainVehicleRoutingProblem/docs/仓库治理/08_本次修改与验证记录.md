### 3.2 沙箱导致的"假失败"（记录方法学，避免下次误判）

首次在本环境跑上述 11 件时，7 件以 `PermissionError` 失败。经定位，**不是仓库问题**：

- `tempfile.mkdtemp()` 落在 `%TEMP%\dsh-*`，被文件沙箱拒绝（`[sandbox: file access denied under workspace-write mode]`）。
- `results/c0/` 缺少沙箱 SID `S-1-4-463412727-624150001` 的写 ACE（`results/` 与 `results/o0d/` 有），故 `test_coldchain_contract.py` 无法写 `results/c0/coldchain_contract_tests.json`。
- 在授予完整访问后重跑，7 件全部转为 **exit 0 / ALL PASS**。

**结论**：除 `test_rolling_optimizer.py` 外，文档化回归套件当前全绿。

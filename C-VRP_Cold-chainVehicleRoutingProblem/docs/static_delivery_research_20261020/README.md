接下来的落地顺序：

1. 用原Solomon路由层核验静态模型和传统基线；新品质约束改编数据作为有单位的第二条公开基准候选，保留作者原文件。
2. 使用文献核实的番茄TA保留与鲻鱼感官评分变化做独立品质评价。若要转向更接近消费者接受的番茄硬度/颜色指标，先取得同指标完整参数和接受阈值，不能把TA系数换个名字。
3. 依补充调研形成注明实测/拟合/假设身份的数值情景，再实现最大净效益共同评价器。文献图示初值和经济设定可以作为候选；商品—需求映射、品质—交付价值关系及车辆/负载匹配须显式定义。统一虚拟货币尺度可用于数值研究，不把它称为实际业务利润。
4. 以ALNS为首个新目标传统基线，配合小例显式数学规划验证，再接MaskCO与神经候选。各臂须同目标、同硬约束和可核验预算，按原实例身份分组。当前没有启动新神经训练。

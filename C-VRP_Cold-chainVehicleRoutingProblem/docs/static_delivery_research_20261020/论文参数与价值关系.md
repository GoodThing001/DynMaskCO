# 参数、价值关系与统一单位的证据裁定

文档版本：[全项目文档索引](../文档索引与版本状态.md)。

2026-10-20。目标为最大单次配送净效益；鱼种按用户选择为有氧冷藏鲻鱼片。本页明确区分实验参数、数学推导、数值基准设定和未配置项。来源层级与访问限制见[sources.json](sources.json)，不能从“有论文”推出“全部参数已闭合”。

## 1. 番茄：品质变化有参数，货损与价格没有直接等号

[Wang等，Foods 12(1),6](https://doi.org/10.3390/foods12010006)的出版PDF及EuropePMC XML已取得，Table2（p10）原图核对。对象是樱桃番茄，0/4/10/25°C储藏；TA为可滴定酸指标。式(2)一阶衰减、式(4)Arrhenius及同组表值给出：

`TA(t)/TA(0)=exp(-∫k(T)dt)`，`k_day(T)=104.58*exp[-18789.64/(8.314*(T_C+273.15))]`。

小时制用`k_h=k_day/24`。Ea取J/mol是与气体常数配套的量纲解释；原表头印为kg mol^-1，时间预测式还存在符号冲突，不能称逐字无修正复现。报告显式选择论文的衰减式，不按参考成本或希望的损耗调参数。

可用输出是**TA相对保留率**。`1-TA(t)/TA(0)`只表示酸度指标相对下降，不能当作丢掉的kg比例、可售量减少率或价格折扣。精确批次初始TA、TA单指标可售阈值、TA到售价函数均未闭合。

更接近接受度的替代路线有依据：[Schouten等，2007](https://doi.org/10.1016/j.postharvbio.2007.03.012)同时考虑颜色、硬度、采收成熟度和消费时机，但本轮只核到机构摘要。[Pinheiro等期刊论文](https://doi.org/10.1016/j.jfoodeng.2012.08.024)与[作者机构海报](https://repositorio.ucp.pt/bitstreams/bc493d39-f2f4-41a1-9942-d4217a123e46/download)提供硬度动力学候选；海报与期刊终稿身份不同，平衡硬度也不是可售阈值。不能将不同探头的N/mm阈值套进N模型。

[Jordan等，1985](https://doi.org/10.1017/S0081305200025139)有番茄质量特征的享乐价格估计方法；已核出版者摘要，未取得可本地审阅的完整参数表。它支持“可用市场数据拟合品质价值”的方法，不提供当前樱桃番茄TA的通用折价系数。[Gaukler等，2023](https://doi.org/10.1016/j.ejor.2023.03.006)的成熟番茄运输方式决策进一步支持时间—温度信息具有经济意义；本轮未取得其完整参数，不能摘摘要反推价格。

## 2. 冷藏鲻鱼：采用同物种、同包装、同指标参数

[Ntzimani等，Fishes 9,480](https://doi.org/10.3390/fishes9120480)的出版全文已保存；§3.2 p11和Table6 p12核对。对象为50g鲻鱼片，有氧、未封袋，恒温实验0/2.5/5/10/15°C。总体感官印象按零阶下降：

`S(t)=S0-∫k(T)dt`，`k_day(T)=0.452*exp[-81400/8.314*(1/(T_C+273.15)-1/277.15)]`。

原表kref为0.452±0.056（表记d^-1；零阶感官模型下解读为评分点/天），Ea=81.4±9.8kJ/mol，均值±标准误；小时制除24。论文感官拒绝阈值为5，量表1—9。**初始评分未核到精确拟合值，不能直接取9。** 在4°C参考条件连续8h的中心预测为下降0.150667评分点；这是从原参数推导的变化量，不是可售重量损失，也不是绝对到货评分。当前示例未传播参数不确定性。

这些温度是实验/拟合条件，不能直接当作运输安全硬界。感官合格亦不能替代独立安全判断。本轮不提供法规合规结论，不把冷冻海鲈、虹鳟或其他鱼的系数混入鲻鱼模型。

经济关系需要另外估计。[Sakai等，Marine Resource Economics 39(1),21–38](https://doi.org/10.1086/727493)在日本零售市场发现竹荚鱼的新鲜度溢价，但沙丁鱼未见显著溢价；指标是生物阻抗，并非鲻鱼感官评分。[Sakai等，J Food Sci 2026](https://doi.org/10.1111/1750-3841.70764)的真鲷刺身实验还显示信息披露会改变鲜度与支付意愿关系。本轮仅核两文摘要。这些结果反对跨鱼种、跨市场套用一个线性“评分×价格”规则；不把其他鱼的价格系数移植到鲻鱼。

## 3. 冷藏车功率：找到同工况证据，仍需与车队匹配

[刘业凤等，《低温物理学报》45,64–70，2023](https://doi.org/10.13380/j.ltpl.2023.01.009)，[期刊官方全文](https://dwwl.ustc.edu.cn/ch/reader/create_pdf.aspx?file_no=202301009)。网页工具读取官方7页PDF文本；本地下载403，原图截图失败，该限制原样登记。

Table2（印刷p67）区分名义/预冷/运输工况。§2.3（p69）在外30°C、厢内0°C、80Hz、9MPa的**同一运输工况**，给出制冷量1.75kW、COP1.66。式(2)定义`COP=Q0/P`，P含压缩机与冷风机，因此：

`P_input=1.75/1.66=1.0542169 kW`（推导值）。

`E_input[kWh]=∫P_input[kW]dt[h]`；`C_refr=E_input*p_energy[currency/kWh]`。

若参考该点并额外假设连续运行8h，则能耗8.4337349kWh；这只是明确假设下的参考积分，**没有把它写成实际路线耗能**。论文实验在焓差室，提及18m³以下车辆匹配背景，但未提供本项目载重、开门热、路上占空比与电价。不能将1.054kW用作任何设温、环境与多舱车辆的固定功率，也不能把18m³直接映射为20t或33托盘。

[Kayansayan等，HEFAT2014](https://repository.up.ac.za/items/63f40fa1-f2d2-4765-89d3-3fa9977df180)全文Table4 p7同时给制冷量和燃料热输入，例如工况1为6.552kW与28.57kW。COP_f以燃料热输入为分母；15kW发动机额定值也不是电输入。该-20°C实验作为量纲核验，不能与上述CO2机组拼成一辆车。若按其燃料热值换算质量消耗，仍缺同燃料价格/密度才能算货币或L。

现有[RRP论文](https://doi.org/10.3390/en13236214)提供另一完整单舱冷冻车辆基准及载重/速度牵引燃料式。原L/km、L/h等系数可保留作该基准的成本核验，不能声称已校准本轮冷藏小车或多温车。

## 4. 统一单位与净效益合同

新任务按一次配送计算，不年化。统一质量kg、时间h、距离km（须来源明确）、功率kW、能量kWh、温度报告°C/Arrhenius计算K、活化能J/mol。原论文day速率换算为h；原Solomon抽象单位保持原名，不悄悄转换成物理单位。

最大净效益可写为：

`max Π = Σ_i m_i * y_i * p_i(Q_i) - C_purchase - C_traction - C_refrigeration - C_decision_dependent_other`。

其中m为装载质量kg，y为有证据的可售质量比例，p为每kg交付商品在该品质下的价值。若只有品质折价证据，没有重量损失证据，不凭空加非平凡的y；若没有任何定价证据，则不计算该利润。已在收入中减少的损耗不得再重复扣货损费用。初始质量、货龄、包装与温度历史边界都须明确。

订单和固定班次人员均固定时，采购成本/固定工资可作为常数列在完整报表中，但从优化排序中省略；额外用车、额外司机、加班等若随决策变化，则需要有来源的对应费用。原RRP时薪只适用于其基准，不能默认套入新业务。

统一币种及价格参考期尚未确定，不在本轮自动换汇。若用虚拟价值单位，应将**所有已货币化项除以同一个正参考金额**，属于无量纲化；它保留原价格比例，不能代替未知的售价/品质映射。不能用`TA比例×100`、`评分/9`或任意能耗权重宣称净利润。

容量、客户恰好服务一次、车辆/温区兼容、交付时间窗、最低品质等放入硬约束。原实验温域不自动等同安全温界。当前仍坚持静态必服务配送，不擅自增加动态接拒或可选订单以制造效益。

## 5. 数据选择与方法边界

[SINTEF Solomon](https://www.sintef.no/projectweb/top/vrptw/100-customers/)原56例用于经典路由层，保持原需求/坐标/服务/时窗。原目标按最少车、再最短距离，对其参考值的比较不能当作新净效益结果。

另已取得[Hülagü等作者数据](https://github.com/SelinHulagu/vrptwq-solomon-instances)，对应[2026 Transportation Science论文](https://doi.org/10.1287/trsc.2025.0262)。作者直接提供56份改编文件，README明列km、kg、min及20,000kg/60kmh等设定。其品质400、下降上限80等是该文数值基准，**不是番茄或鲻鱼的实测指标**；其制冷费用参数也不能冒充本地电价。完整论文PDF本轮受限，未复现其精确算法。我们不自行运行生成器或缩放原Solomon来替代作者文件。

优先保留ALNS（自定义净效益搜索）、OR-Tools/PyVRP（经典路由和距离策略迁移控制）、RouteFinder/DeepACO/MaskCO（待同目标适配）；新增CaR为约束处理研究候选。全部20项逐一状态见[方法适用性](../../comparisons/static_coldchain/方法适用性.md)。仅有源码或经典路由结果不表示已经具备新净效益求解资格。

## 6. 已闭合与仍缺项

已闭合：两类品质的所选变化方程、同来源中心速率/温域及单位换算；鲻鱼的感官阈值；指定机组同工况的制冷量/COP/输入功率推导；经典数据来源/原文件；可运行传统路由基线。

尚缺：批次初始品质与货龄、番茄可售判据、同物种同指标的价格/可售量函数、采购与售价参考期、商品—客户原始需求映射、匹配车辆容量及温控/开门/占空比、电或燃料价格。用户已确认暂无指定价格，故这些字段保持未配置。当前可交付导师的是**经典路由结果＋文献品质变化＋参数缺口说明**，不能把它写成完整经济闭合或算法正收益。

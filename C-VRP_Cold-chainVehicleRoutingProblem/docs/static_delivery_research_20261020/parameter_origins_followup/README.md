# 论文如何提供初值、价格和算例：补充调研

日期：2026-10-20。对应用户问题：其他论文是随机生成、采用原有算例，还是已有实测初始数据？本页补充并修正[上一轮参数报告](../论文参数与价值关系.md)。这是针对当前模型的证据核查，不是覆盖全领域的系统综述。

后续执行：[文献数值情景净效益初步结果](../net_benefit_scenario/README.md)已完成72次ALNS搜索和6个共同初解。本页及候选JSON保留调研阶段身份，未直接作为程序配置读取；采用的部分数值与新增价值假设在独立`net_benefit_scenario_v1.json`中明确记录，旧配置/结果未改。

**结论：三种做法都有，而且一篇论文内可以混用。我们可以开展明确标注来源和假设的数值实验，无须等所有企业实测数据齐备；但要分别写清楚实测、拟合、文献数值设定和随机规则。**“没有当前批次实测值”不等于“没有可参考的文献初值”。

Li博士论文的完整题名为 *Modèles et algorithmes pour une classe de problèmes combinés de production et de tournées de véhicules*。其第6章是独立核查对象，**不声称与2016会议论文逐项参数相同**。

## 2. 品质初值：实验论文确实提供了信息

### 樱桃番茄

[Foods 12(1):6，DOI 10.3390/foods12010006](https://doi.org/10.3390/foods12010006)，§2.1说明山东潍坊农场来源及采收/预处理条件。Figure1(c)，PDF p6，画出初始TA约4 g/kg；p7正文也以约4描述起点。这是**该实验批次的近似值**，不是我们当前批次的精确化验值，也不是一阶回归的精确截距。

因此可用两种明确身份的初始条件：文献批次参考情景取TA0约4 g/kg；只研究相对TA保留时，定义r=TA(t)/TA0，则r(0)=1是归一化定义，无须编造新的绝对初值。两者都不意味着TA下降百分比等于质量损失百分比或价格折扣。

论文数据声明称数据在正文和补充材料中。已保存PDF/XML和图；本次没有取得每个生物重复的完整机器可读TA原始表，不声称有完整原始实验数据库。图示见[原页](page_checks/tomato_figure1_p6.png)。

### 有氧冷藏鲻鱼片

[Fishes 9(12):480，DOI 10.3390/fishes9120480](https://doi.org/10.3390/fishes9120480)，Figure6(c)，PDF p11，t=0总体感官印象的图示起点约为9分；同页给出感官拒绝阈值5，Table6给出零阶/Arrhenius动力学参数。

**修正上一轮表述：“没有核到精确拟合截距”仍成立，但“因此不能取9做任何情景”过于严格。** 9分不仅是量表上限，原图也显示了该实验批次约9的起点。因此可把S0约9用于“文献新鲜批次参考情景”，并在参数表中标为近似读图值；不能称当前配送批次实测值或精确拟合截距。图示见[原页](page_checks/mullet_figure6_p11.png)。

该文p15声明数据可向通讯作者索取。已取得文章中的图、表、动力学参数，**尚未取得作者底层评分记录**。不自动联系作者。

前一轮配置`product_evidence_v1.json`和品质计算保留原字节，以维持历史结果SHA；其中`score9_is_not_a_measured_initial_score`是当时的不充分裁定，不能再据此否认文献图示起点。本轮新判断在[候选参数表](parameter_candidates.json)中记录，未自动启用经济模型。

## 3. 经济参数：有论文定值，也有调查值和随机规则

### A. 番茄已有论文售价和明确采购假设

Buisman与Rohmer，2023，*Inventory dynamics at the retailer—An economic and environmental analysis of packaging fresh produce*，[DOI 10.1016/j.samod.2023.100020](https://doi.org/10.1016/j.samod.2023.100020)。出版者全文Table2列樱桃番茄售价**4.50 EUR/kg**；同节明确假设采购/订货成本为售价的80%，由此推导**3.60 EUR/kg**。该80%是作者假设，不能写成市场调查。

这给出了可引用的**樱桃番茄经济情景起点**，不再笼统称“完全没有价格来源”。该文讨论零售库存、包装和货架期，不是运输品质TA与售价的实测函数；其常温货架期也不能替代我们的运输温度模型。售价的原始市场采价出处本次未单独确认，故归类为“论文报告的数值设定”。

该文Appendix E列出3份CC BY补充原始研究数据ZIP。已核实出版者页面有这些条目，**尚未下载/审计附件内容**，不将其算作本地已取得的数据，也不称其包含配送坐标或订单。

### B. 同物种鲻鱼有真实市场调查价格，但商品形态不同

Nadia等，2022，*Fish availability and market channel in Rajbari, Bangladesh*，[DOI 10.1016/j.heliyon.2022.e10526](https://doi.org/10.1016/j.heliyon.2022.e10526)，[PMC全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC9474837/)。调查期为2020年6—12月。Table5的*Mugil cephalus*一行给出生产者2.7、拍卖商2.9、供应商3.5、批发商4.8、零售商6.0，原表单位为**$ kg^-1**。本轮保留原币符号；机器表不擅自补ISO币种或换汇率。

这是同物种、特定地区和历史期间的渠道价格。它不是希腊实验50g鱼片的采购/零售价，更不是中国当前配送业务报价；渠道价差也不是同一商品因感官下降产生的品质折扣。可列为物种价格量级参考，不能当已校准的鱼片经济参数。EuropePMC原XML已下载，Table5物种行与表注已核。

### C. 品质—价格函数确有数值研究先例

Li博士论文第6章Table6.1给出：

`g_i(q) = beta1 - (beta1-beta2) * q / |Q|`

其中q=0表示新生产/最好品质，q随货龄增加；beta1来自U[10,20]，beta2来自U[4,7]。需求来自U[30,210]，单位生产成本来自U[4,7]。原页见[Table6.1](page_checks/thesis_table6_1_p114.png)。

这是**作者给定函数和随机范围**，并非估计出的食品通用价格规律。可以借鉴“价格随品质分级变化”的建模方式，并做敏感性分析；如果把q改为我们的TA或感官评分，那个映射是本项目新增假设，必须另列，不能说论文已验证该映射。已知分布和规则也不等于拿到了论文全部实例或能逐例复现。

## 4. 冷藏车与单位也按同一原则处理

2021 QDVRP的§4.1明确列出温度、装卸/降温时间和车队情景假设；2025 Crowd-Shipping结合历史电价政策、模型参数及合成算例。可以参考这种混合来源写法，但不能因参数列在论文里，就把它全写成实测。

我们已有的2023 CO2机组同工况证据和功率推导继续有效，详见[上一轮车辆部分](../论文参数与价值关系.md#3-冷藏车功率找到同工况证据仍需与车队匹配)。`Qcool/COP`得到电输入功率；`kW×h×货币/kWh`得到制冷费用。若恒功率/占空比/开门处理是情景假设，就显式标注并考察敏感性。车型、载重、温区不匹配时，不能把多个论文参数拼接后称“同车实测模型”。

可以使用统一虚拟货币单位开展算法实验。其前提是收入、采购、牵引、制冷都处在**同一个货币尺度**，并声明价格/成本比例的来源或设定；也可将完整货币目标除以统一正参考金额进行归一化。虚拟单位不要求当前市场报价，但不能把kg、评分、kWh直接相加。番茄EUR与鱼的原表$当前不能无换算地合并；初步可分别做单产品情景。

固定订单、固定班次下，采购总额和固定工资是常数，可从优化排序中省略并在利润报表中列明；用车数/加班等随决策变化时再纳入对应费用。该判断来自目标函数的常数项消去，不借论文时薪强行添加司机成本。

## 5. 适合当前项目的推进方式

1. **路由数据直接用已取得的原作者实例。** 原Solomon继续验证经典算法；带单位的56例VRPTWQ作为品质约束基准。不开启客户生成器，不虚构番茄/鱼的客户标签。论文中的随机生成案例用于方法论说明，不覆盖当前工程规则。
2. **做可追溯的文献品质情景。** 番茄先报告相对TA保留，也可另列TA0约4；鲻鱼可另列S0约9、阈值5的参考批次。每项保留近似/拟合/假设身份，原有30项变化量结果不改写。
3. **经济层采用明确的数值研究身份。** 番茄4.50与3.60 EUR/kg可作为论文情景候选；鱼先保留同物种价格调查作参考。品质折价可参考文献分级函数开展独立情景，但“TA/评分如何映射等级”、商品需求映射、统一成本尺度仍要在运行前形成清楚的合同。当前调研不擅自激活这些配置。
4. **避免目标形式变化却没有经济作用。** 若所有订单必须服务、所有可行交付均按固定价出售、采购量固定，则收入和采购为常数，最大净效益与最小决策成本具有相同最优解。这是代数结论。如果希望品质带来效益差异，须明确可行区间内的品质溢价/分级价值关系；不通过偷偷增加可拒单来改变任务。
5. **对导师的表述**可写：“以公开经典路由实例为基础，引入食品实验文献的品质动力学，并采用注明出处的经济情景设定开展静态冷链配送数值研究。研究结果评价算法在这些条件下的净效益，不解释为企业实际利润预测。”分别报告经典基准结果、品质预测和带假设的经济结果。

本轮完成的是参数来源调查与可实施情景边界，不新增求解、训练或净利润结果。论文PDF/XML、下载SHA、3张原页和候选参数分别见[sources/](sources/)、[获取记录](acquisition_manifest.json)、[候选参数](parameter_candidates.json)、[本轮核验](verification.json)。原数据、第三方代码与既有求解结果保持原件。

# 同商品价值参数与制冷单位：补充证据审查

2026-10-20。目标仍为最大单次配送净效益，容量、覆盖、时间和交付品质作为约束。本轮找到了更直接的番茄分级定价数值，但尚未取得把运输时间、温度和可交付等级完整连接起来的同指标参数。已完成9组价格/单位计算与6项语义检查，**没有新增路线搜索或利润预测**。

## 番茄：可引用的原文数值

Gaukler、Zuidwijk与Ketzenberg，2023，*The value of time and temperature history information for the distribution of perishables*，EJOR310(2):627–639，DOI[10.1016/j.ejor.2023.03.006](https://doi.org/10.1016/j.ejor.2023.03.006)。其荷兰至美国案例是藤熟番茄，不能直接等同此前樱桃番茄TA实验。[大学记录](https://pure.eur.nl/en/publications/the-value-of-time-and-temperature-history-information-for-the-dis/)；[机构原文](https://pure.eur.nl/files/155582174/1-s2.0-S037722172300200X-main.pdf)。

| 参数 | 原文数值 | 来源位置与身份 |
|---|---:|---|
| 包装 | 25 lb/箱，80箱/托盘 | §4.1，印刷页634 |
| 高质价格参考 | 20 USD/箱，即1600 USD/托盘 | §4.1，页635；论文引用2018年迈阿密市场历史价格，不是当前报价 |
| 高质价格实验范围 | 1200—2000 USD/托盘 | Table2，页635；数值实验均匀取值范围 |
| 低质价格 | 高质价格×d，d∈[0.4,0.8] | Table2；作者敏感性设定，非估计置信区间 |
| 批发品质阈值 | 55 | §4.1，页634；论文自身品质指数，**不是TA保留55%** |
| 温度参考 | 9°C | §4.2，页635；该案例模型的温度设定，非所有番茄通用最优值 |

以上是原文数值转述。本地直取PDF返回403，已核查机构原文的网页索引段落，**未获得本地全文和原页视觉核验**；其完整品质动力学参数、补充材料未取得。论文中的低质销售/残值渠道，也不代表本项目必送客户允许接收低质货。

## 统一单位的可复算示例

按[NIST精确换算](https://www.nist.gov/system/files/documents/2023/01/30/appb-23-HB44.pdf)，1 lb=0.45359237 kg。由包装推导每托盘907.18474 kg，参考高质价为1.763698 USD/kg。

| 低质/高质价格比 | 低质USD/托盘 | 低质USD/kg | 相对价值单位 |
|---|---:|---:|---:|
| 0.4，文献下端点 | 640 | 0.705479 | 0.4 |
| 0.6，区间中点，非文献拟合值 | 960 | 1.058219 | 0.6 |
| 0.8，文献上端点 | 1280 | 1.410958 | 0.8 |

表中价格由1600 USD/托盘推导；并未推出每件货的等级。若用虚拟价值单位，可把同币种销售收入、采购及运输费用全部除以同一正参考金额。归一化本身不会把EUR变为USD，也不会把TA、kg或感官分数变成货币。未配置同市场采购价及共同币种时，不能把本表与旧欧元成本拼成新利润。

## 品质与售价：实证能支持到哪里

Boiteau与Pingali，2022，*Food loss of perishable produce from farm to retail: evidence from tomato supply chains in South India*，AJCN115(6):1535–1548，DOI[10.1093/ajcn/nqac039](https://doi.org/10.1093/ajcn/nqac039)。该研究的2019—2020年调查按交易参与者报告的品质/等级比较预期市场价格，见Methods及Figure3。其1—9分为综合品质强度，**不是实验TA，也不是实际成交价序列**。[原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC9170466/)；本地[原始XML](sources/south_india_tomato_2022.xml)已下载并核验SHA。

因此，“番茄等级与价值有关”有直接同商品证据；“TA与价格按指定线性函数变化”仍未验证。未把图中均值猜成精确回归系数；该文原始数据/代码需向作者索取，当前未取得，也未发送联系消息。

[UC Davis番茄采后指南](https://postharvest.ucdavis.edu/produce-facts-sheets/tomato)给出成熟绿果12.5—15°C、浅红果10—12.5°C、硬熟果7—10°C（3—5天）。这是成熟度相关技术指南，不是本项目拟合数据；不能仅凭4°C下TA保留较好就宣布整体品质最优，也不能据此断言一天4°C必然不合格。

## 鲻鱼：保留同指标实验参数

既有[Fishes2024原文](https://doi.org/10.3390/fishes9120480)Table6给出的有氧冷藏鲻鱼片整体感官下降速率为4°C下0.452±0.056分/天，活化能81.4±9.8 kJ/mol，接受阈值5分；Figure6c起始约9分为读图近似，不是本项目批次实测。参数可用于感官品质约束与变化评价，尚不能推出鱼的售价函数；两种论文都用1—9量表，也不意味着测量同一品质。

## 制冷：热量、输入电能和燃油分开

[品质驱动冷链路由论文](https://doi.org/10.1016/j.ijpe.2020.107849)§3.3式17—20分别计算壁面/开门热负荷，并经COP、转换效率和燃料热值换算燃油。对应[既有本地原文](../sources/quality_driven_2021.pdf)。按该会计关系：

`E_electric = E_heat / COP`；`fuel_L = E_heat / (eta_e × COP × ECF_kWh_per_L)`。

| 数值 | 可说明什么 | 不能说明什么 |
|---|---|---|
| 作者公开基准5×10⁻⁵ EUR/(W·min)=3 EUR/热kWh | 基准费用系数的量纲换算 | 当前电价或实际压缩机耗电 |
| 旧4°C情景稳态热漏1728 W→5.184 EUR/车小时 | 沿用该基准系数的费用代理 | 已校准开门、太阳辐射、热惯性或真实油耗 |
| 1.75 kW制冷量、COP1.66→输入约1.054217 kW | [2023年CO2机组论文](https://doi.org/10.13380/j.ltpl.2023.01.009)同一工况的推导 | 20吨基准车辆的道路功率/占空比 |

最后一行工况为环境30°C、厢内0°C、80 Hz、9 MPa；输入定义含压缩机和冷风机。原实验为焓差室机组测试，18 m³厢体背景与20吨车型尚未匹配。固定共同工资继续从方案排序中省略；若增加车辆或加班改变费用，才需另配置有来源的增量成本。

- [新配置](../../../configs/static_delivery/direct_value_evidence_v2.json)逐项保留数值、单位、证据身份和缺项；[计算模块](../../../comparisons/static_coldchain/adapters/direct_value_evidence.py)支持同币种归一化、分级报价和热量换算，拒绝TA冒充原文品质指数、跨币种相减及缺失COP。

- [上一轮72次ALNS](../net_benefit_scenario/README.md)保留为假设情景；通用品质端点比不再推荐为番茄校准默认。不能只把rho改成0.6，继续使用未验证TA线性价格式，再声称已获论文支持。
- 下一步优先取得上述番茄同指标完整品质动力学及补充材料，或取得可验证的等级/剩余货架期映射，再定义交付验收与销售渠道；同时闭合共同币种和车型成本。随后冻结评价协议并开展MaskCO对比。原Solomon及作者改编实例继续使用，不制造新坐标、需求或初始年龄来放大收益。

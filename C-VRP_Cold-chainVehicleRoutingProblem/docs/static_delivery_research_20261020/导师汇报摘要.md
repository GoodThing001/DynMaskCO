# 静态冷链配送：当前可汇报的初步进展

文档版本：[全项目文档索引](../文档索引与版本状态.md)。

日期：2026-10-20。

研究目标为：利用MaskCO的掩码重构范式求解静态多车冷链配送，在客户服务、容量、时间窗、温区和交付品质要求下最大化单次配送净效益。食品范围优先樱桃番茄与有氧冷藏鲻鱼片。已完成的RRP年化成本模型保留作基准，不代表新的商品利润模型。

已完成三项基础工作：

1. **数据与对比框架。** 原版Solomon56例和作者发布的品质约束改编Solomon56例已按原字节保存并核验。后者明确km、kg和min单位，但其通用品质指标不等同食品实测。重新评估原17种对比方法，补充ALNS、HGS和CaR；新目录保存7个官方仓库的8份固定版本源码。
2. **品质和功率证据。** 番茄TA采用一阶Arrhenius；鲻鱼整体感官评分采用零阶Arrhenius，参数来自各自同指标论文。完成30项恒温参考计算。另从2023年CO2冷藏车机组同一运输工况的1.75kW制冷量和1.66COP，推导约1.054kW输入功率；仅适用该实验工况，尚未与本项目载重和开门占空比匹配。
3. **实际经典基线。** 对C1/C2/R1/R2/RC1/RC2六类各首个100客户实例，用OR-Tools和PyVRP各10秒搜索，12/12解由独立评价器验证可行，另有9项针对检查通过。C101和C201两方法的车数与距离均达到SINTEF两位小数参考；PyVRP在R101也达到该显示精度。R201的PyVRP多用1车，RC101两方法分别多用2/1车；这些不足如实保留。详细车数、距离和时刻见[完整初步结果](initial_results.md)。

当前尚不能报告番茄/鲻鱼净利润或MaskCO优于传统算法。TA损失不是质量kg损失，鱼的评分也不是价格比例。初始品质/货龄、产品与订单的对应、商品价格/品质折价、匹配车辆及能源价格仍缺，未用虚拟单位掩盖这些缺项。已有传统基线是经典路由目标，不能与未来净效益目标混作同一主表。

下一阶段先补齐同商品的价值合同与车辆物理匹配，建立独立净效益评价器及ALNS基线；以小例验证后，再进行MaskCO和神经候选的同目标训练、分组测试与公平预算比较。现阶段不通过生成客户、放大损耗或改参数制造正收益。

主要论文与逐项出处见[参数与价值关系](论文参数与价值关系.md)、[证据目录](sources.json)、[参考文献](references.bib)。以上结论仅来自当前已核验材料和实际运行，不以文献中的算法收益代替本项目结果。

2026-10-21研究调整：[面向算法论文的模型证据与实验协议](../static_delivery_research_20261021/论文实验协议.md)。已取得RCR货币损失与耗油制冷成本、IJPE 80%及EJOR 90%—93%品质阈值原文，统一单位及双分区证据另列。真实企业价格与车型校准不再作为主算法数值实验门槛，重点转为冻结可复算问题、改造MaskCO和强基线同目标比较；本次没有新训练、路线或优势结论。下述为历史阶段材料。

日期：2026-10-20。

最新选型结论：[11篇原始冷链路由论文对照](dataset_product_review/README.md)。经典Solomon改编与通用易腐商品数值设定在所查论文中多次出现，具体应用另有鲜切蔬菜、牛奶、鲜肉；没有依据把番茄＋鲻鱼称作通用组合。建议主算法实验采用经典体系和明确的通用商品价值损失会计，小型公开鲜切蔬菜案例补充物理验证；番茄/鲻鱼作为原应用候选保留。已补4份原文、6张关键原页、7客户/3商品案例表及成本数值候选；未启用新协议或计算新利润。以下均为既有阶段结果。

最新参数证据：[同商品价值与制冷单位审查](direct_value_evidence/README.md)。Gaukler等2023藤熟番茄案例给出1600 USD/托盘历史参考、低质价格比0.4—0.8、原文品质指数阈值55和9°C参考；这不是TA—价格拟合。南印度调查支持分级与预期价格的关系，仍缺可直接移植的精确映射。新增9组计算及6项检查，未新增路线搜索；旧情景通用rho不再推荐为番茄校准默认。藤熟番茄作为新证据候选，与下述樱桃番茄TA实验身份分别保留。

最新新增：[文献数值情景净效益计算](net_benefit_scenario/README.md)。已从参数调研推进到实际搜索：6个完整100客户作者实例、4种价值设定×3种子共72次ALNS搜索和6个共同初解，78份路线/财务独立重算及10项新语义检查通过。中心设定下18个配对中17正1负；结果是明确假设下的数值研究，非真实利润预测或正式算法优势。较早的[论文初始数据调研](parameter_origins_followup/README.md)及其“未新增运行”表述保留为前一阶段记录。

研究目标为：利用MaskCO的掩码重构范式求解静态多车冷链配送，在客户服务、容量、时间窗、温区和交付品质要求下最大化单次配送净效益。食品范围优先樱桃番茄与有氧冷藏鲻鱼片。已完成的RRP年化成本模型保留作基准，不代表新的商品利润模型。

已完成四项基础工作：

1. **数据与对比框架。** 原版Solomon56例和作者发布的品质约束改编Solomon56例已按原字节保存并核验。后者明确km、kg和min单位，但其通用品质指标不等同食品实测。重新评估原17种对比方法，补充ALNS、HGS和CaR；新目录保存7个官方仓库的8份固定版本源码。
2. **品质和功率证据。** 番茄TA采用一阶Arrhenius；鲻鱼整体感官评分采用零阶Arrhenius，参数来自各自同指标论文。完成30项恒温参考计算。另从2023年CO2冷藏车机组同一运输工况的1.75kW制冷量和1.66COP，推导约1.054kW输入功率；仅适用该实验工况，尚未与本项目载重和开门占空比匹配。
3. **实际经典基线。** 对C1/C2/R1/R2/RC1/RC2六类各首个100客户实例，用OR-Tools和PyVRP各10秒搜索，12/12解由独立评价器验证可行，另有9项针对检查通过。C101和C201两方法的车数与距离均达到SINTEF两位小数参考；PyVRP在R101也达到该显示精度。R201的PyVRP多用1车，RC101两方法分别多用2/1车；这些不足如实保留。详细车数、距离和时刻见[完整初步结果](initial_results.md)。
4. **净效益情景与数据冲突审计。** 番茄采用论文售价/采购比例和实验TA动力学，另明确提出待验证的TA—价值映射；制冷采用作者基准热学参数的稳态费用代理。原作者56例中9例在本轮明确速度/服务/返仓时域下存在必要条件冲突，原件不改；预先按六类各取首个通过检查的规则选择C105、C205、R101、R201、RC101、RC201。比较净效益搜索与同预算成本控制组，保留全部正负配对；不是原作者完整VRPTWQ算法复现。

当前可以报告“带明确假设的番茄情景净效益”，仍不能报告实测番茄/鲻鱼业务利润或MaskCO优于传统算法。TA损失不是kg质量损失，TA—价格映射尚未实证验证，番茄可售阈值未配置；路由可行不能写成食品品质完整合格。鲻鱼只计算相同路线下的感官品质反事实，不计货币收益。恒温与制冷热负荷代理也需进一步校准。已有经典路由结果与新情景分表报告。

下一阶段优先验证或替换同商品的价值假设，明确番茄交付接受指标并完善车辆热负荷，再冻结共同协议，适配MaskCO和神经候选的同目标训练、分组测试与公平预算比较。独立评价器和ALNS情景基线现已具备，当前没有运行新神经训练。

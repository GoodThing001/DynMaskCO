# 冷链路由论文使用什么数据和商品：选型与补缺

2026-10-20。**建议把Solomon体系作为主要算法基准，把“通用易腐商品”作为明确的数值研究对象；再用公开鲜切蔬菜案例检验食品品质和运输物理机制。** 番茄、鲻鱼仍是已有证据的应用候选，不把两者强行组合成所谓通用冷链标准。

这是对11篇代表性路由原始研究的有界核查，另补查3项食品/价值证据。检索包含Solomon相关词，样本有选择性，**不能据此给出全领域商品使用频率或声称某一商品最常用**。证据支持的是：经典路由数据与商品参数常分别提供，未发现一套可以直接覆盖本项目全部需求的统一标准食品利润数据集。

El Raoui的制冷系数Table4写作0.03/0.04 EUR/unit，而式(3)–(4)乘时间：不能擅自改标为欧元/kWh或实测功率。其式(6)–(8)提供指数形式的交付/卸货价值损失；但§6.2式(35)的CPLEX比较仅用C1+C2+C3，**未含C4货损**，不能直接拿其表中成绩充当完整新目标成绩。Table4的alpha=0.8也未被本轮确认是食品验收阈值。

Zhu的Table2没有写出eta1/eta2的时间单位，正文还出现“开门损耗更快”与eta1>eta2的叙述冲突，而表中0.005<0.01。原表值可引用；正式实现前仍需统一原始时间尺度并审计公式，不能用引用遮盖单位/符号缺口。机器参数保存于[parameter_examples.json](parameter_examples.json)，身份为协议设计候选，没有激活为实验配置。

## 最大净效益如何保留

若订单数量固定、全部必须交付，记参考总价值`B=PΣq_i`，可以采用文献货损计价口径：

`最大化 Π = B − 交付价值损失 − 运输费 − 制冷费 − 决策引起的固定费用`。

这是参考价值减损失的数值净效益，等价于最小化包含相同价值损失的总成本。若售价完全固定且交付价值损失也不随决策变，目标就退化为普通最小成本；仅改名称不会产生新的效益机制。不得同时从收入扣一次相同折价、又在成本扣一遍同一货损。

采用虚拟价值单位时，所有货币项除以同一个正参考金额即可。例如沿El Raoui价格20欧元/单位归一化：基准产品价值1，车辆固定系数1.25，距离系数0.15，制冷时间系数0.0015/0.002（沿该文时间单位）。**虚拟单位能统一目标尺度，不能补出缺失的时间物理单位、品质阈值或真实商品校准。** 固定共同工资按用户约定省略；如果方案改变用车或加班，才配置相应增量费用。

本项目仍保留容量、恰好一次、时间窗、返仓时域和品质验收约束；文献的软时间窗、允许拒单、多目标排序或开放路线不直接照搬。这里完成的是有依据的模型选型，并非宣称已完成一个与原文全规则一致的新求解器。

## 本轮实际补齐的数据与仍缺的证据

已新增[QDVRP公开表转录](../../../data/published_cases_20261020/QDVRP_2021/README.md)：8×8距离矩阵、7×3需求、8×8有向速度，需求总计12671kg。保留Product1/2/3编号，不把它们擅自命名成番茄/鱼；不反推坐标、不增造时间窗。参考速率依次3.08、3.84、1.96×10⁻⁶ s⁻¹，活化能77.900、76.304、88.521kJ/mol；这些k0用于原文**参考温度修正的**Arrhenius式，不能当作未平移式的前指数因子。

食品层另核对[Tsironi2017](https://pubmed.ncbi.nlm.nih.gov/27745710/)正式论文摘要：研究的是气调混合鲜切沙拉，40%红叶生菜、45%绿叶生菜、15%芝麻菜；货架期终点与假单胞菌8log(cfu/g)及维生素C损失20%有关。它提供实际指标和阈值依据，但完整动力学表尚未取得，也不能把这一混合配方直接配给QDVRP的3个编号商品。较早会议摘要的配方与正式论文不一致，本轮采用正式论文身份。

番茄方面进一步核清[Gaukler2023](https://pure.eur.nl/files/155582174/1-s2.0-S037722172300200X-main.pdf)p630：0—100品质是与剩余货架期相关的物流指数；其两档价格不是TA线性价格。完整温度相关k0(T)及补充参数仍未取得。不能因为补出了价格端点就宣布动力学—价值链闭合。

鲻鱼方面找到[2021年空运鱼货检验论文](https://ejabf.journals.ekb.eg/article_207405_49d6e492d9bacc74e5efe504574b5d61.pdf)Table4，p898：grey mullet拒收960kg、按3科威特第纳尔/kg计损2880第纳尔。该信息来自期刊原文索引，本地直取SSL失败；拉丁种名/制备规格与有氧鲻鱼片未匹配。它可支持“整批拒收×计价”的经济损失例子，**不能补成鲻鱼片感官分数—售价曲线**。

因此，当前更合理的推进方式是：**先把通用易腐品基准的单位与损失会计协议固定，再进行MaskCO和ALNS的同目标比较；鲜切蔬菜公开案例作物理层补充，番茄/鲻鱼的市场化利润继续单列待校准。** 本轮没有改变现有实验商品或配置，没有凭空补价、生成客户或运行新训练。

## 主标准的时钟与公式

`rrp_mip_dimensional_v1`公式优先并明示量纲修正。仓库`a0=t0=d0=start_time*3600`；P为本车已卸托盘数，从0计：

```text
a_j = d_i + 3600*distance(i,j)/speed(floor(d_i/3600))
t_j = a_j + wait_j                    # 服务开始模型钟
d_j = t_j + service_j
service_j = 300 + 2*12 + Σ[p=P…P+q_j−1](36 + 2*3*floor(p/3))
```

每车只装其需求乘600kg，服务后扣货再算出弧，回库0载量。出发槽决定整弧速度，跨小时不切速；热学按服务开始槽查表。

```text
F_traction_tour = Σ_arcs[A*d*(7450+remaining_load_kg) + B*d/v + C*d*v²]
E_trans_year = Σ_arcs Σ_month[days_m * table[m,slot(t_i),7]
                             * (t_next−t_i)/3600 / table[m,slot(t_i),8]]
E_inf_year = Σ_customers Σ_month[days_m * (table[m,slot(t_i),5]
                             + table[m,slot(t_i),6]*(service_i−40))
                             /3600 / table[m,slot(t_i),8]]
C_traction_year = F_traction_tour * 329 * 1.4
C_refrigeration_year = (E_trans_year+E_inf_year) * 0.30 * 1.4
C_driver_year = (return−start) * 329 * 0.0022   # with_wage；另一目标不含工资
C_total_year = C_traction_year + C_refrigeration_year + C_driver_year
```

`t_next`为下一客服务开始，末弧为返仓，MIP式(14)连续覆盖全部等待；CP式(34)写服务+行驶，与之不同，本轮明确选择MIP。客户服务>40s；仓库服务0，不套客户开门热式。制冷已按月日数年化，不再乘329。

## 原资料冲突的处理

1. 式(20)印刷2ψ，JSON/TXT及Figure3数列更接近1ψ；默认保留2，不调系数追成本。
2. 式(13)除σ、表1给L/kWh；依表内单位乘σ，不能称字面式(13)复现。
3. Table7(b)13/15向量等于`[0,*TXT_raw[:-1]]`，支持服务前索引；D2-n9/n34为不同快照，不仅是偏移。主映射与保存钟诊断映射分别记录。
4. D1-n9的8个原零值保留，完整保存钟的所有入弧/离开等式唯一导出9个零值，记录为派生；缺物理字段仍拒绝，无pilot回退。
5. 表1 Tmax=9h与驾驶9h文字未在所列MIP/CP约束完整闭合。默认`source_day_domain`要求回库早于86400s并另报9h超限；`operational_tour_9h`显式增加总tour≤9h。二者不混用，也不提供法规合规认定。

`paper`为主公式旧别名。`archive_compatibility`用系数1、物理到达钟及保存钟诊断等待；`archive_pre_service`用系数1、服务前钟。结果携带实际等待、profile、objective和time_domain；不择成本近者为主结论。v2按保存钟逐例决定canonical的策略已撤销，旧证据保留。

## 多车继承范围

每车同仓同时出发，独立装载、卸货位置和计钟；全局恰好一次、逐车≤33托盘。车队成本逐车求和；K为显式实验上限，原论文没有车队数/固定费，不新增该分项，也不声称真实固定费为零。

Split依据[Prins2004](https://doi.org/10.1016/S0305-0548(03)00158-8)、[Vidal2016](https://doi.org/10.1016/j.cor.2015.11.012)，只对给定排列/等待求最优连续分割。一般DP的O(Kn²)不含段评价耗时，没有套用线性CVRP证明；原订单/容量不变，多车是新方法扩展。

完整重算、全可行、全部成本一致、原算法复现是不同结论。本轮默认标准只有前两项通过，其余残差保留。番茄/鱼品质动力学、多温舱和可售阈值未启用。

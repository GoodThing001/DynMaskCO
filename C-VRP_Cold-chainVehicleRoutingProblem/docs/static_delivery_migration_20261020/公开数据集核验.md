# 静态冷链配送：公开数据集核验

文档版本：[全项目文档索引](../文档索引与版本状态.md)。

> 文档身份（2026-10-20同步）：首轮候选研究快照。当前只启用原RRP，且已实现同构多车扩展；本文“先单车/以后多车”是当时顺序，不是当前进度。其他下载候选和原中心清单已移入`archive/transition_20261020/public_dataset_candidates/`；当前多车取舍见[后续数据核验](../static_delivery_followup_20261020/multi_public_data.md)。

核验日期：2026-10-20。范围为公开路由实例及其原始文件，不生成客户、需求、时窗或路线，不运行训练/求解，不改 `MASKCO_code/`。小型原始文件保存在扩展目录 `data/public_sources_20261020/`；逐文件 URL、版本/DOI、许可、下载 UTC 时间、字节数与 SHA256 见该目录的 `download_manifest.json`。下载与元数据访问总量远低于本轮 20 MiB 边界。

## 结论与选择边界

**用户本轮已选择“优先完整复现公开 RRP 冷链基准，再扩展多车”。因此 RRP D1/D2 是本轮首选主数据；先保持原单车冷冻食品配送合同、原参数和已知时变气候/交通，不添加逐客户时窗或多车。** 原始实例全部输入静态已知；时间依赖行程/能耗不等于动态订单。Solomon / Gehring–Homberger 仅作为以后多车+时间窗扩展的候选，不能用它们替代本轮已选定的 RRP 复现任务。

“不自行随机生成路由数据”与“必须全部为真实业务采集”是两种要求。Solomon、MaskCO CVRP 和 RRP 的作者公开实例包含合成/半实证基准；使用其已发布原始文件满足前者，却不自动满足后者。本轮没有找到同时满足“真实番茄/鱼类订单 + 单仓静态多车配送 + 客户需求/时窗/路网完整 + 温度/品质测量完整”的可直接采用数据集。以下内容不作此声明。

## 1. 作者公开食品冷链 RRP：已完整取得，本轮首选主数据

论文：[Ceschia, Di Gaspero & Meneghetti (2020), Extending and Solving the Refrigerated Routing Problem, Energies 13(23), 6214](https://doi.org/10.3390/en13236214)。作者说明公开实例/答案在 [Bitbucket 仓库](https://bitbucket.org/sceschia/the-refrigerated-routing-problem/)。[公开仓库 API](https://api.bitbucket.org/2.0/repositories/sceschia/the-refrigerated-routing-problem) 返回 `is_private=false`。

固定提交为 `f5c5317a5ecd8fe64df779e79bd0397904bc0f9e`（2021-01-03）。已下载 [固定提交 ZIP](https://bitbucket.org/sceschia/the-refrigerated-routing-problem/get/f5c5317a5ecd8fe64df779e79bd0397904bc0f9e.zip)，205,296 bytes，SHA256 `55de1479ac1d51f91cc5cf4a39ad90e5006015e914848b3d57861a3465fab1d7`。安全提取 README、D1/D2 各 15 个数据 JSON、各 15 个答案 TXT，共 61 文件，原文件合计 1,848,297 bytes。逐项清单为 `refrigerated_routing_rrp/download_manifest.json`；仓库 `size=579280` 不是解压文件总量。

**来源性质。** 论文原生研究冷冻食品配送，参考实际气候与交通资料，但其 §5.1 明确使用参数化实例生成器、随机放置节点。应称“作者公开食品冷链基准/半实证场景”，不能称全部真实企业订单。这里使用的是作者已发布原文件，本轮没有再生成实例。[论文 §5.1](https://www.mdpi.com/1996-1073/13/23/6214)

**实际 JSON 字段。** 抽样 `D1-n4-np33.json`：`clients=4`，`demands=[0,11,11,11]`，`distances` 为 4×4 矩阵；`clients` 包含仓库，不能把文件名 n4 当 4 个客户。`Tint=-20`；含 `U`、`surface`、`cp`、`mass`、`carb_weight`、`A/B/C`、`alfa`、`fuel_cost`、`driver_wage`、`fix_time`、`opening_time`、`row_q`、`row_time`、`refr_fuel` 等参数，以及 `start_time`、`time_up`、`days`、`month_days`、24×5 的 `speed_ranges`、288×9 的 `temperature_ranges`。没有客户坐标，也没有逐客户 `tw_start/tw_end` 数组。物理量含义和单位需逐项对照原论文，不能凭变量名猜测。

**答案用途。** README 只称其为 best solutions；不能把全部 TXT 无条件称为已证明最优解。TXT 提供路线、等待/到达/停靠/旅行/离开时间及成本分量。本轮先完成来源/格式核验，随后另做[全部30份作者既定解的静态代数核验](rrp_reference_algebra_audit.json)，未求解新路线、未训练或按目标值挑实例/模型。已观察的公开参考成本不能再声称盲测。该探索性复算仍有D1/D2分项和目标版本差异，状态以参数报告与原始残差为准，不写成完整复现通过。

**任务差异。** 单车全部货物起始装载的配送，目标涉及牵引、制冷和司机成本。天气/速度按时段变化不等于订单动态到达。原问题不是多车 CVRPTW；不能沿用其答案评判新多车+时窗合同，也不能把其 -20°C 冷冻品重标为鲜鱼或番茄。

**许可。** README 与根目录未发现独立 LICENSE。论文有开放获取许可，不自动推出整个代码/数据仓库均为同一许可。报告将其列为“作者公开提供研究比较的数据，仓库未单独声明许可”，不写 MIT/CC BY。若后续需要再发布原数据包，应单独核实仓库使用/再分发条件；此项不阻碍本轮公开读取与来源核验。

## 2. Solomon / Gehring–Homberger / CVRPLIB：公开路由基准，不是原生冷链

[SINTEF Solomon 入口](https://www.sintef.no/projectweb/top/vrptw/solomon-benchmark/) → [100 customers 与官方备份 ZIP 锚点](https://www.sintef.no/projectweb/top/vrptw/100-customers/)；另有 25/50 客户版本。不要把页面措辞中的“100 instance definitions”解释为 100 个问题：经典 100 客户 Solomon 套件为 56 个实例；实际采用时以下载清单再核对。[原作者入口](http://web.cba.neu.edu/~msolomon/problems.htm) 可能受旧站迁移影响，优先 SINTEF 备份。

[官方格式说明](https://www.sintef.no/projectweb/top/vrptw/documentation2/) 定义：车辆数 K、容量 Q；节点 0 为仓库；每行节点号、X/Y、需求、ready time、due date、service time。due date 是**最晚开始服务**时间。原基准距离与行程时间数值相等。SINTEF BKS 用先最少车再最小距离的层级目标和 double precision；新冷链目标改变后，原 BKS 不能充当新目标最优值。

[Gehring–Homberger 官方入口](https://www.sintef.no/projectweb/top/vrptw/homberger-benchmark/) 提供 200/400/600/800/1000 客户规模；仍为欧氏 VRPTW。适合之后的规模扩展，不因规模更大就自动适合小样本训练。本轮未从网页中找到明确数据开源许可证，不能替其宣称 CC BY/MIT。公开下载与明确许可证是两回事。

[CVRPLIB 原入口](https://vrp.atd-lab.inf.puc-rio.br/) 当前可能跳转到 [新入口](https://galgos.inf.puc-rio.br/cvrplib/)。库内不同家族可能是合成或案例数据，且标准 CVRP 家族通常没有时窗；不能把整个 CVRPLIB 都说成 VRPTW 或真实冷链。选用前应逐实例核对 depot、坐标/矩阵、需求、容量、距离舍入规则与文件来源。

**下载状态。** 本轮网页工具读到 SINTEF 页面、格式与备份下载锚点，但本机直连页面/试探 ZIP 返回 403，网页工具点击 ZIP 缓存失败；尚无官方 ZIP 的成功下载哈希。不得将猜测的 `/globalassets/...zip` 路径列为已核实直链。应从以上官方页面的备份链接取原包，取得后核对原始 56 文件并保留哈希，再纳入正式数据登记。

**推荐标注。** “使用公开 Solomon VRPTW 原实例，附加文献支持、预先锁定的冷链物理配置”。不得写“Solomon 冷链实测数据”。保留原节点、需求、时窗和服务时间；长度/时间单位转换必须确定且可追溯。对某个时段统一映射成物理分钟/公里是模型适配，不能伪装为数据本身的物理实测单位。

## 4. 已下载的其他候选

### 4.1 易腐品 cross-docking：Figshare

[VRPCD for Perishable products -Data Set](https://doi.org/10.6084/m9.figshare.5593357.v1)，Rahbari 等，2017；[官方 API](https://api.figshare.com/v2/articles/5593357) 明确 public、非 metadata-only、CC BY 4.0，只有一个 **XLSX，不是 ZIP**。[稳定下载入口](https://ndownloader.figshare.com/files/9729508)，原名 `VRPCD for Perishable products -Data Set.xlsx`，73,276 bytes；SHA256 `eccfe8934be727ebf32fc3deb2dd9ab534603c65561cd51035c46be29bd4ee85`。

已检查 8 sheet 和 `iter1..iter20`：`a_iter/b_iter` 时窗上下界；`c_iter` 节点间旅行时间；`Dip_iter` 按产品需求；`fl_iter` 产品寿命；`Wp_iter` 保鲜相对权重；`u_il` 订单到入库车映射。`c_iter` 是稀疏弧表，不应未经验证直接补成全连接距离矩阵。无客户坐标、温区或制冷设备测量。适合易腐品调度小实例独立验证；先还原入/出库与起终点语义，不能删除 cross-dock 约束后仍声称复现原任务。寿命和产品 p1/p2/p3 也不能直接重标为某种真实食品。

### 4.3 Suguo 门店库存路由案例

### 4.4 药品冷藏物流 VRSP-OAPRL

[Lee & Kim, 最新 V3, 10.17632/yrdc5d6j93.3](https://data.mendeley.com/datasets/yrdc5d6j93/3)，不是仅 V2；CC BY 4.0。[官方元数据 API](https://data.mendeley.com/public-api/datasets/yrdc5d6j93) 给出原文件 `Experiemental Data of VRSP-OAPRL.zip`，310,026 bytes，SHA256 `7f27115b370d9741805910c1b3e3ad99d7e3caf03833a043fd898e7011c6cee4`。已下载，ZIP 共130项，包含小/大规模与敏感性实验 CSV。

### 4.5 多仓医疗冷链 Zenodo

## 5. 有文件但不应作为首选的食品文献候选

## 6. 公开路由 + 文献物理参数的可接受边界

1. 原始几何/矩阵、需求、时窗、服务时间和实例 ID 直接来自公开文件；不随机新造客户，不将作者代码生成器当成本轮数据获取的替代品。
2. 冷链层独立版本化：记录食品类别、仓内设定温度、环境温度、热传导/开门/制冷效率、品质反应模型和初始品质的每项文献来源、单位及适用条件。RRP 原参数只对其冷冻食品/半挂车配置直接成立，不能无依据移植到鲜鱼/番茄或小型多舱车。
3. 缺失的温度/品质实测信息写“实验设定/文献参数”，不写“数据集测得”。固定 deterministic overlay 仍是研究者定义的适配，不能称原数据天然具备该字段。
4. 序列化/归一化、固定子集投影、单位转换可作为确定性适配，但保留原始字节、映射与哈希。任何筛选规则须在看正式测试求解表现之前锁定；不能依据 BKS 目标值挑易例。
5. 从多仓/首公里/cross-dock/多期库存或单车RRP改成多车静态配送，都改变任务。原论文最优值/最佳解只在原合同下有效，必须另算新合同基线；本轮未代跑正式实验。

因此已选定的数据路线是：**本轮完整复现公开 RRP 原实例与单车原合同；完成并核验原协议以后，再制定多车扩展合同和选择公开 VRPTW 候选。** 以后多车、逐客户时窗、多温舱或食品品质优化都属于扩展，不可拿其结果直接复述为原始 RRP 成绩。真实业务采集冷链数据仍是未闭合证据项，不用合成数据或药品标签掩盖。

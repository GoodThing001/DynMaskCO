## 0. 科学问题（从"有没有"推进到"是谁产生的"）

> 在**相同冻结锚点、相同公开状态、相同合法插入空间**下，实际冻结的 MaskCO 重构器是否产生**与强非学习重构器不同、且通过同一参考检查**的完整计划？

它要回答的不是"锚点后有没有合法候选"（ANCHOR-01 已答），而是"**候选的差异性是否由学习到的重构行为产生**"。这是 ANCHOR-01 明确无法回答、且被复核判为最关键的分界。

## 1. 七要素

| 要素 | 草案 |
|---|---|
| **唯一主对照** | 相同锚点、相同 mask、相同预算下的**非学习 distance-SGBS 重构**（仓库既有 `sgbs_search`：greedy + beam=2、每父≤2、≤8 completions、`plan_hash` 去重、distance 提议）。不加第二对照、不调参 |
| **实验对象** | **既有 15 个在途后缀相位**（SAA 9 / MYOPIC 6）。**不补抽、不新跑源日、不扩大分母** |
| **MaskCO 侧** | **冻结 M-pre decoder，不训练价值头**。定义与入口须在 `registration.json` 里先冻结（仓库 M-pre 线：冻结 `cvrp100.ckpt` 的 CVRP decoder + 适配层 + 定向 insertion 头，取**任何 REINFORCE 训练之前**的状态）；具体 checkpoint 路径、是否本地 CPU 可复现服务端 logits，属**运行前待核定项**，未核定不得开跑 |
| **主观察量** | 经**同一**参考检查接受的、**与主对照不同**的完整计划（`plan_hash`）数量；以及这些计划在**锚点之后**的首动作。两者必须分开报 |
| **关键消融** | **把 mask 选择与 repair/insertion 选择分别记账**：同一 mask 下两者的 insertion 序列是否不同；同一插入空间下两者的 mask 是否不同。只报合计差异将无法归因 |
| **资源** | CPU；小规模静态诊断；**运行上限须事前冻结**（wall-clock cap、最大候选数、单相位超时）；无 GPU、无训练 |
| **资格** | `REFERENCE_ONLY`。不声称终局效用、不声称部署、不声称优于保守域 |

## 2. 两层 Go / No-Go

**第一层（决定训练路线是否终止）**

若下列任一成立 → 判定 **CAMR 的 MaskCO 独立机制未建立**，**停止训练路线**，不再投入持久化工程与标签生成：

- 实际 MaskCO 产生的候选**无法保持锚点**；
- 或全部候选**通不过路线级参考检查**；
- 或与非学习重构器得到**完全相同**的完整计划集合（逐 `plan_hash` 相同）；
- 或差异仅出现在 mask 选择上而 insertion 完全相同、或反之——即差异可被单一记账通道完全解释。

**第二层（只在第一层通过后开启）**

若确实得到**不同且合法**的候选 → 才值得申请：(a) 更严格的参考物理检查（含**新增**能耗/品质投影路径，见下）；(b) **隔离的**事务实现。

即便第二层也通过，**不自动**获得完整认证、真实续程或训练授权。

## 3. 两个独立阻断（不合并）

1. **C0 能耗预算 `B` 未落定**。`B_ref` 是登记过的参考值，**不能**自动替代正式批准的硬预算；只要 `B` 未定，"通过冷链物理认证"就无可判定判据。相关事实（本轮复核新确认）：现有 `certify_route` 无条件返回 `projected_energy_kwh=None / projected_quality_loss=None / projected_thermal_margin=None`（`scripts/simulation/action_contract.py:171-173`），因此**能耗与品质在本管线里不是"没跑"，而是"跑不了"**——任何物理认证主张都必须先新增这条投影路径。
2. **HIST 未来支持域问题未解决**。它决定"以哪些未来信息为对照"是否合法；不解决会把未来信息泄漏成方法收益。该项不属本包可自行裁定。

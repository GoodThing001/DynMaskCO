## 0. 唯一主假设

> **H-GEOM-01**：在相同公开状态、冻结锚点、固定 mask 与共享合法动作空间下，`MaskCO-greedy` 产生的完整车队计划，其**剩余行驶距离**是否低于**冻结 distance-SGBS 候选集合中距离最短的计划**？

**唯一主对照**：`min_{P ∈ S_distance-SGBS} D_res(P)`（同一单元内）。
不再以 `distance-greedy` 为唯一对照——`S_distance-SGBS` 本身已包含它（`completions[0]` 就是无分支贪心补全），因此取集合最小即已包含更强对照。

**唯一主指标**：

```
ΔD(unit) = D_res(P_MaskCO) − min_{P ∈ S_distance-SGBS} D_res(P)
```

- `ΔD < 0` → MaskCO 的静态几何剩余距离更低；
- `ΔD = 0` → 相等；
- `ΔD > 0` → 距离搜索集合中存在更短方案。

**次级诊断（不替代主判据）**：`D_min^enum` 与 `D_res(P_MaskCO) − D_min^enum`，见 §5。

## 3. 距离指标

```
D_res(P) = Σ_{v ∈ P} D( anchor_v → suffix_v → 0 )
         = Σ_v [ dist(anchor_v, s₁) + … + dist(s_n, 0) ]
```

冻结口径（逐条对应裁定）：

- **计划来源**：`build_vehicle_plans` 语义——`closed` 车不进入计划（无剩余距离）；`committed` 车 `anchor_node = committed_next`；其余车 `anchor_node = current_node`；`suffix` 不含 `0`。
- **空后缀**：计入 `dist(anchor_v, 0)`（假设返程）。**这是一个几何完成约定，不代表引擎已决定返仓**；措辞见 `NOTE_L1A_SUFFIX_SEMANTICS.md`。
- **不计入**：已执行行程与在途承诺腿（`current_node → committed_next`）。它们在全部候选间**完全相同**，是常数平移，不影响 `ΔD`。
- **不引入**：燃油成本、制冷能耗、鱼类品质、拒单损失、`coldchain_cost`、任何效用权重。**距离减少不等于 utility 增加**，本轮不为此编造数值。
- 距离单位与缩放沿用公开视图的 `dist_mat`（Euclidean，公开坐标），**不做**任何归一化或与历史结果口径混用。

## 5. 穷举几何参考（次级止损检查）

### 5.1 定义

```
P_legal(unit) = 在共享合法动作集合下、以 mask 移除→逐单插回完全枚举得到的全部合法完整计划
D_min^enum   = min_{P ∈ P_legal} D_res(P)
```

`P_legal` 包含 `P_MaskCO` 与 `S_distance-SGBS`（两者都由同一关系产生），因此在同一距离目标上 **MaskCO 不可能严格优于 `D_min^enum`**。

### 5.2 为什么它比 L1-B 更要紧

**"固定双订单 + 小队列"意味着合法空间可能非常小。** 若廉价穷举就能轻易得到更短距离计划，那么"distance-SGBS 未覆盖"只说明**小 beam 的覆盖不足**，不说明学习评分具有独立的几何搜索价值。这是一项**刻意的科学止损检查**。

### 5.3 关于"152 个候选"的更正提示

ANCHOR-01 记录的 152（13 相位 × 8 + 2 相位 × 24）来自 **relocate 语义 + `allowed = mutable ∪ {committed}`** 的枚举；CAMR-STATIC 使用的是 **mask 移除→逐单插回**。中间状态的可行性剪枝不同，**最终可达集合可能不同**。因此：

- **不得**把 152 当作本包的闭包规模；
- 闭包规模必须在执行时**实测并报告**（`|P_legal|` 逐单元）；
- 若两者恰好相等，也只是经验巧合，不是先验结论。

### 5.4 枚举上限的逻辑方向（必须冻结）

设枚举设上限 `CAP`（拟 `|P_legal| ≤ 5000`/单元）。若某单元触顶：

- `D_min^enum(capped) ≥ D_min^enum(true)`；
- ⇒ 由 `D_res(P_MaskCO) > D_min^enum(capped)` 可安全推出 `> D_min^enum(true)`（**"MaskCO 不如穷举"的结论在触顶下依然成立**）；
- 但 `D_res(P_MaskCO) ≈ D_min^enum(capped)` **不能**推出"MaskCO ≈ 穷举最优"（触顶下最优可能更低）。
- 触顶单元一律标记 `ENUMERATION_CAPPED` 并单独列出；**不得**计入"MaskCO 达到几何最优"的计数。

## 6. 失败账（占据原定分母，不静默删除）

| 代码 | 含义 | 处置 |
|---|---|---|
| `RECOVERY_NOT_FOUND` | 记录哈希在闭包中不存在（关系不一致或闭包不完整） | 该单元 `INVALID`，**保留在 19 内**；先修关系再谈差异 |

| `METRIC_INDETERMINATE` | 距离计算出现非有限值 / 缺失公开坐标 | 该单元 `INVALID` |

# 地基约束规格（3b，文献标定 2026-09-23）

> **2026-09-28 版本范围**：本文为 09-23 历史设计，拒绝无独立罚项、Arrhenius 品质货币化、ρ=0.10 等条目不适用于 A-v1。现任务保持 make_c0_contract_v2、主 p_c=(5,10,15)、ρ=0.60 与既有预算标定；不为获得正向结果改参数。品质不绑定的数学核查及冷链证据要求见 [09-28 核查清单](../决策与审计/方向A全链路核查与正向增益改进清单_2026-09-28.md)。

上承 [A 工作包](../工程实现/动态承诺与条件场景前瞻_A_工作包.md) §4 的绿色约束 formulation。全部参数由 3 路顶刊调研标定，替换 pilot 占位值。

## 1. 目标（利润最大化，动态承诺标准写法）

```
max  Σ_{accepted} revenue(class)  −  品质损耗惩罚  −  距离(燃油)成本
```

- **拒绝 = 丢失收益**（机会成本，无独立拒绝惩罚项）——Ulmer & Thomas (TS 2020)、Bent & Van Hentenryck (OR 2004) 的标准写法。
- 品质损耗惩罚 = `Σ product_value(c)·q·(1 − Q_delivered)`（连续量，软惩罚进目标）。

## 2. 约束（硬软分层）

| 约束 | 类型 | 规格 | 依据 |
|---|---|---|---|
| 容量 | 硬 | 每车 `Σq ≤ Q`（冷链加分温区容量） | 标准 |
| 时间窗 | 硬（承诺）+ 软迟到惩罚 | 同天 TW 宽 ~2h；lead time 2–4h | Ulmer & Thomas 2020 |
| 承诺 | 硬 | accepted ⟹ 恰好服务一次、不可取消 | 动态承诺独有 |
| **品质阈值** | 硬 | `Q_delivered ≥ 0.8`（可售极限，认证口径） | Rong 2011 / Amorim |
| **绿色能耗预算** | 硬 | `E_refrig ≤ B = (1−ρ)·E_refrig^baseline`，ρ 主报告 0.10（敏感性 0.05/0.20） | GVRP/EVRPTW 能量容量先例 |

**硬软取舍**：物理/契约量（容量、承诺、品质阈值、能耗预算）= 硬约束；连续衰减/迟到 = 软惩罚进目标。

## 3. 参数（文献标定）

### 3.1 三档温区（Arrhenius 一阶 `Q(t)=Q0·exp(−k(T)·t)`，`k(T)=k_ref·exp[(Ea/R)(1/T_ref−1/T)]`，T_ref=277.15K）

| 温区 | T_set | k_ref (1/h) | Ea/R (K) | 货架期→Q=0.8 | product_value | revenue |
|---|---|---|---|---|---|---|
| 常温 | 18°C | 1.6×10⁻³ | 6000 | ≈2.5 天 | 1.0 | 10 |
| 冷藏 | 4°C | 1.3×10⁻³ | 7000 | ≈7 天 | 1.3 | 20 |
| 冷冻 | −18°C | 5×10⁻⁴ | 10000 | ≈1 年 | 2.0 | 30 |

- **⚠️ 关键修正**：pilot 的 `k_ref` 排序（常温 0.0010 < 冷藏 0.0020 < 冷冻 0.0035）**方向反了**——冷冻应最慢。文献 Ea/R 典型 6000–12000 K（Q10≈2–3），pilot 的 3500/4500/5500 偏低。
- product_value 用真实商品价差标定 1:1.3:2（冷冻肉/水产溢价）。

### 3.2 制冷能耗（绿色预算的物理量）

```
E_refrig = Σ_车 [ UA·ΔT_class·(在途+服务时长) + E_door·n_开门 ] / COP      (kWh)
```

| 参数 | 值 | 依据 |
|---|---|---|
| UA 传热 | ≈30 W/K（小型冷藏车；ATP K≤0.4 W/m²K） | UNECE ATP / CE Delft |
| ΔT_class | 常温 7K / 冷藏 21K / 冷冻 43K（T_amb=25°C） | 设定点 |
| E_door（每次开门渗入） | ≈0.2 MJ ≈ 0.056 kWh | CE Delft |
| COP | ≈1.5 | 电驱 TRU |
| 冷机功率 | 冷藏 ~1–2 kW / 冷冻 ~2–4 kW | CE Delft（0.5–1.2 / 2.5–3 L/h 换算） |

- 报告时能耗附 `×0.26 kg CO₂/kWh`（或 `×2.68 kg CO₂/L 柴油`）给碳排解释。
- **绿色只约束制冷能**（距离/燃油已在目标里罚，不进绿色约束）。

## 4. 耦合机制（绿色约束如何咬住决策——这是承重点）

每次 accept = 一次开门 = `E_door` 渗入能；每单 class 决定 `ΔT`（冷冻最耗能）；每单增加在途时长 = `UA·ΔT·时长`。→ **accept/reject 就是在不确定需求下分配制冷能耗预算**，条件前瞻正是为此。

> 注：这是**"开门能耗"耦合**（物理真实，CE Delft/ATP 标准），区别于已被驳回的"门冲击动产品温度"耦合（空气 vs 货物热容，那个确实不成立）。耦合以诚实的能量形式回来，且由绿色预算显式约束。

## 0. 研究问题（原文）

> 在相同 strict-online 可见信息、冻结承诺、合法掩码集合和计算预算下，
> 是否存在**强非学习方法未能充分利用**、但**可以通过当前公开状态预测**的**可认证重构改善**？

### 0.1 必须严格区分的四件事 → 四层门

| 层 | 问题 | 若该层不过，结论是什么 | 不得混入 |
|---|---|---|---|
| **H** · 机会存在性 | 合法候选空间里**是否存在**改善机会 | 没有机会 → 方法无从谈起 | 不得用"未来信息"制造机会 |
| **P** · 可预测性 | 机会是否可由**当前公开信息**预测 | 有机会但不可预测 → 那是**未来信息**或**规则**，不是 MaskCO 的地盘 | 不得用任何 `reveal_time > clock` 的信息 |
| **U** · 已利用度 | **强非学习方法**已经吃掉了多少 | 已饱和 → 剩余空间不足 | 不得用弱基线做比较 |
| **M** · 机制必要性 | 剩余机会是否**需要掩码生成** | 不需要 → 残余机会属学习型邻域/预算效应 | 不得把"能算更久"当成方法 |

**四层必须逐层通过，不得跳级。** 任一层的否证都是有价值的负结果，且**不**被后面层的结果翻案。

### 0.2 信息边界（硬约束，不得违例）

- 决策只能使用 **clock 时刻已揭示**的信息；归一化**必须**用 `coord_normalize_visible`，**禁止** `coord_normalize`。
- **禁止**把 `reveal_time > clock` 的订单真实信息用于在线决策（含"以未来订单数做特征"）。
- **clinch/clairvoyant 臂只能作上界参照**，**永远不得**作为在线臂参与比较或选择。
- 冻结承诺与冻结前缀不得回滚；每车每单**恰好服务一次**。

## 要素① 可证伪假设

> **H1（包级）**：在相同 strict-online 可见信息、冻结承诺、合法掩码集合与**同等计算预算**下，
> 存在**强非学习方法未充分利用**、且**可由当前公开状态预测**的**可认证**重构改善；
> 并且该改善在**同等预算的随机掩码重构**对照下**不可复现**（即它依赖"学到的掩码选择"而不是"掩码—重建这个动作本身"）。

**分解为四个可独立否证的子假设**（逐层）：

| 层 | 子假设 | 否证条件（事前固定） |
|---|---|---|
| **H** | 在**终局**口径上，完全信息枚举修复相对强非学习对照存在 > 0 的改善 | 终局差 ≤ 0，或 CI 跨越 0 → `H_FALSIFIED` |
| **P** | 仅用 clock 时刻公开状态，可**样本外**预测该改善（实例级留出） | 样本外 Spearman ≤ 0，或 CI 跨越 0 → `P_FALSIFIED` |
| **U** | 强非学习方法在**等墙钟**下**未**吃掉大部分改善 | 捕获率 ≥ `θ_capture` → `U_SATURATED` |
| **M** | 剩余改善需要在**同等预算**下由掩码重构产生，且不能被随机掩码复现 | `Δ(M − random-mask) ≤ 0` 或 CI 跨 0 → `M_FALSIFIED` |

**H1 成立 = 四层全过。** 任一层否证 → H1 否证（且该层的负结果独立成立）。

**H1 不是**"学习方法优于 distance"（那已被 §1.3 的既有读数负向回答），
**不是**"MaskCO 有效"，**不是**"在线增益已建立"。它只回答"**这条路有没有可预测的、方法专属的改善空间**"。

## 要素② 唯一主对照

> **唯一主对照（决定方法主张的那一个）= 同等计算预算的随机掩码重构臂 `M_rand`。**
>
> `M_rand`：与 M 层被测臂**共享同一 replanner、同一掩码—重建流程、同一接受规则、同一墙钟预算**，
> 唯一差异是**掩码的选取**由**均匀随机 + 固定种子**给出，而非学到的策略。

**为什么是它**：到 M 层时，distance / regret-2 / 资源规则都已在 H–U 层被吸收；此时唯一还能把
"MaskCO 掩码生成"与"任何重构"区分开的，就是**掩码选择本身**。`M_rand` 恰好隔离这一项。

| 项 | 冻结值 |
|---|---|
| 唯一变化因素 | `mask_selector` ∈ {learned, uniform_random}，其余全部冻结 |
| 共享项（机器可检验） | 同一冻结状态、同一 `P0`、同一合法掩码集合 `mask_candidate_pool`、同一接受规则、同一墙钟、同一随机种子集 |
| 随机性处理 | `M_rand` 用 **K 个固定种子**；报告其**分布**而非单次结果 |

**强制并列报告臂（不是对照，但缺一不可）**

| 臂 | 角色 | 依据 |
|---|---|---|
| `R`（regret-2） | 历史参照 | N1/N2 的既有基线 |
| `distance + SGBS` | **当前实测最强非学习** | §1.3：1.0617/1.1447，优于 R 与全部学习臂 |
| 资源机会成本规则臂 | 竞争性解释 E2 的对照 | 按 `est` 能耗/车时排序 |
| clairvoyant | **上界参照，不得在线** | §1.4 |

### 3.1 三口径必须分列（本仓既有规定）

| 口径 | 定义 | 本包使用 |
|---|---|---|
| `candidate` | 提出但**未认证**的计划质量 | H 层可用；**不得**称"部署" |

### 3.2 各层主指标（事前固定）

| 层 | 主指标 | 统计 |
|---|---|---|
| H | `g_terminal = J_vis(strong_nonlearn) − J_vis(exhaustive_best)`（**终局**，非近视） | 按**实例聚类** bootstrap 均值 + CI |
| P | 样本外 **Spearman**（可见状态探针分 vs 终局收益）+ **MAE** | **实例级留出**（instance-level split；**不是**独立样本切分） |
| U | **捕获率** = `(J(dist+SGBS) − J(R)) / (J(exhaustive) − J(R))`，**等墙钟** | 实例聚类 bootstrap |
| M | `ΔJ(M_learned) − ΔJ(M_rand)`，`accepted` 与 `closed_loop` 两列 | 实例聚类 bootstrap + **win/tie/loss** |

## 要素⑤ 预期方向和失败条件

**事前声明方向（基于 §1 的既有读数，逐条可追溯）**：

| 层 | 预期 | 依据 |
|---|---|---|
| H | **偏负**：近视有头腔，终局大概率消失 | D3 terminal_headroom_exh = −0.0055；因果头腔 myopic 有害 +0.0914 |
| P | **偏负**：可见状态对终局收益线性不可预测 | Spearman −0.0733、R² −1.362 |
| U | **偏饱和**：distance+SGBS 已用 1.7 s 超过全部学习臂 | §1.3 |
| M | **不确定**，但即使为正也面临 E1/E4 两个未充分排除的解释 | §1.5 |

**因此本包的"最可能结果"是 H 或 P 层即被否证。** 这**不是失败**——它是把"MaskCO 在动态冷链上有没有地盘"这个问题
**在最小成本下**问清楚的方式，并且**优于**再投入一轮训练。

**失败条件**
1. 任一层子假设被否证（见要素① 的表）；
2. 竞争性解释 E1/E2/E3/E4 中任一未被对照 → 该层结论降级 `EXPLORATORY`；
3. 身份不符 / 共同状态无法物化 / 掩码作用域越界 → **不启动**，记 `BLOCKED`（不是 FAIL，不是 PASS）；
4. 任何"为通过而换判据/换种子/换状态集" → 该批次**作废**；
5. 任何在线臂使用了 `reveal_time > clock` 的信息 → 该批次**作废**（信息边界违例）。

## 6. Go/No-Go 分叉

```
H 不过                        → STOP：无机会（负结果，独立成立）
H 过 · P 不过                 → STOP：有机会但不可预测 → 属未来信息或规则，**不是 MaskCO 的地盘**
H 过 · P 过 · U 饱和          → STOP：强非学习已吃掉（负结果）
H 过 · P 过 · U 有残余 → 进 M
   M 不过（≡ M_rand）          → NO-GO：残余机会不需要掩码生成机制
   M 过                       → GO（**仅限登记批次内**；不升级生产资格、不建立在线增益）
```

**止损**：每层**一次**机会；不补跑、不拼接、不换种子；首层否证即终止。

### 6.1 最小可行实验（MVE，逐层可独立停）

| 层 | 最小规模 | 运行时 | 产出 |
|---|---|---|---|
| H | 用户裁定 `|S|`；**先用 `dist_sgbs` 与枚举对照**（枚举极贵，建议小规模） | 纯 CPU | `g_terminal` 的聚类均值 + CI |
| P | 同 S 的子集 | 纯 CPU | 样本外 Spearman / MAE |
| U | 同 S | 纯 CPU（等墙钟） | 捕获率 + 预算曲线 1×/2×/4× |
| M | 同 S | **需 encoder**（见 §8） | `ΔJ(M_learned) − ΔJ(M_rand)` + win/tie/loss |

**明确不做**：不训练任何新模型、不改任何生产算法、不跑 GPU、不跑正式 rollout、不碰最终测试种子。

## 4. 七个要素的统一口径（两包相同）

① 可证伪假设 · ② 唯一主对照 · ③ 主判据与统计方法 · ④ 数据、参数、种子及允许的次数 ·
⑤ 预期方向和失败条件 · ⑥ 资源门、时间上限与停止条件 · ⑦ 完整源码、数据、合同、权重及运行身份。

**两包共同的纪律**：

- **三口径分列**：`candidate` / `accepted` / `closed_loop`——`candidate` **不得**称"部署"。
- **分母不得缩小**：`cert_fail` / `timeout` / `no_legal` / `FAILED_EXCEPTION` 全部留在分母并单列。
- **聚类统计**：按实例/日聚类 bootstrap；**禁止**把同日多状态当作独立样本。
- **一次机会**：正式批次启动即消费；不重跑、不补跑、不拼接。
- **fail-closed**：身份不符 → `BLOCKED`（不是 FAIL，更不是 PASS）。

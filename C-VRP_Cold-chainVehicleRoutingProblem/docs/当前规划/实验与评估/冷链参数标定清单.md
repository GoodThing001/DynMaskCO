## 1. 立即采用的范围

在最终版本实验前确定可解释的模拟合同、单位、nominal 与敏感性，不强制 v2-light，也不重复建一套物理实验门控。

## 3. 参数采用规则

每一最终值注明 source_id 或 assumption、原单位/目标单位、转换公式、方程兼容性、适用范围与限制。
不再用“每个参数都必须来自同一真实设备”阻断算法研究；跨来源设定必须称组合仿真，不假装是一辆真实车。

重点核查：

- 传热系数 U、UA 与有效 UA/C 不同；当前 heat_transfer_per_hour 是 1/h。
- 制冷能力不等于电输入功率；功率乘时间才是能量，门热/预冷不可重复累计。
- 品质指标的反应阶数、参考温度、Ea/R、日/小时单位与代码一致。
- 当前 Q 是数量与相对价值加权的初始品质损失比例；不能把某感官分数直接当此比例。
- 无商品阈值验证时 num_unsalable 是模拟阈值超限，不是实际食品安全结论。
- 当前 hours_per_time_unit=1、speed_kmph=1 是占位设定；最终模拟要交代里程/时间映射及路程、暴露时长数量级，不天然解释为物流工况。
- 如果 Q/E 在目标场景近常数或饱和，先查时间尺度、公式和数据分布，不能放大权重硬造主模型优势。

nominal 允许明确的仿真假设；不能把 assumption 改标签伪装成 calibrated。文档 evidence 标签与旧 loader 的 source_type 映射见[范围决策](CAL-PHYS/CAL_PHYS_SCOPE_DECISION.md)。

## 5. 数据取得与转换

优先作者仓库/附录原始数据，其次论文表格，最后才是图表数字化。
下载后登记版本/日期/许可、本地路径与实际文件 SHA；未下载时 hash 留空，不能生成假证据。
图中读取值注明 approximate_digitized、图号/坐标轴、工具和误差；图点、均值、置信带不能当独立实验重复。
公开路由数据加 reveal_time/temp_class/品质设定属于合成扩展，保存变换代码和 seed。
采用别人的原方法实验表不能替代本项目同协议重跑；更不能复用其最优成本标签宣称新方法实验结果。

## 6. 最终设定如何收敛

先按依据确定 nominal；DEV 检查单位、可行性和分量数量级；固定少量低/高压力与权重替代场景。
物理值不能由谁赢来选择；任务偏好权重可在开发中研究，但最终主设置与选择过程公开，所有预声明敏感性均报告。
参数变化建立新合同，重新估计受影响的 baseline scale 并生成匹配标签；最终比较双方均在新 evaluator 下重跑。
可以保留旧 pilot 作为方法开发/迁移对照，不混入最终 nominal 主表。
物理方程无需创新，算法方法的创新由学习、掩码重构与公平性能证据承担。

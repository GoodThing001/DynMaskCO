### 1.3 【仍需独立资格审核】`_EPS` 时间锚点与浮点误差 —— **本轮处理结果**

> **结论：本层（L1 时长）现在可以被逐项预算；但它不等于连续温度已获认证，也不等于浮点执行器已获认证。**

**用户点名的四项，逐项交代：**

| 审查项 | 结果 |
|---|---|
| **所有合法时间锚点路径** | `coldchain_updated_time` 全树只有 **6 处写入**（TBA-01 从源码机械重枚举）：`strict_online_env.py:206/230/332/403` 与 **2 处快照恢复**（`recourse_snapshot.py:305`、`dynmaskco_cc_context.py:72`）。**上一轮"锚点只能由事件循环移动"的说法不完整**：恢复路径可注入锚点，故证书**必须拒绝**区间内发生恢复（L1-4，TBA-07） |
| **浮点时间差** | 每次真实推进传入 `fl(end − depart)`，`n` 次误差**不抵消**，上界 `n·½ulp`。（TBA-03：实测累加误差 ≤ 1.11e-16，界 2.13e-13） |

**修正后的预算（替代上一轮的单一常数）**

```
Δ_eff  ≥  (clock_n − clock_{n−1})  −  SLACK
SLACK  =  [ _EPS + ½·ulp_c(T_max) ]        锚点跳过项（每区间一个常数）
        + [ max_iter · ½·ulp_c(T_max) ]    逐次减法舍入项
        + [ 0 ]                            仅当 hpu == 1.0；否则 NOT_CERTIFIABLE
```

| `T_max` | 跳过项 | 舍入项 | 合计 | 旧 `2·_EPS` 是否覆盖 |

| 1e6 h | 1.1164e-9 | **1.1642e-6** | **1.1653e-6** | **否**（差 3 个数量级） |

> **诚实结论**：上一轮的 `2·_EPS` 在**本配置下**覆盖得住（1.0e-9 < 2e-9），
> 但那是**算术巧合**，不是构造性事实；TBA-04 给出它失效的配置。

# DynMaskCO-CC 风险与解决预案

> 2026-09-18 · 路线 B / event_plan_v1。优先修会使论文结论无效的问题，不把每个研究疑问变成工程审批。

## 1. 当前最大的两类风险

一类是一直完善门控，却没有新的学习模型和方法结果；另一类是急于“比别人好”，把不公平比较或选择偏差当贡献。
前者通过 [event_plan_v1](../工程实现/event_plan_v1执行协议.md)的有限方法开发及两轮投入边界解决；后者通过共同协议、强基线、透明 DEV 选择和未见 TEST 解决。旧 teacher/M0/M1 已实现，不继续以“待搭底座”描述当前瓶颈。
实车资料不足不再列为阻断。缺来源限制现实主张，不禁止透明仿真研究。

本轮特别注意：完整计划评价尚是研究假设；首段不同不保证收益、首段相同不保证无效；候选不能按真实下一次 reveal 筛选。若只是减少接受而恢复 baseline，不算 learned 正收益。若两个有限开发轮次仍无可复现信号，收束该配方，不能继续换阈值/测试集直到赢。具体判断表统一维护在执行协议 §8。

## 2. 会使结果无效的正确性问题

| 风险 | 检查/处置 |
|---|---|
| 未来订单/温度或全体坐标归一化泄漏 | 特征白名单、visible-only normalization、未来扰动；部署不调用真实未来 oracle |
| snapshot/continuation 分支串扰 | 同状态 KEEP parity、A→B→A、独立恢复 deferred/repair |
| mutable scope、committed 或 ownership 被破坏 | full-fleet certificate 与完整写回/回退；冻结区域不变 |
| 取货/配送语义混用 | 空载出发，service_finish 入舱，return_arrival 卸货，单行程无 reload |
| 单位/热模型分叉 | 统一 contract/state/trace；D/Q/E 可重算，不用 legacy 代理作真值 |
| teacher/evaluator 合同不一致 | raw/effective contract 和 profile 均记录；变更后重生成受影响标签 |
| 缺失、非有限值被填零 | 协议错误显式失败；不进入 loss 或有效性能样本 |
| incomplete 方法靠少服务降低成本 | 全体服务失败率先报告；complete 子集只作诊断，不能赢主排名 |
| 同源实例跨 split | 根 seed、内部 seed、原实例和增强一起检查；事件/动作不能随机拆 split |
| TEST 被用于选择 | 保留污染记录；不再称未见，不循环新 TEST 直到赢 |

只暂停受影响的结果解释或计算。相关回归已覆盖且代码未变时，不从 P0-M 起重做全部流程。

## 3. 文献模拟的高频错误

- 把公开路由数据+合成温区/揭示时间称为真实冷链数据：改写为透明的基准扩展。
- 把 cooling capacity 当电输入功率，把 UA/C 当 U：核对原单位和代码公式。
- 把零阶感官指标速率放入一阶剩余品质：换兼容来源、显式变换或声明模拟假设，不抄系数。
- 引用文献即标 calibrated：仅有依据时标 literature；未完成拟合不能称本项目校准。
- 将参数范围边界组合成不合理场景：说明组合依据，做敏感性而非伪造实车。
- Q/E 数值饱和或近零：查时间映射、方程和数据分布，不能只调 lambda 使方法胜出。
- 无商品阈值依据却称食品安全/实际不可售：仅报告模拟阈值超限。
- 只挑主模型赢的物理设定：公开 nominal 依据和全部预声明压力结果。

## 4. 方法学习失败如何诊断

| 观察 | 优先检查 | 合理下一步 |
|---|---|---|
| 小训练集也拟合不了 | label/feature 对齐、loss mask、梯度、shuffle 代码 | 过拟合 sanity |
| 训练有效、DEV 无效 | 同源泄漏、标签噪声、数据量、表征不匹配 | 对照 feature-only/generic；试 adapter |
| pair accuracy 高、regret 差 | 平局占比、advantage 权重、KEEP 错误 | 以效用后果重评 |
| 分数不同、动作不变 | decoder/mask 是否进入选择 | 记录 rank、first divergence |
| 离线好、在线差 | 状态分布偏移、错误接受、fallback | 小 on-policy 聚合，不从 TEST 回流 |
| oracle 也无 headroom | 候选覆盖、尺度、预算、样本精度 | 查动作而非立即堆网络 |
| pretrained 与 generic 相同 | 输入/checkpoint/edge mode、对照预算 | 合理微调或收窄表征贡献 |
| mask/iteration 无增量 | mask 是否实际消费、K 增加的预算 | 简化方法或继续 DEV 研究 |
| thermal 去掉仍相同 | 冷链状态是否有可用决策信息 | 不声称独立冷链感知 |

M0 无显著改善不是禁止 M1 的理由；M0 可作为 M1 内部短诊断。论文贡献不需要每个尝试组件都成功。

## 5. 比较和统计风险

不能只选 NN 或 naive-masked learned baseline。加入冷链启发式、强 solver 和尽可能公平的 learned 适配，比较包含全部在线开销。
不同整方法允许不同搜索；单组件消融控制候选/fallback/预算，避免把扩大候选的收益归因给网络。
实例×学习 seed 为推断层；同 seed 的多 cell 保留相关性，action 对不能计独立 n。
正式 5 seeds 是计划目标，不可看结果挑最优 seed、追加直到显著或只报显著 cell。
报告主均值/CI、分项、服务、失败和速度；不需要机械叠加多个统计检验来“过关”。

## 6. 停止/继续的边界

正确性错误：停止解释该版本受影响结果，修复并复验。
开发性能差：允许改方法和 DEV 迭代，记录选择；不宣称已有优势。
预算超出：先缩实例/上下文计时，保留完整候选定义，不无界跑三天 oracle。
归因或 TEST 不支持：按证据删减主张、报告局限；不是删除负结果或改参数救回 GO。
独立物理数据不可得：继续路线 B，限制为仿真方法结论。
源码/备份已封口：正常开发用版本化记录，不再反复新增治理工作；旧不可变包保持不动。

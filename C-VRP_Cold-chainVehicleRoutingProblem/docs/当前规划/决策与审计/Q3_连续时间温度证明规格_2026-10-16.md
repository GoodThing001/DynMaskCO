## 0. 本规格证明什么、不证明什么

**证明（在 §1 冻结的适用域内）**：
1. 每段推进后的温度落在 `[τ_z, τ_z + δ_z]`（τ 为目标温度，δ 为门事件在该温区的升温幅度）；
2. 段内最大值的**精确**候选为 `max(T0, max(τ, Φ_Δ(T0)) + δ)`；朴素的 `max(T0, Φ_Δ(T0) + δ)` **不是**上界；
3. 由 1 直接得到硬边界安全性的**充要条件** `τ_z > low_z 且 τ_z + δ_z ≤ high_z`（本合同的三个温区均满足）。

**不证明**：
- 不以本文件宣称"温度不可能违规"这类总体命题；本规格只覆盖 §1 列出的域，**域外一律不成立**（§1.7 列明）。
- 数值对照（§5.4）**只能证伪、不能确立**：它是**验证靶**，不是证明。
- `CT-1`～`CT-5` 只作**反例验证**，**不得**用于替代本规格的证明。

## 2. 逐段数学证明

### 引理 L1（地板精确）
对任意 `T0`，`ψ_Δ(T0) ≥ τ`。

*证明*：`max` 返回其参数之一，且另一参数为 `τ`；故结果 ≥ τ。**在 IEEE-754 下同样成立**（无舍入间隙）。
这也是为什么 §7.1 只对**上界**要求裕度，对**下界**不要求。

### 引理 L2（对 `T0` 单调）
`Φ_Δ` 对 `T0` 严格增（`∂Φ/∂T0 = exp(−hΔ) ∈ (0,1]`）；`ψ_Δ = max(τ, Φ_Δ)` 为非降函数与常数的最大值，
故**非降**；叠加常数 `δ` 后，段映射对 `T0` **非降**。

*用途*：把"对某个初值成立的上界"提升为"对某个区间成立的上界"，这是 §4 归纳的唯一桥梁。

### 引理 L3（漂移条件 ⇒ 段内非增）
设 `T0 ≥ τ` 且 `h·(A − τ)⁺ ≤ c`。则 `t ↦ Φ_t(T0)` 在 `[0, ∞)` 上**非增**。

*证明*：记 `T(t) = A + (T0 − A)·exp(−ht)`（未截断自然温度），则 `Φ_t' = h(A − T(t)) − c`。
- 若 `A > T0`：`T(t)` 自 `T0` 单调升向 `A`，故 `A − T(t) ≤ A − T0 ≤ A − τ`（用 `T0 ≥ τ`）⇒
  `Φ_t' ≤ h(A − τ) − c ≤ 0`（用 D3）。
- 若 `A ≤ T0`：`A − T(t) ≤ 0` ⇒ `Φ_t' ≤ −c ≤ 0`。
两情形都非增，且两情形**穷尽**。∎

*推论*：`Φ_Δ(T0) ≤ Φ_0(T0) = T0`。**这正是"段内最大值不超过段初值"的来源**，也是 §3 中
"门事件是唯一可能抬高温区的机制"的来源。

**D3 的实测**：`h(A−τ) = 1.4000 / 3.3600 / 5.1600` 对 `c = 2.0 / 5.0 / 8.0`，
差值（即 `Φ'` 在 `τ` 处的值）为 **−0.6000 / −1.6400 / −2.8400 ℃/h**，全部严格为负。

## 3. 定理 A（逐段极值，精确形式）

**定理 A**：在 D1–D6 下，设段初 `T0 ≥ τ`、无门事件，则该段温度函数非增，最小值 ≥ τ、最大值 = `T0`；
**若该段服务订单且订单温区为 `z`**，则被开启温区在**段末瞬时**取值

```
T_end,z = ψ_Δ(T0) + δ_z,
```

故该段在温区 `z` 上的**精确**最大值候选为

```
T_max,z = max( T0 , ψ_Δ(T0) + δ_z ) = max( T0 , max(τ, Φ_Δ(T0)) + δ_z ),   且  T_pre := ψ_Δ(T0) ≤ T0。
```

*证明*：段内温度函数由 L3 非增，故最大值在 `t = 0`（取值 `T0`）或**门事件之后的段末**。
门事件发生在推进**之后**（D4），故段末值 = `ψ_Δ(T0) + δ_z`；又由 L3 推论 `ψ_Δ(T0) ≤ T0`。∎

### 3.1 必须记录的更正（有数值反例）
**朴素式** `max(T0, Φ_Δ(T0) + δ_z)`（**漏掉内层截断 `max(τ, ·)`**）**不是上界**。实测反例：

| 项 | 值 |
|---|---|
| 温区 | 2（目标 −18 ℃） |
| `Δ` | 4.322996 h |
| `T0` | −17.993308 ℃（**恰在目标之上**） |
| 门 | 开启 |
| 执行器段末 | **−17.880000 ℃**（= τ + δ = −18 + 0.12） |
| 朴素上界 | −17.993308 ℃ |
| **超出量** | **+0.113308 ℃** |

原因：`Φ_Δ(T0) < τ`（冷却把未截断值压到目标之下），执行器取 `max(τ, ·) = τ`，**门再把 τ 抬高 δ**；
朴素式用的是被压到 τ 之下的未截断值，因而**低估**。在 4000 个随机段上，
朴素式被超出的最大值为 **1.133e-01 ℃**；**修正式 `max(T0, max(τ, Φ_Δ(T0)) + δ)` 从未被超出（超出量 0.000e+00）**。
这与 Q3 数学勘误的更正一**一致**，并给出了它必须更正的**数值证据**。

## 4. 定理 B（跨多次开门的组合归纳）与推论

**定理 B（可达带不变式）**：在 D1–D6 下，对任意段序列，每个温区在其**段边界**满足

```
T_z ∈ [ τ_z , τ_z + δ_z ]。
```

*证明（对段数归纳）*：
- **基**：D2 给出 `T = τ ∈ [τ, τ+δ]`。
- **归纳步**：设某段段初 `T0 ∈ [τ, τ+δ]`。
  - 由 L2（对 `T0` 非降）与 L3 推论（`Φ_Δ(τ) ≤ τ`）得 `Φ_Δ(T0) ≤ Φ_Δ(τ) ≤ τ`，故 `ψ_Δ(T0) = τ`（当 `Δ > _EPS`）；
    若 `Δ ≤ _EPS`，执行器短路返回原值 `T0 ≤ τ + δ`。
  - **无门事件**：段末 = `ψ_Δ(T0) ∈ {T0, τ} ⊆ [τ, τ+δ]` ✔
  - **有门事件（温区 `z`）**：段末 `= ψ_Δ(T0) + δ_z ≤ τ + δ_z`，且由 L1 `≥ τ` ✔；
    其余温区 `heat = 0`，增幅为 `0/capacity = 0`，其值不变 ✔
- 归纳成立。∎

**推论 B1（段内亦在带内）**：在**声明的插值剖面** `T_z(t) = max(τ_z, Φ_t(T_z(0)))` 下，
由 L3 该剖面非增、由 L1 其 ≥ τ，故**段内任意时刻**亦落于 `[τ, τ+δ]`；且该剖面在**每个段边界与执行器一致**
（`t = Δ` 时恰为 `ψ_Δ`）。**注意**：段内剖面是**声明的插值约定**，不是执行器逐步积分的结果（§4.3）。

**推论 B2（硬边界安全的充要条件）**

```
安全  ⇔  τ_z > low_z  且  τ_z + δ_z ≤ high_z          （每个温区）
```

*证明*：必要性由可达带端点**可取到**（δ 由门事件实际加入，`:424-426`；τ 由地板实际取到，L1）；
充分性由定理 B。**实测**：

| 温区 | τ | 硬下界 | τ − low | τ+δ | 硬上界 | high − (τ+δ) |
|---|---|---|---|---|---|---|
| 0 | 18 | 0 | **+18.0** | 18.03333 | 30 | **+11.966667** |
| 1 | 4 | 0 | **+4.0** | 4.08750 | 8 | **+3.912500** |
| 2 | −18 | −25 | **+7.0** | −17.88000 | −12 | **+5.880000** |

三温区**全部满足**，最小上裕度 3.9125 ℃、最小下裕度 4.0 ℃。

### 4.3 分段粒度阈值（执行器是离散格式，不是 ODE 解）
执行器每段**只调用一次**闭式，故它不是 `dT/dt = h(A−T) − c` 的时间离散；把一段拆成两段**不必然**得到同一状态。
在可达带内可给出**精确阈值**：门后最坏偏移为 `τ+δ`，而 `Φ' ≤ −margin_z := −(c_z − h_z(A−τ_z)) < 0`
直到回落到 τ，故**回落时间 ≤ `Δ*_z := δ_z / margin_z`**：

| 温区 | `Δ*`（小时） | 分钟 |
|---|---|---|
| 0 | 0.05555556 | **3.33** |
| 1 | 0.05335366 | **3.20** |
| 2 | 0.04225352 | **2.54** |

**结论**：任何时长 ≥ `Δ*_z` 的段，其段末**恰为** τ（映射为常数，粒度无关）；
只有**短于约 3 分钟**的分段才存在粒度依赖，其最大偏差实测 **3.53e-04 ℃**（对数均匀采样，4000 例）；
"长段段末不是 τ"的样本数 **0**。执行器闭式与连续 ODE 解在可达带内的最大差 **8.25e-04 ℃**。

## 7. 尚未建立 / 残余

1. **浮点上界裕度未声明**（D6）：地板（下界）是精确的；上界 `τ+δ` 的成立依赖 `ψ` 的计算与 `max` 比较，
   在 IEEE-754 下需给出**显式裕度**（例如以 `1e-9` 或若干 ulp 表示），或改为**向外舍入**求值。

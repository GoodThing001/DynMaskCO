## 1. 候选做了什么（对应 L-1…L-5）

| 要求 | 实现 |
|---|---|
| **L-1 深度冻结** | `deep_freeze_plan()` 递归冻结为 `FrozenFleet`/`FrozenVehiclePlan`（frozen dataclass）+ `tuple` suffix；`assert_deep_frozen()` 递归断言，发现 `dict`/`list`/`set`/**非 frozen dataclass** 即 `FREEZE_NOT_DEEP` |
| **L-2 只读输入 + 前后各核对** | 回调收到 `MappingProxyType` 视图；**安装前**与**安装后**各算一次**冻结对象**的完整身份 |

| **L-5 锚点交叉核验** | `anchor_cross_check()` 用**冻结执行状态**核 `anchor_node` / `anchor_time` / `anchor_load`，不一致 ⇒ `ANCHOR_NOT_FROM_FROZEN_STATE` |

## 3. 安装边界：四档结论与它们的可证边界（报告要求第 2 类）

| 档位 | 何时 | 可证 | 实测 |
|---|---|---|---|
| `REFUSED_BEFORE_INSTALL` | 安装前核对失败（证书缺失/身份不符/锚点不符） | 回调**从未调用**，`n_installs=0` | C7（调用方在认证后改计划 ⇒ 回调 0 次）、C12（锚点不符）、C13（无证书） |
| `INSTALL_COMPLETED` | 回调正常返回且冻结身份不变 | 冻结体前后一致，归档绑定该身份 | C6（**内容相同但对象不同**的合法情形通过） |
| `INSTALL_ROLLED_BACK` | 回调已执行、后置核对失败、**回滚已执行且报告成功** | 回滚跑过并报成功；**post-rollback 状态未被本模块独立复核** | C11 |
| `INSTALL_OUTCOME_UNVERIFIED` | 回调已执行、无已复核回滚 | **只**能证明回调被调用 | C8（回调改冻结体）、C9（回调抛异常）、C10（先写副作用再失败） |

**S-19 的核心约束已落实**：

- 只有 `REFUSED_BEFORE_INSTALL` **可以**声称"没有安装"；
- `INSTALL_OUTCOME_UNVERIFIED` 的收据用文字写明 **"does NOT prove that nothing was installed"**；
- `INSTALL_ROLLED_BACK` 的收据写明 **"the state AFTER the rollback is not independently verified"**；
- **没有任何一处**用"事后多算一个哈希"冒充安装原子性（C17 逐条核对四档措辞不同）。

## 4. 不能证明的物理资格（报告要求第 2 类，逐条）

| # | 不能证明 | 说明 |

| P-4 | **多线程 / 并发**修改 | 未覆盖 |
| P-5 | **跨进程 / 外部进程**修改 | 未覆盖 |
| P-6 | **逃逸引用**（冻结前保存的原对象引用） | 冻结是深拷贝，改原对象不影响冻结体；但本模块不主张原对象受保护 |
| P-7 | 真实**执行器副作用** | 只有"已复核的回滚"能部分弥补 |
| P-8 | G-2 预算资格、Q3 连续温度 | 与 G-3 无关，仍未建立 |

## 7. 与 S-19 的关系（结论）

**B-9 现在被拆成两半**，这一点必须写清楚，否则会把"身份不变"误读成"安装安全"：

| 半 | 内容 | 状态 |
|---|---|---|
| **B-9a 对象身份** | 认证对象 = 使用对象 = 归档对象，且深度冻结不可改 | **隔离候选已给出并通过 17/17**（工程诊断，未接线） |
| **B-9b 事务原子性** | 回调已执行后的副作用是否发生/能否回滚 | **未建立**（`INSTALL_OUTCOME_UNVERIFIED` 就是它的诚实表达） |

**所以本轮的结论不是"TOCTOU 已修复"，而是"TOCTOU 的对象身份一半已被机械闭合，
原子性一半被明确划为未证明"。**

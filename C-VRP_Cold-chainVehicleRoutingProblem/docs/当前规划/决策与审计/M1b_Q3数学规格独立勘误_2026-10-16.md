## 1. 更正一：精确段内极大值

### 1.1 源码执行顺序（逐行）

| 步 | 位置 | 操作 |
|---|---|---|
| ① | `coldchain_state.py:216` | `temperature_before = state.compartment_temperature_c`（段首 `T₀`） |
| ② | `:217-218` | `_advance_temperatures(...)` ⇒ **`T_pre`**（**尚不含门事件**） |
| ③ | `:232-244` | 若 `served_customer is not None`：`_apply_door_event(T_pre, ...)` ⇒ **`T_post = T_pre + Δ_door`** |
| ④ | `:413-430` | `Δ_door = door_heat_kwh[z] / thermal_capacity_kwh_per_c[z]`（**瞬时、仅开启温区**） |

⇒ 门事件**不**发生在段首之后立即，而是发生在**段尾的服务完成时刻**，且**作用于 `T_pre`**。

### 1.2 更正后的表述

对活性温区 `z`、段时长 `Δt`：

```
T_pre = max( target , A + (T₀ − A)·e^{−hΔt} − c·Δt )        (coldchain_state.py:373-376)
T_post = T_pre + Δ_door                                      (:425, 仅当该段服务某订单)
```

**精确**段内最高温候选（在 §2 的单调性前提成立时）：

```
T_max = max( T₀ , T_pre + Δ_door )        若该段有门事件
T_max = T₀                                 若无门事件（因单调不增）
```

**原文件 §2.2 的 `{T₀, T₀+Δ_door}` 是保守上界**（因为 `T_pre ≤ T₀` 时
`T_pre + Δ_door ≤ T₀ + Δ_door`）。它**可用作充分条件**，
但**宣称"精确极值属于该候选集"是不准确的**，且**上界偏松可能误拒可行计划**。

**同理**段内最低温候选为 `T_post` 之后到段尾的最小值；在单调性前提下即 `min(T_pre_final, target)`。

### 1.3 保留的限定（用户已指出，照录）

3. **门事件只加热**：`Δ_door = door_heat/thermal_capacity ≥ 0`（`:425`）；
4. **温度推进模型**如 §1.2 所声明；
5. `max(target, ·)` 使 **target 成为构造性下限**（`:376`）。

### 2.2 证明（逐段归纳）

**基例**：`T(0) = target ≥ target`。
**归纳步**：设段首 `T₀ ≥ target`。由 `:376` 的 `max(target, ·)` 得 `T_pre ≥ target`；
由 `:425` 的 `Δ_door ≥ 0` 得 `T_post = T_pre + Δ_door ≥ target`。
⇒ 对**任意**段数成立 `T(t) ≥ target`。

**与硬下限的关系（实测三温区全成立）**：

| 温区 | target | `hard_lower` | `target > hard_lower`？ |

| 1 | 4.0 | 0.0 | **是** |
| 2 | −18.0 | −25.0 | **是** |

由 `T ≥ target` 与 `target > T_hard,lower` 得 `T(t) > T_hard,lower`。**∎**

⇒ **P-1 成立**，且**下限安全可直接证明**；**不存在**"现有全开模型本身无法解释的持续过冷风险"。

### 2.3 N-3 的更正写法

**原写法（不准确）**："尚未能证明温度是否可能突破 `hard_lower`。"

**更正为**：

> **N-3′**：尚未**机械核实**所有**真实可达轨迹**均满足 §2.1 的适用域前提
> —— 即（i）全温区开启（若未来允许**关闭某温区**，则 `max(target,·)` 对该温区**不生效**，

## 3. 更正三：术语——`ambient − c/h` 不是更新函数的稳态

`A − c/h` 是**无截断连续动力学**的固定点（由 `h(A − T*) = c` 解得），
即"传热增益恰好等于制冷速率"的温度。

但**当前更新函数** `T_next = max(target, A + (T₀−A)e^{−hΔt} − cΔt)` 的**稳态是 `target`**
（当 `A − c/h ≤ target` 时），因为 `max` 把温度**钉在下限**。

⇒ **更正**：应表述为"**无截断动力学的固定点**（用于导出初始导数条件）"，
**不得**称为"更新函数的稳态温度"。

**该量的正确用途**（本轮新增，且**使证明更容易**）：见 §4。

## 4. 积极结论：单调性条件成立，连续极值证明很可能不需要数值优化

### 4.1 单调性条件

无门阶段的被截断前温度为 `φ(t) = A + (T₀−A)e^{−ht} − ct`，其导数：

```
φ'(t) = h(A − T₀)e^{−ht} − c
```

**实测（当前合同）**：

| 温区 | `h` | `c` | `h(A − target)` | `h(A−target) ≤ c`？ | `φ'(t)` 在 `T₀ = target` 处 |
|---|---|---|---|---|---|
| 0 | 0.200 | 2.000 | 1.4000 | **是** | −0.6000 |
| 1 | 0.160 | 5.000 | 3.3600 | **是** | −1.6400 |
| 2 | 0.120 | 8.000 | 5.1600 | **是** | −2.8400 |

由 §2 已知 `T₀ ≥ target` ⇒ `A − T₀ ≤ A − target` ⇒
`φ'(t) ≤ h(A − target)e^{−ht} − c ≤ h(A − target) − c ≤ 0`（**全段非正**）。

⇒ **`φ` 在段内单调不增**；叠加 `max(target, ·)`（单调不减函数）后
**`T_pre(·)` 在段内仍单调不增**。

### 4.2 由单调性得到的逐段解析界

| 量 | 解析候选（有限集，无需数值优化） |
|---|---|
| 段内**最高温** | `max(T₀, T_pre + Δ_door)`（有门）或 `T₀`（无门） |
| 段内**最低温** | `min(target, T_pre_end)` ≥ `target` |
| **全轨迹上界** | `T₀^{initial} + Σ_doors Δ_door` 的逐段递推（每段至多加一个 `Δ_door`） |
| **全轨迹下界** | `target`（§2.2） |

⇒ **用户判断成立**：在既定前提（全温区开启 + `h(A−target) ≤ c` + 有效初态）下，
连续极值证明**很可能可直接构造逐段解析上/下界**，**不需要**复杂数值优化。

**但以下四项仍须冻结后才可称"证明"**（沿用 §1.3 限定）：
①时间插值语义；②状态初值来源；③浮点容差；④`active_zone_mask` 段内不变。

### 4.3 与现有反例的关系

**T-Q2-5a（连续 9 次开门、间隔 0.01 h）** 仍是有价值的**验证靶**：
它检验"累计门增温不得越过 `hard_upper`"，其解析上界即 §4.2 的全轨迹上界。
**但它是验证靶，不是证明本身**；**CT-1…CT-5 同样如此**（沿用原文件 §2.6 定位）。

日期：2026-09-23。性质：方向决策 + 文献锚点，用户已裁定按"先 B 后 A、先无训练筛选诊断"执行；进入执行。硬约束不变：**MaskCO 为核心方法、冷链物流为领域**；不修改 `../MASKCO_code/`；全部新代码在扩展工作区内。

## 1. 为什么必须改协议：三条根因（代码层坐实）

20+ 小时负结果 + 13 个判死方向（排序/分舱/异构车队/派车时机/昼夜/预冷/中心站/搜索增强/蒸馏/交换修复…），全部命中以下至少一条：

| 根因 | 代码坐实 | 后果 |
|---|---|---|
| **R1 组合密度=0** | 50 节点 / 25 车 ≈ 每车 2 单 | 路由无组合内容；中心站批量预冷组合头腔 ≈0.003–0.015 |
| **R2 未来信息主导且不可预测** | `run_value_predictability` 线性探针 out-of-sample Spearman ≈ −0.04 | strict-online 下终局头腔=clairvoyant，任何方法都抓不到 |
| **R3 冷链物理可分且与距离共线** | `coldchain_state.py`：品质=f(取货后在途时间)、能耗=f(时长×功率+开门)、`zone=temp_class` 无指派决策 | 冷链目标=时间/距离的确定函数，一切决策坍缩成"压缩在途时间"，规则可捕获 |

→ 负结果不是"MaskCO 不行"，而是当前协议把掩码生成的全部优势域（条件补全、可行性掩码、并行多样采样）都关掉了。

## 2. 文献结论（4 路调研，含关键锚点）

1. **方法空白（最关键）**：掩码生成 NCO（MaskCO / DIFUSCO / DISCO / MDLM）只被用作**静态单实例求解器**；**没有任何工作把掩码生成用作"条件于部分计划/可见状态的随机路由场景生成器"**。这是 A 的方法新颖性落点。
2. **耦合物理有锚点**：door-opening thermal shock + box-temperature recovery（Stellingwerf 2018/2020、Giliberto & Paradiso arXiv:2504.15741）——开门加热 + 一阶恢复 + 按实际经历温度积分衰减，使**服务序列成为热决策**。
3. **因果判据**：前瞻有因果价值 iff (i) 未来需求可从可见状态预测 + (ii) 当前动作不可逆且有机会成本（Bent & Van Hentenryck 2004、Ulmer et al. 2019）。团队 D3"myopic 有害 / ≈100% 未来信息"正是 (i)(ii) 缺失的特例。
4. **诚实风险**：非线性耦合是唯一无人认领的 niche，但核心风险正是团队 D1–D7 已证的"规则可捕获"；学习型场景生成 vs 历史 bootstrap 只在"条件化 + 小场景预算"下赢（Decision-Focused Scenario Generation NeurIPS 2025、Golsefidi & Pisinger EJOR 2026）。

## 3. 方向（定稿 2026-09-23）：A 直接上——动态承诺 + 掩码条件场景前瞻

- **A（主战场，先做）**：可预测需求（空间热点 + 时间峰 + 提前期，带历史多日数据）+ accept/reject 承诺 + 派车时机；已接订单交 OR-Tools/HGS 滚动重优化路由。MaskCO 职责 = **掩码条件场景生成**（mask=未来订单，采样 K 个未来场景 + 补全计划，随机前瞻按共识 accept/reject）。冷链以 Arrhenius 凸衰减目标给决策以冷链接 stakes。贡献 = 掩码生成作为随机组合优化的条件场景生成器（文献空白）。
- **B（可选，后置）**：静态非线性冷链目标基准（距离 + Arrhenius 品质 + 能耗，不追耦合），MaskCO 构造 vs HGS/CP-SAT 的速度-质量前沿。
- **耦合物理支柱已拆**：门冲击耦合经对抗验证驳回（货物是热缓冲、门冲击动空气不动产品；放大 40–70× = 信号制造；跨区耦合仍规则可捕获），见 §4.1。三条支柱由「密度 + 可预测性 + 耦合」改为「**密度 + 可预测性/承诺**」。

## 4. 执行顺序与筛选门（均先无训练）

1. **B 协议设计 + 无训练筛选诊断**（本步）：纯 NumPy、1 天内。问题 = "耦合目标下，冷链接感知搜索相对距离路由是否有材料且非规则可捕获的头腔"。判定：无头腔 → 加强物理量级；规则可捕获 → B 死、先改物理；两者皆过 → B 立项。

   ❌ **第一步（B 协议设计 + 无训练筛选）已做，结论为负（2026-09-23）**：三个耦合物理方案（门冲击跨区耦合 / 单共享车厢 / 最小改动）被对抗复核**全数驳回**，理由一致且硬——①门冲击需放大 40–70× 才能材料（相对现有 0.07–0.12°C 尖峰），这是信号制造；②货物本身是巨大热缓冲，门冲击动的是**空气**不是**产品**温度，把 8°C 空气尖峰直接作用到产品品质正是"0.2→0.003"同类简化误差；③跨区耦合仍是单调可加的逐单门暴露和，规则可捕获（一个 `bool` 字段还会使 `validate()` 崩溃）。筛选冒烟（即便把门冲击放大到不物理的 8°C）G_S≈1.5–2% → **NO-HEADROOM**。**结论：门冲击耦合不是可行的耦合机制——B 的耦合源需重新选定**（候选：共享制冷回路能耗耦合 / 设定点×混装 / 长时未制冷转运；或承认产品品质本就逐单可分、B 前提需再评估）。生产契约文件（`coldchain_contract.py`/`coldchain_state.py`）已回退、未改动。设计记录见 `历史已收束/研究设计/B_静态耦合MCVRP_协议设计与无训练筛选.md` 顶部回传。
2. B 立项后：HGS / CP-SAT / 精确 B&P 基线 → MaskCO 条件构造对照。
3. A 立项前筛选：可预测性探针 + "历史 bootstrap SAA 相对 myopic 是否有材料头腔"。
4. A：掩码条件场景生成 vs 无条件 bootstrap（决策质量口径）。

## 5. 诚实边界

- 耦合物理单独不够，必须叠加 R1（密度）+ R2（可预测性）；三层每层都要先过筛选门，任何一层不过就回到 DGP/物理量级修正。
- B 若质量输 HGS，只能走速度-质量前沿框架，不宣称绝对更优；文献提示该框架在分布外受质疑（Distributional-Dependent Performance / Purity Law）。
- 场景生成 vs bootstrap 的胜负只在"条件化 + 小场景预算"下成立，方法主张须写成"状态条件掩码生成 vs 无条件 bootstrap 在决策质量上"。
- 无实车数据时结论只针对声明的冷链仿真，不写真实食品安全/节能收益。

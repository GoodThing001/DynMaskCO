## 1. 问题 1：非对称倍率——分母是**转置**抽样，不是自身

生成器（`generate_coldchain_data.py:84-85`）：

```python
asymmetry_noise = rng.uniform(0.85, 1.35, size=(total_nodes, total_nodes))
asymmetry_noise = (asymmetry_noise + 1.0 / (asymmetry_noise.T + 1e-8)) / 2
```

即 `A[i,j] = (X[i,j] + 1/(X[j,i] + 1e-8)) / 2`。**`X[i,j]` 与 `X[j,i]` 是独立抽样**，
所以实值上确界取"一个取最大、另一个取最小"：

```
A_max = (1.35 + 1/(0.85 + 1e-8)) / 2 = 4295000027/3400000040 = 1.263235287197232
```

我上一轮用 `max_x (x + 1/x)/2 = 1.045370`，**把同一个抽样当成了自己的倒数**。
**控制 K-1** 用精确有理数复算，并给出取到上确界的抽样对 `(X[i,j], X[j,i]) = (1.35, 0.85)`。

**后果（K-2）**：合法的单位方块对角实例（`euclid = √2`）在上确界倍率下达到
**3.572969**，高于旧上界 **2.956754** ⇒ **旧值不是域上界**。
上一轮 D-2 的实测边权 2.594 之所以"没推翻"旧上界，只是因为它**恰好落在旧值以下**——
这正好说明：**一个实测案例不能认证一个解析上界**。

## 2. 问题 2：扰动边**有放回抽样**，同一条边可被多次放大

生成器（`:103-106`、`:141-143`）：

```python
ei = rng.integers(0, total_nodes, size=n_edge_perturb)     # 有放回
ej = rng.integers(0, total_nodes, size=n_edge_perturb)
perturbed_edges = list(zip(ei, ej))                        # 未去重
for (i, j) in perturbed_edges:
    if i != j: dist_mat[i, j] *= rng.uniform(1.5, 5.0)     # 同一 (i,j) 可命中多次
```

同一条有向边命中 `k` 次 ⇒ 倍率 **`5^k`**。源码只给出 `k ≤ n_edge_perturb`：

| 参数 | 值 |
|---|---|
| `n_edge_perturb = max(1, int(N²·p·0.3))` | N=51, p=0.1 ⇒ **78** |
| 由此的倍率上界 | `5^78 ≈ 10^54`（**空界**） |

**控制 K-3**：构造同一有向边被放大两次（×25）的合法实例 ⇒ 最大边 **35.355339**，
高于旧上界 **7.071068**（k=1）与 k=1 声明下的任何值。
**控制 K-4**：两机制复合 ⇒ 倍率 `(asym×rush) × 5^k`，合成上界覆盖乘积实例。

**结论**：`long_tail_perturbation` 模型**必须带声明的 k**（`5^k`）。
未声明 ⇒ `PERTURB_MULTIPLICITY_UNDECLARED` ⇒ `NOT_CERTIFIABLE`（**控制 K-6**），
**不得静默假设 k=1**。且 `k=1` 的声明若被实例越过（59.36 h > 31.07 h）⇒ `REFUSED`（同 K-6）。

## 3. 精度问题：强制返仓用的是**有向入库边** `dist_mat[i,0]`

`_force_return_all` 走 `:273 → :664 → :304`，推进到 `depart + travel(current_node, 0)`。
"客户间某条边超过上界"**不能**证明这条**返仓路径**会越界。
**控制 K-5**：只把 `dist_mat[1,0]` 放大到 3.0（其余边全为欧氏 0.9），
经**真实** `_force_return_all` 实测推进时钟 **26.899999618530273**，
高于 `horizon + √2 = 25.414214` ⇒ 欧氏上界在该路径上确实失效；
而**depot 列见证**（`max_i dist_mat[i,0] = 3.0`）给出 4.714 的上界覆盖它。
⇒ 相关最大值是**depot 列**，不是成对最大值。

## 4. 按要求的五段分离（不得混同）

### 4.1 旧解析上界的错误

- `ASYM_MAX = 1.045370`（错，应为 `1.263235287`）；
- `PERTURB_MAX = 5.0`（错，应为 `5^k` 且 k 须声明）；
- 由二者导出的 `2.956754` / `7.071068` **不再具有"域上界"资格**。

### 4.2 已验证实例的有限域结论（**撤销解析上界不影响它**）

**K-7**：登记 3 个 split 共 **96/96** 实例，`dist_mat` 与 `euclid(coords)` 的最大偏差
`1.1e-7 ~ 1.2e-7`、对称 ⇒ **实测倍率 ≈ 1.0**、`max_multiplier_observed ≈ 1.0`。
这是**对那 96 个实例的测量**，不是任何解析上界的推论；**因此不因上界被否而撤销**。
`depot_column_max` 也已逐实例测得（示例：0.663）。

### 4.3 新的**条件化**解析上界

```
travel_bound = sqrt2_up · box · [ Π ceilings ] / tw_speed · (1 + 4·2^-52)
ceilings:  euclidean = 1
           asymmetric_transit = ((1.35 + 1/(0.85+1e-8))/2) · 2.0 = 2.526471
           long_tail_perturbation = 5^k            （k 必须声明）
           external_undeclared = 无 → REFUSED
```

`sqrt2_up` 为 `math.sqrt(2)` 向**外**膨胀 2 ulp；最终再乘 `1 + 4·2^-52`（4 ulp 相对膨胀），
覆盖路径上 `euclid → ×asym → ×rush → ×5^k → /speed` 的浮点舍入。

### 4.4 仍无法认证的外部距离矩阵

`external_undeclared` ⇒ **`DISTANCE_MODEL_UNBOUNDED`**，只能退到**逐实例测量**
（`per_instance_witness`，仅对该实例、且离线）。**不允许**在线读完整矩阵求最大边权
（`require_offline` 拒绝 `stage='online'`）。

### 4.5 `T_clock_sup` 与时间误差预算受到的影响

| 项 | 旧 | 新 | 影响 |
|---|---|---|---|
| 非对称域 `T_clock_sup`（horizon=24） | `26.956754` | **`27.572969`** | 值改变 |
| `ulp_c`（binade） | `[16,32)` | `[16,32)` | **同 binade ⇒ ulp 不变** |
| slack（n=20003, hpu=1） | `1.0710684844307253e-09` | **`1.0710684844307253e-09`** | **数值不变** |
| 身份摘要 | — | — | **改变**（`T_clock_sup` 进摘要） |
| 登记（欧氏）域 | 不受影响 | 不受影响 | 该域用逐实例见证，解析上界不参与 |

**K-8** 逐位核对上述等式。**结论**：纠错改变了**值**与**摘要**，没有改变**这个域里的数**；
但若 horizon 落在 binade 边界附近，旧基准会低估一倍（上一轮 E-02 已示）。

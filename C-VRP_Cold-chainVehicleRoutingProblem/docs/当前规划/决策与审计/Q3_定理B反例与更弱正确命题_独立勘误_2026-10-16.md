## 2. 为什么原证明错了（以及为什么此前的数值检查看不见）

1. **方向用反**：L2 说 `Φ` 对 `T0` 非降；由 `T0 ≥ τ` 只能得到 `Φ(T0) ≥ Φ(τ)`。原证明写成了
   `Φ(T0) ≤ Φ(τ)`，据此断言 `ψ_Δ(T0) = τ`、进而 `T_end ≤ τ+δ`。**这一步是错的**，
   实测反例正是"`Φ(T0) > τ` ⇒ 不截断 ⇒ 门叠在偏移之上"。
2. **根因是"斜率 ≠ 回落时间"**：D3 只约束 `Φ' ≤ −margin < 0`（`margin_z = c_z − h_z(A−τ_z)` =
   0.6 / 1.64 / 2.84 ℃/h），**不约束多快回到 τ**。从 `τ+δ` 回到 τ 需要
   `Δ*_z = δ_z/margin_z` = **3.33 / 3.20 / 2.54 分钟**；**短于它的段无法把温度带回地板**，
   于是下一次门在偏移之上再加 δ，逐次累积。原规格 §4.3 **已经算出** `Δ*`，却在定理 B 中
   把它当成"任意段序列"的结论使用——这是同一文件内部的自相矛盾，本勘误予以纠正。
3. **`Δ ≤ _EPS` 分支同样不恢复不变式**：执行器短路保留段初值（不冷却、不截断），门再加 δ（N-10：
   `4.05 → 4.1375`）。故"极短段"不是安全情形，而是**最坏情形**。
4. **此前的 4000 段数值检查在结构上不可能发现它**（N-13）：它每次只从 `T0` 采样**一个**段并比较
   解析式与执行器，**从未组合两段**；不变式是**跨段**性质。**单段采样集无法验证跨段不变式**——
   这正是"有限测试不能称作证明"的一个具体实例。
5. **`T-Q2-5a` 的定位被写反了**（N-14）：原规格 §5.5 说"`T-Q2-5a` 已被定理 B 覆盖，最坏情形恰为 `τ+δ`"。
   事实相反：**`T-Q2-5a`（连续开门累积升温）就是定理 B 的反例**，它当初是对的，是被定理 B 错误地"覆盖"了。

## 3. 替代命题（更弱但正确；均已证明并在负控中与执行器对照）

记温区 `z` 的第 `n` 段时长为 `Δ_n`，该段是否开启 `z` 为 `I_n^z ∈ {0,1}`，段初值 `T_{n-1}`，
执行器映射 `ψ_Δ(T) = max(τ, Φ_Δ(T))`（`Δ ≤ _EPS` 时 `ψ_Δ(T) = T`）。

### 命题 P1（**U 递推**，逐段上界传播）
取 `U_0 = τ_z`，`U_n = ψ_{Δ_n}(U_{n-1}) + I_n^z δ_z`。则对一切 `n`：`T_n^z ≤ U_n`。

*证明*：归纳。`x ↦ ψ_Δ(x) = max(τ, Φ_Δ(x))` 在 `Φ` 对 `x` 非降（L2）与 `max` 保序下**非降**；
`x ↦ x + I δ` 非降；短路分支为恒等映射，亦非降。故 `T_{n-1} ≤ U_{n-1} ⇒ T_n ≤ U_n`。∎
**这是定理 B 的正确替代**：它给的是"沿实际段序列传播的上界"，而不是"与段长无关的固定带"。

### 命题 P2（**门次上界**，闭式、只需计数）
`T_n^z ≤ τ_z + N_n^z·δ_z`，其中 `N_n^z` = 前 `n` 段中开启 `z` 的次数。

*证明*：由 L1 `T_{n-1} ≥ τ`；由 L3 `Φ_{Δ}(T_{n-1}) ≤ T_{n-1}`，故 `T_n^{pre} ≤ T_{n-1}`（短路分支亦然）；
每次开门加 δ。对 `x_n := T_n − τ` 得 `x_n ≤ x_{n-1} + I_n δ`，`x_0 = 0`。∎
**用途**：给出**只依赖"同温区接单次数"的充分条件**，无需仿真即可检查。

### 命题 P3（**最小段长**恢复带状不变式）
设 `margin_z := c_z − h_z(A−τ_z) > 0`（D3 保证）、`Δ*_z := δ_z/margin_z`。
若温区 `z` 的**每一段**都满足 `Δ_n ≥ Δ*_z`，则 `T_n^z ≤ τ_z + δ_z` 对一切 `n` 成立。

*证明*：归纳。设 `T_{n-1} ≤ τ+δ`。不开启 `z` 时 `T_n = T_n^{pre} ≤ T_{n-1} ≤ τ+δ` ✔。
开启 `z` 时需证 `T_n^{pre} = τ`，即 `Φ_{Δ}(T_{n-1}) ≤ τ`。在未截断自然值仍 ≥ τ 的区间内
`Φ' = h(A−T) − c ≤ h(A−τ) − c = −margin < 0`（用 `T ≥ τ` 与 `A > τ`），故从 `T_{n-1} ≤ τ+δ`
降到 τ 至多需要 `δ/margin = Δ*`；`Δ ≥ Δ*` ⇒ `Φ_Δ ≤ τ` ⇒ `T_n^{pre} = τ` ⇒ `T_n = τ+δ` ✔。∎
**这是定理 B 需要的真正前提**：不是"漂移条件"，而是"**每个段都不短于回落时间**"。

### 推论 C1（**硬边界安全的修正充分条件**）
`τ_z > low_z` 且以下**任一**成立即安全：
(a) `N_max^z·δ_z ≤ high_z − τ_z`（门次口径，P2）；或
(b) 沿该计划算出的 `U_n^z ≤ high_z`（P1，更紧）；或
(c) 所有段 `Δ ≥ Δ*_z` 且 `τ_z + δ_z ≤ high_z`（P3，与段序无关）。
**必要性仍不完整**：违反 (a)(b)(c) 不自动意味着违规（那只是本组条件的不足），**未证明任何充要条件**。

**实测口径**（默认合同）：门次上限 `(high−τ)/δ` = **360 / 45.71 / 50**（温区 0/1/2）。
以温区 1 为例，`Δ = 0.01 h` 时**实际**在第 **59** 次开门触到 `high = 8`（P2 的 45 次是**保守**上界 ✔）。

### 命题 P4（**实例条件化的带不变式**，把"域内反例"与"是否可达"分开）
门事件**只在服务段**发生，而服务段时长 `= service_finish − depart ≥ service_time`
（因 `arrival = depart + travel ≥ depart`、`service_start = max(arrival, tw_start) ≥ arrival`）。
故若某实例族中 `service_time ≥ Δ*_z`，则**每一段开门段的时长都不短于回落时间**，P3 的条件即被满足。

**只读实测（未修改任何数据）**：13 个冻结实例文件（`m0_scale` 50 节点 R1 全三份；
`data/archive/baseline_v1_buggy/50_node` 的 C1/R1/RC1 × EDoD 0.2/0.5/0.8；
`100_node` 的 C1 一份）中，**正 service_time 的最小值为 9.00000036 分钟**
（取值集合 {9, 12, 15, 18} 分钟），而最大回落时间 `Δ*` = **3.3333 分钟**
⇒ **0 个文件低于该阈值**，判定 `COUNTEREXAMPLE_PATTERN_UNREACHABLE_IN_PROBED_INSTANCES`。
零值条目存在（50 节点每实例 1 个、100 节点每实例 10 个），与 **depot / 占位行**一致，
而非被服务的订单节点；**这一点必须在计划层复核**（见下）。

**P4 的地位必须写清（三层不可混用）**：
1. **对任意段序列的数学充分条件**：P1（U 递推，恒成立）、P2（门次上界，恒成立）；
   P3 需要"每段 ≥ Δ*"，**这是条件，不是自动成立的前提**。旧定理 B 属于**已被推翻**的一类。
2. **对具体可达路线的充分条件**：由 P4，只要该计划中**每一个开门段所服务的节点都有
   `service_time ≥ Δ*_z`**，带不变式成立。这是**计划层可检查的条款**（需要知道被服务节点的
   service_time 与段时长），而不是合同层的自动结论。
3. **仅在合成/经验上成立的现象**：13 个文件的最小 service_time 是**经验测量**，
   覆盖范围有限（其他节点规模、其他数据族未测），**不构成证明**，也**不构成必要性**。

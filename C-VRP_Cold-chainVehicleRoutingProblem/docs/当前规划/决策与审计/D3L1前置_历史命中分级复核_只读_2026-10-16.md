## 3. 判定方法（先结构，后特征；内容复核仅在必要时）

**结构证据**（不读值）：JSON 外层键的回溯搜索、摘要账本形状（整块以裸 64-hex 行为主）、路径类别
（测试/文档、证据/归档、源码、第三方内嵌副本）、行形状（`def`/`add_argument`/`getpass`/注释/类型标注）、
**Python tokenizer 的 token 归属**（命中落在 STRING/COMMENT token 内 ⇒ 是代码里的散文而非赋值）、
Markdown 反引号跨度、围栏代码块、引号奇偶与"命中起点即开引号"。

**特征证据**（可计算但不含值）：长度、字符集、熵（bit/char）、已知凭据前缀族、测试词表、
**对固定占位符词典的单向摘要匹配**、是否含 CJK 码位。

**一次性事实**：预签名 URL 的 `X-Amz-Date` + `X-Amz-Expires` 与 blob 首次进入仓库的日期比较（§4.2）。

## 4. 三类实质性发现（都不构成新泄漏，但都有信息量）

### 4.1 规则的**误报机制**已定位（不是内容问题，是规则问题）
命中量最大的两个族是 `R3` 命中 191 条 `value_is_expression_or_reference` 与 112 条 `value_is_path_or_filename`
——即凭据形状词（`token`、`secret` 一类）的右侧是**表达式或路径**，不是字面量。剩余的 `pass`/`password` 命中经 tokenizer
判定落在 **STRING/COMMENT token 内**：`print('… pass: …')`、assert 消息、Markdown 表格单元、状态段落。
**本条发现的现场复现**：本报告的初版**被修复后的扫描器自己拒绝**，命中的是第 55 行里用来描述规则的示例串
（凭据形状词紧跟等号加省略号）。处置方式是**改写措辞**，**不是** `--skip-secret-scan`：
控制按设计 fail-closed，而"为了写下规则说明而豁免扫描"正是它要防的事。
另有 44 条字面量经**固定占位符词典的单向摘要匹配**命中（同一个占位串在约 40 个互不相关的部署/巡检脚本中
**完全相同地重复**——真凭据不会这样重复，占位符会）。
**结论**：`R3` 的实际语义是"凭据形状的词 + `:`/`=` + 非平凡值"，它对**散文与代码**同样敏感。这条要写进扫描器
的使用说明，避免下一次把误报当成发现。

### 4.2 一个**真实存在但已失效**的凭据形状：出版商预签名 URL
5 个归档 HTML（`archive/历史文档/其他/v1/init*.htm`）内含 Elsevier/ScienceDirect PDF 的
**AWS SigV4 预签名 URL**，参数含 `X-Amz-Security-Token`/`X-Amz-Signature`/`X-Amz-Credential`。
按元数据（**日期与有效期，不是密钥**）核定：签名时间 2026-08-16T11:53–11:58Z，**有效期 300 秒**，
即 2026-08-16T11:58–12:03Z 到期；而该 blob **首次进入仓库是 2026-09-12T14:47Z**（+08:00 22:47）。
⇒ **凭据在它被提交之前就已过期约 27 天**；凭据 id 形状为 **ASIA（临时会话，非 AKIA 长期密钥）**，且属
**第三方（出版商）**、按对象授权。判定 `BENIGN_WITH_REASON: expired_presigned_third_party_url`，逐条附
`expires_at` / `blob_first_seen` / `expired_before_first_commit`。**这不是我们的凭据，无物可轮换。**

## 6. 可以说什么 / 不可以说什么

**可以说的**
1. 433 条启发式命中**全部**有分类状态与可核验理由：2 条已知案件、431 条有理由的良性、**0 可疑、0 未确定**。
2. 全历史可达 blob 100% 读过；不可达 blob 也已读完并单独报告。
3. 历史中**不存在第三个 `execution_secret_*` 路径**，**不存在位于非密钥路径上的裸 64-hex 令牌 blob**，
   不可达集合里同样**没有**裸令牌 blob。

**不可以说的（必须与用户给的边界一致）**
1. **不能**说"全历史不存在凭据"。锐化判据只覆盖**一种形状**（整块为裸 64-hex 令牌）；**嵌入在其他内容里的
   凭据不在这条判据的射程内**。
2. **不能**说"规则集保证不漏"。规则是**启发式的**：**没有命中不等于不存在规则未描述的凭据形状**。
3. **不能**说"分类必然正确"。本轮以**来源/结构/不可逆特征**判定，一个刻意伪装的凭据可能被误判。
4. **不能**对"本轮之前已被删除、且此后经过 gc 的对象"作任何陈述：它们不在可达集合、也不在不可达集合里。
5. 因此本报告给出的是 **`D3L1_HISTORY_HITS_ALL_CLASSIFIED`（分类完成）**，**不是**
   `历史凭据风险已排除`。两者不可互相替换。

## 7. 已采纳的规则：历史脚本的**重新启用准入**（不批量清理）

用户裁决：**不批准**批量修改 61 个 `rglob/glob` 使用点与 14 个无显式 `encoding` 的 `text=True` 调用；
历史脚本**保持原样**。采纳的规则原文如下，作为后续工作的约束：

> 凡准备**重新成为**交付、验证、实验或冻结流程**依赖**的历史脚本，必须先通过一次
> **编码、路径遍历与 fail-closed 行为**检查；**检查未通过者不得被重新启用**。

补充两条已被本轮证据支持的事实，供该规则执行时参照：
① `rglob`/`os.walk` 本身不是错误，问题取决于**被遍历目录是否可能含 NTFS junction/symlink**——本仓库
`results/m0_scale/_bverify_pinned/shadow` 就是联结，实测一份树被看 3 遍（20307 vs 6903）；
② `text=True` 本身不是错误，取决于**输出是否含非 ASCII** 与**机器默认编码**——本机默认为 gbk，实测在
UTF-8 输出上直接抛 `UnicodeDecodeError`。

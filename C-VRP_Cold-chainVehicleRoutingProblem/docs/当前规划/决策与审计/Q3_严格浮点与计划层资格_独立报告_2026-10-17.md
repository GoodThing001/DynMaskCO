## 2. 本轮最重要的三个结论（先读这一段）

1. **`nextafter × 4 ulp` 不是上界，也不是"尚未证明的上界"，而是已被证伪的上界。**
   存在**合法执行器状态**（温区 1，`T0 = 4.021875`，`Δ = 1e-6 h`），在 `math.exp` **完全精确**
   （κ = 0）的假设下，该函数返回值仍**低于**执行器浮点值的严格上界 **2.41 ulp**。
   240 个网格点中 **12 个**如此。**这是可执行反例，不是"未证明"。**（§3.4）
2. **P2 的实现（门次计数上界）对执行器是错的，缺口随门次数线性增长。**
   温区 0、360 次零长开门：执行器 `30.000000000000597`，模块报 `30.000000000000014`，
   **低 164 ulp**。修正后的 `count_bound_strict` 在 **18/18** 个检查点上支配执行器。（§3.5）
3. **"只有开门段需要满足最小段长"这个更弱命题成立，而且它是本轮唯一的正向新结论。**
   它把原 P3 对**所有**段的约束削减为只对**该温区的开门段**的约束；短的无门段（真实路线里
   就是**返仓段**与段间空驶）因此**不再阻断认证**，而安全性**没有降低**（§4.1 证明，
   §4.5 PL-10/PL-11/PL-13 用真实执行器对照）。

## 3. 任务 A：严格浮点资格

### 3.1 必须先分开的两个对象（旧模块把它们混为一谈）

| 对象 | 定义 | 证明它需要什么 |
|---|---|---|
| **R 级（实数模型）** | `Φ_Δ(T0) = A + (T0−A)·e^{−hΔ} − c·Δ`，`ψ = max(τ, Φ)`，门加 `δ = door_heat/capacity` | **什么额外假设都不需要**。`e^{−x}` 用精确有理数**包围**即可 |
| **F 级（执行器浮点）** | `coldchain_state.py` 真正存进 `compartment_temperature_c` 的 double | **需要**平台 `math.exp` 的误差界 `κ`。IEEE-754 **不规定** `exp` 正确舍入 |

旧模块的 `math.nextafter` 上升 4 ulp 属于**在 F 级上留下一个未声明的 κ 假设**，
但它同时又被用来声称"上界"——而"上界"是对 R 级说的。**对象混淆是本节的核心缺陷。**

### 3.2 证明清单

**保留并复核（未被本轮推翻）**：L1（地板精确，`max` 返回其参数之一）、L2（对 `T0` 非降，
**方向必须写对**）、L3（漂移条件下 `Φ` 对 `t` 非增）、**定理 A**（逐段极值，含精确候选式
`max(T0, max(τ,Φ_Δ(T0))+δ)`）、以及"朴素式 `max(T0, Φ_Δ(T0)+δ)` 不是上界"这条更正。

**旧定理 B 仍为伪。** 本轮 **PL-14** 独立复现了两个反例（**与勘误数字逐位一致**）：
温区 1，`Δ=0.01 h`，2 门 `4.158433246270557`，9 门 `4.651800834095439`，`τ+δ = 4.0875`。
**不恢复、不引用、不使用** B / B1 / B2 充分性。

**本轮新增五条引理（全部在 `q3_strict_float_experimental.py` 中实现并被测试）**

| 引理 | 陈述 | 证明要点 |
|---|---|---|
| **L-A** `exp` 包围 | 对 `x ≥ 0`、`K ≥ 1`、`K+1 > x`：`L_K = Σ_{k≤K} x^k/k!`，`tail(exp x) ≤ t_{K+1}/(1−x/(K+1))`，故 `1/(L_K+tail) ≤ e^{−x} ≤ 1/L_K` | 正项级数部分和 ≤ 指数；尾项按几何比放缩（`t_{K+j}/t_{K+j−1} = x/(K+j) ≤ x/(K+1) < 1`）。**全程精确有理数，不假设任何 libm 行为** |
| **L-B** 舍入界 | 舍入到最近：`\|fl(v) − v\| ≤ u·\|v\|`，`u = 2^{−53}` | 每个 IEEE 基本运算都是舍入到最近；`+-*/` 五个环节逐一用 `_round_enclosure` 覆盖；次正规区改用绝对地板 `2^{−1000}` |
| **L-C** 单调性 | 执行器一步映射在 `t0` 上**非降** | 舍入到最近是单调函数；`t−A`、乘、`exp`（与 `t0` 无关）、加、减、`max`、加 δ 均单调 ⇒ 复合单调。这是"把界递推下去"的唯一桥梁 |
| **L-D** P1 健全性 | 在**同一冻结常量、同一表达式顺序**下，认证器逐位复现执行器的一步；**因此 4 ulp 只需覆盖"认证器与执行器的分歧"，而不是舍入误差** | 位等价时 `U_n = _up(exec(U_{n−1})) ≥ exec(U_{n−1}) ≥ exec(T_{n−1})`（末步用 L-C）。**故 P1 递归本身在位等价前提下是健全的** |
| **L-E** P2 不健全性 | 闭式 `τ + Nδ` 舍入**一次**再移 4 ulp **不是**执行器浮点状态的上界 | 执行器做 N 次加法，累积舍入可达 `N·u·\|值\|`（N=360 时 164 ulp），远超 4 ulp。修正为 `v ← (v+δ) + u·\|v+δ\|`（**注意绝对值**：负目标温区用 `*(1+u)` 方向相反——本轮第一版就踩到这里并被 SFC-06 抓住） |

### 3.3 三种认证方案的比较（A3）

| 方案 | 说什么 | 需 κ？ | 松紧 | 本轮判定 |
|---|---|---|---|---|
| **S1 保守 P2（门次计数）** | `T_n ≤ τ + N_n·δ`，只需数同温区开门次数 | **不需要**（`Δ ≤ _EPS` 分支根本不调用 `exp`） | 最松；对长段极松 | **可证书化**（修正累积舍入后） |
| **S2 更紧 P1（逐段区间传播）** | `U_0=τ`，`U_n = ψ_{Δ_n}(U_{n−1}) + I_n δ` ⇒ `T_n ≤ U_n` | **R 级不需要；F 级需要** | 紧（R 级包围宽度实测 1.31e-128） | **可证书化，但分两级**：R 级无条件；F 级以 κ 为条件 |
| **S3 位等价重放** | 认证时**执行**冻结执行器，记录其浮点值；"执行器状态 = 记录的浮点" | **不需要**（不需要给 `exp` 定误差，因为不预测它，而是观测它） | 精确（相等） | **在浮点层面唯一无假设的路径**，代价是必须绑定输入身份（→ C2/C3/G5） |

**结论**：至少两种可证书化方案存在（S1、S2-R），第三种（S3）消除 κ 但把负担移到**身份绑定**。
**旧模块两者都不是**：它用 `math.exp`（所以对 F 级是位等价，S3 味道）却**又**加 4 ulp
（所以试图做 S2-F，需要对 κ 的声明）——**两种读法下 4 ulp 都不成立**。

### 3.4 A4：`nextafter × 4 ulp` 的判定 —— **DIAGNOSTIC，且已被证伪为上界**

**反例一（F 级，κ = 0，即对旧模块最有利的假设下仍然失败）**

| 项 | 值 |
|---|---|
| 温区 / 段初 / 段长 | 1（τ=4，δ=0.0875）/ `T0 = 4.021875`（∈ 带内）/ `Δ = 1e-6 h` |
| `advance_upward` 返回 | 严格 F 级上界**之下 2.41 ulp** |
| 网格统计 | 240 点中 **12 点**不足；最大不足 **2.41 ulp** |

**反例二（4 ulp 等价于一个从未声明的 κ 声明，且该声明在某些点上连 κ = 0 都不成立）**

`κ*`（4 ulp 尚能覆盖的最大指数相对误差）= **0.00 ulp**（温区 0/1/2 在 `Δ ≈ 1e-9 h` 处均为 0）；
平台实测 `κ ≈ 1.017e-16 = 0.458 ulp`（300 样本，中位数 0.37 ulp）。
**关键结构性事实**：`Δ` 越短，`E = e^{−hΔ} ≈ 1`，灵敏度 `|T0−A|·E` 越大而结果的 ulp 越小
⇒ **κ\* 正是在短段处最小，而短段正是反例机制所在的位置。**

**反例三（反方向：假拒绝）**
温区 2、50 次零长开门：执行器 `−12.00000000000001`（**在硬界内**），
模块 `tight = −11.999999999999993`（**越过 −12**）⇒ 判 `INTERVAL_BOUND_EXCEEDS_HARD_BOUND`。
**同一个未量化裕度既会造成不健全，也会造成过度拒绝。**

**还有一处"侥幸正确"，必须记录**：温区 0、360 次开门时执行器 `30.000000000000597` 已越界，
模块 `tight = 30.000000000000014` 也越界——**但只高出 1.4e-14（恰为 4 ulp），
而它自报的上界比执行器低 164 ulp**。判据成立是**巧合**，不是证明。

**判定：`nextafter × 4 ulp` 只能保留为 DIAGNOSTIC，不得升级为证书。**
`fractional_margin_declared = False` 必须**保持**，直到用户签署 `η`/`κ` 口径（§9 第 2 项）
或改走 S3（以身份绑定替代浮点裕度）。

## 4. 任务 B：P3 的条件优化与 P4 计划层验证

### 4.1 更弱命题 P3′ —— **已证明成立**

> **P3′（仅开门段满足最小段长）**
> 设温区 `z`，`τ = τ_z`，`δ = δ_z`，`margin := c_z − h_z·(A − τ_z)^+ > 0`，`Δ*_z := δ_z/margin`。
> 若（i）被检查后缀的**段初状态** `T_z(0) ∈ [τ_z, τ_z + δ_z]`，且
> （ii）**每一个对该温区开门的段**都满足 `Δ_n ≥ Δ*_z`，
> 则**每一个段边界**都有 `T_z ∈ [τ_z, τ_z + δ_z]`。
> **不对无门段施加任何长度要求**（含 `Δ ≤ _EPS` 的恒等分支）。

**证明（对段数归纳）**

- **基**：条件（i）。
- **归纳步**：设 `T_{n−1} ∈ [τ, τ+δ]`。
  - **段 n 不对 z 开门**：`T_n = ψ_{Δ_n}(T_{n−1})`。由 L1 得 `T_n ≥ τ`；
    由 L3（`Φ` 对 `t` 非增）`Φ_{Δ_n}(T_{n−1}) ≤ Φ_0(T_{n−1}) = T_{n−1}`，
    故 `ψ ≤ max(τ, T_{n−1}) = T_{n−1} ≤ τ+δ`。∎（**无需任何 Δ 假设**；
    `Δ_n ≤ _EPS` 时映射是恒等，同样成立。）
  - **段 n 对 z 开门且 `Δ_n ≥ Δ*_z`**：记 `x(t) = Φ_t(T_{n−1}) − τ`。
    `x(0) = T_{n−1} − τ ∈ [0, δ]`。只要 `x(t) ≥ 0`，未截断自然温度满足
    `T(t) = x(t) + τ + c·t ≥ τ`，于是
    `x'(t) = h(A − T(t)) − c ≤ h(A − τ) − c = −margin`（若 `A ≤ τ` 则 `A − T ≤ 0`，
    同样 `x' ≤ −c < 0`）。故 `x` 在 `x ≥ 0` 期间以至少 `margin` 的速率下降，
    `x(t) = 0` 对所有 `t ≥ x(0)/margin ≤ δ/margin = Δ*` 成立
    ⇒ `Φ_{Δ_n}(T_{n−1}) ≤ τ` ⇒（L1 给 `≥ τ`）`ψ = τ` ⇒ `T_n = τ + δ` ✔。
  - **其余温区**：该段 `heat = 0`，`+0.0/capacity` 对浮点是**精确**的 ⇒ 值不变 ✔。
- 归纳成立。∎

**为什么这是一个"有内容"的加强**：在真实时间线里，每个服务段的**本温区**一定有门，
而**没有门**的段只有**返仓段**（以及段间纯空驶）。原 P3 要求**返仓段**也 ≥ `Δ*`
（温区 0 的 `Δ*` = 3.33 min）；返仓常常只有几十秒 ⇒ **原 P3 会拒绝完全安全的计划**。
P3′ 把这类拒绝全部消除，且安全性不变。

**必须同时记录的限定**
1. P3′ 仍是**充分条件**，不是充要条件；违反它只说明"本认证路线不足"，**不**说明计划违规。
2. P3′ 的 R 级证明**无条件**；把它提升到**执行器存储浮点**仍需 §3 的 κ 或 S3（模块的
   `not_claimed` 里明写）。
3. `Δ*` 由合同常量算出；`h/c/δ/τ/A` 任一变化**必须重算**（PL-09 覆盖）。
4. 关闭温区仍为域外（地板消失、门仍加热）。

### 4.2 `Δ ≤ _EPS` 与 `Δ > _EPS` 分开处理（要求项）

| 分支 | 映射 | 无门段 | 开门段 |
|---|---|---|---|
| `Δ ≤ _EPS` | **恒等** `ψ = T_{n−1}`（`state.py:361-362`） | `T_n = T_{n−1} ≤ τ+δ` ✔ **安全** | `T_n = T_{n−1} + δ`，若 `T_{n−1} > τ` 则**越界**（最坏情形） |
| `Δ > _EPS` | `ψ = max(τ, Φ_Δ)` | L3 ⇒ 非增 ✔ | 需 `Δ ≥ Δ*` ⇒ `ψ = τ` ⇒ `τ+δ` ✔ |

**实测对照（PL-13，真实执行器）**：`Δ = 0` 的无门段夹在长开门段之间 ⇒ 带内（0 违规）；
`Δ = 0` 的**开门**段 ⇒ `4.5 > 4.25`（越界）。**与证明一致。**

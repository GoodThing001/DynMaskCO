## 4. Q3 最小闭合评估（最贵、也最可能决定 L2 生死）

### 4.1 已有的技术基础（来自 `Q3_事件分段资格与S3边界_独立审核`，已入库）

| 项 | 状态 |
|---|---|
| S3 位等价重放 | **只能事后审计**：分段时钟 = `min(下一 reveal, 预约截止, 各 finish)`，其中 **reveal 是未来信息**；且分段**改变终值**（同起点同总时长：1 段 `4.054313` vs 4 段 `4.054433`，差 `1.20e-04 ℃`）⇒ **"逐位相等"不是决策时刻可认证的性质**（决定性负面结论，`§3.2`） |
| P5（门间累计冷却） | **PROVED**（两条引理 + 真实事件流可审计条件） |
| **分割无关括区** | 任意分割的带地板落点落在 `[max(τ, Φ_Δ^raw(T0)), max(τ, F_Δ(T0))]`，**两端都不需要知道分割**；下端 = 最粗分割（BR-1），上端 = ODE 流（L-G）且**正是 P5 用的量** |
| 数值验收 | 1500 个随机分割**全部落在括区内，0 例外**；多区间串联 400 条轨迹 **0 例外**；括区宽度 ≤ `0.000997 ℃`，两端被地板夹住时**恰为 0** |

⇒ **决策时刻的连续温度条件在原理上存在**，且**不依赖未来分段**、**不依赖 libm 假设**。

### 4.2 缺什么（逐条）

| # | 缺口 | 为什么阻断 L2 |
|---|---|---|
| Q3-1 | 括区目前覆盖"门间推进"与"多区间串联"，**未证明覆盖完整候选路线**（含服务停留、返仓、预约截止 WAIT 的完整序列） | L2 要在决策时刻对**整条候选计划**给出可执行性判断 |
| Q3-2 | **执行器浮点外扩未建立**（`math.exp` 误差与门处浮点加法）：括区是**实值**区间，执行器存的是 double | 若实际存储值越出括区，"可执行"就未被证明（B-3） |
| Q3-3 | 括区两端的**在线可算性**未给预算：每个无门推进要算 `Φ^raw` 与 `F` | 若单次候选评估超出在线预算，L2 无法在严格在线下运行 |
| Q3-4 | **拒绝条件**未写成判据：上端超过阈值时必须拒绝 | 需要与 M1-b 的门语义对齐 |

### 4.3 最小闭合路径（估计）

| 步骤 | 内容 | 预估 | 风险 |
|---|---|---|---|
| **S1** | 把括区从"门间推进"扩到**完整候选路线**（含服务/WAIT/返仓），并把"上端 > 阈值 ⇒ 拒绝"写成判据 | **小–中**（复用已 PROVED 的引理与串联验收） | 低 |
| **S2** | 给括区两端的**在线成本**定界（每次候选评估的实数运算量） | **小**（纯算术，可静态计数 + 计时） | 低 |
| **S3** | **执行器浮点外扩界**（`math.exp` 与门加法的向外界） | **中–大**，且**可能失败**（这正是 B-3） | **高** |
| **S4** | 把 S1–S3 接入 M1-b 的组合认证（合同 v2） | **中**（依赖 B-4 的合同） | 中 |

**失败分叉**：若 S3 只能给出**空界**（例如向外界大于阈值本身），则 L2 的"可认证质量"退化为
"实值安全但存储值未证" ⇒ **L2 不能声称连续温度认证** ⇒ 转 §11 的 NO-GO 路径。

## 8. 可以不依赖任何新正式实验、现在就能作出的结论

1. **G-TMIN 信任旁路已在活跃源码封堵**，且**不得追认**任何前置正式验收（`..._FAIL_AS_LITERALLY_...` 永久）。
2. **V-10 的证据本地性缺口**：干净 checkout 为 FAIL，根因是数据集与私有清单未入库，**不是**套件过期。
3. **S3 不能认证未来后缀**（分段由未来事件时钟决定，且分段改变终值）——这是**已 PROVED 的负面结论**，
   论文可将其作为**方法学贡献**：*位等价重放 ≠ 决策时刻可认证性*。
4. **分割无关括区存在**（1500 分割 0 例外、宽度 ≤ 1e-3 ℃、不依赖未来分段与 libm）——这是**正面技术结论**。
5. **旧设定的核心负结果**（无因果可捕获 headroom；未来信息占比接近 100%；规则可捕获）**已复现归档**
   于 `negative_result_paper/`，**不依赖** L2 是否启动。
6. **C2/G-3/G-1 的身份机制**（无损编码、深度冻结、消费对象绑定、P-a…P-d）已交付并可被论文引用为
   *认证边界工程*，但**均不构成生产资格**。

## 10. L2 GO/NO-GO 推荐

### 10.1 推荐：**有条件 GO**

**理由（基于已入库证据，不需要新实验）**：

1. Q3 的**决策时刻**路线**存在且已被 numerical 验收**（P5 + 括区，0 例外、宽度有界）——
   这是过去多轮里第一次出现"不依赖未来分段"的可行认证形态；
2. G-2 的 `T_clock_sup` / `n_max` 可**规格级收口**（无需新实验）；
3. 除执行器浮点外扩外，**所有前置的成本都是 CPU 分钟级 + 文档签署**；
4. L2 的科学价值最高：它是**第一次**直接检验"学习式重构的可认证质量价值"。

**三条先行裁决（未完成则 GO 无效）**：S-A（预算 B）、S-B（L1 前置解释）、S-C（指标/阈值）。
**一个硬止损点**：见 §10.2。

### 10.2 止损点（**必须现在写入，不得事后解释**）

> **若在两轮授权内，Q3 的完整路线括区（S1+S2）与执行器浮点外扩界（S3）不能同时建立，
> 则转 NO-GO**：不放松物理标准、不无限扩张 Q3/G-2、不追加认证测试凑通过。

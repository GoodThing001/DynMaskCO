## 1. 假设

影子局部搜索（`shadow_mode='ls'`）的路线质量可用（relocate/swap 已有实现与回归），瓶颈是
**每候选全路线可行重放**（`_route_feasible_u` O(n)/候选、O(V²n²) 候选 × 2 passes × 每插入后调用）
与每场景全热力学终局（`_complete_u`）。若把评价结构改为：**(a)** 路线段摘要 + O(1) 拼接评估
距离/载重/TW（文献 [10][12][16]）；**(b)** slack 预检 O(1) 否决不可行候选（[11]）；**(c)** C0 能源
**上下界剪枝**、仅对最终被接受的动作做精确 `transition_segment` 复算——则影子 ls 能在 10s 内
完整完成、**0 超时**，且影子质量 ≥ greedy 影子。**S3-3/density 批次反复出现的超时（32–38 次/天）
即本杠杆的直接动机。**

## 2. 唯一主对照与判据

- **唯一主对照**：与现行 `shadow_mode='ls'` 同修订版按天配对（唯一差别 = 评价结构）；另报同 K/时限
  的质量/耗时对比。若旧 ls 无同版 40 天基线，则对照同修订版 greedy 影子（并如实标注）。
- **判据（战役协议 S3-4 预声明）**：主判据（cond−uncond 按天配对 mean≥20 且日聚类 CI 下界>0 且
  hard=1.0 且全日可裁决）+ **0 超时** + 同 K=10/10s 的质量与耗时对比；1×40 天三档。

## 3. 参数与次数

- 无自由参数（增量评价是**等价实现**，验证「影子值不因近似改变」即可）；
  能源上下界保守性阈值预声明：逐场景能源偏差 ≤ 1% 或 ≤ 0.5 kWh/场景。
- 2 天 p_c=0 烟测（0 崩溃 + 增量版 vs 旧版逐场景值相等性 + 能源界保守性）→ ≤1 次 40 天三档。

## 4. 预期方向

0 超时；影子路线质量与旧 ls 的逐场景差 ≈ 0；cond−uncond 按主判据裁决（不预设方向）。

## 5. 失败条件

能源上下界不保守（对照完整 `_complete_u` 偏差超阈值）→ 判负回滚；超时未清零且耗时未显著下降 →
判负；主判据未过 → 按序推进 S3-6（不把「超时清零」单独当成功）。

## 9. v2 修订（2026-10-02，基于耗时分解 profile 实测）

> profile（ls+incr-v1，2s 名义上限，1 天）：wall 3254s、local_search **3056s（94%）**、
> insert_u 52s、complete_u **12s**、超时 192。**瓶颈 = ls 候选循环的逐候选 O(m) 可行重放与
> 全量距离求和**（真实剖面 TW 松弛大 → 多数候选可行 → v1 预筛几乎不省算）。

**v2 变更**：候选**排序**改用 O(1) 预筛 + O(1) 边差分 Δ（`_delta_ins/_delta_rem/_delta_replace`），
**选中者仍做旧式全量终检**（可行性 + 全量距离），终检失败回退旧式全扫描（正确性兜底）。
**代价与诚实标注**：Δ 与旧全量求和的浮点运算顺序不同 → **近并列（<1e-9 距离差）候选的选择顺序
可能与旧 ls 不一致**（最终路线订单顺序罕见分歧，顾客集合与总距离不变）；v1 的「逐位一致」
在 v2 降级为「**影子质量逐场景差 ≈ 0**」（§4 原判据口径）。验证方式：T32 改判
「预筛零假拒 + 顾客集合一致 + 总距离差 < 1e-6 相对」；烟测 A/B 逐日效用相等性 + 超时对比。
若 v2 仍无法把 ls 压进 10s（0 超时），按序评估 D3（anytime 部分投票，需另注册）。

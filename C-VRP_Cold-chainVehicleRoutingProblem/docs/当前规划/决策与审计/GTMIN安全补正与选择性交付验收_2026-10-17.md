## 1. 本轮安全补正的动因（用户审查发现）

上一版 gate 0b 在拒绝收据里写 `'value_received': repr(getattr(self, 't_min_refused_value', None))`。
**`repr()` 在不可信输入上会执行调用方代码**，因此可以：

1. 抛异常 → 拒绝路径本身崩溃（fail-open 风险）；
2. 产生可观察副作用 → 在认证器内部执行未授权行为；
3. 返回字符串 → 可能把敏感信息写入收据/日志。

**处理**：删除该字段与 `t_min_refused_value` 这个对象引用；拒绝收据只留固定 reason code 与布尔/常量。

## 1. 问题 A 的最小订正

```diff
-        self.verified_t_min = verified_t_min
+        self.t_min_claim_supplied = verified_t_min is not None
...
-        self.t_min_refused = self.verified_t_min is not None
+        self.t_min_refused = self.t_min_claim_supplied
```

**兼容性**：全树检索 `\.verified_t_min` 只命中构造期赋值与 `_resolve_t_min`；

实测：三项全 `[]` / `False`；`t_min=0`、`final=REFUSED`、收据 `detail` 仍为固定三字段。

## 2. 问题 B 的订正：从已登记基准**重建** `PRE_FIX`，并真实 SKIP

### 2.1 关键发现：不需要私有本地副本

`git show 759fe7fb81dd869c212a28eed352f82ff99a1b1e:<认证器路径>` 取出的 blob
与本地 `PRE_FIX` 副本**逐字节相同**（32114 B，LF 行尾，无 CRLF），
sha256 = `8bd105f6…e43eaf399ef35`（即登记值）。

> 首版尝试用 PowerShell `>` 重定向取 blob，得到 65312 B 且 digest 不匹配 ——
> 那是 **UTF-16 重编码**，不是 git 的问题。改用 `subprocess.run(..., capture_output=True).stdout`
> 取**原始字节**后逐位一致。这条教训记在此处。

### 2.2 实现

`acquire_prefix(workdir)` 按优先级取 PT：
1. **基准 blob**（`git show <BASELINE_REF>:<CERT_REL>`）→ 校验 sha256 == PIN；**通过则写入临时文件**；
2. 否则**本地私有副本** → 同样校验 PIN；
3. 两者都不成立 ⇒ `prefix_path = None`，相关行**真实 SKIP**，**不再访问任何缺失路径**。

**所有对 `prefix_path` 的读取都在 `have_prefix` 判真之后**（V-01 的 `body`/`numstat`、
V-03 的 `src_old`、V-06 的 `shutil.copy`）。
`--simulate-fresh-checkout` 现在**显式把 `prefix_path` 置 None**，堵住"模拟时文件仍在"的漏洞。

### 2.3 V-03 的降级处理（诚实标注）

缺 PT 时无法比较 `self.env` 使用次数**前后差值**，故：
- 保留**存在性**断言（`assert_visible_set_matches_env` 仍在、`self.env` 仍被使用）；
- 记录 `env_count_comparison_available = false`；
- **不**把"次数恰好减 1"当作通过条件。

## 3. 问题 C 的订正：三态汇总标签

```diff
- 'verdict': ('GTMIN_INSTALL_VERIFICATION_PASS' if not any(FAIL) else '..._FAIL')
+ PASS       当且仅当 全部 11 项实际 PASS
+ INCOMPLETE 存在 SKIP 且无 FAIL
+ FAIL       存在 FAIL
+ 'not_for_production': True   # 与 kind=DIAGNOSTIC 一致（原为 False）
```

实测：
- **本地完整跑**：**11 PASS / 0 SKIP / 0 FAIL → `GTMIN_INSTALL_VERIFICATION_PASS`**；
- **封锁两种来源（等价于干净 checkout）**：**7 PASS / 4 SKIP / 0 FAIL → `GTMIN_INSTALL_VERIFICATION_INCOMPLETE`**，
  reason = `4 required check(s) could not be evaluated in this checkout`。**不再无条件 PASS。**

**其它报告消费方检查**：全树检索 `GTMIN_INSTALL_VERIFICATION_PASS` 与
`test_q3_gtmin_install_verification`，仅命中本测试自身与前两份 GTMIN 记录中的**叙述性引用**；
无任何代码或门禁在**机械消费**该 verdict。故标签订正不影响其它链路。

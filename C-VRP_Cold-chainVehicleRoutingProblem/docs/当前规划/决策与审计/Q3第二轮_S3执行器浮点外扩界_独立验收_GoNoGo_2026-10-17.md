## 2. S3 的对象与**不可回避性**（本轮的第一条定理级结论）

S3 的对象是（预声明 E1.2）：

```
∀ P ∈ P_declared,  ∀ partition π ∈ Π(P):  T_executor(P, π) ∈ [lo_S3(P), hi_S3(P)]
且 hi_S3 ≤ τ_z + δ_z + ε_F,  lo_S3 ≥ τ_z − ε_F,  且落在 hard bounds 内
```

**位等价重放已从选项中删除。** 理由是第一轮之前就已 PROVED：分段时钟 =
`min(下一 reveal, 预约截止, 各 finish)`，其中 reveal 是未来信息，且分段改变终值。本轮用
`partition_spread` 再量化了一次：**同一 gap 的 201 个分段终值离散度 1.61e-04 ℃**，
且**上确界严格高于最粗分割**（`S3-N4`）。⇒ 任何"单条事后轨迹"都不能代表 `Π(P)`。

### 2.1 引理 S3-IMP（不可回避性）

> 任一**非平凡**且对所有分段一致成立的 F-level 上界都蕴含一个关于平台 `fl_exp` 的**一致相对精度**陈述；
> 反之，**不使用**任何一致精度陈述时唯一有效的界是 `fl_exp ∈ [0, 1]`，它要求每个无门段
> ≥ `(A − τ_z)/c_z`。

**实测（`no_assumption_free_bound`）**：所需段长为 **3.5 / 4.2 / 5.375 h**（`S3` 的 Θ_z 仅
**0.0552 / 0.0531 / 0.0421 h**，即小 60–128 倍）。任何合法路线都不可能满足
⇒ **无假设的外扩界是空界**。

⇒ S3 的成败**完全**取决于 κ 的资格。这不是"还缺一个细节"，而是本轮要证明的那件事。

## 3. κ 资格审计（任务书 §2）→ `EXP_ERROR_BOUND_NOT_ESTABLISHED`

### 3.1 平台身份（运行时读出，非抄写）

| 项 | 值 |
|---|---|
| 解释器 | **CPython 3.12.7**（Anaconda 打包，**MSC v.1929, 64-bit AMD64**） |
| 操作系统 | **Windows-11-10.0.26200-SP0** |
| 浮点格式 | IEEE-754 binary64（`radix=2`、`mant_dig=53`、`rounds=1` 即就近舍入） |
| `math.exp` 语义 | CPython `mathmodule.c` **直接调用 C 库 `exp`**；CPython 自身不实现 exp ⇒ 任何精度陈述都是关于**平台 libm** 的，不是关于 Python 的 |
| `math.exp.__doc__` | `"Return e raised to the power of x."` —— **无任何精度承诺** |

### 3.2 三个问题的逐条回答

**(a) 是否存在可独立核实的 `math.exp` 误差上界？**
**没有。** 三层都查了：
* **C 标准**不规定 `exp` 的 ulp 误差；
* **IEEE-754-2019** 把 `exp` 列在 *recommended operations*，**推荐**正确舍入而非**要求**；
* **Microsoft UCRT 文档**（[`exp, expf, expl`](https://raw.githubusercontent.com/MicrosoftDocs/cpp-docs/6222f92f41d1cb097072480cb7142b958483b8a9/docs/c-runtime-library/reference/exp-expf.md)）
  只描述函数契约与返回值，**不给 ulp 界**。

**(b) 上界覆盖的输入范围是什么？**
不适用 —— 没有界，因此没有范围。

**(c) 是否存在"不改物理合同、且可在本轮证明"的保守替代界？**
**没有。** 唯一无假设的替代就是 §2.1 的 3.5–5.375 h 段长要求，它是空界。
在**不修改冻结执行器**的前提下（本轮禁止改 `coldchain_state.py`），无法把 `math.exp` 换成自带证明的实现。

### 3.3 实测（**CONFIRMED，不是证明**）

在声明输入域 `[0, 4.8]` 上取 **3503 个**参数（含三个 zone 的 `h` 网格与随机点），逐点用

```
[lo, hi] ⊇ 真 exp(−x)   （精确有理 Taylor 括号，SF.exp_neg_enclosure）
|fl_exp(−x) − 真值| ≤ max(|v − lo|, |hi − v|)      （无需任何平台假设）
```

得最大相对误差 **1.102e-16 ≈ 0.496 ulp**（另一组 8003 点的网格为 **0.944 ulp**）。
**这可以推翻一个 κ 主张，但永远不能建立它**：执行器可在区间内任意参数上求值，
而平台 libm 不受执行器合同约束。

### 3.4 裁决

```
EXP_ERROR_BOUND_NOT_ESTABLISHED
f_level_established = False
```

**这是本轮的决定性结论。** 它由 `S3-P1`（无 κ ⇒ `REFUSED`）与 `S3-N11`
（经验/网格/惯例/IEEE 推理四类来源一律 `KAPPA_SOURCE_NOT_ACCEPTABLE`）两道闸门机械保证：
**评估路径连算术都不做**，因此不存在"算出来挺好看"这条旁路。

> 特别记录：**本轮没有任何一行把 `f_level_established` 置为 True。**
> `S3-P6` 用"看似合规的来源 + 超过 κ\* 的 κ"验证了该标志的第二个条件，
> 配合 `S3-P1`/`S3-N11` 的第一个条件，把这个标志的所有通路都关死了。

## 4. F-level 误差预算（逐项，全为精确有理数）

`E_z = T-κ + T-round + T-door + T-time + T-skip + T-floor`，作用于 S1 **同一** gap 对象
（**不重立口径**，预声明 E2.2）：

| 项 | 闭合式 | 实测值（zone 0 / 1 / 2） |
|---|---|---|
| `T-κ` | `κ · S_z · n_pieces`，`S_z = A − τ_z` | 3.11e-11 / 9.33e-11 / 1.91e-10（κ = 1 ulp） |
| `T-round` | `n_gaps · n_pieces · 7 · u · V_max` | 3.89e-09（三 zone 同） |
| `T-door` | `n_doors_z · 2 · u · V_max` | 2.22e-13 |
| `T-time` | `u · V_max`（`end−depart` 与 `× hours_per_time_unit`） | 2.78e-15 |
| **`T-skip`** | **`(margin_z + h_z·δ_z) · n_max · 1e-9`** | **1.214e-05 / 3.309e-05 / 5.710e-05** |
| `T-floor` | `0`（显式登记，**不得省略**） | 0 |
| **`E_z`** | 合计 | **1.214e-05 / 3.309e-05 / 5.710e-05** |

`n_max = 20003` **运行时由 G-2 调用图普查重算**（`1 + 2·max_iter + 2`，`max_iter = 10000`），
**不是抄写**——这是 G-2 的结构上界第一次被真正消费。

外扩界：`lo_S3 = lo_R − E_z`、`hi_S3 = hi_R + E_z`，`lo_R/hi_R` **直接来自 S1 已冻结的括区**。

**`ε_F = 1.0e-3 ℃`**（预声明 E2.3）：比最窄 band（zone 0 的 3.33e-2 ℃）小 33×，
比实测 `E_z` 大 **17.5×**，是温度物理分辨率量级。**未事后调整。**

### 4.1 本轮最重要的实测发现：`T-skip` 主导，不是 `math.exp`

`T-skip` 占 `E_z` 的 **99.97% / 99.99% / 99.99%**。它来自执行器自身：

> `coldchain_state.py:361-362`：`duration_h ≤ _EPS (1e-9)` 时 `_advance_temperatures`
> **直接返回原值**，即这段时间**完全不做冷却**。

`S3-N9` 用**真实执行器**证明了后果：把 `n_max` 段各 1e-9 h 拼成一段，
执行器停在 `τ+δ = −17.88 ℃`，而 S1 的 ODE 流已经降到 `−17.880057 ℃` ——
**执行器比 S1 的上端高 5.7096e-05 ℃**。⇒ **S1 的实值上端不是 F-level 上界，即使 `math.exp` 完美**。

并且：**朴素写法 `margin_z · n_max · 1e-9` 覆盖不了**（5.6809e-05 < 5.7096e-05，差 0.507%），
因为 `T − F_d(T) = (T − T_∞)(1 − e^{−hd}) ≤ (T − T_∞)·h·d` 且
`T − T_∞ ≤ margin/h + δ`。⇒ 修正为 `(margin + h·δ)`，**有证明**（预声明 ERRATA-S3-1）。

## 6. 三条本轮新增、可被引用的技术结论

### 6.1 κ\*：整个 F-level 问题归约为一个标量

| zone | `κ*_z` | 折合 ulp |
|---|---|---|
| 0 | 7.055e-09 | 3.18e7 |
| 1 | 2.302e-09 | 1.04e7 |
| **2（绑定）** | **1.096e-09** | **4.94e6** |

⇒ **只要平台 `math.exp` 的相对误差 ≤ 1.10e-09，F-level 外扩界就成立且非空**；
实测 **≈0.5–0.94 ulp（≈1e-16）**，比门槛小约 **7 个数量级**。
**结论：障碍是"文档/保证"，不是"精度"。** 这是本项目后续任何 F-level 工作唯一需要钉住的东西。

### 6.2 F-level 预算的瓶颈是执行器模板，不是数学库

`T-skip` 比 `T-κ` 大 **5–8 个数量级**（§4.1）。含义有二：
① 即便拿到完美 κ，若不补 `T-skip` 仍然是**不成立**的界 ⇒ 本轮修复了这条真实缺陷；
② 反过来，**界对 κ 极度鲁棒**：κ 被低估到 1e-9 仍成立，只是界变宽。

### 6.3 在本轮计划集上，F-level 从不成为**唯一**拒绝理由

`S3-E1` 的 24 个计划里，10 个 `NOT_CERTIFIABLE` **全部**由实值层（短 gap 使 S1 的 band 越界）先拒绝；
**F-level 加宽导致的唯一拒绝 = 0**。原因是 `E_z`（≤5.71e-05）远小于 `ε_F`（1e-03），
而实值层的 band 判据本身是**零裕度**的。

> 这同时说明：**第一轮的实值证书与第二轮的浮点加宽是"串联"的** ——
> 实值层先筛掉不合格计划，浮点层只在余下的计划上加一个 ~5.7e-05 ℃ 的保守量。

## 7. 预声明勘误（ERRATA-S3，逐条给冻结原文、实测现实、处置）

> 规则：勘误**不得**把判据改松以追求 GO。下面三条中 **ERRATA-S3-1 更严**，
> **ERRATA-S3-2/3 是"已披露的削弱"**（结构性不可测），并附补偿性更强的新行。

### ERRATA-S3-1（更严）：`T-skip` 的闭合式少了 `h·δ`

* **冻结原文**（E2.2）：`T-skip = margin_z · n_max · eps_time`。
* **实测现实**：`S3-N9` 测得真实 surplus **5.7096e-05**，而冻结式只给 **5.6809e-05** ⇒ **少 0.507%**。
  原因是 `T − F_d(T) = (T − T_∞)(1 − e^{−hd})`，而 `T = τ + δ`，故单位时间失冷量为
  `margin + h·δ`，不是 `margin`。
* **处置**：改为 `(margin_z + h_z·δ_z) · n_max · ε_time`，并给出证明（`1 − e^{−x} ≤ x`）。
  **更严**；新值 5.7097e-05 **恰好覆盖**实测 surplus。κ\* 因此变化 < 0.5%，
  预登记的 ≈1.10e-09 在三位有效数字上**仍然成立**。

### ERRATA-S3-2（**已披露的削弱**）：`S3-N5` 的端到端可检出性在结构上不可能

* **冻结原文**（E4.2）："从预算中移除 `T-door` 后必须能被检出（对拍出越界）"。
* **实测现实**：`T-round = n_gaps·n_pieces·7·u·V` **恒**覆盖门处舍入误差
  （`n_doors·u·V`），故移除 `T-door` 永远不会造成端到端越界。
* **处置**：改为**代数项敏感度审计**（六项齐全、`total == Σparts`、`T-floor` 恰为 0、
  删任一项总额恰减该项）；大项的行为性检出由 `S3-N2`（`T-κ`）与 `S3-N9`（`T-skip`）承担。
  **这是削弱**，故显式登记，并以两项**更强**的新行补偿。

### ERRATA-S3-3（**已披露的削弱**）：`S3-N2` / `S3-N3` 的对象替换

* **冻结原文**：`S3-N2`"κ 小于实际误差 ⇒ 能检测适用条件被违反"；`S3-N3`"实值通过但执行器越界 ⇒ 不得误判通过"。
* **实测现实**：
  ① 因为 `T-round`/`T-skip` 比 `T-κ` 大 4–8 个数量级，**κ 被低估时外扩界仍然成立**（只是更宽），
  不存在可检出的**不**可靠失败 ⇒ `S3-N2` 的冻结形态不可实现。
  ② 短 gap 计划的实值括区**很宽**（中位宽 4.09e-04 ℃），越界现象在那里更强、更可复现，
  但它在该计划上实值裁决为 `NOT_CERTIFIABLE`，不是 `PROVED`。
* **处置**：
  `S3-N2` 改为**必要性检验**（κ=1e-4 时全预算 142.02 ⇒ 拒绝；删 `T-κ` ⇒ 1.02e-04 ⇒ 通过），
  这在**同等或更强**的意义上证明 κ 项承载真实决策；
  `S3-N3` 改为**同一计划上"预算清零 ⇒ 147 次越界 / 全预算 ⇒ 0 次"**的对照，
  比冻结形态更强（括区越宽越难越界，仍然越界）。
  **两者都不是判据放松，而是对象的等价替换**，但**削弱了"以 PROVED 计划为对象"这一限定**，
  故显式登记。

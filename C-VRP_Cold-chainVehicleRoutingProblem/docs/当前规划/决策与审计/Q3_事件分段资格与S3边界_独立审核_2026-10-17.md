## 2. 修正后的条件：P5（门事件间累计冷却）

### 2.1 两条引理（PROVED）

**L-F（单步被 ODE 流支配）** 对任意 `Δ ≥ 0`、任意 `T`：

```
Φ_Δ(T) − F_Δ(T) = (c/h)·[(1 − e^{−hΔ}) − hΔ] ≤ 0        （因 1 − e^{−x} ≤ x, ∀x ≥ 0）
```

其中 `Φ_Δ(T) = A + (T−A)e^{−hΔ} − cΔ` 是执行器的闭式，`F` 是 `dT/dt = h(A−T) − c` 的精确解
`F_Δ(T) = T∞ + (T − T∞)e^{−hΔ}`，`T∞ = A − c/h`。

**L-G（分割不改变上界）** 对**任意**分割 `Δ₁+…+Δ_k = Δ_total`：

```
Φ_{Δ₁}∘…∘Φ_{Δ_k}(T) ≤ F_{Δ_total}(T)        （且带 max(τ,·) 地板时：ψ 复合 ≤ max(τ, F_{Δ_total}(T))）
```

*证明*：L-F 给每步 `Φ ≤ F`，`Φ`、`F` 对 `T` 均单调 ⇒ 归纳套叠
`Φ₁(Φ₂(x)) ≤ F₁(Φ₂(x)) ≤ F₁(F₂(x)) = F_{1+2}(x)`，逐步到 `F_{Δ_total}`。∎

**数值核对**：1200 个随机分割，`max(raw 复合 − F) = 0.000e+00`（SEG-04）。

### 2.2 P5 的陈述与证明

> **P5** 设温区 `z`，`τ = τ_z`，`δ = δ_z`，`T∞_z = A − c_z/h_z`，定义
> `Θ_z = (1/h_z)·ln((τ_z+δ_z−T∞_z)/(τ_z−T∞_z))`。
> 若（i）派发时 `T = τ_z`；且（ii）同一车辆上**同温区相邻两次开门之间的时钟间隔 ≥ Θ_z**，
> 则**每次开门前温度恰为 `τ_z`、开门后恰为 `τ_z+δ_z`**，故带 `[τ_z, τ_z+δ_z]` 在每个门事件上成立、
> 累积不可能发生。**结论与环境如何切分该间隔无关**（L-G）。

*证明*：设间隔起点温度 `≤ τ+δ`。由 L-G，间隔内无门推进的复合终值 `≤ F_{Θ}(τ+δ) = τ`；
地板只降不升 ⇒ 段末 `≤ τ`，而地板给 `≥ τ` ⇒ **恰为 τ**。门加 δ ⇒ `τ+δ`。∎
**首次开门**无需任何条件：`Φ_Δ(τ) ≤ Φ_0(τ) = τ`（L3）⇒ 首门后恒为 `τ+δ`。

### 2.3 为什么不能用旧的单段公式（**这一条决定"能不能直接套用"**）

| 量 | 定义 | 温区 0 | 温区 1 | 温区 2 |
|---|---|---|---|---|
| `Θ`（ODE，P5 用） | 上式 | 0.055249 h | 0.053127 h | 0.042147 h |
| `Δ*`（旧闭式线性化） | `δ/(c−h(A−τ)⁺)` | 0.055556 h | 0.053354 h | 0.042254 h |
| `T_single`（单段实际回落时间） | 数值求根 | 0.054271 h | 0.052458 h | 0.041851 h |
| **不安全窗口 `Θ − T_single`** | | **3.521 s** | **2.409 s** | **1.064 s** |

**BR-1（细分升温）**：`Φ_a(Φ_b(T)) − Φ_{a+b}(T) = c·b·(1 − e^{−ha}) ≥ 0`
（数值核对：实测与闭式差 `1.2e-14`，SEG 的 REP-03）。

⇒ 在 `Δ_total ∈ [T_single, Θ)` 的窗口里，**单段公式说"已回到 τ"，而真实的分割复合仍在 τ 之上**，
下一个门就落在 `τ+δ` 之上。窗口只有 1–3.5 秒，但它**存在**（SEG-05 用三个温区各给一例）。
所以**对"总间隔"使用 `Δ*` 或 `T_single` 是不健全的**，必须用 `Θ`。

### 2.4 真实事件流上的可审计条件（P5 的落地）

**可证的下界（F-6）**：`finish_n − clock_{n−1} ≥ service_time_n`。
*证明*：`depart_n = max(ready_n, clock_{n−1}) ≥ clock_{n−1}`（`:266`），`ready_n = committed_finish_{n−1} = clock_{n−1}`（`:370`）；
`arrive_n = depart_n + travel ≥ clock_{n−1}`；`finish_n = max(arrive_n, tw_start_n) + service_n ≥ clock_{n−1} + service_n`。∎

⇒ **`service_time ≥ Θ` ⇒ 门间隔 ≥ Θ ⇒ P5 成立。** 上一轮的 9 min 数字**因此仍然可用**，
但它的正确链条是"**同温区相邻取货间隔 ≥ 后一次取货的服务时长**"，**不是**"开门段时长"。

**只读实测（DIAGNOSTIC，1 个实例 / 贪心基线）**

| 项 | 值 |
|---|---|
| 车辆 / 门事件 / 同温区间隔数 | 24 / 50 / 13 |
| 最小间隔 | **58.54 min**（温区 0） |
| 最小 `Θ` | **2.53 min**（温区 2） |
| 裕度 | **≥ 23×** |

| `间隔 ≥ 后一次服务时长` 的反例 | **0** |

**必须同时记录的负面观察（SEG-11）**：在这条轨迹上，**按 M1-b 分段（每服务一段）的 unsplit replay
与环境记录的服务末温度逐位相同（最大差 0.0）**。但这不是语义一致，而是**地板吸收**：
间距远大于 `Θ` 时第一次推进就落到 τ，之后的切分被 `max` 抹平。**"结果相同"不等于"分段相同"**
（SEG-05 给出不一致会发生的位置）。

### 3.2 S3 **不能**证明未来后缀（决定性负面结论）

分段时钟 = `min(下一个 reveal, 预约截止, 各 committed_finish / return_finish)`
（`:488-510`）。其中 **reveal 时间是未来信息**（strict-online 禁止读取）。
而分段**改变终值**（REP-06：同一起点、同一总时长，1 段 `4.054313` vs 4 段 `4.054433`，
差 `1.20e-04 ℃`）。因此：

> **S3 只能对"已经固定下来的分段"声称位等价；对未来后缀，分割由未来事件时钟决定，
> 所以"计划 + 当前状态"不决定终点，"逐位相等"不是可以在决策时刻认证的性质。**

**三条附带限定（写进工件，REP-08）**：不得升级为段内连续安全；不得把"对同一实现调用两次"当作独立性；
不得声称可移植（P2 只记录）。

### 3.3 S3 能做什么：**事后审计**（可审核的执行器级证据）

- **全轨迹重放**：把记录的完整事件序列（无门推进 + 门）重放，**50 个服务末状态逐位相同
  （最大差 0.0）**，覆盖 99 个事件时钟（REP-02）。
- **1 ulp 篡改即拒绝**（REP-07）：把记录的某个温度移动一个 ulp，审计 FAIL。
- 这正是 **C2 / G6** 需要的东西：安装前/写收据前的"记录确实来自这条代码路径"的核对，
  而**不是**决策时刻的预言。

### 3.4 如果必须做决策时刻的证明：用**分割无关括区**

> **括区（BRACKET）**：对一段总长 `Δ` 的无门推进，**任意**分割的带地板落点都落在
> `[ max(τ, Φ_Δ^{raw}(T0)) , max(τ, F_Δ(T0)) ]`
> —— 两端都**不需要知道**分割。

- **下端** = 最粗分割（1 段），由 BR-1 得它最小；
- **上端** = ODE 流，由 L-G 得它最大；**且上端正是 P5 用的量**。

**数值验收**：1500 个随机分割（未带地板 / 带地板两个口径）**全部落在括区内，0 例外**（REP-04）；
多区间串联括区覆盖 400 条随机分割轨迹，**0 例外**（REP-09）。

**代价是可算的、有界的**：括区宽度在测试网格上 **≤ 0.000997 ℃**（REP-05），
且一旦两端都被地板夹住就**恰为 0**。

⇒ **P5（上端）+ 括区（两端）给出一个不依赖未来分段、也不依赖 libm 假设的决策时刻条件**；
S3 退居"事后核对"。这是本轮对用户"双层结构"建议的具体落地方式。

### 5.2 三个特殊问题（用户点名要回答的）

**Q1：P3′ 能否应用于真实环境事件流？**

### 5.3 新发现：M1-b 采样级温度门可能**偏冷**（乐观偏置）

`m1b_thermal_gate.replay_thermal_envelope` 对每个服务用**一段**
`service_finish − depart`，门加在该段末尾；环境则在事件时钟处切分。
由 BR-1，**少切分 ⇒ 更冷**，故 replay 的 `per_zone_max` **不是**环境 `per_zone_max` 的上界。
量级：括区宽度 ≤ **0.000997 ℃**（REP-05），而硬界裕度是 3.9 / 11.97 ℃ —— **实践影响可忽略，
但"这是上界"的断言不成立**。必须在 G5/G6 之前把它写清（或让 M1-b 采用 ODE 上端）。

**这一条与本轮主线同源**：两者的根因都是"公式/实现与真实事件分段没有对齐"。

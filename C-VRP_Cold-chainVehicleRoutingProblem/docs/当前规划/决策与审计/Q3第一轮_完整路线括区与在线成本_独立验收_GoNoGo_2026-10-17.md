## 2. S1：对象与证明结构

### 2.1 本轮要回答的决策时刻问题

> 给定**全车队**的候选计划（冻结前缀 + 候选后缀 + WAIT + 返仓 + mid-tour 入口状态），
> 在不读取任何未来揭示时钟、也不知道未来事件分割的前提下，能否**证明**连续温度在每个门事件都位于
> `[τ_z, τ_z + δ_z]`？

### 2.2 引用并复用的引理（本轮**不**重新证明，只引用）

| 引理 | 内容 | 来源 |
|---|---|---|
| **S1-L1** | 门时钟由**计划**决定（`depart=max(ready,clock)`、`arrive=depart+travel`、`start=max(arrive,tw_start)`、`finish=start+service`；`_plan_and_commit` 在上一次服务完成的**同一 clock** 上 pop 下一个后缀元素） | 本轮证明（源码 `strict_online_env.py:650-655`, `:266,287-289,370`）；数值见证见 §3.4 |
| **BR-1** | `Φ_a(Φ_b(T)) − Φ_{a+b}(T) = c·b·(1−e^{−ha}) ≥ 0`（细化抬高） | `q3_float_replay_qualification_experimental` |
| **L-F** | `Φ_Δ(T) ≤ F_Δ(T)` | `q3_event_segmentation_experimental` |
| **L-G** | 任意分割下 `Φ_{Δ1}∘…∘Φ_{Δk}(T) ≤ F_Δ(T)`，带地板同样成立 | 同上 |
| **地板** | `max(τ,·)` 单调，且只抬高不降低 | 本轮显式登记 |
| **L-A** | 有理 `exp` 括号（Taylor + 几何尾界），对**真**指数成立 | `q3_strict_float_experimental` |
| **新：Θ 有理括号** | `Θ_z = ln(K_z)/h_z`，`K_z=(τ+δ−T_∞)/(τ−T_∞)`，用 atanh 级数 `ln K = 2Σ u^{2j+1}/(2j+1)`（全正项）+ 几何尾界 `≤ u^{2J+1}/((2J+1)(1−u²))` 给出 `[Θ_lo, Θ_hi]`，**不调用 `math.log`** | 本轮实现 `q3_s1_route_bracket_experimental.rational_ln_enclosure` |

### 2.3 括区传播（逐 zone，逐车独立车厢）

```
入口: lo = hi = 入口区间（fresh 车 = [τ,τ]；mid-tour 车 = 声明的入口区间）
每个 gap Δ（一个 gap = 一个 zone 的一条门间/入口间区间）:
    若 hi ≤ τ                        → 已在谷底，坍缩到 τ       （0 次超越求值）
    否则若 hi ≤ τ+δ 且 Δ ≥ Θ_hi      → 已证回到谷底，坍缩到 τ    （0 次超越求值）
    否则                             → 取 1 个有理 exp 括号 [E_lo,E_hi]
        hi ← max(τ, T_∞ + (hi−T_∞)·E_hi)                    （ODE 端，L-G）
        lo ← max(τ, A + (lo−A)·E_hi − c·Δ)                   （最粗分割端，BR-1）
    若该 gap 以门结束                 → lo += δ_z, hi += δ_z
```
`sup_z = max over zone-z doors of hi_after_door`；**band 判据** `sup_z ≤ τ_z + δ_z`（精确有理比较，
**无容差**）；**hard 判据** `sup_z ≤ hard_high_z` 作为附加报告（逐 zone 严格包含于 hard 界内）。

**为什么两端各自可用**：`Φ_raw` 与 `F` 都对入口值单调，且 `max(τ,·)` 保序 ⇒ 分别传播两端得到整段外包。

## 5. 预声明勘误登记（ERRATA）—— 逐条给冻结原文、实测现实与处置

> 规则：勘误**只允许**把判据改得**更严或等价**，不允许放松。三条勘误均属此类，且逐条列明。

### ERRATA-1：`S2-1` 的计数单位

* **冻结原文**（E4.2 `S2-1`）："实测 `math.exp` 调用数 == 闭合式 `n_exp(plan) = #S`"。
* **实测现实**：`SF.exp_neg_enclosure` **不调用 `math.exp`**（它是纯 `Fraction` Taylor 级数），
  `rational_ln_enclosure` 也不调用 `math.log`。因此按字面统计 `math.exp` 调用数，**全路径恒为 0**，
  该行按字面**不可测量**。
* **处置（更严，不是放松）**：把计数对象明确为"**严格超越括号求值次数**"
  （`exp_neg_enclosure` + `rational_ln_enclosure` 的实际调用），并**同时**要求
  `math.exp/log/pow` 调用数为 **0**（`S2-3` 的 AST 检查）。
  ⇒ 冻结行的**目的**（界住超越运算成本）被完全满足，且额外获得一个更强的结论：
  **判定路径没有任何 libm 调用**。

### ERRATA-2：`S2-7` 的闭合式上界偏大

* **冻结原文**（E4.2 `S2-7`）："全短 gap 最坏形态：`n_exp == n_doors + Z·A`"。
* **实测现实**：实现把**入口区间并入首个门的 gap**（一"门"一"gap"行，`prev` 从决策时钟起算），
  因此不存在独立的入口 gap 行，`Z·A` 项**被重复计入**。实测 `n_exp = n_short_gaps ≤ n_doors`。
* **处置（更严，不是放松）**：`S2-7` 改判为
  `n_exp == n_short_gaps` 且 `n_short_gaps ≤ n_doors − n_active_vehicles ≤ n_doors`，
  并把冻结的 `n_doors + Z·A` 作为**仍然成立的上界**保留在报告中（实测 20 ≤ 64）。
  逐项**严格更强**于冻结式。

### ERRATA-3：`S1-P1R` 由门控行降为增补行

* **冻结原文**（E4.1 `S1-P1R` 位置本为"真实实例 0 的贪心合法路线"，属 `S1-P1` 的门控内容）。
* **实测现实**：`data/m0_scale/` **未入库**（这正是 V-10 干净 checkout FAIL 的记录根因）。
  若把它做成门控行，本轮会给仓库**新增一个**干净 checkout 下的硬依赖 —— 与本轮 E7.1 的
  "不新增证据本地性缺口"相冲突。
* **处置**：门控正控改为**完全合成、固定种子、可复现于任何 checkout** 的 `S1-P1`；
  真实数据行保留为 `S1-P1R`（**数据在则运行、不在则 SKIP**，**不计入门控**）。
  本轮数据在，`S1-P1R` **实际运行并通过**（`PROVED`、`n_short_gaps=0`），所以证据并未丢失；
  改变的只是**门控归属**，即"哪里算失败"。这削弱的是**一个行的门控力**，
  **不是**任何数值结论，故在此**显式登记而非静默处理**。

### 未构成勘误的两项（记录以备核查）

* `S1-P3` 的"逐位相等"：实测偏差**恰为 0.0**，冻结期望**字面成立**；测试仍保留 `1e-4` 的
  float32 守卫（`tolerance_used = (max_dev > 0)` 会报告它是否被用到），守卫**本次未被使用**。
* `S1-P2` 的"1500 条"：按 3 个 zone × 500 条 = **1500 条**执行，与冻结数量一致；
  但每条改为**精确有理算术**验证（比冻结的"数值确认"更严）。

## 6. 预声明未覆盖、但本轮实测到的两条事实（登记，不据以扩张范围）

### 6.1 实值证书**不需要 κ** —— 问题面被缩小

判定路径经 AST 检查**完全不含 libm 超越调用**（`S2-3`），裁决比较为精确有理（`S2-4`）。
⇒ **"决策时刻能否判定连续温度"这一问不再依赖 `math.exp` 的正确性**。
S3 因此只剩一跳：**执行器存下来的 double 与实值区间的关系**（要么给 κ，要么给位等价重放）。

### 6.2 F-level 缺口的**经验尺度**（探针，**不是证明**）

在 `S1-P2` 的同一批分割上，把走法换成执行器的 float 算术：1500 条中 247 条落在实值括区之外，
**最坏越界 `6.22e-15 ℃`**；而 zone 0 的 band 宽度为 `3.33e-2 ℃`。
⇒ 经验上 F-level 跳的尺度约为 band 宽度的 **2e-13**。
这**乐观地提示** S3 一旦给出有效界，界很可能远在 band 内 —— 但这是**经验尺度，不是界的建立**，
**不构成** `FLOAT_EXECUTOR_OUTWARD_BOUND_NOT_ESTABLISHED` 的任何解除。

> 值得强调的是：这条同时说明**为什么必须把 S1 的限定写清楚**。
> 若把 float 走法的零违例当成"证明"，本轮就会得到一个**约 1e-15 ℃ 级别错误**的"PASS"——
> 这正是 Q3 从一开始拒绝的那类 hop。本轮把它记录为**探针**而不是判据。

40 ms 上限只容纳 **7–13 个短 gap**。⇒ **S3 很可能同时需要一次成本优化或预算重议**，
这一点应写进 S3 的预声明，而不是等测出来再解释。

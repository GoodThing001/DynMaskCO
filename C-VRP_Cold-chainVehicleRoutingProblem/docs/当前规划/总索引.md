# DynMaskCO-CC 总索引

> 版本：2026-09-03 v4  
> 主线：**MaskCO masked generation → causal event mask → cold-chain-aware full-fleet action → counterfactual terminal utility → iterative online recourse。**

## 1. 一句话研究问题

如何将 MaskCO 的静态掩码重构范式扩展到动态冷链物流，在未来订单不可见、执行前缀不可回滚的条件下，联合优化车队—路线决策、货品品质与制冷能耗，并保持服务和硬约束可行？

主实验运营语义固定为 **dynamic cold-chain pickup-to-depot**：车辆空载出发，客户服务完成后取货入舱，返仓卸货并关闭；品质从 `service_finish` 累计到 `return_arrival`。这不是 depot-to-customer 配送协议。

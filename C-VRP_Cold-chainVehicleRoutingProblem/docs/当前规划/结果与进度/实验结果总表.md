# DynMaskCO-CC 实验结果总表

> 版本：2026-09-08 v7  
> 历史表中的 cost 均为纯 `distance_cost`。C0 已建立权威计算口径；正式 O0-CC DEV-GATE v4 已完成（verdict=GO，九 cell 等权 Δ=−0.2771），但该结果仍是 pilot 参数的 oracle headroom，不等同于论文级现实冷链结论。
> 历史 `complete` 只覆盖客户访问与返仓，不等于 v4 要求的 all-picked + all-delivered-to-depot + empty-manifest 冷链完整性。  
> P0-M 与 C0 已完成；C0 功能/口径 20/20、pilot sensitivity 7/7。参数仍为 pilot、尚未现实校准，因此这些测试不构成论文性能结果。
> 比较规则：先 service/硬约束，再分别比较距离与冷链目标；不同 split、样本量、合同或预算不混表。

证据标签：`B`=文档记录但未独立复算；`P`=存在 comparator/口径风险，待复核；`TBD`=尚未实现或运行。

## 4. VAL32 factorial（✅ 已复核 2026-09-02）

修复后重跑（`results/p0r/oracle_ceiling/`，四路 complete 均 100%，service-eq n=32/32）：

| Partition \ Sequencing | Greedy | TSPTW |
|---|---:|---:|
| JF1-H partition | 24.4133 | 24.6369 |
| OR partition | 24.5446 | 23.0253 |

修复后 interaction：

$$
C_{OT}-C_{OG}-C_{HT}+C_{HG}=-1.7430.
$$

instance statistics（service-eq n=32）：mean −1.7430、median −1.9114、95% bootstrap CI [−2.387, −1.104]、$P(I<0)=81.2\%$。

修复前后对比：HG/HT 逐位相同（24.4133 / 24.6369），OG 24.5533→24.5446、OT 23.1618→23.0253（OR 预算内 run-to-run 方差），interaction −1.6151→−1.7430，**方向与显著性不变**。结论：partition×sequencing 交互在 comparator 修复后依然成立，CI 不跨 0。

coverage 注记：TSPTW 臂 1549 calls / 1524 optimal / 25 k>8-unavailable / 0 drop（clean）；OR-assign+gr 臂 1529 calls 中 602（39.4%）存在**事件级** greedy drop，但 episode 级 n_dropped=0（complete 100%）——OR 分区内 greedy 常无法一次排完，靠后续事件重规划补服务，现已显式报告（旧 run 为 silent）。

## 5. B0 gap decomposition（✅ 已复核 2026-09-02）

修复后重跑（`results/p0r/b0_gap_decomposition/`）：

| 数据口径 | 修复后值 | 旧记录 |
|---|---:|---:|
| train256 NN | 27.42 (96.1%) | 27.41 |

| $G_{seq}$（service-eq n=253） | **−1.227%**（Δ−0.336，CI [−0.498, −0.177]） | −1.25% |

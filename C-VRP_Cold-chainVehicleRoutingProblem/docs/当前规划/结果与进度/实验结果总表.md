**三路收益分解（DEV，τ\*，实例等权）：** hindsight 上限 full_ref=0.0209；固定首选+事后完美接受 fixed_ref：F_H 0.0064 / F_R 0.0109 / F_soft 0.0098。pick_loss（选错候选）与 accept_loss（接不接受）各约 0.010~0.017。注意 `accept_loss=fixed_ref−actual`，其下降**不能独立解释为接受能力改善**；F_soft 相对 F_R：pick_loss 0.0100→0.0111（略差）、accept_loss 0.0118→0.0108（略降）、合计约 0.0218→0.0219（基本不变）。

**有货候选分层（修正后，legal & ~pseudo 分母）：** 合法普通候选有货 **58–67%**（旧「17%」是 padding 分母错误）；context 含合法有货 ~50%，机会中涉及有货 ~30–40%。有货 context 贡献并不差（DEV 上 Huber 组为正），但**有货子集内 S−F 配对差异≈0**——状态增量未证明，且不能归因于空车稀释。

**软标签排序（F_soft，70 维，替代硬符号排序）：** margin 误差（\|s·m−(−δ)\|）F_H 0.019 / F_R 0.035 / F_soft 0.023。口径：margin 误差按**各模型自己的首选候选**计算，三模型被评估的动作不同，故下降**不能全部归为「同一批动作上的分数校准改善」**；无监督首选未入误差分子但计入 context 分母（本批 sf/lm=0）。软标签把硬排序抬高的幅度误差降回（逐 seed 全降）、fixed_ref 0.010（保留候选潜力），但 net@τ\* F_soft −0.0010（未改善）。

**阶段结论**：在当前数据划分、模型与训练预算下，硬排序与软标签辅助损失相对纯 Huber **均提高了固定首选候选的 hindsight 收益潜力**（三 seed 配对增量均为正）；软标签版本降低了各模型首选候选上的加权 margin 误差，但未改善 CAL→DEV 实际净收益。结果支持「损失设计影响候选选择与分数幅度」，但尚未建立可部署正效用，也**不足以确定净收益失败的唯一原因**——软标签缓解了幅度冲突但不解决问题，故不能把幅度冲突视为已确认的唯一瓶颈。按预定停止规则，损失支线收束；**停的是这套「单动作干预的终局差值回归 + 候选重排」配方的继续搜索，不是宣布 MaskCO 不可行**。`fixed_ref≈0.01` 是使用真实标签的事后潜力，不能当作模型已能实现的收益。

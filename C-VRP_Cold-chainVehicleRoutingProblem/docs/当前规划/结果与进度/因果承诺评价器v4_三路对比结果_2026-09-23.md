# 因果承诺评价器 v4 结果：myopic / k-NN / clairvoyant 对比

日期：2026-09-23。性质：真 3b 首个可比数据（无训练，逐单能耗简化模型）。

## 1. 设定

- 评价器：StrictOnlineEnv 因果执行 + 四项闭环（因果 booking_horizon / 承诺 accepted 持久 / 独立认证 / 失败计分）+ NN 最优插入路由。
- 决策：订单揭示时当场 accept/reject；绿色能耗预算 B=(1−ρ)×历史"全接"逐单能耗均值；能耗逐单 E_class（简化，物理路由能耗=后续阶段）。
- 三路：
  - **myopic**：揭示时"预算内 + 有车能服务"接受（可行性感知）。
  - **k-NN**：myopic 判据 + "revenue/e > 未来边际 λ"（k=10 近邻场景）。
  - **clairvoyant**：离线按 revenue/energy 贪心 + 同路由（参考，非上界）。
- 指标：可行利润（仅可行实例）+ feasible_rate + 承诺违约数（accepted 未被服务）。

## 2. 结果（60 测试实例，ρ 敏感性）

| ρ（预算砍幅） | myopic feasible | myopic 利润 | k-NN feasible | k-NN 利润 | clairvoyant 利润 | k-NN−myopic 配对 |
|---|---|---|---|---|---|---|
| 0.40 | 0.817（违约11） | 2206.6 | 0.533（违约28） | 2280.7 | 2327.5 | +100.7（n=30） |
| 0.50 | 0.95（违约3） | 1843.6 | 0.567（违约26） | 1965.2 | 1978.0 | +135.0（n=34） |
| 0.60 | **1.0（违约0）** | **1477.3** | 0.85（违约9） | 1594.4 | 1601.7 | +122.6（n=51） |

## 3. 结论（诚实）

1. **clairvoyant > k-NN > myopic**（利润）：k-NN 前瞻在可行实例上比 myopic 高 ~8%。
2. **k-NN 过度承诺**：revenue/energy 判据偏爱便宜的常温单（高 revenue/energy 比），接受更多订单，车队 TW/容量服务不了 → 承诺违约（9/60 @ ρ=0.6，myopic 为 0）。
3. **有意义负发现**：naive 的"按价值/能耗比"前瞻能提利润但代价是过度承诺——**前瞻必须同时考虑路由可行性**，不能只看能耗比。这是下一步（masked 生成器 / 更强前瞻）要解决的。

## 4. 边界

- 能耗逐单 E_class 是简化模型，物理路由能耗（coldchain_state）是后续阶段；升级前所有头腔结论限定"逐单预算模型下"。
- k-NN 匹配用 morning 温区计数（3 维），高维状态 + 冻结 encoder 的收益尚未测（这是主方法的核心待验假设）。
- clairvoyant 是贪心参考，非上界。

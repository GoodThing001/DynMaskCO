## 🎯 研究主线

> DynMaskCO-CC将MaskCO的掩码—重构—迭代改进范式扩展到严格非预知的动态冷链取货回仓任务，以真实闭环冷链效用检验可执行车队—路线优化；训练职责与目标按最新工作包明确，不预设终局收益回归有效。

主实验语义固定为 `pickup_to_depot`：车辆空载出发，在 `service_finish` 取货入舱，在 `return_arrival` 返仓卸货并关闭行程。

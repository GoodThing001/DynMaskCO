## 🎯 研究主线

> DynMaskCO-CC 将 MaskCO 的掩码—重构—迭代改进范式扩展到严格非预知的动态冷链取货回仓任务，以反事实终局冷链效用对齐可执行的车队—路线动作。

主实验语义固定为 `pickup_to_depot`：车辆空载出发，在 `service_finish` 取货入舱，在 `return_arrival` 返仓卸货并关闭行程。

# 搜索路线收束后：几何先验与冷链残差研究建议

日期：2026-09-22。性质：下一阶段研究设计建议，不是已验证的新方法，也不是自动启动训练的执行指令。沿用“助手维护研究文档，执行端实施、实验与提交”的分工。

## 1. 正式结束的分支与保留结论

接受执行端最终回传：clean seed42 的直接目标训练、固定状态评估、原解码闭环和 mask=2 两层搜索验证已完成。当前 checkpoint 的搜索增强路线收束，不再增加 beam、EAS、训练步数，也不为继续该路线安排第三次纠正包。

| 接受后 J | TRAIN | CAL |
|---|---|---|
| 距离提议＋两层搜索 | 1.0617 | 1.1447 |
| R 单次 | 1.0697 | 1.1515 |
| M-trained＋两层搜索 | 1.0789 | 1.1528 |
| M-trained greedy＋7采样 | 1.0779 | 1.1528 |
| M-pre＋两层搜索 | 1.0890 | 1.1629 |

trained−距离搜索：TRAIN +0.017 [0.010,0.024]，CAL +0.008 [0.003,0.014]。训练确实改善了 M-pre，但在已测试的局部任务与搜索配置中未建立超越非学习方法的价值；此前 clean 原解码闭环也未建立稳定优势。这足以支持投入边界上的收束。

统计边界保留：CAL 与 R 差异跨零不证明等效；trained 与采样接近不证明两者所有预算下等效；相同补全次数不是相同墙钟成本。模型劣于当前距离搜索不证明所有学习机制均无效。质量改善同时存在于 trained−pre，不能写成“所有收益与学习完全无关”。

本轮只读核查本地模型与搜索源码，最终数值、服务器 SHA 一致和缓存真实状态零差异由执行端回传，本助手未独立重跑。当前 `sgbs_search` 在 mask=2 下覆盖两层 top-2 候选；更深任务的 frontier 保留仍需单独设计，不能直接当成通用、按 rollout 价值剪枝的 SGBS。当前 mask=2 每状态7次验证不因此作废，亦不触发旧线重跑。

## 2. 下一研究问题

**在相同公开信息、动作范围和计算预算下，MaskCO 能否在可靠的几何先验上，学习车辆状态与有序路线引起的冷链效用修正，优于距离搜索及简单的冷链修正？**

职责变化在于：距离增量成为明确的动作偏好；MaskCO 主要承担对该偏好的状态相关修正。并不假设几何先验永远正确，也不把所有成本问题都交给一个自由学习的分数重新解决。

这一选择是有来源的研究假设：RRNCO 提供几何／时长偏置的先例；JAMPR 和 Vehicle-as-Prompt 提供车辆—节点—路线条件化的先例。它们不证明本项目会有收益，也意味着“加距离偏置”“加车辆注意力”本身不能直接宣称新颖性。

来源：[RRNCO](https://arxiv.org/abs/2503.16159)、[JAMPR](https://arxiv.org/abs/2006.09100)、[Vehicle-as-Prompt](https://arxiv.org/abs/2604.05195)、[SGBS](https://arxiv.org/abs/2207.06190)。具体源码审读见[上一报告](D:/PyCharm_/MASKCO-Main/C-VRP_Cold-chainVehicleRoutingProblem/docs/当前规划/研究设计/对比方法可迁移机制审读_2026-09-22.md)。

## 3. 第一个交付：使用已有结果查找互补性，不重训

从最终两层搜索的 `per_state.json` 读取同一状态的 accepted J。该脚本已保存这些列，不需要重新生成候选就能计算：

`J_union(s) = min(J_distance_search(s), J_trained_search(s), J_trained_greedy7(s))`

`gain_union(s) = J_distance_search(s) − J_union(s)`。

报告实例聚合后的平均改善、正改善状态／实例比例、分位数及聚类 CI；TRAIN 与 CAL 分开。由于定义包含距离结果，gain_union 必然非负，其非负或统计显著不构成独立算法验证。它只描述已有候选集合的可利用余量，不是所有方法的全局最优上界，更不是零成本部署结果。

重点是回答：模型虽然平均输，是否在一些状态中找到距离搜索未找到的完整改善？若存在，记录改善出现在何种车辆／路线条件下。若不存在，说明已有候选不能支撑“简单混合两种求解器即可变好”，不再开新混合比例搜索；但仍不能证明新表示没有学习空间。

若原始产物没有方案／D-Q-E细项，只做上述现成统计，明确机制原因未知。不要从总 J 猜测是品质还是距离收益，也不要为了画机制图批量重跑旧模型。确需机制核查时，只在 TRAIN 选择少量已归档状态恢复完整计划并由唯一 C0 评价器计算；选择规则、数量与成本写明。

可探索的机制是“几何便宜的插入是否延迟已有货物返仓、造成更大冷链代价”。注意 pickup-to-depot 与配送不同：取货前不累计车载品质损耗，不能把“越早服务所有易腐订单越好”当作通则。品质判断必须来自当前合同的温度演化、货量和品质累计，而非单一温区优先规则。

状态分组仅使用决策时可见字段；TRAIN 用于形成解释，CAL 用于描述迁移，不在 CAL 上穷举分组再宣布新机制。TRAIN/CAL/DEV 已反复查看，后续最终确认必须另设未用于开发的实例。

## 4. 新模型的最小概念设计

对同一个合法插入动作 a，定义：

`score_theta(a | s, P_partial) = −Δdistance(a) / scale_D + residual_theta(a | s, P_partial)`。

scale_D 使用固定 TRAIN 统计或公开合同尺度；不按隐藏未来归一化。动作分布仍是全部合法动作上的 softmax，仍由 MaskCO 对部分计划进行条件重构，完整计划仍交给唯一 J_vis 评价和硬认证。搜索宽度、采样温度和奖励不与结构一起调参。

残差模块有两种受控版本：

- **基础残差：** 复用 MaskCO backbone 的节点／边／有序插入表示和现有显式动作特征，不新增车辆关系模块。
- **关系残差：** 在基础残差上加入小型车辆—部分路线编码，表示 anchor、当前温区状态、载重／品质摘要、冻结边界，以及有序可变路线；节点与车辆／路线之间交互，再参与动作修正。动作仍明确关联目标物理车辆。

新增残差的最终出口零初始化，初始确定性动作排序与距离提议一致，tie-break 也一致。这继承的是距离提议，不是 regret-2；也不意味着随机采样策略与确定性距离搜索完全相同。不要把现有 edge score 未经归零就加到距离项上，再声称初始继承几何策略。

可采用已冻结 clean 模型作为共同特征初始化，旧模型另保留只读。所有需比较的 MaskCO 版本使用同一来源和可训练参数规则。零出口首步仅出口有梯度是正常的，后续须验证梯度进入相应上游模块。

先不接订单明细 attention。当前温区品质加权和在既定同温区共同衰减模型下已包含加性品质项的重要统计量，读取 cargo 明细并非自动增加必要信息。若有充分机制理由再定义字段／容量／无截断语义，不把未消费表当作当前失败的既定原因。

## 5. 为什么这可能变好，以及不能保证什么

潜在优势：初始化就具有可靠的距离偏好；模型可用完整修复奖励学习“某些局部较长的选择是否降低总体冷链代价”；车辆—路线表示使延迟传递、返仓时间和现有 cargo 的影响更早参与关系计算。

仍可能失败：距离搜索可能已覆盖多数有用方案；当前任务的可部署冷链收益余量可能小；256状态不足以学稳定规则；现有输入可能已足够而新模块徒增开销；局部 J_vis 改善仍可能不转成未来闭环收益。不能靠增加品质权重、放松约束、挑更容易胜出的测试场景来消除这些失败。

保留距离方案作为 incumbent 只在已经花预算生成并评价它、且同时保留它时保证单次可见计划不更差；这不是免费保证，不证明相同4s总预算下不劣于完整距离搜索，更不保证动态终局不变差。

## 6. 一次有上限的结构 pilot

首先完成第3节的一页机会报告和第4节的接口／输入设计。若继续，建议一次并行对照包，而不是“第一个失败后再换另一个直到成功”。

| 组 | 提议机制 | 回答的问题 |
|---|---|---|
| D | 距离提议＋冻结搜索，无学习 | 当前强局部参照 |
| G | 距离先验＋MaskCO基础残差 | 几何先验配合现有学习表示是否足够？ |
| GV | 距离先验＋MaskCO车辆—路线关系残差 | 显式关系模块有无额外价值？ |
| L | 距离先验＋轻量非MaskCO修正网络 | 同样可见信息下，是否需要MaskCO？ |

L 必须访问同一信息白名单及有序路线信息，不能通过故意删除温度／货物／路线顺序把它做弱。其具体编码在运行前固定，不要求与大模型参数量完全相等；同时报告训练参数、时延和计算资源。G 与 GV 的可见信息也应尽量一致，GV 改变的是组织／交互方式；新增字段同时提供给其他可用该信息的对照，否则应明确报告信息变化与结构变化不可分离。

pilot上限建议：G/GV/L 各 seed42、1000更新、8状态×4采样，最多各32000次候选评价，共最多96000次；D不训练。全部使用同一干净 TRAIN 状态清单、mask=2、同一完整计划奖励／优化器／学习率，预固定最终 checkpoint。此预算是新研究建议，不代表已启动。若需要改训练预算，须在观察新 CAL 结果之前统一定义，不能只给希望最大的组追训。

训练目标保持完整修复的 J_vis 改善，不同时加入辅助 CE、换teacher、换PPO或新奖励。把奖励基线改成距离解可能改变方差，不会自动改变期望优化目标，也不是超越距离解的保证。

冻结搜索过程和实际预算，先在匹配训练范围的固定状态比较；三个训练组相同预热、测量范围和候选上限，顺序交错，避免第一个方法独自承担编译。接受失败与超时保留 P0，不删样本。统计按实例聚类，seed与实例分别报告，不把每个事件当独立重复。

主比较预先指定为 GV−D；GV−G、GV−L用于解释来源。其余是次要／探索性比较。设一个实际收益目标作为立项标准，建议先用相对 D 的平均 J 降低1%作为开发目标；这不是论文通用门槛，更不是从现有结果推导的功效结论。最终阈值在运行前锁定，报告实际效果和CI，不事后为过关降低阈值。

## 7. pilot后只走明确的分支

| 结果 | 处理 |
|---|---|
| GV优于D，且优于G/L，延迟可用 | 关系条件化和MaskCO均有初步价值，进入有限闭环和后续独立重复 |
| G优于D，但GV不优于G | 保留更简单的G，不强保新注意力模块；论文主张缩到有证据的部分 |
| G/GV优于D，但L同样好或更好 | 学习修正有价值，MaskCO必要性未建立；不能包装为MaskCO核心创新 |
| 仅TRAIN改善，CAL无稳定信号 | 记录泛化不足，不直接补到第三个训练预算档 |
| 所有学习组仍输D | 收束该残差设计，不立即再换teacher或加MoE |

pilot未建立信号时，没有理由先跑多个seed、完整场景矩阵或最终测试。当前课题硬性要求保留MaskCO；这限制了可以主张的论文方向，但不能用要求替代正面证据。

## 8. 通过pilot后，距离论文还缺什么

**部署验证。** 先跑完整动态闭环，保持公开状态、冻结前缀、保护集合、服务约束和唯一评价器。训练／部署动作范围要一致：先提供同为mask=2的受控闭环，完整R和距离搜索仍保留作部署强参照，不能为模型缩小它们的正常动作范围。若最终方法采用mask=2/4/8，则后续训练与验证必须覆盖对应范围；新数据清单、范围变化及对照预算同时锁定，不能用早期mask=2结果冒充全范围。

**稳定性。** 对入选设计补至少3个训练seed；依据实例级配对差值方差与实际收益目标事先规划新留出实例数。现有CAL/DEV只作为开发证据。不要反复查看新TEST并据此改模型。

**强基线。** R和距离搜索是必要但不足的参照。最终至少需要适配到同一pickup-to-depot、当前信息和动作约束的强传统求解器（现有OR-Tools/PyVRP适配可作为入口），以及有竞争力的学习型路由方法（例如已审读的RRNCO/CaDA中可规范适配者）。对方同样有权使用冷链目标或合理的冷链搜索扩展，不能只给我们的模型使用完整目标。不能直接用论文原始CVRP成本、clairvoyant结果或旧naive future-mask结果作胜出证据。

**归因。** 几何先验、车辆—路线条件化、MaskCO表示各自的消融；后续若主张预训练价值，需要随机初始化或合适的非预训练训练对照；若主张迭代掩码价值，需与相同预算的单轮／其他重构方式比较。将输入打乱只能作为机制敏感性诊断，不能替代信息匹配的训练消融。

**机制与范围。** 报告按冻结权重／尺度合成的J，以及D/Q/E、服务完成率和尾部延迟。将物理上可达的车辆热／载货状态变化作为机制案例，不随意拼接不可达状态。若只在有根据的特定条件有效，预先定义适用范围并在独立数据确认；不能隐藏其他场景负结果。

**新颖性。** 现有文献已有几何先验、车辆注意力、残差适配及搜索。潜在贡献是针对不可撤销在线取货、在舱热状态与部分路线耦合的具体建模／决策方法，并证明它在有限预算中有额外价值。模块组合、复杂工程、100%可行或单一CI不跨零均不自动构成论文贡献。

## 9. 工作量与停止边界

下列是条件性排期，不是成功概率或发表保证：

| 工作 | 预计投入 |
|---|---|
| 原始结果冻结、现成逐状态互补性分析、机会报告 | 1–2个工作日 |
| 最小残差／车辆路线模块及输入一致性验收 | 3–5个工作日，接口问题可能延长 |
| 三组等预算pilot与固定状态判读 | 3–5个工作日，GPU耗时由实际吞吐估计 |
| 若通过：闭环、3seed、强基线、机制／泛化与独立确认 | 约2–4周或更久，依基线适配规模而定 |
| 方法与实验写作、复现材料 | 可并行；通常另需1–2周整理 |

只有新设计较顺利地建立增量时，才有约4–8周形成较完整投稿材料的规划意义。若pilot仍失败，不能以这个时间估计继续承诺发表；应在该预算点重新决定课题范围与MaskCO核心要求。

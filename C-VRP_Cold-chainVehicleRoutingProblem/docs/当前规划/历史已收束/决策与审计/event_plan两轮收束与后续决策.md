# event_plan 两轮收束与后续决策

> 2026-09-19 · 对应 D-056。依据本地结果 JSON、manifest 和源码审读；没有重训、重跑 episode、远端核验或提交代码。用户/执行端负责实现与实验，当前审读助手只维护文档。

## 1. 当前决定

按预先约定停止 event_plan 两轮配方的继续搜索，不自动启动 pairwise、加训练步数、扩大数据、修改 projection 后全量重跑或 on-policy aggregation。

这是投入与开发决策，不是对“完整计划评价”“物理表示”或“MaskCO”的普遍不可行性证明。当前实现和预算未取得泛化的选择收益与闭环正效用；个别实现仍偏离协议，也不构成必须无限修复并继续实验的理由。

以下结论可保留：

- 当前 TRAIN 上存在有限候选的 hindsight 改善机会；不是已证明可见状态能识别这些机会。
- A 的正选择收益仅见 TRAIN；CAL 三 seed 均略负。B 未建立稳定优于 A 的选择或闭环收益。
- CAL 的 A/B/S_proxy 全部选 ∞，DEV 没有干预且 ΔJ=0；这是外部 fallback。
- 修正距离选择的本批 DEV ΔJ=+0.041983，汇总 CI=[+0.009762,+0.074288]，接受140次。该结论限定本候选规则、数据及预算。
- E4 的 MaskCO 生成/掩码/refinement 增量仍未验证；论文主方法尚未完成。

## 3. 本轮源码审读发现的限制（留档，不自动重跑）

| 事实 | 依据与影响 |
|---|---|
| WAIT没有推进到协议的公开H | `event_plan_projection.py` 的WAIT分支只设open_plan=True，没有到H的transition；H仅用于归一化/余量占位。该路径遗漏等待期间的品质/能耗增量，不是协议约定的H终点物理代理；影响量未测，不能认定它造成所有退化 |
| committed的load计数重复 | `action_contract.build_vehicle_plans` 的anchor_load已含committed客户需求；projection以anchor_load起算，又在committed分支加一次该需求，影响max_load等数值。这不等于环境实际载重或cargo真的重复入舱；错误在代理数值字段 |
| 训练seed与生成seed耦合 | exporter固定生成seed=0，closed_loop把42/43/44作为replanner seed，而生成器确实用它选择top-3动作。A/B同一seed仍共享该生成规则，但跨seed及与distance/proxy seed0比较混入生成变化，不是纯训练随机性；不能直接归因全部差异给表示 |
| 代理及B不能按“完整物理表示已验收”归档 | 有序投影/货物摘要已实现，但B没有直接列入各温区温度/zone_load等全部原计划字段；投影有上述偏差。字段缺失本身不证明缺信息（投影已间接使用温度），但不能声称原规范完全实现 |
| 运行追溯证据不齐 | closed_loop目录目前只有汇总JSON，runner未落盘方法逐实例rows，CAL耗时填0是丢弃计时后的占位，不能当实际0耗时。缺完整因果扰动/双路径验收产物时，不从“finite/分区0失败”推断它们全部通过 |

修正这些问题可能改变结果，也可能不改变；本轮没有运行验证。结果仍作为“当前实现负结果”保存。只有将来明确复用投影引擎/这套评价器时，才先处理对应缺陷及针对性验收，不能把它们自动转成第三轮研究任务。

## 5. 下一阶段讨论什么：更换方法假设前的决策约束

当前问题不再是“再加哪些特征”，而是：**在不观察真实未来的条件下，学习模块到底承担哪项能被公平验证的决策工作？** 原主线仍是DynMaskCO-CC，不因评分器失败自动放弃MaskCO或冷链。

重新立项必须写清下列四点，未写清不发下一批训练指令：

1. **学习模块职责**：生成可行高质量候选、分配重构/搜索预算，还是估计跨未来情景的效用。不能继续把“更大MLP重排同一批终局差值”换名字当新假设。
2. **信息与目标**：一个真实未来下的g_B是已有监督，不等于当前可见状态下的期望优势。如果新路线采用因果情景/分布，需要明确来源、训练/部署可用性及与真实未来的隔离；不能因本轮失败直接认定标签有噪声就是根因。
3. **可部署强对照**：相同可见信息、相同搜索/推理预算，比较简单生成/选择、无学习求解及MaskCO组件。物理代理或更大计算带来的收益须单独识别。
4. **最小可否证目标与投入上限**：先定义模型要超过哪个可部署对照、用什么独立开发证据判定继续；不再用hindsight oracle有空间替代learned可行性证据。

可讨论的路线及其代价（均未决定或实施）：

| 路线 | 新假设 | 必须额外证明 |
|---|---|---|
| 保留MaskCO主线，让学习负责重构/搜索提案 | 在相同因果状态和可部署评价/预算下，学习提案更有用 | 生成器确有独立增量；不能仅靠更大搜索或把旧结构模仿原封不动重开 |
| 显式处理未知未来的效用学习 | 可见历史与声明的未来分布能支持更可学的期望决策目标 | 情景分布有效性、无未来泄漏和计算成本；不是自动加rollout预算 |
| 缩小论文主张为协议/基准/系统研究 | 已有框架与失败证据在严谨比较下有独立研究价值 | 文献定位、足够外部基线、可靠可复现证据；不能保证负结果本身可发表，也需重新确认论文定位 |

建议先把“学习负责什么”和可部署强对照写成方法重构方案，而非直接选一种损失继续跑。本轮不宣布上述任何路线一定能取得增益，也不擅自改变课题主线。最终方法有效性、MaskCO增量和发表可行性仍未建立。

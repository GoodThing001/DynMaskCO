## 0. 总览（TL;DR）

按你们自己的审计证据排序，四个杠杆的优先级是：

1. **影子模拟的路由策略强度**（杠杆①）是当前唯一有 +324/天 实证量级的杠杆；场景条件化（杠杆②③）是在影子值估计之上叠加的第二层信号，影子估计有偏/方差大时，再好的条件场景也传不出去。
2. **预算感知 margin 规则**（杠杆①）成本最低，能耗预算只覆盖约 30–40% 订单日的设定下，稀缺性定价是确定存在的结构。
3. **场景集工程**（杠杆②的缩减/收缩混合、杠杆③的决策感知缩减）作为无学习/低成本的中间层，先于生成式 REINFORCE。
4. **REINFORCE 决策感知场景生成**（杠杆③）放在最后，且必须在杠杆④的预注册协议下做，否则 40 天 dev 上多轮尝试的选择偏差会让任何正结果不可信。

### 1.2 核心机制（可落地）

**(a) Bent & Van Hentenryck 多场景法（MSA）+ consensus function。** 每个决策点维护多个场景（含已知 + 采样未来订单）的路由计划；执行动作由**共识函数**从这些计划中选出（例如：客户出现在 ≥τ 比例场景计划中 → 服务/接受）。2004 论文针对最大化服务客户数；抽象到你们的 accept/reject：**把"接单"定义为场景计划的共识投票**（appear-count / K ≥ τ），τ 是唯一的免费风险旋钮（τ↑ 更保守，相当于 margin）。

**(b) 场景对冲式 SAA（Hvattum 2006）。** 动态+随机 VRP 上第一个把"采样场景 → 逐场景求解 → 跨场景合并"做成可执行策略的论文：逐场景解后按出现频次/一致性合并成最终执行计划。对你们的启示：SAA 不一定要产出单一最优计划，**跨场景统计量（出现频次、边际值分布）本身就是接单特征**。

**(c) Rollout 与影子策略强度（Goodson 2013；Ulmer 2019 offline–online）。** Rollout 的核心性质：基策略确定性时，rollout 策略不劣于基策略（Ulmer 2019 有政策改进保证；Goodson 2017 EJOR 258(1):216–231 给出有限时域框架，DOI 10.1016/j.ejor.2016.09.040，经 `[✓ 引用链]` 核实）。→ **影子模拟器越强，SAA 接单决策越好，这是有理论保底的单调方向**，与你们 OR-Tools +324/天 的实证一致。注意反面：SAA 对离散优化有系统性偏差（Kleywegt 2002），K 小 + 贪心下游 → 价值被系统性低估/高估，接单阈值被污染。**"修正评分缺陷"前后的翻转恰好符合"影子强度主导、评分细节次之"的图景。**

**(d) Anticipatory customer selection（Ulmer 系）。** ATB（2018）把"是否确认请求"写成 ADP：状态=(时刻, 剩余时间预算)，价值=未来期望确认数，用动态查找表（DLT）离线近似；**Meso-parametric VFA（Ulmer & Thomas 2020）直接处理"接单/拒单"决策**：对聚合状态（车队负载、剩余时长等）近似接单的机会成本，在线 O(1) 决策——这正是你们 SAA 前瞻想逼近的对象，也是"10s/决策"约束下的替代路径：**离线用 SAA 预计算 (状态特征 → 接单阈值/机会成本) 的查找表，在线查表**。

**(e) 预算/容量感知的 accept/reject。** Klapp 2020（request acceptance）：同日达中接单决策必须与剩余容量/时间预算耦合，用 DP/近似 DP 刻画"接单的机会成本 = 未来更好订单被挤出"。Ulmer 2020（动态定价）把机会成本写成 VFA 并用于定价。**映射到能耗预算 B**：拒单惩罚 p_c、能耗边际成本 est(c)=c0_marginal_energy(·) 与影子价值 ΔV 合并成单一 margin 规则（见 L2 伪代码）。Klein & Steinhardt 2023 是 accept/reject+在线巡游的最新综述与基准方法（anticipatory VFA vs 规则 vs 采样前瞻的系统比较），值得作为对照基准来源。

### 2.2 核心机制

**(a) 多维计数特征下的 k-NN 条件重采样怎么改。**
- **维度灾难**：40 天样本在高维计数特征上做硬 k-NN，邻域几乎必为空/单点 → 条件分布退化为单个历史日的复制（你们结果 E 的"条件匹配 −4.27、略有害"完全符合这个诊断）。
- **Li & Racine（2003）**：离散/连续混合变量的核平滑 + 数据驱动带宽，对**计数特征用离散核**（如 Li & Racine 的 Aitchison–Aitken 核）而非欧氏硬阈值；等价地：给每个历史日一个**平滑权重** w_i ∝ Π_j kernel_j(x_j, x_{i,j})，而不是 0/1 邻居成员资格。这就是"软 k-NN"。
- **Lall & Sharma（1996）**：k-NN bootstrap 的完整工序——先选 k 近邻，再**在近邻内按核权重重采样并加扰动**（避免重复单点）；对你们：总单量等**连续化计数**可以加小抖动打破 tie。
- **特征选择/尺度**：Bertsimas & Kallus（2020）与 Ban & Rudin（2019）的教训——**特征选少而关键**（当日已到单量、时段速率、工作日/周几），且**尺度归一决定邻域形状**；带宽/特征尺度应按**下游指标**（按天配对 Δ）交叉验证，而不是按似然。

**(b) 条件重采样的去偏。**
- **收缩混合（首选，零成本）**：p_ω = λ·w_cond(ω|x_t) + (1−λ)·w_hist(ω)。λ 随有效样本量 n_eff（邻居权重和）增长：λ = n_eff/(n_eff+n_0)。n_0 是收缩先验强度，CAL 上调。这把"条件 vs 无条件"从二分变成一条可以停在中间点的曲线——你们当前 ≈0 的 gap 可能正落在两端都不好的位置。
- **重要性加权（Shimodaira 2000；协变量偏移下的加权对数似然）**：若坚持用条件样本做 SAA，场景权重应按 w = q_target/q_source 校正；但 K 小（4–8）时加权 SAA 方差急剧放大（Kleywegt 2002 的离散 SAA 偏差对权重大样本敏感），**K 小场景下优先用"选择 + 权重"（缩减式），不用连续重要性权重**。
- **条件密度估计做对比参照**：Li & Racine 的离散核条件 CDF 可以当"诊断线"——报告条件采样器在 (x_t) 处的条件分布 vs 边际分布的差异度（如 total-variation），差异接近 0 时就直接解释"为什么条件化无收益"。

**(c) 两阶段（数量 → 订单构成）条件分布建模。**
- 第一阶段：条件化**全天总单量 N|x_t**（用离散核计数回归，或泊松/负二项 GLM）。总单量是**能耗预算是否绑定的第一变量**——预算只覆盖 30–40% 订单日时，接单错误主要由"会不会爆预算"驱动。
- 第二阶段：在总单量匹配的历史天（按 N 分层）中均匀/加权抽取**订单构成**（时空位置、温区构成），必要时用矩匹配（Høyland & Wallace 2001）或简单拒绝采样对齐 N。
- 好处：把**规模不确定性**（决定预算绑定）与**构成不确定性**（决定路由质量）解耦，40 天样本下每层都更可估。Kaut & Wallace（2007）给出场景质量的检验标准（in-sample stability / out-of-sample），Kaut（2021）是"从历史数据直接选场景"的现代版（含 k-means、迭代采样选择、矩基优化选择）——**你们"历史日重采样"的直接文献锚**。

### 2.3 适配建议与成本

| 建议 | 适配方式 | 成本 |
|---|---|---|
| 软 k-NN + 离散核权重（Li & Racine 式） | 3–4 个核心计数特征、标准化 L1 距离、核带宽 CAL 扫描 | 低（纯 NumPy） |

### 3.2 核心机制

**(a) Predict-then-optimize / decision-focused 学习的原理与适用边界。**
- Donti（2017）：把预测模型与随机规划目标端到端训练，关键是**通过优化问题反传**（凸/连续时直接求导，或松弛）；SPO+（Elmachtoub & Grigas）给出凸代理损失；Wilder（2019）用连续松弛过组合层；Vlastelica（2020）对**黑盒组合求解器**做线性插值的分段常数梯度近似。
- 对你们的现实：SAA 下游是"贪心插入影子模拟 + 硬能耗认证"，**不可微且噪声大**。可行的接入点有三：
  1. **把"场景生成"当作可学习模块，而不是把整条链端到端**：对生成器参数 θ 用 SAA 下游目标做黑盒反馈——这正是 Pisinger & Hemmati Golsefidi（EJOR 2026）的位置；
  2. 学习**平滑的价值代理** ŷ(计划特征)（你们有现成的 plan 特征/评分工程），让"场景 → 影子值"局部可微，梯度经代理回传到生成器；
  3. 对**接单阈值/λ 这类低维参数**直接做黑盒微分（SPO+ 只需要对线性目标求 argmax 的次梯度，比训练生成器便宜一个数量级）——把决策感知信号先用在 τ/λ 上。

**(b) 场景缩减/选择（先于生成式）。**
- Dupačová 2003 / Heitsch & Römisch 2003（快速前向选择 FFS）：以概率度量（Wasserstein 型）贪心选出代表场景 + 重配权重，O(候选×已选) 即可，**纯 NumPy、离线预计算、在线零成本**——40 个历史天选 K=8 是标准用例。
- **决策感知缩减**：Bertsimas & Mundru（2023）直接在场景缩减目标里写**下游优化目标**（比分布距离缩减在小场景数时显著更好，尤其缩减到 1–2% 时）；Hewitt（2022）按"决策效果"聚类场景。这两个是你们"用下游接单价值选场景"的直接方法论。**落地版**：把 FFS 的距离度量换成"两天的接单决策相似度"（或 SAA 值差），复杂度不变。

**(c) 生成式场景采样做 SAA（Pisinger & Hemmati Golsefidi, EJOR 2026）。**
- 元数据核实无误：EJOR vol 335, issue 3, pp.1008–1038, published-print 2026-12, 在线 2026-07-02, ERC 资助, OA。
- ⚠️ 机制描述边界：**ScienceDirect 全文 403，未能获取摘要/全文**；以下机制描述基于标题 + 其 56 条 Crossref 引用列表推断：论文将**深度生成模型生成的场景**与**对生成场景集的搜索/选择**结合，以直接改进下游随机优化目标；其引用列表覆盖的构件包括 CVAE/流/GAN 生成器、决策基聚类（Hewitt）、优化基缩减（Bertsimas & Mundru）、历史数据选择（Kaut）、两阶段 SP 的习得场景表示（Wu 2022）。**建议：由有 ScienceDirect 权限的人取全文核对具体算法（是训练生成器还是搜索场景集）后再决定是否对齐。**
- 能源领域的 GAN 场景生成（Chen 2018）是"似然训练生成器"的成熟对照：无决策感知，仅复现边缘/时序统计。

**(d) 用下游目标训练生成模型（似然之外的信号）。**
- **REINFORCE（Bello；Kool）**：奖励 = 决策价值差。你们已有内部先例：M-pre/M-trained 的 REINFORCE 在全修复奖励上收束为负（闭环增益不迁移，被距离启发式支配）。**教训直接可用**：奖励必须定义在**按天配对的接单决策价值**上（r = Δ(day | 生成器) − Δ(day | uncond_dynamic)），而不是 J_vis 计划质量；且必须**与最强基线相减**后训练，否则学的是与贪心的噪声差。
- **可微 SAA（Donti 路线）**：只有把影子模拟换成连续松弛（如插入代价的软分配）才可行，会破坏"真实能耗硬认证"的设定 → 不推荐作为主路，仅可当梯度代理。
- **黑盒差分（Vlastelica）**：对"场景 → 影子值"映射做线性插值梯度，配合低维参数（k-NN 带宽、λ、特征尺度）是性价比最高的入口。

### 3.3 适配建议与成本

| 建议 | 适配方式 | 成本 |
|---|---|---|
| FFS 场景缩减（Dupačová/Heitsch & Römisch） | 40 天 → K=8，离线预计算 | 极低 |
| 决策感知缩减（Bertsimas & Mundru / Hewitt 思想） | FFS 距离换成下游决策相似度 | 低–中 |
| 黑盒差分调低维参数（τ/λ/带宽） | SPO+/插值梯度，仅低维 | 低 |
| REINFORCE 生成器（决策感知） | 奖励=按天配对决策价值差，与 L1 强影子叠加；预注册（见④） | 中–高（训练 + 在线采样管线已有雏形） |
| 端到端可微 SAA | 与硬认证设定冲突 | 不推荐主路 |

### 4.2 核心机制

**(a) 多假设检验控制。** 你们已经在 40 天 × 2 种子 dev 上做了多个杠杆/变体的开发期评价——每个变体一次"显著性检查"就是一个隐含假设检验；n 个变体全按 α=0.05 报 CI 跨零/不跨零，家族错误率 ≈ 1−(0.95)^n。落地：**按杠杆族做 FDR（Benjamini–Hochberg）**，或更简单：**dev 只用来排序，最终判定只做预注册的主比较**（每个已定杠杆在 dev + 新的确认 split 上各一次）。另外 2 个种子太少：报告**分层（按种子）聚类 bootstrap CI**，并在确认 split 上用新种子复算。

**(b) 预注册（针对"开发集上优化多次"）。** 没有专门的可引用"预注册论文"，可操作范本：
- ML4CO（Gasse 2022）的竞争协议：**固定评价集、固定时限、提交次数受限、公开排名脚本**——对你们相当于"确认 split 用一次、脚本冻结、公开复算"。
- 预注册内容建议：主指标（按天配对 Δ，p_c=0 为主信号）、成功判据（如 studentized 聚类 bootstrap 95% CI 下界 > 0）、**杠杆尝试预算**（本次最多评估 n 个变体）、敏感性报告（p_c=(10,20,30)）、以及"dev 结果不算结论，只算选型"的书面约定。你们已有 compute/control/analysis 冻结与 snapshot 纪律，把它扩展到**统计计划**即可。

**(c) NCO 负结果/批判论文的写法先例。**
- **Joshi et al.（Constraints 2022）**：负结果论文的模板——把失败分解为**受控消融链**（架构/训练范式/评估协议），每个消融配一个可归因结论，最后给出"rethinking"式的方向清单；公开发代码与数据。
- **Garmendia et al.（ACM TELO 2024）**：批判论文的模板——在**经典强基线（精确求解器、成熟启发式、OR-Tools 这类通用工具）**面前逐一检验 NCO 主张，覆盖性能/计算成本/可迁移性/可复用性四个维度。你们"OR-Tools 比学习/采样方法好 +324/天"的发现正是该文要的比较形态：**如果最终结论是负的，这篇是现成的写作结构**（且是 OA）。
- Bengio–Lodi–Prouvost（2021）：ML×CO 定位与评估方法论的总纲（目标函数 vs 指标、泛化、与经典方法的公平比较），可作为引文支撑。

### 4.3 适配建议与成本

| 建议 | 成本 |
|---|---|
| 预注册主指标 + 成功判据 + 变体预算（写进统计计划文档） | 极低 |
| 按杠杆族 FDR；dev 只排序、确认 split 定论（新种子 × 40 天） | 低 |

### 方案 1（L1）影子策略升级 + 预算消融

```python
# 输入: 决策点状态 s（因果可见）, 已接受集 A, 候选订单 c,
#       未来订单场景集 Ω (|Ω|=K, 生成器任意——先沿用 uncond_dynamic),
#       能耗预算 B, 每决策时间盒 T=10s
def marginal_accept_value(c, s, A, Ω, solver_budget):
    dv = []
    for ω in Ω:                       # 同一场景同时评 accept 与 reject（CRN）
        P_a = shadow_solve(A ∪ {c}, ω, time_limit=solver_budget)  # 强求解器
        P_r = shadow_solve(A,      ω, time_limit=solver_budget)
        if not certify_plan(P_a, B) or not certify_plan(P_r, B):   # 硬能耗认证
            dv.append(-inf if not certify_plan(P_a, B) else 0)     # 爆预算→不可接受
            continue
        dv.append(value(P_a) - value(P_r))
    return mean(dv)

# 接单规则: marginal_accept_value(c) > tau; tau 在 CAL 单参数扫描。
# 消融矩阵(全部按天配对Δ评价):
#   solver ∈ {greedy_insert, regret2+relocate/swap, OR-Tools(PATH_CHEAPEST_ARC+GLS)}
#   solver_budget ∈ {0.1, 0.5, 1.2, 2.0} s/场景,  K ∈ {2,4,8,16}（K*solver_budget ≤ 10s）
#   tau ∈ {−∞, 0, +margin网格}
# 输出: "求解强度→按天配对Δ"曲线, 用于选定工作点并写入统计计划。
```

### 方案 2（L2）预算感知 λ-margin

```python
# 在方案1的边际值之上叠加能耗稀缺定价
λ = λ_init                      # 影子价格, 逐决策点更新
for each decision at time t:
    accept iff ( revenue(c) − reject_risk(c)          # p_c 敏感性下报告
                 − λ * est(c)                          # est = c0_marginal_energy(c, q, cooling_share, contract)
                 − marginal_accept_value(c) ) > 0      # 方案1的CRN边际值
    # λ 更新: 用场景集中"预算绑定"的经验频率做低通
    bind_frac = mean_ω[ 1{ E_used_until_booking_end(ω) ≥ B } ]
    λ = clip(λ + eta * (bind_frac − target_bind), 0, λ_max)   # target_bind≈0.5, eta 小步长
# 调参: {λ_init, eta} 在 CAL 小网格; 报告 p_c=0 为主信号, (10,20,30) 敏感性。
# 理论锚: Ulmer & Thomas 2020 (机会成本定价), Klapp 2020 (接受与剩余容量耦合)。
```

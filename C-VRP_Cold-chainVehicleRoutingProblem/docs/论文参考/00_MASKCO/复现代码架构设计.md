# MaskCO 复现代码架构设计

## 1. 这份文档的用途

这份文档不是再解释论文思想，而是直接回答一个工程问题：

> 如果我要自己从零实现一个 `MaskCO`，项目应该怎么拆文件、每个模块负责什么、训练和推理代码怎么组织？

为了降低复杂度，这里优先按 **`TSP` 最小复现版本** 来设计。因为 TSP 最容易先跑通完整闭环。等 TSP 跑通后，再把同样框架扩展到 `CVRP` 和 `MIS`。

## 3. 每个文件应该负责什么

## 3.1 `config.py`

作用：统一放实验超参数、路径和任务配置。

建议内容：

- 数据路径
- 训练集/验证集/测试集规模
- 节点数 `n`
- batch size
- learning rate
- epoch 数
- 掩码比例范围
- 解码步数 `K`
- 校正轮数
- hidden dim
- 设备 `cpu/cuda`

建议写成一个简单配置类：

```python
from dataclasses import dataclass

    decode_steps: int = 10

    device: str = "cuda"
```

## 3.2 `dataset.py`

作用：

- 生成或读取 TSP 实例
- 提供参考解标签
- 返回训练所需张量

### 对 TSP 最小复现来说
每条样本至少包含：

- `coords`: 节点二维坐标，形状 `[n, 2]`
- `dist`: 两两距离矩阵，形状 `[n, n]`
- `tour`: 参考路径，例如 `[0, 3, 5, 1, ...]`
- `edge_label`: 边选择 0/1 标签，形状 `[n, n]`

### 你需要实现的函数

#### `generate_tsp_instance(num_nodes)`
- 随机生成二维坐标
- 通常范围 `[0,1] × [0,1]`

#### `tour_to_edge_label(tour, num_nodes)`
- 把路径转成边标签矩阵
- 若 `(i, j)` 在 tour 中被选，则 `label[i, j] = 1`

#### `build_distance_matrix(coords)`
- 计算欧氏距离矩阵

#### `TSPDataset`
- `__getitem__` 返回：
  - 坐标
  - 距离矩阵
  - 参考边标签
  - 可选：tour 长度

### 数据来源建议

你有三种路线：

#### 路线 A：自己生成 + 用启发式生成标签
- 生成随机 TSP 点
- 用 `2-opt` 或其他启发式生成高质量 tour
- 适合先快速跑通

#### 路线 B：自己生成 + 用精确解
- 小规模点数时可行
- 更贴近论文监督训练

#### 路线 C：公开数据集
- 用常见 TSP benchmark
- 更方便后续对比

对于你当前阶段，建议先做路线 A。

## 3.3 `masking.py`

作用：把完整解 `x*` 变成部分解 `x_hat`。

这个文件是 MaskCO 的关键模块之一。

### 需要输出什么
对于一条完整解标签 `edge_label`，你至少要生成：

- `partial_label`
- `known_mask`
- 可选 `unknown_mask`

### 推荐编码方式
不要只用一个 0/1 矩阵表示部分解，最好拆成两部分：

- `partial_label[i,j] = 1`：已知这条边在参考解中
- `known_mask[i,j] = 1`：这个位置的信息对模型可见
- `known_mask[i,j] = 0`：这个位置被掩码，需要模型恢复

这样模型能区分：

- “这里明确知道是 0”
- “这里根本不知道”

### 需要实现的函数

#### `sample_mask_ratio(cfg)`
- 在 `[mask_ratio_min, mask_ratio_max]` 采样比例

#### `mask_solution(edge_label, ratio)`
功能：
- 从参考解中随机掩掉一部分已选边
- 输出部分解和可见性掩码

伪代码：

```python
def mask_solution(edge_label, ratio):
    selected_edges = where(edge_label == 1)
    keep_num = int(len(selected_edges) * (1 - ratio))
    keep_edges = random_subset(selected_edges, keep_num)

    partial = zeros_like(edge_label)
    known_mask = zeros_like(edge_label)

    for e in keep_edges:
        partial[e] = 1
        known_mask[e] = 1

    return partial, known_mask
```

### 注意点
对于 TSP，部分解中的边必须仍然满足基础可行性：

- 每个点度数不能超过 2
- 不应凭空产生明显非法结构

如果掩码是从合法 tour 中删边得到的，通常这一点天然成立。

## 3.4 `model.py`

作用：输入图结构和部分解状态，输出每条候选边属于最终解的概率。

这是主网络。

## 3.4.1 输入设计
对 TSP 来说，建议输入：

- 节点坐标 `coords`
- 距离矩阵 `dist`
- 当前部分解 `partial_label`
- 可见性掩码 `known_mask`

### 边级特征可设计成
对于每条边 `(i, j)`：

- 两端节点坐标
- 欧氏距离
- 当前是否已在部分解中
- 当前是否可见

例如拼成：

```python
edge_feat(i, j) = [x_i, y_i, x_j, y_j, dist_ij, partial_ij, known_ij]
```

## 3.4.2 网络最小实现建议
最小可用版不一定非要完全复刻论文网络细节，先做一个能工作的版本：

### 方案 A：边 MLP 打分器
最简单，适合快速验证流程

- 对每条边构造特征
- 过一个 MLP
- 输出 score/logit

优点：
- 好实现
- 训练快

缺点：
- 结构建模能力弱

### 方案 B：图神经网络编码器 + 边打分头
更推荐，比较像正式方案

大致结构：

1. 节点编码器处理坐标
2. 通过消息传递融合邻接/距离信息
3. 结合当前部分解状态得到节点表示
4. 再对边 `(i, j)` 组合两端节点表示，输出边概率

### 推荐最小版本
你可以这样做：

```python
class MaskCONet(nn.Module):
    def __init__(self, hidden_dim):
        ...

    def forward(self, coords, dist, partial, known_mask):
        # 输出 [B, n, n] 的 logits
        return edge_logits
```

## 3.4.3 输出
模型输出：

- `edge_logits`: `[B, n, n]`

训练时：
- 对参考边标签做 `BCEWithLogitsLoss`

推理时：
- 对 logits 做 sigmoid
- 再交给 `decoder.py` 的选择函数

## 3.5 `feasibility.py`

作用：检查一个部分解或完整解是否合法。

这是保证推理质量的核心文件。

## 3.5.1 对 TSP 至少需要实现这些检查

#### `can_add_edge(selected_edges, i, j, num_nodes)`
检查一条边是否可以加入当前部分解：

- `i` 的度不能超过 2
- `j` 的度不能超过 2
- 在未完成最终 tour 前，不能提前形成子环

#### `is_valid_tour(edge_matrix)`
检查最终解是否是合法 tour：

- 每个节点度都等于 2
- 图是单个哈密顿环

#### `get_connected_components(...)`
辅助判断是否形成子环

### 为什么这一层必须单独写
因为模型只会打分，不会天然保证输出满足 TSP 约束。
真正让它能变成可用求解器的是：

- 模型负责“哪条边更可能好”
- 可行性模块负责“哪条边现在能加”

## 3.6 `decoder.py`

作用：把模型分数变成一个完整解。

### 论文思路对应到代码里
论文推理阶段是多步解码。代码里你可以实现一个：

- 从空部分解开始
- 每轮预测所有候选边得分
- 选择一批合法高分边加入
- 重复直到成解

### 需要实现的函数

#### `select_edges_greedily(scores, partial, k, feasibility_checker)`
输入：
- 当前边分数
- 当前部分解
- 本轮允许加入的边数 `k`

输出：
- 更新后的部分解

#### `decode_tsp(model, batch)`
整体流程：

1. 初始化空边矩阵
2. 循环 `K` 步
3. 每步调用模型打分
4. 用 `select_edges_greedily` 扩展部分解
5. 若提前形成完整解则停止

### 建议的实现逻辑

```python
def decode_tsp(model, coords, dist, steps):
    partial = zeros(n, n)
    known_mask = ones(n, n)  # 当前部分解对模型可见

    for _ in range(steps):
        logits = model(coords, dist, partial, known_mask)
        probs = sigmoid(logits)
        partial = select_edges_greedily(probs, partial)
        if is_valid_tour(partial):
            break

    return partial
```

### 注意
真正实现时：
- 空解时 `known_mask` 该怎么设定，需要和训练时编码保持一致
- 你也可以把“当前已选边”为已知，其他位置为未知
- 关键是训练/推理输入格式要一致

## 3.7 `objective.py`

作用：计算解质量。

### 对 TSP
需要实现：

#### `compute_tour_length(edge_matrix, dist)`
- 根据选中的边求总路径长度

#### `compute_gap(obj, opt_obj)`
- 若你有最优值，可以算 GAP

这个文件不要和 `feasibility.py` 混在一起：

- `feasibility.py` 判断是否合法
- `objective.py` 判断好不好

## 3.8 `improvement.py`

作用：实现论文里的“掩码-重构校正机制”。

这是复现 MaskCO 时非常重要的一部分。

### 核心流程
给定当前完整解 `x`：

1. 随机掩掉一部分当前解中的边
2. 得到部分解 `x_hat`
3. 用模型重新补全
4. 得到新解 `x_new`
5. 比较 `obj(x_new)` 和 `obj(x)`
6. 保留更优者
7. 重复多轮

### 需要实现的函数

#### `mask_current_solution(solution, ratio)`
- 从当前完整解里删一部分边

#### `reconstruct_solution(model, coords, dist, partial)`
- 从部分解重新解码出完整解

#### `improve_solution(model, coords, dist, init_solution, num_steps)`
- 反复做掩码-重构
- 输出最优解

### 伪代码

```python
def improve_solution(model, coords, dist, solution, num_steps):
    best = solution
    best_obj = compute_tour_length(best, dist)

    for _ in range(num_steps):
        partial, known_mask = mask_current_solution(best, ratio=random())
        candidate = reconstruct_solution(model, coords, dist, partial, known_mask)

        if is_valid_tour(candidate):
            cand_obj = compute_tour_length(candidate, dist)
            if cand_obj < best_obj:
                best = candidate
                best_obj = cand_obj

    return best
```

## 3.9 `train.py`

作用：训练主模型。

### 训练主循环应该做什么

每个 batch：

1. 从 `dataset` 取出：
   - `coords`
   - `dist`
   - `edge_label`
2. 在 `masking.py` 中生成：
   - `partial_label`
   - `known_mask`
3. 输入模型得到 `logits`
4. 计算 `BCEWithLogitsLoss(logits, edge_label)`
5. 反向传播
6. 记录训练损失

### 验证阶段
除了看 loss，建议还看：

- 恢复精度
- 解码后 tour 的合法率
- 解码后平均路径长度

### 推荐函数结构

#### `train_one_epoch(...)`
- 单轮训练

#### `validate(...)`
- 单轮验证

#### `save_checkpoint(...)`
- 保存模型参数

#### `main()`
- 训练入口

### 最小训练伪代码

```python
def train_one_epoch(model, loader, optimizer, cfg):
    model.train()
    for batch in loader:
        coords, dist, edge_label = batch
        partial, known_mask = mask_solution_batch(edge_label, cfg)
        logits = model(coords, dist, partial, known_mask)
        loss = bce_loss(logits, edge_label)

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
```

## 3.10 `infer.py`

作用：加载模型并测试求解性能。

### 推理流程

1. 读取测试集实例
2. 用 `decoder.py` 生成初始解
3. 用 `improvement.py` 做校正
4. 用 `objective.py` 计算结果
5. 统计平均 `OBJ / GAP / TIME`

### 需要输出的结果
至少建议输出：

- 平均 tour length
- 平均推理耗时
- 合法解比例
- 若有最优解，则输出 GAP

## 3.11 `self_training.py`

作用：实现论文材料中提到的 `self-training` 思路。

这个文件不是第一阶段必须的，但后面很有用。

### 它负责什么

1. 用已有模型跑训练集或未标注集
2. 生成比原启发式更好的解
3. 把这些更优解作为新伪标签
4. 再继续训练模型

### 建议等什么时候再写
- 第一版训练 + 推理闭环完全跑通之后
- 基础性能稳定之后
- 再加它

不建议一上来就写这个模块。

## 4. 数据流怎么串起来

下面是整个工程的主数据流。

## 4.1 训练数据流

```text
完整参考解 x*
   ↓
masking.py 生成部分解 x_hat
   ↓
model.py 输入 (图 + 部分解)
   ↓
输出每条边的 logit
   ↓
与 x* 做 BCE
   ↓
train.py 更新参数
```

## 4.2 推理解码数据流

```text
空解 / 当前部分解
   ↓
model.py 输出所有候选边得分
   ↓
decoder.py 调用 feasibility.py 做合法扩展
   ↓
得到完整 tour
   ↓
objective.py 计算路径长度
```

## 4.3 校正优化数据流

```text
当前完整解
   ↓
improvement.py 随机掩码
   ↓
model.py 重新补全
   ↓
decoder.py 重建新解
   ↓
objective.py 比较新旧目标值
   ↓
保留更优解
```

## 7. 第一版最推荐的实现策略

为了尽快落地，我建议你遵守下面这个原则：

> 先复现“MaskCO 的流程”，再逐步逼近“MaskCO 的最好性能”。

所以第一版代码建议：

### 模型
- 先用简单图网络或 MLP 边打分器

### 标签
- 先用启发式 tour 作为参考解

### 损失
- 先只用 BCE

### 推理
- 先用受约束贪心扩展

### 校正
- 先做最基础的随机掩码 + 重构接受更优解

这样你能很快得到一个真正跑起来的版本。

## 9. 你真正写代码时可以照着抄的主流程

## 9.1 训练入口主流程

```python
cfg = Config()
dataset = TSPDataset(cfg.train_size, cfg.num_nodes)
loader = DataLoader(dataset, batch_size=cfg.batch_size, shuffle=True)
model = MaskCONet(cfg.hidden_dim).to(cfg.device)
optimizer = torch.optim.Adam(model.parameters(), lr=cfg.lr)

for epoch in range(cfg.epochs):
    train_one_epoch(model, loader, optimizer, cfg)
    validate(model, cfg)
    save_checkpoint(model, optimizer, epoch, cfg)
```

```python
model = load_checkpoint(...)
for batch in test_loader:
```

# 动态冷链路径规划对比方法 — 最终清单（开源 vs 不开源）

> 调研日期：2026-08-16（第 3 轮，最终版）
> 用途：为 DynMaskCO 论文整理「同问题（动态冷链 + 路径规划）」的对比方法，分**开源可运行**与**不开源（论文数据对比）**两类。
> 原则：不开源的方法**单独列出**，用论文报告的数据与我们对比，前提是**评估指标一致**（见 §3 对齐协议）。

## 0. 我们的评估指标（对比基准，务必先对齐）

当前口径见 `docs/当前规划/评估口径.md`；以下内容保留历史版本语义：

| 指标 | 符号 | 定义 |
|------|------|------|
| **距离成本** | C_dist | **纯行驶距离**（不含任何惩罚，跨方法统一口径） |
| 时间窗可行率 | TW Feas | 零违规实例比例 |
| 容量可行率 | Cap Feas | 零超载实例比例 |
| 未服务数 / 迟到数 | N_unserved / N_late | 平均未服务/迟到客户数 |
| 品质损失 / 能耗 | Q / E | Arrhenius 品质衰减 / 制冷能耗 |
| 目标标量 | J | C_dist + λ_q·Q + λ_e·E + M_u·N_unserved + M_t·N_late |

**基准实例**：Solomon R1 / C1 / RC1，50 节点（+100 节点扩展），EDoD ∈ {0.2, 0.5, 0.8}。

> ⚠️ **对齐关键**：冷链论文几乎都报告「总成本 = 距离 + 制冷 + 碳排放 + 惩罚」，而我们的 C_dist 是纯距离。做「论文数据对比」时，**必须从对方总成本中拆出距离项**，或双方统一到同一目标标量 J 下（见 §3）。

### 2.1 逐方法评估指标对齐分析

#### (1) ESWA 2025 — 时间依赖型电动取送货冷链 DRL ★ 最贴题
- **期刊等级**：Expert Systems with Applications（JCR Q1，中科院一区 TOP，应用智能权威）
- **覆盖要素**：冷链 + 时变旅行时间 + 电动车辆 + 取送货（PDP）+ 时间窗 —— **与我们「冷链 + TW」高度对齐**；但「时变」是**旅行时间**时变，非「订单揭示（reveal-time）」动态。
- **评估指标（需读全文核实）**：典型冷链 EV-PDP 目标 = 距离成本 + 能耗/充电成本 + 制冷成本 + 碳排放 + TW 惩罚。
- **对齐方式**：若其报告**距离成本分项**，可直接与我们 C_dist 对比；若只报总成本，需双方统一目标标量 J（λ_q=λ_e=0 时退化为纯距离）。

#### (2) Alexandria Eng. J. 2025 — 农产品动态配送 RL ★ 动态+生鲜
- **期刊等级**：Alexandria Engineering Journal（JCR Q1，中科院二区）
- **覆盖要素**：**动态（replenishment demand）+ 农产品（易腐）** —— 与我们「动态 + 品质衰减」对齐；「补货」动态 vs 我们「订单揭示」动态机制略异。
- **评估指标（需核实）**：配送成本 + 易腐损耗/新鲜度惩罚 + 补货时效。
- **对齐方式**：其「易腐损耗」≈ 我们品质损失 Q；距离项可对齐 C_dist。

#### (3) Mathematics 2025 — 多温区冷链配送 DRL
- **期刊等级**：Q2（低，非 B 级以上，仅作冷链专用参考）
- **覆盖要素**：**多温区（常温/冷藏/冷冻）** —— 与我们的温度分级**完全对齐**。
- **评估指标（开放获取，可读全文）**：目标 = 运输成本 + 制冷成本 + 货物损耗成本 + 惩罚。
- **对齐方式**：温度分级一致，制冷/损耗项可映射到我们 Q/E；期刊等级不足，仅作「冷链多资源」定位佐证。

#### (4) Mathematics 2026 — 低碳冷链动态需求协同优化
- **期刊等级**：Q2（低）
- **覆盖要素**：**动态需求 + 低碳 + 冷链** —— 与我们「动态 + 冷链多资源（含能耗/碳排放）」对齐。
- **评估指标（需核实）**：多目标（成本 + 碳排放 + 时效）。
- **对齐方式**：其「碳排放」≈ 我们能耗 E（可换算）；动态需求机制需对照。

#### (5) Scientific Reports 2024 — 多车型生鲜时变路径优化
- **期刊等级**：Q2
- **覆盖要素**：时变 + 多车型 + 生鲜 + 能耗。
- **对齐方式**：生鲜 + 能耗相关，但方法偏传统优化/启发式，作为补充参考。

## 3. 评估指标对齐协议（做「论文数据对比」时的强制步骤）

> 由于冷链论文的目标函数与我们的「cost = 纯距离」口径不同，对比前**必须**完成以下对齐：

1. **距离项拆分**：从对方总成本中拆出「纯行驶距离」分量（若论文给了分项表格），与我们 C_dist 对齐。
2. **统一目标标量 J**：双方都在 `J = C_dist + λ_q·Q + λ_e·E + M_u·N_unserved + M_t·N_late` 下重新计算（λ_q=0.1, λ_e=0.01, M_u=1000, M_t=500）。
3. **基准实例对齐**：确认对方用的是 Solomon R1/C1/RC1 还是随机实例；若不同，**只在相同实例集上比较**，或声明实例集差异。
4. **问题规模对齐**：确认对方节点数（50? 100?）；规模不同则不可直接比。
5. **可行性口径对齐**：确认对方是否报告 TW Feas / Cap Feas / 未服务数；若无，则只能比「可行实例上的 cost」，并显式声明对方未报告可行性。

**诚实底线**：若对方论文未报告距离分项、未报告可行性、实例集不同，则**只能做「同问题定位」引用，不能做数值对比**，需在论文中显式说明这一局限。

## 5. 一句话结论

> **开源可运行的动态冷链学习型方法，目前仅 Omega 2025 一篇（且是补货非路径）。** 其余「动态冷链路径规划」学习型方法均在 Q1/Q2 期刊且**无代码**——可用**论文数据**对比，但**必须**先做 §3 的指标对齐（拆距离项、统一目标 J、对齐 Solomon 实例与规模）。这个「稀缺 + 无开源 + 口径不一」的现状，正是我们「统一建模 + 开源可复现」贡献的说服力来源。

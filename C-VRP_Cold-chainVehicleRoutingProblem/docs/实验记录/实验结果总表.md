## ⭐ HFR-M0 结果（2026-09-01：Hierarchical Fleet–Route Masked Reconstruction，Gate A FAIL = F3）

> **HFR-M0 完整实现（Step 1-5：teacher routes → `hierarchical_fleet_route.py` → `train_hfr_m0.py` → `hfr_replanner.py` → `run_hfr_gate_a.py`）**。训练端 Sanity Gate 全 PASS，但下游 Gate A FAIL（F3）。

**训练端 Sanity Gate（dev 1649 states，按 instance 切）**：

| Gate | 值 | 含义 |
|------|-----|------|
| S1 G 有真实信号 | AUROC **0.727** / AUPRC 0.667 / F1 0.619 / bal_acc 0.654 | G 学到 partition 信号 |
| S2 A_joint 优于 A_base | L_A 13.57 → **8.92**（Δ−4.65） | group-conditioned 提升 route 重构 |
| S3 real G >> shuffle G | 8.92 vs 29.56（Δ+20.64） | G→A coupling 载重性成立 |

**Gate A（VAL128，JF1-H=24.50，7 变体消融）**：

| 变体 | partition | insert（route 排序信号） | cost | Δ | complete |
|------|-----------|------------------------|------|---|----------|
| JF1-H | min-travel | min-travel | **24.50** | 0 | 100% |
| g_only | **G** | min-travel | **24.97** | +0.47 | 100% |
| min_travel（骨架） | travel | travel（cheapest-insertion） | 25.92 | +1.38 | 98.4% |
| a_only | travel | A_joint | 26.63 | +2.12 | 100% |
| full | G | A_joint | 29.95 | +5.41 | 99.2% |
| group_only | G | ΔA + logσ(G)（无 A_base） | 30.19 | +5.69 | 100% |
| group_logit | G | 纯 logσ(G) | 30.07 | +5.52 | 99.2% |

**结论（F3 坐实）**：
1. **G（grouping）对 partition 有正价值**：g_only(24.97) < min_travel(25.92)，Δ−0.95。
2. **任何 route/sequencing 信号都无 online utility**：a_only/full/group_only/group_logit 全部 > min_travel；且 A_group（ΔA 脱离 A_base）比 A_joint 更差 → ΔA 是相对 A_base 训练的残差，脱离即失义。
3. **根因**：OR-joint 优势在全局 partition×sequencing 协调，不分解成局部 per-edge/per-pair 偏好 —— **structural imitation ≠ online utility**。

**历史方向（已覆盖）**：当时冻结 HFR-M0 structural imitation，并计划转向 **Cost-Aware Joint Fleet–Route Preference Learning**。v4 将 cost-aware 限定为 DynMaskCO-CC 内部监督机制，不再作为独立论文主线；历史依据见 `archive/docs/优化历程/v3/层次化车队路线重构_最小完整方法与下一步执行方案_2026-09-01.md`。

## ⭐ strict-online 现状（2026-08-31 更新：R1.7 + B0 + JF1 + JF1.5 closure，VAL128）

> **核心结论**：strict-online VAL128（R1 EDoD=0.5，128 实例）闭环「fleet allocation 是主瓶颈」——JF1-H（heuristic joint）24.50 首次大幅超越 NN（27.66，−11.4%），但 learned edge logits 作 assignment score 有害（JF1-R 26.84）。

**JF1 四路 + 参照（dcc_50_r1_edod05_val.npz，128 实例）**：

| 方法 | cost | complete | 说明 |
|------|------|----------|------|
| OR-Tools-RH（OR-joint） | 23.04 | 100% | 强动态基线 |
| **JF1-H（heuristic joint）** | **24.50** | 100% | 最强 joint baseline（min travel） |

| JF1-S（shuffle joint） | 29.10 | 96.1%* | shuffle control |
| model_shuffle (H3) | 30.19 | 100% | shuffle control |

> `*` = complete 非 100%，service-first 协议下不可按 cost 直接排名。

**R1.7 归因**：H2-G(27.10) < H1(27.66) 首次超越 NN −2.0%，H3-G(27.69) ≈ H1 → **learned preference 提供全部 2.1% 收益**（`local_first_divergence = 61.3%`）。

**B0 三层**（256 train paired）：`G_seq = −1.25%`（sequencing 饱和）、`G_fleet = 17.90%`（fleet 主导）→ 17.6% gap 几乎全在 fleet allocation。

**JF1.5 null**：assignment beam B=1/4/8/16 无差异（均 24.68，99.2%），因 assignment surrogate 近似可分 + canonical R1/K=25 容量极宽松（利用率 21.8%）→ assignment-level beam width 非优化自由度；且 B=1(24.68) ≠ JF1-H(24.50) 因 `pair_feasible` hard filter + MRV 改变 candidate semantics。真正 search depth 留到 JF3。

**下一步 = JF2**：MaskCO 内新增 Fleet Assignment Head（`S(k,j|FleetState)`），residual 到 JF1-H（`S=S_H+α·r_θ`，α=0 复现 24.5019/100%），OR-joint assignment supervision。详见 `archive/docs/优化历程/v2/JF2下一阶段完整执行方案_2026-08-31.md`。

### Week 4：可解释性分析（2026-08-21~22 完成）

#### 边影响分析（Day 1-2，反事实 relocate）

模型路线（beam+2opt）vs 贪心参考路线，128 实例 × 50 边 = 6400 边/类型。方法：移除客户 v → TW 可行前提下贪心重插入最小成本位置 → Δcost。

| 数据 | 路线来源 | neutral（已最优） | harmful（可改进） | mean Δcost |
|------|---------|:---:|:---:|:---:|
| R1 | 模型（beam+2opt） | 99.5% | **0.4%**（28 条） | −0.001% |
|    | 贪心参考 | 88.7% | 11.3%（724 条） | −0.056% |
| C1 | 模型 | 99.6% | **0.4%**（26 条） | −0.004% |
|    | 贪心参考 | 87.5% | 12.5%（800 条） | −0.049% |
| RC1 | 模型 | 99.5% | **0.5%**（33 条） | −0.003% |
|    | 贪心参考 | 88.8% | 11.2%（720 条） | −0.054% |

**次优边下降**：R1 −96.5%、C1 −96.8%、RC1 −95.5%（约 22-31×）。

> **结论**：模型路线 99.5% 距离局部最优；beam + TW 2-opt 把贪心参考的 11-12% 次优边降到 0.4%。回应「模型路线可信吗」。
> **caveat**：relocate 限制同车（Or-opt 邻域），非全局最优；不含容量约束检查。

#### 约束消融（Day 3-4，typed_v1_edge seed42，128 实例/类型，effect_gap 噪声校正）

三个扰动：`temp_swap`（打乱温度标签）、`tw_relax`（TW 宽度 ×2）、`capacity`（40/60/70）。

| 实验 | 类型 | edge_overlap | noise_overlap | **effect_gap** | cost Δ% |
|------|------|:---:|:---:|:---:|:---:|
| **temp_swap** | R1 / C1 / RC1 | 0.340 / 0.316 / 0.329 | 0.368 / 0.335 / 0.354 | −0.03 / −0.02 / −0.02 | −0.50 / +0.43 / +0.41 |
| **tw_relax** | R1 / C1 / RC1 | 0.254 / 0.247 / 0.255 | 0.368 / 0.335 / 0.354 | **−0.11 / −0.09 / −0.10** | **−2.36 / −3.16 / −2.65** |
| **capacity=40/60/70** | R1 | 0.355 / 0.345 / 0.355 | 0.368 | −0.01 / −0.02 / −0.01 | −0.67 / −0.05 / −0.56 |

> **结论（支撑三层贡献）**：
> 1. **温度次级**：temp_swap effect_gap −0.02（≈噪声地板）+ cost Δ +0.11%（符号混）→ 不改成本，规模化确认 R1 弱效应。
> 2. **TW 绑定**：tw_relax effect_gap −0.10（**5× 于其他扰动**）+ cost Δ −2.7%（C1 最多 −3.2%）→ TW 是主导硬约束，放宽即释放优化空间。
> 3. **容量非绑定**：capacity effect_gap −0.02（≈噪声）+ cost Δ ≈0 + 车辆数 Δ≈0（窄 TW 下车队 TW 限制，~25 车 ≈ 2 节点/车）。
> ⚠️ **口径**：`effect_gap = edge_overlap − noise_overlap`（噪声地板 = 同数据不同 seed 再解码一次，实测 0.335~0.368，即单次解码边集本身欠定 ~35%）。**cost Δ 是主证据**，effect_gap 是路线级敏感度的稳健化证据，两者一致。

> **诚实结论（导师冻结）**：*"Quality-aware decoding has a demonstrable causal effect in controlled settings, but its practical influence is substantially constrained by binding time-window constraints in realistic narrow-TW instances."*
> - ✅ 机制正确（toy 完美翻转证明 weighted completion time 因果成立）

## ⚠️ 历史状态（2026-09-01，已被 2026-09-03 v4 覆盖）：HFR-M0 实现完成 + Gate A FAIL（F3）

**HFR-M0（Hierarchical Fleet–Route Masked Reconstruction）已完整实现（Step 1-5）**。训练端 S1/S2/S3 全 PASS（G 学到 partition 信号 AUROC 0.727；A_joint 优于 A_base；real G >> shuffle G 耦合 active），但 **Gate A FAIL（F3）**——VAL128 七变体消融：G 对 **partition 有正价值**（g_only 24.97 < min_travel 25.92，Δ−0.95），但**任何 route/sequencing 信号都无 online utility**（a_only 26.63 / full 29.95 / group_only 30.19 / group_logit 30.07 全部 > min_travel 25.92）。**根因**：OR-joint 优势在全局 partition×sequencing 协调，不分解成局部 per-edge/per-pair 偏好 —— **structural imitation ≠ online utility**。

**历史方向（已覆盖）**：当时冻结 HFR-M0 structural imitation，并计划转向 **Cost-Aware Joint Fleet–Route Preference Learning**。v4 将 cost-aware 限定为 DynMaskCO-CC 内部监督机制，不再作为独立论文主线；历史依据见 `archive/docs/优化历程/v3/层次化车队路线重构_最小完整方法与下一步执行方案_2026-09-01.md`。

**旧数字全部作废**：14.77 / 15.45 /「100% feasible」/ 68.8% / 13.53 均为 P0 审计前旧协议数字。

**R1 诊断历史（2026-08-28，已被 R1.5-M 取代）**：旧 strict-online 曾发现「模型输出与 EDD 贪心逐位相同」（complete 68.8% @ 28.24），根因 R1-R4——经 P0 协议修复 + Fix A + Fix B + R1.5-M 测量后，模型已 active（61% divergence）。

## 当前论文与执行主线

当前主控目录：[`当前规划/`](当前规划/)

论文目标固定为：**基于 MaskCO 的掩码生成与迭代重构范式，构建面向动态冷链物流的因果、约束可行、冷链效用对齐在线优化方法。** Cost-aware preference 是内部训练机制，不是替代 MaskCO/冷链的顶层主线。

主实验运营协议固定为 **dynamic cold-chain pickup-to-depot**：空载出发、客户取货、返仓卸货、单次行程且无 reload。C0 将实现订单级 cargo manifest；不得把当前容量动力学解释成 depot-to-customer 配送。

## 状态标记

- **当前权威**：决定当前研究与实验动作。
- **证据追溯**：用于核对结果、决策和 provenance。
- **冻结方法档案**：方法已完成诊断，不再沿原目标优化。
- **历史材料**：不得覆盖当前主控文档。

旧协议的 `14.77`、`15.45`、`14.08` 等数字只能作为历史记录，不得用作当前性能结论。

## 命名规则

- 用户维护的说明文档除 `README.md` 外使用中文文件名；MaskCO、JF2、HFR、O0 等方法或阶段代号可以保留。
- `AGENTS.md`、`CLAUDE.md` 等工具约定文件保留固定名称，否则对应工具无法自动识别。
- CSV、JSON、NPZ、checkpoint 等程序产物保留脚本约定名称。
- 原始论文 PDF/DOCX 保留出版物标题、DOI 或下载文件名，避免破坏文献溯源。

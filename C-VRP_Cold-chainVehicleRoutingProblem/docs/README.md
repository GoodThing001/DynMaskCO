# DynMaskCO-CC 文档导航

_用于区分当前权威文档、证据追溯材料和历史档案。_

---

## 📍 阅读入口

1. 先阅读项目根目录的 [项目当前状态](../项目当前状态.md)
2. 再进入 [当前规划导航](当前规划/README.md)
3. 根据导航中的职责分类查阅研究、工程、实验、结果或审计文档

项目的实时阶段不在本文档重复维护，以状态入口和执行进度表为准。

## 📚 目录职责

| 目录 | 职责 | 地位 |
| --- | --- | --- |
| `当前规划/` | 论文主控、实现契约、评估与进度 | 当前权威 |
| `实验记录/` | 历次结果与决策证据 | 证据追溯 |
| `论文参考/` | 论文、方法调研与对比材料 | 参考资料 |
| `../archive/docs/` | 旧版方案、优化历程与阶段汇报 | 历史档案 |

## 🔗 使用规则

- 当前权威文档决定现行口径
- 证据追溯材料不自动成为当前结论
- 历史档案只用于解释演进，不得覆盖现行协议
- 除 `README.md`、`AGENTS.md`、`CLAUDE.md` 等工具固定文件外，用户维护的说明文档使用中文文件名

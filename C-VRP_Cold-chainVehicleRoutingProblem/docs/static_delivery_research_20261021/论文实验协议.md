# 静态冷链 MaskCO：论文模型证据与实验取舍

后续已按用户要求选定并冻结[组合模型与数据尺度v1](组合模型与数据尺度_v1.md)，完成47例可行证书、9例排除证据及188份路线集合重算。本文保留此前候选筛选阶段的证据和“未冻结”时间身份，不覆盖后续v1选择。

核验日期：2026-10-21。研究目的为评价改造后的 MaskCO 在静态冷链路径优化中的效果。采用可引用、可复算的文献数值模型即可推进；真实采购价、批次检验和实测车型校准不作为算法数值实验的前置条件。本页是模型选择与实验协议，不是完整业务理论。原番茄/鲻鱼证据、RRP 年化欧元基准及历史结果均保留；本轮没有新增训练或方法胜出结果。

## 2. 价值损失：有来源的货币模型，不再强行把TA当价格

RCR 2020 对同一种冷冻商品分别计算运输与卸货货损。省略分配变量后的单次服务项为：

\[
 L^{travel}_j=P m_j[1-\epsilon_1 e^{-\theta(t_j-t_{dep})}],\qquad
 L^{unload}_j=P M^{remain}_j[1-\epsilon_2 e^{-\theta m_j/u}].
\]

原文表5：`P=5000元/吨`，`ε1=1`，`ε2=0.9`，`θ=0.002`；`u=3.6吨/小时`。`Mremain` 是卸完当前客户后剩余载荷。注意 **ε2 在指数外**，不能改写成另一个衰减率；原式在卸货时长为0时仍有10%的该项损失。这是原论文的成本近似，不是严格逐批质量守恒模型。

原表将 θ 单位写为 none。根据速度 km/h、卸货吨/h及时间差，统一采用小时解释时，θ 必须取 h⁻¹；这是我们的量纲澄清，不能说原文明确打印了 h⁻¹。表5及原式截图均保留。

对于所有需求必须送达、参考总货值与采购总额不随路线改变的实验，可以写：

\[
 \max\Pi=B-C_{purchase}-L-C_{transport}-C_{refrigeration}.
\]

其中 `B` 为固定满值货值。该目标与最小化 `L+Ctransport+Crefrigeration` **代数等价**，仍按最大净效益表达和报告；这里的损失按货币价值折损解释，不能再从收入中重复扣一次。未知但共同固定的采购费用可以从优化奖励中省略，输出称“净贡献/净效益差额”，不伪报已知绝对利润。如果允许拒单或需求可变，这个常数等价关系需重新处理。

## 3. 品质验收：论文采用研究阈值，并无跨食品统一百分比

**IJPE 2021**：以初始品质为1，用零阶温度相关衰减；§4.3.1/表5实际测试 **80%** 验收。该案例中85%及以上不可行，71%以下约束不起作用；这些界限只针对其原案例。系数以秒为基础，温度使用K，费用为欧元，不能把每秒系数当每小时系数。

**EJOR 2025**：甜玉米示例采用

\[
 q(t)=\exp[-\int_{\tau}^{t}\alpha(T(s))ds],\quad
 \alpha(T)=0.0048\exp(0.1036T).
\]

`t` 按小时，`T` 按℃；批次品质是对采收区间的上述保留率取平均，不是只算最后采收时刻。§5.1.1采用 **90%、91%、92%、93%**；表2低温/高温场景分别95%/80%；表3另有75%—90%的场景。成本以人民币表示。该研究是采后预冷取货，不能冒充静态配送复现；可以引用其品质模型、阈值情景设计依据。

这两篇的百分比是数值研究中的最低品质要求，**不是番茄或鲻鱼的法定验收标准**。`q≥qmin` 可作为我们的硬约束，但从一篇取衰减函数、另一篇取阈值、再结合经典路径数据，必须明示为本文组合设定。

重要预检：若采用RCR的小时解释，`exp(-0.002×24)=0.95313`，80%对应111.57小时。因此在24小时内只用这一运输衰减项时，80%约束不生效。不能把它用于声称品质掩码的优势；应先报告可行比例与约束实际触发次数，再按预先声明的文献模型/情景做比较。开门项不能默默合并成这一单指数检验。

## 4. 统一单位与运输成本

论文没有强制通用币种；本研究建议统一 **分钟、kg、km、人民币/单次配送**。RCR原文数值可直接统一如下，均为单位换算，没有新拟合：

| 参数 | 原文 | 统一后 |
|---|---|---|
| 参考货值 | 5000元/吨 | **5元/kg** |
| 距离运输费用 | 3元/km | **3元/km** |
| 行驶制冷耗油、油价 | 2 L/h；6.68元/L | **13.36元/h = 0.222667元/min** |
| 卸货制冷耗油、油价 | 2.5 L/h；6.68元/L | **16.70元/h = 0.278333元/min** |
| 卸货速度 | 3.6吨/h | **60kg/min** |
| 车速 | 40km/h | **2/3 km/min** |
| 衰减系数，小时解释 | 0.002/h | **0.0000333333/min** |
| 原案例载重 | 2吨 | **2000kg** |

这提供了无需臆造压缩机功率的制冷成本依据，属于论文的耗油费用模型；不称实测电功率。距离费与额外牵引燃油费不能重复累计。

司机工资：固定且对所有方案相同的部分是常数，优化中可省略。RCR的200元/车把维护、折旧和司机工资捆绑，**不能既采用整包200元又声称已剔除工资**。当前不将其作为新的纯车辆启用费。车数可变时，按车固定费也不再是共同常数，需单独声明是否纳入。

虚拟单位可以使用：将所有货币项同时除以同一个正尺度 `S`，最大净效益的最优路线不变。只归一化货损而不同比缩放运输费，会改变问题。不要把欧元成本与人民币商品价格直接相加；如果选择上述RCR费用族，全部采用人民币。

## 5. 面向论文的取舍与方法比较

主线采用“经典公开路由数据＋明确声明的通用易腐商品品质/价值模型”，番茄和鲻鱼作为有证据时的扩展案例，不再要求同时凑齐两种食品的真实商业参数。原Solomon坐标、需求、时间窗和作者改编版本分别固定身份；原始抽象时间/需求若映射到分钟/kg，应先冻结并公开映射，不能把新增物理单位冒称原Solomon标准。不同容量、服务时长或时间尺度的组合属于新冷链基准，不拿原距离BKS充当新净效益最优值。

优先路线：先在已转录的IJPE七客户案例验证品质衰减与80%阈值，再冻结大规模经典路由的组合模型。RCR货损费用可作为货币基准，IJPE/EJOR品质模型可作为约束模型候选；**目前尚未把它们拼成已启用、已校准的唯一配置**。剩余要决定的是组合模型的时间/需求映射、品质起算点、等待/卸货/返仓记账及可行阈值场景，而非继续索取真实企业价格。

方法贡献候选为品质剩余裕量状态表示、能够检查剩余可达性的品质约束掩码、面向货损的局部改进。仅改奖励符号不足以建立方法贡献；新增模块应分别消融。

对比保留官方源码快照，使用 **同一目标改造的原MaskCO、强ALNS、SA/VNS及小规模精确解**。现有OR-Tools/PyVRP距离解可作初解或距离参照；适配新目标前不能作为等目标最终比较。EJOR预冷算法和CIE满意度ALNS是结构参考，未经问题及实现对齐不标作原文复现。

冻结协议后用相同测试实例、独立评价器和明确计算预算比较净效益差额、货损、运输制冷成本、可行率与运行时间。按几何组划分训练/验证/测试，避免同几何变体泄漏；随机算法采用配对种子，统计比较以实例为配对单元，重复种子先汇总，报告效应量及多重比较修正。归一化后的利润百分比受共同常数影响，优先报告绝对净效益改善与等价损失总成本改善。选择模型和阈值不以MaskCO测试集是否胜出为依据。

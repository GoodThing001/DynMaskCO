# 静态冷链净效益：组合模型与数据尺度 v1

2026-10-21已选定并完成可执行预检。协议：`static_delivery_isothermal_quality_net_benefit_v1`。用途是检验改造MaskCO的算法效果；这是有来源、公开声明组合假设的数值研究，不宣称复现任一篇完整模型或预测真实企业利润。

**确定采用：作者VRPTWQ–Solomon原数据＋恒温零阶品质保持率＋线性品质价值会计＋统一虚拟货币U。** 主线为单仓、单产品、静态、必须全部服务、多车闭合配送。商品称“通用易腐品，采用鲜切蔬菜参考品质动力学”，不再将其命名为番茄或鲻鱼。

## 2. 统一品质尺度与硬约束

采用[IJPE 2021](https://doi.org/10.1016/j.ijpe.2020.107849)的零阶、参考温度修正Arrhenius形式，并明确简化为恒温运输：

\[
 k_p(T)=60\kappa_{p,ref}\exp\{-E_{a,p}/R\,[1/T-1/T_{ref}]\},\quad
 q_i=1-k_p(T)(C_i-D_{r(i)}),\qquad q_i\ge0.80.
\]

`C_i`是卸货服务完成时刻，`D_r`是该车出库时刻，品质保持率无量纲。行驶、途中等待和完整服务时间均计入货龄；货物交付后不再计入，空车返仓不继续给已交付货物扣品质。载重仍是原kg需求，品质衰减不伪装成物理质量减少。

| 参数 | 主实验 | 来源 |
|---|---|---|
| 初始运输品质保持率 | 1 | 以各车出库品质归一化的定义 |
| 实际/参考温度 | 275K/275K | IJPE §4.1及参考动力学；**275K严格为1.85℃**，保留源论文取整K值，不偷偷替换成275.15K |
| 外部温度 | 293K | IJPE §4.1；严格为19.85℃ |
| 主品质参数 | Product1：κref＝3.08×10⁻⁶/s，Ea＝77900J/mol | IJPE表3；取三种已发表速率的中间值，先于方法比较确定 |
| 分钟衰减率 | k＝0.0001848/min | 60×κref，因T＝Tref指数项为1 |
| 验收阈值 | 80% | IJPE §4.3.1/表5的研究阈值；不是统一食品安全标准 |
| 主实验最大交付货龄 | 1082.2511min≈18.04h | (1−0.8)/k，由上述数值推导 |

没有复制IJPE原文的多产品温度升降、开门传热、载重相关降温和完整成本公式。恒温是本文简化；因此不声称原文42%等质量下降或原最优路线已被复现。在此简化下，品质约束等价于最大交付货龄，品质价值则引入需求加权交付货龄；不将这一等价结构包装成新的数学问题。

**出库时间允许决策，品质从各车实际出库计龄。** 研究边界是出库后的运输品质保持率，不估计仓储货龄、生产时刻或出库前绝对鲜度。同一订单必须服务，不能靠拒单逃避低品质。客户窗约束服务开始，品质约束服务完成。

对于固定路线顺序，采用最晚可行出库时刻，再向前递推最早服务。其严格依据是：服务时刻可写为若干`D＋常数`与窗口常数的最大值；因此`服务完成−D`随D增大不增加，总tour时长也不增加。最晚可行出库同时不降低品质价值、不增加制冷费用。所有方法共用该路线排程规则，不给MaskCO单独增加调度优势。已有前缀追加客户时，出库时刻可能前移，必须重新检查此前所有客户的品质，不能只检查新增客户。

## 3. 最大净效益与虚拟货币单位

\[
 \max\Pi=\sum_i Pm_iq_i-c_d\sum_r\ell_r-c_e\sum_r(R_r-D_r).
\]

`m_i`为需求kg，`ℓr`为包含返仓的路线km，`Rr`为返仓时刻。此处净效益扣除了共同固定项：固定采购量对应的采购总额、共同工资/固定开销不参与排序，也不伪报未知的绝对会计利润。不加入按车启用费、加班或随用车数变化的工资；若以后研究这些费用，需另起协议。

| 金额项 | 冻结数值 | 来源与推导 |
|---|---|---|
| 距离费cd | 1 U/km | 以作者数据的1 EUR/km为数值尺度定义U |
| 参考货值P | **5/3 U/kg** | RCR 2020表5：5000元/吨＝5元/kg、距离费3元/km；保持`货值/每公里费＝5/3 km/kg`这个相对经济比值 |
| 品质价值 | P×需求×品质保持率 | 本研究线性价值近似；借鉴RCR“单位货值×需求×保持率损失”的会计关系，**不是实测鲜切蔬菜价格函数** |
| 制冷费率ce | **0.0972 U/(车·min)** | 作者README：λ＝0.36W/(m·K)、S＝30m²、L＝0.1m、费用系数5×10⁻⁵/(W·min)；采用所选293−275＝18K温差 |

制冷推导：`H＝λS/L×18＝1944W`；`ce＝1944×5×10⁻⁵＝0.0972 U/min`。H是墙面热负荷，**不是压缩机电输入功率**；费用系数是作者基准数值，不解释为电价。费用计出库到空载返仓的完整车时，含等待和服务；不另收同一制冷耗油费、牵引燃油费或相同货损。

来源：[RCR原文表5和式3](https://pure.coventry.ac.uk/ws/files/28060196/Binder6.pdf)、作者仓库README的Fleet/Refrigeration表。RCR的2吨车型制冷油耗、200元工资折旧整包、ε2开门近似均**没有移植**到本20吨场景。

这个选择不是汇率换算：运输/制冷保留作者费用族的相对比例；货值仅转移另一篇的货值—距离费比。跨商品、跨车型的比例转移是本研究显式经济情景设定，不冒充同商品实测标定。后续所有货币项再同时除以同一正数，路线最优解不变。

也可等价评价`PΣm−Π＝货币品质损失＋距离费＋制冷费`，便于跨方法比较；最终主目标仍表述为最大净效益。不要在质量折价收入之外，再减一次相同货损。

## 4. 预先冻结的敏感性与几何划分

只使用已发表的三种动力学，不随机编造系数：慢Product3 κref＝1.96×10⁻⁶/s、Ea＝88521；主Product1如上；快Product2 κref＝3.84×10⁻⁶/s、Ea＝76304。温度不变。阈值取80%和85%，后者亦为IJPE讨论的研究条件；原文85%不可行指其原变温案例，不推断本恒温新数据组合也不可行。

训练/验证在各自几何集合上覆盖`3速率×2阈值`六种条件，主表固定Product1/80%，另外五组为敏感性，不按测试集结果挑主条件。**慢速率/80%在24h内品质硬约束理论上不触发**，作为约束不活跃对照，品质折价仍有作用。

56个作者文件实际只有四组不同坐标：C1、C2、R1＋R2、RC1＋RC2。采用完整几何四折轮换，每折一组测试、下一组验证、其余两组训练；同坐标的不同时间窗/动力学条件不得跨角色。过滤九例后：

| 折 | 测试 | 验证 | 训练 | 训练/验证/测试例数 |
|---|---|---|---|---|
| 0 | C1 | C2 | R＋RC | 38 / 4 / 5 |
| 1 | C2 | R | C1＋RC | 20 / 23 / 4 |
| 2 | R | RC | C1＋C2 | 9 / 15 / 23 |

每个主测试实例只得到一次所在留出折的预测。报告逐例及四组几何宏平均；不能把47个窗口变体或282个品质条件当成同等数量独立空间样本。四组几何限制了统计推断强度，种子重复不能增加空间样本数。

## 5. 已做的实算检查与后续方法比较

预检结果：[summary.json](../../results/static_delivery/publication_protocol_v1_preflight_20261021/summary.json)。

- 56份数据与作者ZIP字节一致；47例有逐客独车可行证书及完整品质可行的确定性近邻构造路线；9例保留不可行证据。
- 全56例×3速率×2阈值＝336个单客边界检查单元，主线47例在六种条件中均有可行解，避免各方法或情景选择不同客户集合。
- 188份完整路线集合由独立的逆向排程＋正向计时/品质/金额重算通过。另有1028次源实例路线检查支持最晚出库支配更早出库的结论；数学依据见上文。
- **39个实例**找到忽略品质后满足路由约束、但违反80%阈值的明确路线；只证明品质约束对可行域有作用，**不等于39个最优解必定紧贴阈值**。
- **47个实例**均有合并两客户严格提高净效益的证书，排除“一客一车已经必然最优”的退化；47个实例也都有省运输/制冷费但降低净效益的合并方案，说明目标并非只看距离。
- 历史产品配置、旧净效益情景配置和原结果SHA保持不变；没有新MaskCO训练或方法优胜结论。上述近邻和双客路线仅作协议诊断。

后续统一用该评价器适配原MaskCO、改进MaskCO和强ALNS/局部搜索；同目标、同强制客户、同出库规则、同品质硬约束、同车数上界。原MaskCO基线也必须有基础可行性检查，不能拿违反品质约束的无效路线衬托新方法。改进可研究品质裕量表示和更充分的部分路线检查，再做消融。相同测试搜索预算、训练/调参仅使用各折训练/验证数据，测试结果不能反向改变v1参数。

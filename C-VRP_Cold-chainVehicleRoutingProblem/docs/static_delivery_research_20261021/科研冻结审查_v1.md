# 实验协议v1：科研审查与冻结决定

日期：2026-10-21。审查对象为[组合模型v1](组合模型与数据尺度_v1.md)及其数据、代码和实算证书。采用scientific-critical-thinking的方法学审查框架，重点核查内部一致性、构念有效性、对比公平性与统计推断范围，不套用临床证据分级。

**决定：通过模型、数据及分析规则的科研冻结。** 基础模型数值、47例主集合和四组几何划分保持不变；补充严格评价边界、独立LP核验及预先规定的分析计划。本协议支持限定数值基准上的算法比较，不能据此宣称商品价格实证、复杂温控优化或广泛空间总体优势。冻结不等于已完成方法实现或已证明MaskCO优胜。

## 二、数学结构与排程核验

恒温下`q_i=1-k(C_i-D_r)`，品质硬约束即交付货龄上界，主条件为1082.2511min；Ea在T＝Tref时抵消。温度不是决策变量，因此不能把算法称作已解决动态温度控制或由常温输入证明温度泛化。

所有客户必须服务、固定服务时间合计9000min、速度1km/min时，等价损失总成本可进一步精确写成：

\[
 L=P\sum m_i-\Pi
 =1.0972\,D+0.0972\,W+874.8
 +Pk\sum_i m_i(C_i-D_{r(i)}).
\]

`D`为总km，`W`为途中等待min，874.8为共同服务制冷费用。这说明部分制冷费用与距离成正比，服务部分是常数；本模型实质上是带品质货龄上界、需求加权交付货龄和距离/等待成本的路径问题。**不能靠改目标正负号或多列一个制冷项声称新的建模创新。** 方法贡献须由同目标强基线和模块消融检验。

对固定路序，最晚可行出库不增加任一交付货龄或tour时长，因此在当前单调折价、非负费率下支配更早出库。为避免两个同源评价程序互相印证，本轮另建独立线性规划，将出库、每客服务开始、返仓时刻全部作为变量，在原始时间窗和品质约束下直接优化金额；不复用解析排程得到的时刻。

核验包含：47例各两条不同路线的最优排程、39条品质不可行证书、九例原路由冲突，以及47例在0.5/1/2货值倍率下的固定路线最优排程。完整数量、求解状态和数值误差见[审查结果](../../results/static_delivery/publication_protocol_v1_scientific_freeze_20261021/audit_summary.json)。浮点LP用于在1e−6 U误差内独立验证，不冒称有理数精确证明或全局最优路由。

## 三、发现并修复的评价边界缺陷

原评价器在外部传入NaN出库时刻时，可能给出`feasible=True`及NaN金额。这没有污染已检查的有限数值预检路线，但不能带入正式实验。

保留原代码和原预检SHA，新增[严格评价入口](../../comparisons/static_coldchain/adapters/publication_model_v1_strict.py)：拒绝NaN/Inf及非法出库值；正式完整解评分不能关闭品质约束；缺客、重复、超载和非有限输出均拒绝。原有限合法路线分数必须与原结果一致。新入口和原依赖一起加入冻结清单。

## 四、经济敏感性、指标与公平对比

主模型P不变，额外预先规定`P×{0.5,1,2}`，即5/6、5/3、10/3 U/kg。半值/双值是作者设计的压力测试，不谎称三组价格均出自论文。它只检查经济权重敏感性，不能验证真实折价函数。主品质条件下增加两个不同P条件，连同原六种品质条件共八个不同测试条件。

神经模型仍按原六种品质条件、名义P训练/验证；经济敏感性固定这些检查点，给所有方法提供当前目标系数重新搜索，不看测试结果微调。不能用“只重算旧路线”替代新权重下的优化实验；本轮的货值LP核验只是评价/排程检查，还不是这些算法比较。

正式比较固定原MaskCO的同目标适配、完整目标ALNS和VNS。纯距离方法只作控制或初解。所有方法共享硬约束、解析出库排程、在线确定性可行初解和完整解严格审计，不能以不合格基线衬托新方法。新增模块及单模块移除消融须在方法清单中提前锁定。

主预算为每实例60s墙钟，保存1/10/60s可行incumbent。特征准备、数据传输、初始化、修复和搜索计时，GPU同步后计时；训练数据上一次性预热/JIT及模型加载单列。传统方法单CPU线程，神经方法至多一GPU，公开机器和资源：这是同墙钟比较，不能写成同FLOPs。训练费用和显存另报。

主指标是四组几何内先平均、再对四组平均的净效益差额U；辅以每例结果、货损、距离、等待、车数、最低品质、失败率和随时间结果。全47例、全种子、全声明条件均保留，崩溃/非法解不得静默删除或把初解回退标成成功。利润百分比受共同常数影响，不作为主指标。

## 五、数据独立性与结论强度

56文件仅四组坐标。九例排除基于强制客户的单独直达可行性，不依据方法输赢；K＝n时，全部单客可行也给出整个实例的充分可行证书。不能把窗口变体当新空间样本。

四折训练/验证/测试几何分别隔离。网络结构、共用超参数或算法设计不能根据任一外层测试结果再调整；每折只能在自己的验证几何上选择。此前已查看可行性诊断和另一目标的传统算法pilot，应如实披露，不能称数据从未见过。

**四组空间差异的双侧精确符号检验最小p为2/2⁴＝0.125**。因此即使四组都改善，也不能把这四组当成充分的空间显著性证据；相互重叠训练集的四折也不是独立实验。

另预先规定十个独立重复种子101—110：神经方法每个重复需在每折重新训练，不能把同一检查点的十次解码当十次训练重复。每个重复先汇总完整固定基准，再比较重复级的配对几何宏平均差；精确双侧符号检验及三对比Holm修正只解释为**固定基准上对算法/训练随机性的稳健性**。不将其扩大为空间总体显著优越。每例和每组的差异、失败及负结果同时报告。

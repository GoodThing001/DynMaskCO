## 1. S-19 裁决：L-1 + L-2 同时强制，L-3 / L-4 不得省略

采纳独立复核意见。规格改为：

| 编号 | 要求（**必须满足**） |
|---|---|
| **L-1** | 安装前形成与调用方**无共享可变引用**的**深度冻结**计划，并对该冻结计划复算**完整**身份 |
| **L-2** | 安装回调**只**接收冻结计划（的只读表示）；**调用前后各核对一次**身份 |
| **L-3** | 归档条目绑定**安装前的冻结计划**；**不得**从回调持有的对象重新复制 |
| **L-4** | 认证器对**实际审核的冻结对象**返回完整身份**及逐字段证据** |
| **L-5** | `VehiclePlan` 的锚点与**冻结执行状态**交叉核验，不一致直接拒绝 |

### 1.1 "深度冻结"的定义（不得只做浅层）

> **只读包装不是冻结。** 对最外层字典使用 `MappingProxyType`、或给对象加一个
> `__setattr__` 抛异常的壳子，**都不满足 L-1**。

L-1 要求冻结是**递归**的：

- 映射 → 不可变映射（无 `__setitem__`），条目有序；
- 每辆车的计划 → **frozen dataclass**（字段赋值抛 `FrozenInstanceError`）；
- `suffix` → `tuple`（不是 list）；
- 冻结完成后**递归断言**：结构内不存在 `list` / `dict` / `set`，也不存在未冻结的 dataclass。
  递归断言失败 ⇒ `REFUSED: FREEZE_NOT_DEEP`。

## 2. 新增：安装回调的**副作用边界**（这是本轮最重要的补充）

独立复核指出一个真实的语义漏洞：**若 `install_fn` 已经执行了真实安装、状态写入或其他
不可逆副作用，事后发现身份不一致时，不能宣称"`REFUSED` 且没有安装发生"。**
否则我们修好了计划对象的 TOCTOU，却在**安装事务原子性**上制造了新的虚假安全保证。

因此候选必须把结果分成**四档**，且每档的可证内容不同：

| 档位 | 何时进入 | 可**证明**的内容 | 可**声明**的内容 |
|---|---|---|---|
| `REFUSED_BEFORE_INSTALL` | 安装前核对失败（认证身份 ≠ 冻结计划身份，或锚点交叉核验失败） | 安装回调**从未被调用**；`n_installs = 0`；无外部写入 | 可以声明"没有安装" |
| `INSTALL_COMPLETED` | 回调正常返回 **且** 安装后核对通过 | 冻结计划在回调前后身份不变；归档绑定该身份 | 可以声明"安装的就是被认证的冻结计划" |
| `INSTALL_ROLLED_BACK` | 回调已执行、后置核对失败、**且**回滚回调已执行**并复核** | 回滚函数被调用；回滚后状态经复核 | 可以声明"已回滚"（须附复核证据） |
| `INSTALL_OUTCOME_UNVERIFIED` | 回调已执行（正常返回或抛异常）、后置核对失败/无法完成、**且无已复核的回滚** | 只能证明"回调曾被调用" | **不得**声明"没有安装"，也不得声明"已回滚" |

**明确禁止**：用"事后多算一个哈希"来充当安装原子性。哈希只能证明**冻结计划对象**未被改动，
**不能**证明外部副作用未发生。

### 2.1 回调抛异常时的处置

- 抛异常本身**不**等于"没有安装"：回调可能在抛异常前已产生副作用；
- 若提供了回滚回调且其执行被复核 ⇒ `INSTALL_ROLLED_BACK`；
- 否则 ⇒ `INSTALL_OUTCOME_UNVERIFIED`，并在收据里记录
  `side_effects_possible: true` 与 `rollback_verified: false`。

## 4. 适用域限制（必须随候选一起登记）

Python 进程内的只读包装**不是**安全沙箱。以下若**未被证明覆盖**，必须写成适用域限制：

| 限制 | 状态 |
|---|---|
| 恶意 Python 代码可通过反射/`ctypes`/`gc` 绕过冻结 | **未覆盖**（不在本候选承诺内） |
| 多线程/并发修改 | **未覆盖** |
| 跨进程 / 外部进程修改 | **未覆盖** |
| 回调通过**逃逸引用**（安装前保存的对象引用）在别处修改 | 部分覆盖：冻结是深拷贝，逃逸引用指向原对象而非冻结体；但**不**证明原对象被修改无害 |
| 真实执行器的外部副作用（写盘、下单、状态机推进） | **未覆盖**；只能由回滚回调 + 复核来部分弥补 |

**这些限制必须出现在候选的最终报告里，不得只写在代码注释里。**

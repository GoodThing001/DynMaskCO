## 1. 上一轮的一处自查错误（先登记，再修正）

勘误 01 §8.2 声称"授权投影"可通过独立复核，探针 Q1-N2 的检查是：

```python
projection = {'derived_from': I0, 'orders': [3, 5]}
check: proj['derived_from'] == identity(frozen)      # 只比较来源标识
```

**该检查不足**：只要保留正确的 `derived_from`，同时任意修改 `orders`，检查**依然通过**。
⇒ "投影声称来自哪个冻结状态" 与 "投影内容是否确实由该冻结状态生成" 是**两件事**，
Q1-N2 只证明了前者。

**处置**：本勘误**保留** Q1-N2 的原记录（不改写），并把它**降级**为
"来源标识一致性检查"；真正的投影真实性检查见 §3（内容必须**重算比对**）。

## 2. 唯一核心假设（可证伪）

```
H_C2:   ConsumedData = VerifiedProjection(S_frozen)
```

其中 `VerifiedProjection` 必须同时满足：

| # | 条件 | 可证伪形式 |
|---|---|---|
| **P-a** | **来源绑定**：投影声明它由哪个冻结身份派生 | 声明与冻结体身份不一致 ⇒ 拒绝 |
| **P-b** | **内容自洽**：投影内容与其自身摘要一致 | 内容被改而摘要未改 ⇒ 拒绝 |
| **P-c** | **可重算**：独立方能从冻结体重算出**同一内容** | 重算结果 ≠ 声明内容 ⇒ 拒绝 |
| **P-d** | **可见性**：投影只含 `reveal_time <= clock` 的订单 | 含未揭示订单 ⇒ `REFUSED: HIDDEN_FUTURE_FIELD_REQUIRED` |

**P-c 是核心**：没有 P-c，`derived_from` 只是一句自称。

**可证伪条件**：若能构造一个投影，满足 P-a、P-b 而**不**满足 P-c，且仍被接受 ⇒ H_C2 被推翻。

## 3. 唯一主对照（不变）

> **主对照 = 现有"四方摘要相同"判据（C1）。**
> 本轮**不引入第二个主对照**。新增的绑定判据（§2 的 P-a…P-d）是**被检验对象**，
> 不是对照：判据必须能在**同一个反例**上给出与 C1 **不同**的结论。

**可证伪形式**：对同一个"报告摘要相同但消费状态不同"的反例，
C1 必须给出 `PASS`，绑定判据必须给出 `REJECT`。若两者给出相同结论 ⇒ 新增判据无信息量，判 FAIL。

## 4. 主判据与失败条件

| 编号 | 判据 | 通过条件 |
|---|---|---|
| **G1** | 差异结论 | 同一反例上 C1=`PASS` 且绑定判据=`REJECT` |
| **G2** | 投影真实性 | `derived_from` 正确但内容被改 ⇒ 绑定判据 `REJECT`（P-c 生效） |
| **G3** | 真实投影被接受 | 由冻结体重算得到的投影 ⇒ `ACCEPT`；**但不得**因此授予生产物理资格 |
| **G4** | 认证后改动 | 冻结体在认证后被改 ⇒ 复算发现并 `REJECT` |
| **G5** | 隐藏未来 | 计划含未揭示订单，或所需字段只能来自未来 ⇒ `REFUSED: HIDDEN_FUTURE_FIELD_REQUIRED` |
| **G6** | 未声明依赖 | 经 helper/回调读到未声明字段 ⇒ 必须报告 `UNDECLARED_DEPENDENCY`，**不得**以直接字段列表替代完整证明 |

**失败条件**：G1…G7 任一不成立 ⇒ 本轮 FAIL，且按 §7 触发 No-Go 评估。

| 项 | 上限 |

4. 资源上限被突破。

## 8. Go / No-Go 定义（本轮唯一裁决口径）

| 结论 | 条件 |
|---|---|
| **Go** | 可信冻结状态、授权投影的**生成与核验**（P-a…P-d）、以及实际消费对象追踪，三者都存在**清晰可实现的最小方案**，且**不需要访问隐藏未来** |
| **No-Go** | 真实消费来源无法复核，**或**必要字段只能来自未来订单，**或**必须改写冻结历史对象才能完成绑定 |

**No-Go 触发时**：停止 C2 扩展，记录科学资格缺口；**不得**用新哈希、新收据或新包装层掩盖。

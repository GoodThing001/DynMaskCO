## 任务与目标

静态、单仓、多车、必须完成全部订单的冷链配送。所有车辆合计净效益为唯一业务目标：

`最大化 Π = Σ(P × 需求质量 × 交付品质保持率) − 总距离费用 − 总制冷费用`。

单位为分钟、kg、km和虚拟货币U。主条件P＝5/3 U/kg、距离费用1 U/km、制冷费用0.0972 U/车·min、275 K、品质阈值0.8；容量20吨，原实例100客户，K≤100。覆盖、容量、服务开始时间窗、交付完成时品质、回仓及闭合路线均为硬约束。具体来源和适用边界以冻结配置为准。

## 当前训练方式

使用真实只读MASKCO骨干，从头初始化，做**教师路线监督的掩码去噪学习**。dev04教师路线由同目标VNS从共同在线近邻初解构造；新增改进教师从这些路线继续ALNS并保留最好可行解。二者都必须满足全部硬约束。当前不是直接以利润梯度训练的强化学习：神经训练损失为交叉熵；教师构造、路线重建与最终比较使用上述净效益。

每个训练样本保留全部原100客户和仓库，随机遮蔽20个客户相关边；模型预测邻接/后继关系。已保留边以及可见部分路线用于输入，隐藏教师的完整时刻不作为特征。客户行参与损失，仓库行权重为0；基础版使用无向邻接分布，方向版使用有向后继分布，原始交叉熵不能跨这两种标签直接排名。

## 当前推理与验证方式

新增开发选项为`--predictor compiled --matmul-precision highest --repair-implementation vectorized`。同精度固定工作量中，合计阶段均值633.05→65.69ms，60份批量修复路线与原修复完全一致，180份路线独立复算通过；不宣称跨平台普遍加速或净效益已经提高。默认精度编译曾失败，不能直接省略`highest`。

共同可行初解→随机移除10个客户→神经热图筛选插入位置（top-k＝8）→按真实净效益增量做遗憾修复→严格完整评分。只用更好的完整可行解替换最优解；各方法使用独立评价缓存。

dev04只验证主品质条件和名义P，在c205—c208上比较四种神经变体及ALNS/VNS。目标每方法10s，迭代上限100000；包含收尾审计的实测略超10s，不称为严格截止实验。正式60s、1/10/60s结果记录、单CPU对照及完整计算核算仍需落实。

四模型均完成240步，重载预测与优化器恢复一致；63份报告SHA及24份验证路线本地独立复算通过。D比基础版平均高2798.17 U，但仍低于ALNS1332.76 U；F＋D比基础版低546.71 U。仅一个开发种子、一个验证几何，不能宣称正式优胜或泛化。见[完整结果](../../docs/static_delivery_research_20261021/5090首轮算法结果.md)。

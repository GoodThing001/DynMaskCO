fix(m1b-q2): close the certification trust boundaries (F-T1..F-T4)

M1-b/Q2-TrustFix. Implements the frozen spec against the 17 negative controls recorded by
M1-b/Q2-Fix-T. Adds one new module and one new spec/report pair; modifies three m1b modules.
Historical reports, results, frozen trees, M1-a and the L1 adjudications are byte-unchanged.

  FLEET_FALSE_REJECT_RESOLVED        holds

F-T1 the continuous-proof hook is fail-closed
  The production certifier REMEMBERS a supplied continuous_extremum_proof and REFUSES the
  certification outright (PRODUCTION_CERTIFIER_REFUSES_PROOF_HOOK); it never emits a
  certificate. The low-level gate additionally requires an explicit allow_test_only_proof
  opt-in, so even reaching that entry point cannot produce THERMAL_CONTINUOUS_OK. A separate
  M1bQ2TrustFixTestOnlyCertifier exists purely for wiring tests: its receipts carry
  test_only, TEST_ONLY_LABEL and not_consumable_as_production_certificate, and its
  composite_pass is always False. Nothing is trusted on the strength of a SHA256, a string
  registration, a self-reported source or a registry hit, because no registration surface
  exists at all. THERMAL_SAMPLED_OK stays independent and still short-circuits to VIOLATED.
  Q2-Fix-T T1-1 flips: an injected (True,{}) can no longer yield CONTINUOUS_OK.

F-T2 the Omega11 direct-call bypass is closed
  certify_return_feasibility now REFUSES when per-instance time inputs are absent
  (OMEGA11_TIME_INPUT_UNAVAILABLE); the silent shim fallback that forced tw_start = 0.0 is
  removed, so a caller bypassing the orchestrator cannot recover the optimistic estimate.
  register_service_times survives ONLY as an import-compatibility symbol and its table is
  read by no verdict (source-level assertion). A legitimate zero service time is still
  accepted. The thermal gate's equivalent bare-callable fallback was isolated the same way,
  so it can no longer auto-build tw_start = 0. Q2-Fix-T T2-1 flips from FALSE_PASS to refusal.

F-T3 a trusted strict-online data projection (new module m1b_public_projection.py)
  build_projection_from_env is the ONE construction boundary allowed to read the environment's
  reveal state: it derives the visible set from env.reveal_time and the current clock, copies
  only a whitelist of fields and only for revealed nodes, retains NO whole-node table, freezes
  its mappings with MappingProxyType, and COMPUTES source_identity from (instance, event,
  clock, visible set, contract hash, snapshot identity) instead of accepting free text. The
  certifier refuses any input that is not a TrustedPublicProjection, checks that declarations
  do not exceed what the projection revealed, binds the projection to the certified snapshot
  and asserts identity stability before and after. T3-6, T3-7, T3-8 and T3-9 all flip. The
  legacy self-asserting PublicOrderAttributes type still EXISTS and is still weak; it is
  labelled NOT_ESTABLISHED_FOR_THE_LEGACY_TYPE_ONLY and cannot reach certification.

F-T4 fleet completeness and THERMAL_NOT_APPLICABLE
  classify_thermal_applicability decides per vehicle. A vehicle that was never dispatched, is
  idle at the depot, has no cargo, no commitment and no candidate work is
  THERMAL_NOT_APPLICABLE: it neither proves nor sinks the fleet. A vehicle holding cargo, a
  commitment or planned work WITHOUT a cold-chain state still refuses, and the original
  cargo-without-state negative control is preserved as T4-4. The composite requires only the
  APPLICABLE vehicles to pass. T4-2 and T4-3 flip: one never-dispatched idle vehicle no longer
  sinks the sampled verdict, and the only remaining reason composite_pass is False is the
  continuous level being fail-closed by design.

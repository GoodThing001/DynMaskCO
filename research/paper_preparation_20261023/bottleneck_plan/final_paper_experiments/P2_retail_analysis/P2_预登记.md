# P2 预登记：RWVRP 八城十种子深入分析

> 本文档在**读取任何新增 P2 端点之前**固定（2026-11-26）。所有特征定义、分组阈值与统计方法均先于结果登记；不因结果方向事后修改。

## 1. 数据名称与身份

- 名称：**RWVRP八城零售门店冷链投影数据集**。
- 身份：八个城市共 8 个百客案例（rw_zg170/br100/cp150/ru120/sg200/me340/ca240/sf300_p100），
  门店位置来自 RWVRP_benchmark（source_commit 2c3a976f2212923db31ac86aea11483930c64b14），
  货量与收货时窗按作者建模投影到统一冷链参数；**不称为完整真实冷链订单数据，不声称复现原作者道路网络实验**。

## 2. 种子与方法（预登记）

- 种子：65001、65002、65003（与零售三批前瞻种子登记一致）+ 新增 **65004–65010**（连续无重复）。
- 方法：ORDER_SPLIT、ORDER_SPLIT_D、ALNS。
- 原三种子的零售端点未记录 5/15/30/60 秒轨迹，不能严格复用 → **十种子全部本批重跑，共 240 终点**；
  每个终点在同一连续搜索内记录初始解及 5/15/30/60 秒历史最好车队，各时点车队事后独立复算。
- 原零售三批 384 个端点保持冻结，不被覆盖；P2 分析使用本批 240 个带轨迹端点。

## 3. 城市结构特征定义（预登记）

全部从案例输入（nodes：0 为仓库，1–100 为客户）与解路线复算得到；坐标以输入单位计。

### 3.1 空间结构
| 特征 | 定义 |
|---|---|
| 客户平均距离 | 100 个客户两两欧氏距离的均值 |
| 客户最近邻距离 | 每个客户到其余 99 个客户最近距离的均值 |
| 客户空间分布范围 | 客户坐标包围盒对角线长度；另报包围盒面积 |
| 客户至仓库平均距离 | 各客户到节点 0 的欧氏距离均值 |
| 客户空间聚类程度 | Clark–Evans R = 平均最近邻距离 / (0.5·√(A/n))，A=客户包围盒面积，n=100；R<1 聚集、R≈1 随机、R>1 均匀；另报到仓库距离的变异系数 |

### 3.2 订单及约束结构
| 特征 | 定义 |
|---|---|
| 客户需求均值/标准差/变异系数 | 100 个客户需求的一阶矩（输入单位 t） |
| 时间窗平均宽度 | 各客户 (右窗−左窗) 的均值（输入时间单位） |
| 平均服务时长 | 各客户服务时长的均值 |
| 最低品质约束紧张程度 | 全局阈值 0.8 为常数；以共同初解复算的最低交付品质 − 0.8 作为初解边际紧张度代理 |

### 3.3 车队结构（从本批端点复算）
初始/最终使用车辆数；平均车辆装载率=总需求/(车辆数×20 t)；每车平均服务客户数=100/车辆数；
总配送距离（含回仓）；总车辆运行时间（出发至回仓）；总等待时间。

### 3.4 门店类型与分组阈值（预登记）
超市占比 = 超市数/(超市数+便利店数)，来自 retail_source/selection.json：
| 城市 | 超市占比 | 分组 |
|---|---|---|
| Brasilia / Cairo / Copenhagen / Melbourne / Singapore | 100% | 高（≥2/3） |
| Ruhr | 40% | 中（1/3–2/3） |
| SF Bay Area / Zagreb | 0% | 低（<1/3） |

阈值固定为 [0, 1/3)、[1/3, 2/3]、[2/3, 1]，不按结果调整。

## 4. 经济收益分解（预登记）

ΔU = 品质价值改善 + 里程费用节省 + 制冷费用节省；三者均为“对照成本 − 本方法成本”，正值对本方法有利。
逐城市逐种子输出三部分与总和；城市均值为三种子平均。留一城市敏感性分析：每次剔除一座城市，
其余七城按城市等权重算完整方法对 ALNS、对 ORDER_SPLIT_D 的配对差，共 8 组，作为敏感性描述，不删除任何主实验城市。

## 5. 统计口径（预登记）

- 配对差按同一 (case, seed) 相减后，城市内先均种子；
- 八城总体 = 城市等权均值；95% 描述区间 = 城市整簇有放回重采样 20,000 次（种子 20261126）的 2.5/97.5 分位数；
- 逐种子胜出次数 = 10 个种子内配对差 >1×10⁻⁶ U 的种子数；
- 特征相关性仅作探索性描述（n=8 城），报告 Spearman 秩相关与对应 p 值但不表述为因果关系。

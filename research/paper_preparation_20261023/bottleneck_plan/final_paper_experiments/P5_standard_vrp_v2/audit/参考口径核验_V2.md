# 参考口径核验（V2 独立复算）

> 本文件为 P5-V2 审计产物，只读复算官方参考数据，**不修改** P5-V1 冻结文档、源与结果。
> 复算脚本：`scripts/p5v2_bks_derive2.py`、`scripts/p5v2_solomon_derive.py`、
> `scripts/p5v2_envparity_probe.py`；原始数据 `data/cvrplib/{instances,bks}`、
> `data/solomon/{instances,bks}`（2026-11-26 自远端 `_maskco_final_paper_p5` 下载，
> 与 P5-V1 同源）。数值落盘：`data/bks_derived.json`、`data/solomon_bks_derived.json`。

## 1. CVRP（Uchoa X 集，100 例）

- **距离口径**：官方 Cost 与"逐边半整数舍入"（`int(hypot(dx,dy)+0.5)` 求和）**100/100 完全一致**，
  0 失配、0 容量违约。因此 CVRP 的 Gap 计算两侧都用逐边舍入口径。
- **索引口径**：实例文件节点 1 = 仓库、2..n+1 = 客户；官方 `.sol` 路线 id 1..n 对应内部客户
  1..n（即 `.sol` id = 文件节点 id − 1）。100 例逐例核对：客户集合恰好 = {1..n}。
- **车队口径（新发现，需登记）**：官方 BKS 解中 **21/100 例使用车辆数 k_sol > 实例名中的 k**
  （例：X-n101-k25 → k_sol=26；X-n148-k46 → 47；X-n172-k51 → 53；X-n195-k51 → 53；
  X-n233-k16 → 17）。即实例名中的 k 是**装箱下界**，不是 BKS 车队数。
  因此：
  1. 不得用"K 超过实例名 k"判定为车队违约；
  2. 表内同时报告本方法 K 与 BKS 路线 K（`k_bks`），K 差异只作描述，不作排名依据；
  3. 距离 Gap 以 BKS 复算值（= 官方 Cost）为分母。
- 浮点距离与舍入距离的差：逐例 <0.02%，仅影响小数位，不影响 Gap 口径结论。

## 2. VRPTW（Solomon 56 例）

- **双精度可行**：48/56 例可行；8 例不可行，最大边界超窗如下（与 P5-V1 登记的 8 例**集合完全一致**）：

  | 实例 | 最大超窗（双精度，分钟） |
  |---|---|
  | R102 | 0.0707 |
  | R105 | 0.1039 |
  | R107 | 0.1368 |
  | R108 | 0.3717 |
  | R112 | 0.4002 |
  | R211 | 0.3412 |
  | RC101 | 0.0703 |
  | RC105 | 0.0972 |

- **官方口径 = 逐边 1 位截断**：把行驶时间按 `floor(d*10)/10` 截断后，**56/56 全部可行**
  （`round(d,1)` 仍余 7 例不可行，证明是截断而非四舍五入）。
  `.sol` 自带的 `Cost` 行也正好等于截断口径求和（C101 827.3、R101 1637.7、RC101 1619.8），
  与双精度求和（828.9369 / 1642.8769 / 1623.5571）不同。
  → 结论：**`Cost` 行不得作为字典序目标值**；V2 以双精度复算值作为参考距离，
  截断口径仅用于解释 8 例参考解的可行性来源。
- **C 系列与经典最优一致**：C101 双精度 828.9369（≈828.94）、C201 591.5566（≈591.56）。
- **R/RC 系列为距离优先解**：CVRPLIB BKS 路线车辆数普遍高于 SINTEF 经典字典序最优
  （R101: BKS K=20 D=1642.88 vs 经典 K=19 D=1650.8；R201: BKS K=8 D=1147.82 vs 经典 K=4 D=1252.37；
  RC101: BKS K=15 D=1623.56 vs 经典 K=14 D=1696.95）。
  → **不得跨口径混合排名**：本方法 K 与 BKS 路线 K 并列报告；字典序胜负数按 (K,D) 逐例给出，
  并同时给出"仅 K 相同子集"的距离对比。
- **对 P5-V1 文本的更正（仅文档，不改 V1 源与结果）**：`P5_预登记.md` 第 71 行称 8 例
  "双精度下边界超窗 ≤0.1"，实测最大 0.4002（R112），其余 7 例在 0.070–0.372 之间。
  V1 的端点与统计不受影响（V1 用双精度评价自身解，此数字只描述参考解可行性），
  V2 报告与图中统一使用本表实测值。

## 3. 对 V2 正式面板的影响

1. CVRP 1800 端点的 Gap 分母 = 官方 Cost（逐边舍入），逐例 K 与 `k_bks` 并列；
2. VRPTW 1008 端点的参考 = CVRPLIB BKS 双精度复算（`data/solomon_bks_derived.json`），
   8 例参考解按"截断口径可行"标注，不作为严格不可行证据；
3. STD_NORM 468 端点沿用同一口径；
4. 外部基线（PyVRP / NDS）只在目标口径可证明一致时并入主表，否则单独报告原生目标
   （见 `audit/EXTERNAL_BASELINE_MATRIX.md`）。

# P3 双因素消融实验配置

## 1. 设计矩阵

| 方法 | 神经引导 | 跨车经济分车 |
|---|---|---|
| HYBRID_D | 无（距离排序） | 无 |
| HYBRID | 有（MASKCO 热图） | 无 |
| ORDER_SPLIT_D | 无（距离排序） | 有 |
| ORDER_SPLIT | 有（MASKCO 热图） | 有 |

- 范围：26 个已锁定前瞻实例（VRPPDL 荷比配送日 10、新 XTW 8、RWVRP 八城 8）× 3 个配对种子 65001–65003；
- 新增 HYBRID / HYBRID_D 共 26×3×2 = **156 个端点**；ORDER_SPLIT / ORDER_SPLIT_D 复用统一16法已审计端点（同一案例、种子、硬件、初解与 60 秒预算）。

## 2. 受控消融入口与差异清单

当前锁版实现为冻结 `carryprobe01/pool_search.py`。其 `solve()` 中：

```python
split_enabled = base == "ORDER_SPLIT"
```

是**唯一**区分 HYBRID 与 ORDER_SPLIT 的开关。逐行比对后确认两臂共享：

1. 每 4 轮 `state = best`（从历史最好解继续）；
2. 40 客户随机掩码（`mask_rng.choice(1..100, 40)`，同种子）；
3. 神经前向复用：每轮一次热图预测（`provider.heatmap`），时段内多次重构复用同一热图；
4. 经济试选：负距离、原热图、校准热图（alpha 同 frozen `calibrated.json`）三种候选排序 × 贪心 / regret-2 两种重插算子 = 六组合，各试 0.04 秒，按真实冷链净效益选优；
5. `conflict_pool` 聚焦子集规则一致；
6. 原生 `repair_batch` 参数一致（allowance≤0.10 秒、temperature=2.5·max(0.1, 1−t/60)、mode 探索-利用选择与 rewards 指数更新一致）；
7. 接受规则一致（`clock.offer` 严格改善，独立复算后入账）；
8. 60 秒单物理核在线预算一致；`epochs%4==0`、`epochs%3==0` 的轮次节奏一致。

**唯一差异**：ORDER_SPLIT 在每 3 轮（`epochs%3==0`）进入跨车分车分支：
- `bundle` 选 2–4 条相近完整路线（总客户 ≤24）；
- 热图提出访问顺序（`order_proposals`）；
- `split` 动态规划按真实路线净效益选择分车点，单组预算 ≤0.30 秒（`stop=min(deadline−0.003, epoch_start+1.6, now+0.30)`）；
- 分车结果严格复算并优于当前解才接受。
HYBRID 从不进入该分支。`_D` 后缀仅把候选排序替换为负距离（`distance_only=True`），不影响分车开关。

**历史 HYBRID 与当前锁版**：reserve02 的 HYBRID/HYBRID_D（27 个既有案例、种子 33001–33003）由同一 pool_search 代码族产生（字段 epochs/ranking_counts/mask_mode_counts 一致）；其 `split_*` 字段记录为 null 属于早期批次模式差异，不影响机制。为满足“严格单因素”要求，P3 不从历史批次复用 HYBRID/HYBRID_D 端点（案例集与种子均与 P3 目标零重叠），全部从当前锁版受控开关新跑。

## 3. 四个配对收益（预登记）

对每个 (case, seed) 计算：

- A. `ΔU_learning_without_split = U(HYBRID) − U(HYBRID_D)`：普通经济重插中的学习引导增益；
- B. `ΔU_learning_with_split = U(ORDER_SPLIT) − U(ORDER_SPLIT_D)`：完整框架中的学习引导增益；
- C. `ΔU_split_with_learning = U(ORDER_SPLIT) − U(HYBRID)`：学习引导条件下的跨车分车增益；
- D. `ΔU_split_without_learning = U(ORDER_SPLIT_D) − U(HYBRID_D)`：纯距离条件下的跨车分车增益；
- 交互：`ΔU_interaction = B − A`（等价于 C − D）。

聚合：逐 (case, seed) 配对差 → 案例内均种子 → 来源内（配送日/新XTW/八城）几何等权 → 三来源等权；
另报改善单位比例（配对差 >1e-6 U 的单位占比）、逐种子结果、几何整簇 95% 描述区间（重采样 20,000 次，种子 20261127）。
所有统计从原始未舍入端点计算；不把正均值表述为统计显著，逐条标注区间是否跨零与来源间差异。

## 4. 解释边界（预登记）

该实验衡量固定 60 秒预算下各机制的**净贡献**（含计算机会成本），不是固定候选数量下的纯信息贡献。
跨车分车每 3 轮占用 ≤0.30 秒，同时改变后续热图与试选轨迹；A 与 B 之差反映分车是否扩大热图净贡献（交互），
C 与 D 反映分车机制本身是否独立于打分来源产生收益。

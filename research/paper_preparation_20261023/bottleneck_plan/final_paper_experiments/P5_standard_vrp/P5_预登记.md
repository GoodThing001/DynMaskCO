# P5 预登记：标准 CVRP / VRPTW 任务适配协议

> 本协议在首次正式运行前登记（2026-11-26）。所有编码、掩码、窗口、目标与种子选择先于任何正式结果固定。

## 1. 任务与目标

- P5-A 标准 CVRP：最小化总行驶距离 D；容量 Q、无时间窗、单仓、不允许分割配送；
  车辆数限制按官方基准定义核查（Uchoa X 的 k 字段与官方口径一致时才作为硬约束）。
- P5-B 标准 VRPTW：SINTEF 字典序目标——第一最小化车辆数 K，第二在 K 相同下最小化 D；
  时间窗、服务时长、等待允许；仓库窗口按原始实例。
- 与冷链任务完全隔离：不设置品质阈值、温度衰减与制冷费用；候选收益、接受条件与分车目标
  全部使用标准任务目标，禁止仅在后处理时替换目标。

## 2. 数据登记（先行于结果）

- P5-A：CVRPLIB Uchoa X 100 例（X-n101-k25 … X-n1001-k43，100–1000 客户），
  逐例下载（实例 id 158–257）并保存原始字节、SHA256、来源 URL 与论文身份
  （Uchoa et al., EJOR 2017, DOI 10.1016/j.ejor.2016.08.012）；BKS 同源下载，仅用于评价器校验与 Gap 计算。
- P5-B：本地 `data/classic_static_sources_20261020/solomon_100/instances/In/` 的 56 个原始 Solomon 实例
  （FILES_SHA256.json 清单锁定），使用原始容量/坐标/时窗/服务时长，不用冷链 20 t 替换。
- 数据清单在查看任何正式结果前登记完毕；不按成绩挑选实例。

## 3. 种子与方法支持（预登记）

- P5-A 种子 **68001、68002、68003**；P5-B 种子 **69001、69002、69003**。
- 预定比较集合为统一 18 法；逐方法核实标准任务适用性：
  - 本文方法（ORDER_SPLIT/ORDER_SPLIT_D/MASK/SLOT/DIST/DIST_SLOT）：经 standard_vrp 适配实现；
  - 传统方法（ALNS、VNS、PyVRP）：原生支持 CVRP；VRPTW 支持按各实现核实；
  - NDS-Econ、CaR、DeepACO、POMO、AttentionModel、MVMoE、CaDA、RouteFinder、RRNCO：
    仅在有对应任务/规模的公开权重与推理实现时运行，否则登记 UNSUPPORTED 并说明原因，
    不得用错误任务权重冒充原版比较；
  - 构造式方法不接受共同初解；记录其原生构造可行率、回退比例与原生成绩。
- 方法名称反映实际适配身份（如“冷链权重迁移+标准目标适配”），不直接等同于作者原论文实现。

## 4. 冻结权重的标准任务适配（预登记输入编码）

- 主实验：冷链 f0_r0 冻结权重直接迁移，不重新训练，不改网络结构与参数。
- 16 通道特征沿用冻结 `partial_batch` 约定，中性编码登记如下（实现：standard_vrp/core/standard_features.py）：
  - 通道 0–1：坐标相对仓库、除以 1440（冻结归一化不变）；
  - 通道 2：需求/20000（冻结归一化不变，与标准容量无关）；
  - 通道 3–5：CVRP 无时间窗/服务 → l=0、r=1440、service=0（“无约束”中性值）；VRPTW 用原始分钟值/1440；
  - 通道 6–9：冻结冷链常数（所有冷链实例恒同）：rate×1440=**0.266112**、最低品质 **0.8**、
    log1p(price×20000/1440)=**3.1842077**、制冷系数 **0.0972**；
  - 通道 10：掩码可见标志（冻结语义不变）；
  - 通道 11–15：由标准任务路线调度计算——完成龄/1440、品质余量=**1.0**（无衰减品质恒为 1）、
    价值对数=**0.0**（rate=0）、松弛/1440、装载率=总需求/20000（冻结公式原样）。
- 掩码规模策略（预登记）：n≤100 时掩码 40 客（冻结原值）；n>100 时每轮掩码
  40 客且预测窗口=仓库+40 被遮客+60 个最近未遮客（≤101 节点），热图只取被遮客行，
  其余被遮客插位候选不足时用距离排序补齐。窗口规则不随结果调整。
- 若使用作者原始标准 CVRP/VRPTW MaskCO 权重，作独立补充对照、单独命名与报告，
  不与冷链权重主实验混排。

## 5. 规模支持（预登记）

- 首先在 100 客户标准实例验证与冷链同尺寸运行稳定，再逐级扩展 200/500/1000；
- C++ 内核、JAX 输入、Split 接口全部动态尺寸化，仅改规模必需部分，不改搜索策略；
- 无法支持的规模如实报告 UNSUPPORTED 与原因，不截断客户、不挑实例。

## 6. 评价规则（预登记）

- **CVRP 距离口径（已按 9.2 锁定，2026-11-26）**：CVRPLIB X 集官方距离为 EUC_2D **逐边整数舍入**
  （round(sqrt(dx²+dy²)) 取整后求和）。本地评价器对 100 份官方 BKS 路线复算：97/100 与官方 Cost
  完全一致（其余 3 例两种口径重合）、0 失配、100/100 可行。P5-A 全部评价采用逐边整数舍入；
  若负 Gap 出现，先查距离/索引/容量语义，确实改进 BKS 时保存完整路线，不得归零。
- CVRPLIB 索引语义：实例节点 1 = 仓库、客户 2..n；.sol 路线 id 1..100 对应内部客户 1..100
  （解析器已按此重映射并记录）。
- VRPTW 距离：双精度欧氏与行驶时间，仅展示时保留两位小数，路径评价不提前舍入；
  字典序比较 (K, D)；固定序列 Split 返回最小 K、再最小 D。
- **VRPTW BKS 参考（已登记，2026-11-26）**：参考解路线 = CVRPLIB 官方 Solomon 集 BKS
  （56 份 .sol，逐件 SHA 登记）。双精度评价下 48/56 例可行；8 例（R102、R105、R107、R108、
  R112、R211、RC101、RC105）在官方 1 位截断行驶时间口径下可行（双精度下边界超窗 ≤0.1，
  属经典基准的截断口径产物，逐例标注）。C 系列与 SINTEF 经典最优完全一致
  （C101→828.9369≈828.94、C201→591.5566≈591.56，双精度复算验证）；
  R1/RC1 系列的 CVRPLIB BKS 为距离优先解，可能与 SINTEF 车辆数优先最优不同——报告中如实标注
  CVRPLIB 身份，车辆数比较以本方法自身 K 与 BKS 路线 K 报告，不作跨口径混合排名。
- 终点状态：AUDITED / UNSUPPORTED / TIMEOUT / INFEASIBLE / FAILED / FALLBACK 逐格登记；
  排名按有效方法数，1/18 表述仅在 18 法全部有效时使用。

## 7. 正确性门槛（先行于正式实验）

1. 5–8 客户小实例：枚举全部排列与车辆划分，验证距离、容量、时间窗、服务/等待、
   回仓、K 目标、字典序与固定序列 Split 与枚举一致；
2. 官方 BKS 路线本地复算与官方值一致；
3. 冷链回归：锁版文件与权重哈希不变、既有固定路线经济评价不变、P0–P3 结果不被覆盖；
4. 每方法每问题类型每规模阶段先冒烟，冒烟与正式面板分离，正确性未过不启动正式批次。

## 8. 聚合与报告

- CVRP 按规模段（100–199 / 200–499 / 500–1000）分别汇总 Gap（逐例 Gap 后等权），
  总体 Gap 另报；同时报告全计划面板覆盖率；
- VRPTW 按 C1/C2/R1/R2/RC1/RC2 分类别报告平均车辆数与平均总距离、逐实例字典序胜负；
  车辆数不同的结果不进入统一距离排名；
- 数据泄漏审计：Solomon 56 例与冷链训练（R/RC 38）、验证（C2）、折外（C1）的空间几何
  重叠单独标注；完整 56 例用于经典基准，但不得全部称为独立未见数据。

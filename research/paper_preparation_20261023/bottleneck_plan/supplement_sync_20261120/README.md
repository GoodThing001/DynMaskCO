# 锁版方法同期复核

2026年11月20日完成 30 个已测案例、3 个种子、4 种方法的同期比较，共360个终点。全部7,951条路线通过独立复算。模型、案例、种子、严格目标和60秒在线预算保持固定，方法在同物理核的配对区组内轮换执行。

MASKCO在丹麦、XTW、GH及低重叠XTW的同期四法中均列第1。三个主来源等权，MASKCO相对同规则距离、ALNS和PyVRP分别高25.17、88.75和2,616.84 U。热图增量95%几何整簇描述区间为[5.19,49.00] U；单来源和低重叠结果见完整报告。

运行平台为5090研究服务器，使用24个独立物理核12—35并行，每个终点单核执行，GPU禁用。控制器于北京时间15:35:19启动，15:56:01完成，90/90区组，失败0。FLEET_PRICE既有计时作业在本轮启动前已结束，本轮避开其原用核0—11。未修改既有实验、权重或封存的32个新例。

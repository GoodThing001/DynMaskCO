## 主要实验

统一16法在62个百客案例上完成2,976个终点，独立复算81,251条路线。三来源前瞻主比较包含荷比10个新配送日、新XTW 8个低重叠几何和RWVRP 8个城市。

完整方法在三个前瞻来源均列外部13法第1，26个单位全部进入前三，其中19个第1。相对ALNS的三来源等权增量为75.37 U，95%描述区间为[43.76,109.44] U。同规则热图增量为12.11 U，描述区间为[−3.04,32.74] U；新XTW满足预设稳定门槛。

主结果来自[论文实验总览](../unified_external_20261120/论文实验总览.md)和[三来源前瞻结果](../unified_external_20261120/results/三来源前瞻结果.md)。原版四臂消融、十种子轨迹、固定车队价格敏感性、经济上界及编译缓存复用分别报告。历史分批实验与前瞻主比较保持各自证据身份。

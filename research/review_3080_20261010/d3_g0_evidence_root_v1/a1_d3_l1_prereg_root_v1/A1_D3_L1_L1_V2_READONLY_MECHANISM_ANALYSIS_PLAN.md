## 0. 为什么只读分析仍有价值

本轮已给出**存在性**答案：在 63 个可比较状态上，两评分器首步分歧 **48/63 = 76.2%**，
两步掩码后未认证最终计划不同 **57/63**，且**顺序混杂为 0**。尚未回答的是**结构**问题：

> 这 48 个分歧**长什么样**？它们是否集中在可被简单规则刻画的子空间里？
> 若是，则"MaskCO 掩码重构相对 `-Δd` 的差异"这一命题在**机制层**是可被廉价规则捕获的
> （与既往 headroom 结论同向）；若否，才值得考虑学习型方法。**这两个结论都不需要新的真实评分。**

## 2. 分析问题（事前固定，不事后追加）

### Q1 — 分歧是否被"确定性廉价规则"捕获（**核心**）

对 48 个 `DIVERGENT` 状态，检验 F 的首步动作能否由以下**不看 MaskCO 权重**的规则复现：

| 候选规则 | 定义 |
|---|---|
| R_geo | `argmax(-Δd)`（即 D-Geo 本身） |
| R_geo_first | legal 序首个 `-Δd` 最小值（既有 tie-break 语义） |
| R_earliest | 最早 `ready_time` / 最紧时间窗 |
| R_latest | 最晚 `ready_time` |
| R_nearest_depot | 最小 `anchor→customer` 距离 |
| R_max_capacity_fit | 最大剩余容量匹配 |
| R_lowest_id | 最小 customer id（ID 敏感基线） |
| R_rare_zone | 最稀缺温区优先 |

**判据**：报告每条规则在 48 个分歧状态上复现 F 首步的**命中率**，
以及**任一规则的命中率是否 ≥ 90%（事前设定的"可被廉价规则捕获"阈值）**。

- 若 **某规则 ≥ 90%** ⇒ 结论："本数据集上 F 的首步选择可被该廉价规则近似捕获"，
  与既往"规则可捕获"结论同向；**不得**升级为任何效用/质量主张。
- 若 **全部规则 < 90%** ⇒ 结论："F 的首步选择未被所测廉价规则捕获"，
  但仍**不得**据此主张学习必要性（L2/L3 才是效用层，且未授权）。

### Q2 — 分歧是否集中在特定结构位置

在 48 个分歧状态上分层统计（每层给出 n 与分歧率，**不做显著性检验**）：

- 按 `n_legal` 分箱（6–10 / 11–15 / 16–20 / 21–27）；
- 按 mask 池大小 `n_mask`；
- 按 `timestep`（`retained_edge_ratio`）分箱；
- 按所在 `day_id`（0–15）——**仅作描述**，不得解释为时间趋势；
- 按首步动作的 `slot_kind`（anchored / new_route）与是否 `vehicle_id` 相同。

**判据**：报告"分歧率随 X 单调/非单调"的**描述性**结论，且必须同时给出每层样本量。
**禁止**：把描述性分层读作因果或效应量。

### Q3 — 分歧的"后果"分布（未认证）

对 57 个最终计划不同的状态，只读统计：

- 两臂最终计划的**结构差异**：受影响车辆数、移动的客户数、`plan_distance` 差（`-Δd` 可算，仅描述）；
- 有多少状态的两臂差异**仅体现在一个客户/一条路线上**（最小差异）；
- 6 个最终计划相同的状态中，有多少是"首步不同但收敛"（分歧被后续掩码步抵消）。

**措辞硬约束**：一律称 **"未认证计划差异"**；**不得**出现"更优/更差/增益/损失"。

### Q4 — 与被排除状态的关系（**边界自查**）

把状态 (0,3) 的 `M = 27` 放回 Q2 的 `n_legal` 分箱语境中，回答：
**它是否位于分歧率最高或最低的分箱**？若位于极端分箱，需在结论中明确
"该状态未被回答，且它落在 X 分箱，故该分箱的推断边界更宽"。
**禁止**用任何插补、邻值或重跑填补它。

### Q5 — 顺序混杂的**残余**检查（只读）

本轮 `ORDER_ATTRIBUTABLE = 0` 且超时 0，故无混杂。仍需记录一项**边界**：
第二臂（D-Geo）的**剩余额度**可从相位日志与 `per_arm_budget.wall_seconds` 反推
（`10.0 − 第一臂墙钟`），据此报告：

- 第二臂在本轮的最小剩余额度是多少；
- 若第一臂成本为观测最大值的 k 倍，第二臂将在何处越限（**纯算术外推，标注为外推**）。

**说明**：这是**风险评估**，不是新的测量；**不得**据此声称"若有更多时间结论会不同"。

## 3. 明确的分析边界（"不可以形成"）

1. **不**形成任何**可认证可执行计划**结论（V3 = `NOT_RUN`，无认证器，未安装）；
2. **不**形成任何**决策质量 / 在线效用 / 收益**结论（L2/L3 未授权）；
3. **不**形成任何**显著性**结论：63 个状态**曾用于开发**，非独立验证；本方案**不做检验**，
   只做描述与规则复现率；
4. **不**形成任何**学习增益 / MaskCO 优于基线**结论；
5. **不**追溯授予 **A1/A2/A3** 任何正式证据门；
6. **不**把 `stable_online_gain` 或任何既有负结果改写；
7. **不**把 Q1 的"规则可捕获"读作"MaskCO 无用"，也不把"规则不可捕获"读作"MaskCO 有用"。

## 6. 与既有结论的关系（预期，事前声明）

既往 D1–D7 headroom 诊断的结论是：终局 headroom **约 100% 为未来信息**，
且每个被测冷库决策要么是未来信息、要么**可被规则捕获**。
本方案 Q1 **直接检验同一命题在 L1 机制层的对应物**：

- 若 Q1 显示"F 首步可被廉价规则 ≥90% 复现"，则与既往结论**同向**，
  机制层再次出现"规则可捕获"；
- 若 Q1 显示相反，则记录**不一致**，并明确这**不**推翻既往结论
  （不同层：既往是终局效用层，本轮是首步机制层），**也不**构成效用层证据。

**任一结果都不改变当前收束状态**，也不自动开启任何后续正式批次。
